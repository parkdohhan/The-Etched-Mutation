## 3. 위상과 거리 — 설명한 것

### 3.1 옵시디언 지도의 원리
- **자료는 위상적**: 점 = 문서, 선 = 언급. 좌표·거리 숫자는 저장되어 있지 않다.
- **그림은 물리 흉내**: ① 모든 점이 서로 밀어냄 ② 선으로 이어진 점끼리 용수철처럼 당김 ③ 가운데로 살짝 모음. 서로 밀고 당기다 멈춘 자리.
- **거리는 정의되어 있지 않다.** 다시 열면 자리가 달라지고, 조절 막대를 움직이면 모양이 바뀐다.
- **안 변하는 것 넷**: 누가 누구와 이어졌나 / 선을 몇 번 건너야 닿나 / 서로 안 닿는 덩어리 수 / 점의 크기(선이 많이 꽂힐수록 큼).
- 세 힘의 정확한 계산식은 공개되어 있지 않음. 조절 막대(가운데 힘·밀어내는 힘·당기는 힘·선 길이)로 보아 "힘 기반 배치" 계열.

### 3.2 진짜 위상의 토러스와 3D 그림
- 토러스의 정의에는 거리도 3D도 도넛 모양도 없다. 있는 것 = **점들(셀 수 없이 많고 빈틈없음) + 이웃 정보(곁이냐 아니냐, 숫자 없음)**. 점만 있으면 구슬 자루.
- 가장 쉬운 정의: **팩맨 화면**(오른쪽 끝 = 왼쪽 끝, 위 = 아래). 도넛을 안 그려도 정의는 끝.
- 3D 그림은 **자리 배정표**를 하나 골라서 띄운 것. 각도 둘(θ, φ)을 받아 자리를 내주는 식: 가로 = (R + r·cosφ)·cosθ, 세로 = (R + r·cosφ)·sinθ, 높이 = r·sinφ. R·r은 아무 값이나 — 이 "아무 값이나"가 곧 거리에 뜻이 없다는 말.
- 컴퓨터는 각도를 촘촘히 나눠(예: 100×100 = 점 1만 개) 자리를 계산하고 세모로 이어 붙인다. **화면 속 도넛은 "점을 촘촘히 잡은 것"이 맞지만**, 그것은 진짜 토러스를 유한한 점으로 흉내 낸 것.
- 그림의 거리는 3D 공간의 자를 빌린 것 = 배정표의 것. 증거: 뚱뚱한 도넛·가는 도넛·컵 모양이 다 같은 토러스이고, 도넛의 바깥 둘레가 안쪽보다 길지만 팩맨 화면에서는 같았다.
- **우리 쪽이 더 쉬운 점**: 씬과 실은 유한하므로 화면의 점과 선이 정의 그 자체다(흉내가 아님).

| | 정의에 있는 것 | 그림에서 빌려 온 것 |
|---|---|---|
| 토러스 | 점 + 이웃 정보 | 도넛 식이 준 자리와 거리 |
| 옵시디언 지도 | 문서 + 연결 | 힘이 정한 자리와 거리 |
| 우리 위상 3D | 씬 + 실 | 힘이 정한 자리와 거리 |

### 3.3 회피 인정 — 사용자 지적 "정의하자고 하면 피하는 느낌"
기록상 이 주제에서 작업자(Claude) 쪽 추천은 매번 같았다: THEORY "거리 = 정의에 없음, 무대가 고름" / 정의 v1 D6 "정의에는 안 넣음(무대 값)" / 오늘 답 "배치의 부산물".
"위상에는 거리가 없다"는 맞지만, 그것을 **"그러니 그림의 거리는 안 정해도 된다"**로 써 온 것이 회피였다. 정의 규율 10번(정의·측정·연출을 따로 적는다)은 연출 쪽을 안 적어도 된다는 뜻이 아니다. 토러스도 도넛으로 그리려면 배정 식이 있어야 하는데, 조각에는 그 식이 없고 "힘에 맡김"만 있었다.

### 3.4 "거리" 아래 다른 물건 둘

| | 위상 조각 (작가용, 전체가 보임) | 무대 (관객용, 방과 통로, 1인칭) |
|---|---|---|
| 필요한 것 | 모든 씬을 한 공간에 동시에 앉히는 규칙 | 지금 방에서 다음 방까지 통로 하나의 길이 |
| 상태 | 정한 적 없음 → 오늘 뜻만 확정 | 11-07 결정: 통로 길이 = 개연성 P(i,k)의 무대 표현 |
| 이름 | **조각 거리** | **통로 길이** |

둘을 한 규칙으로 묶을 수 없는 이유: 개연성은 "씬 1→7"과 "7→1"이 다를 수 있다. 통로는 한 방향으로 걷는 것이라 괜찮지만, 조각에서는 두 점 사이 거리가 하나여야 점을 앉힐 수 있다.

### 3.5 "정의 안 됨"의 정확한 말 (같음 먼저)
- **두 배치가 같다** = 한쪽을 돌리거나 옮기거나 거울에 비추면 다른 쪽과 겹친다.
- **배치 규칙이 정의되어 있다** = 같은 그물을 넣으면 언제나 같은 배치가 나온다.
- 현행 힘 배치는 "다시 흔들기"마다 다른 모양 → 이 기준으로 **정의가 아님.**

### 3.6 조각 거리의 후보 셋 (임현 정의 발견 전에 제시한 것)
- **가. 이어짐에서만 (저항 거리)**: 두 씬 사이에 실이 굵고 여러 갈래일수록 가깝다. 물탱크와 관 비유. 그물만으로 계산, 감정 숫자 불필요, 문턱·상수 없음, 실이 더해지면 그 자리가 당겨짐. D4 "나"가 전제.
- **나. 감정 장부에서 (감정 거리)**: 11-06 회전 실험에서 신호(+0.355). 단 15축을 3D로 누르면 찌그러지고, 축 불안정(절반 표본 54도), 위상이 아닌 측정값이라 조각이 "측정 결과 그림"이 됨.
- **다. 힘에 맡기고 "뜻 없음" 명시**: 현행. 정직하지만 미정의.

### 4.2 정리
- **무엇들 사이의 관계인가**: 이야기와 이야기 사이(주제·행동·사연·소재가 모두 "이야기" 하나).
- **가깝다** = 하나를 보여 주면 다른 하나가 저절로 떠오른다.
- **거리 0** = 둘이 하나의 이야기가 됨(해석 여지 소멸).
- **너무 멀다** = 잇는 길이 없어 따로 논다.
- **적당한 거리** = 직접 잇지 않고 다른 이야기 하나를 거쳐 닿음(징검다리).
- **누구 기준** = 독자. 읽기 전에 이미 아는 맥락.

### 4.3 우리 자료와의 대응 (작업자의 읽기)
- 관객이 씬 i 다음에 씬 k로 간 걸음 = "그 관객에게 i 다음에 k가 떠올랐다"의 기록. 37명의 걸음 179개가 떠올림을 센 것.
- 뜻 = 임현 / 재는 법(안) = 걸음 수와 갈래 수(저항 거리). 저항 거리는 임현의 세 상태를 순서대로 지킨다: 직접 이어짐 < 징검다리 경유 < 길 없음(무한대).

### 4.4 임현 말씀과 작업자 읽기가 다른 지점 (항상 병기할 것)
1. 임현의 거리는 **주제와 행동 사이**. 씬과 씬 사이로 옮긴 것은 읽기.
2. 임현의 떠올림은 **방향이 있음**(흉기→살인자). 저항 거리는 방향을 지움 → 방향은 자리가 아닌 화살표·색으로.
3. "갈래가 여럿이면 더 가깝다"는 임현이 아니라 수학의 덧붙임.
4. 임현의 떠올림은 **독자의 사전 지식**. 우리 걸음은 관객 선택 + **엔진이 연 씬 목록**.
5. (부록 4에서 추가) 문헌에서도 "읽기 전 관습의 가까움"(말뭉치로 잼)과 "읽은 뒤 기억 속 가까움"(반응 시간으로 잼)은 **따로 재는 서로 다른 양**. 우리 걸음은 "이 작품 안에서의 행동"이라 셋째 양일 수 있음.

## 5. 논문에 "이야기의 구조는 이렇게 생겼다"를 쓰려면

사용자 목표(원문): "전체 그림을 엄밀하게 시뮬레이션해서 논문에 이야기의 구조는 이렇게 생겼다고 쓰고 싶은데, 그게 안 되면 적어도 억지 부린 부분 없이 안 될 건 인정하고서라도 정확한 걸 만들고 싶어."

### 5.1 쓸 수 있는 것
- **구조 그 자체는 표다.** 씬 13, 실 54종, 고리 42, 등뼈, 씬 쌍마다의 조각 거리 숫자표. 그림을 어떻게 그리든 안 변함. 주장은 표에 싣는다.
- **그림은 "이 표를 가장 덜 틀어지게 3D에 앉힌 한 장"으로 쓴다.** 거리표에서 자리를 뽑는 계산은 힘 배치와 달리 흔들기가 없다(같은 그물 → 같은 그림, 돌리기·거울상 차이만).
- **틀어진 정도를 숫자로 붙인다.**
- **흔들림 범위를 붙인다.** 37명 중 일부를 빼거나 다시 뽑아(단위 = 관객 한 명의 실 통째) 다시 그려도 모양이 유지되는지.
- 그러면 문장은 **"관객 37명의 떠올림이 만든 그물은 이 표와 같고, 이 그림은 그 표를 몇 % 정확도로 옮긴 것이다."**

### 5.2 안 되는 것 (인정할 것)
1. 3D에 정확히는 안 들어간다(13점 거리표는 최대 12차원 필요). 많이 틀어지면 "그림은 참고용, 표가 본체"로 물러남.
2. 관들이 얽혀 지나가는 모양은 배치의 산물. 뜻 없음. ("구멍 42개짜리 손잡이체"는 얽힘과 무관하게 성립.)
3. **엔진이 섞여 있다(가장 큼).** 관객은 엔진이 연 씬 중에서만 고른다. "열린 씬 중 아무거나 고르는 가짜 관객" 대조 없이는 "이야기의 구조"인지 "엔진의 버릇"인지 못 가름.
4. 37회차 중 12회차는 관리자 계정, 25회차는 익명(중복 여부 불명).
5. 사전 등록 없이 본 탐색 자료. "확인"은 규칙을 먼저 못 박은 뒤 새 자료로.
6. (부록 3에서 추가) 저항 거리가 "두 씬이 각각 얼마나 붐비나"만 반영하는 값으로 무너질 수 있음 → 실제 자료에서 그 둘이 얼마나 겹치는지 **함께 재서 보고**해야 함.
7. (부록 3에서 추가) 실을 쌍별 가닥 수로 뭉개면 순서 정보("3을 거쳐 6에 온 사람은 8로 간다")가 사라짐. 이를 검정하려면 경로 수만 개가 필요한데 37개 → "가장 단순한 모형에 머무는 것은 표본의 한계"라고 적어야 함.
8. 그림의 틀어짐 판정에 흔한 기준표("5% 좋음·10% 보통·20% 나쁨")는 어떤 원문에서도 확인 못 함 → 쓰지 말 것.

### 5.3 결정이 서면 할 계산 순서 (지금은 하지 않음)
거리표 → 3D 자리 → 틀어진 정도 → 흔들림 범위 → 붐빔 값과의 겹침 → 가짜 관객 대조. 선행 조건: D4 결정, 그리고 「기억의 정의」 `D6-조` 행의 "재는 법" 확정.

## 7. 문헌 수색 결과 요약 (원문은 부록 2·3·4)

조사 담당이 "직접 연 것만" 실었다고 보고했고, 주 작업자는 재대조하지 않았다. **인용 전 원문 확인 필수.**

### 7.1 임현 정의의 선례 (부록 4)
- **딱 맞는 선례는 없다.** 조각별로는 있다.
  1. **에코(1979) 「독자의 역할」— 공통 틀·상호텍스트 틀·추론 산책**: "들어 올린 손"만 써도 독자가 "때린다"를 읽는 것은 관습 틀 때문. 흉기→살인자와 같은 구조. 눈금은 없음. (원문 확인, 20~21·32~33쪽)
  2. **스크립트·도식의 기본값 채우기, 채트먼의 "반사 작용"**: 틈을 자동으로 메움. 거리 개념 없음.
  3. **야콥슨(1956) 환유의 길(인접성)**: 임현의 "환유적으로"의 출처로 보임. 종류 구분이지 눈금 아님. (원문 확인, 76~78쪽. 안나 카레니나의 손가방 예)
  4. **인과 연관도 실험(Keenan 1984, Myers 1987)**: 가까움을 정도로 나눔. 중간이 가장 잘 기억됨. (원 논문 미확인. Kuperberg 2011의 요약은 원문 확인)
  5. **바르트의 "지표", 르베르디(1918) "멀고도 들어맞는"**: 시 이미지 이론.
- **역U자("0이면 해석 소멸, 너무 멀면 따로 놂, 중간에서 해석")**: 오른쪽 끝과 가운데는 실험 선례 있음(단 잰 것은 기억이지 해석의 풍부함이 아님). 왼쪽 끝은 Herman(2002, 2차)·김성일(1999, 초록) 이 받침. **"하나의 이야기로 붕괴"라는 표현 그대로의 선례는 못 찾음 → 임현 고유의 정식화로 보는 것이 안전.**
- **표·그물 선례**: 레비스트로스(1955) 오이디푸스 표("신화 = 그 모든 이본", 원문 확인 211~217쪽) / 채트먼(1978) 핵·위성 도식(원문 확인 53~56쪽) / Tomai 외(2011) 같은 영상을 283명이 각자 이야기한 자료(원문 확인) / Chambers & Jurafsky(2008) 사건 동시 출현 점수(원문 확인) / Shahaf & Guestrin(2010) 징검다리 사슬(원문 확인) / Toubia 외(2021) "에두름" 측정(원문 확인).
- **뜻이 다른 '거리'**: 주네트(서술 거리), 미적 거리, 스턴버그(시간 배치), Ryan의 tellability.
- **못 찾은 것**: 사건 쌍의 떠올림 거리로 "narrative distance"를 정의한 서사학 문헌 / 저항 거리를 서사에 쓴 문헌 / "거리 0 = 붕괴" 명시 문헌.
- 다음에 원문 확인할 가치가 큰 것: McKoon & Ratcliff (1992) "Inference during reading" — "저절로"의 심리학적 정의에 가장 가까운 후보.

### 7.2 굵기 매듭(D4)에 대한 문헌의 답 (부록 3) — **결정 아님, 참고**
- **(나) 굵기 = 가닥 수를 가장 지지.** 근거:
  1. "가닥 3개"와 "무게 3짜리 선 하나"는 저항 거리에서 같은 값(Newman 2004 원문, Doyle & Snell 원문, Chebotarev 2011 원문). → (나)는 "(다) 실수 무게에서 단위를 걸음 한 번 = 가닥 하나로 못 박은 것". 문턱·상수 불필요. *(세 문헌을 이은 조사 담당의 추론)*
  2. 기억 심리학의 표준이 굵기를 넣는 쪽: De Deyne 외(2019, 원문) — 연상 강도 = "단서를 줬을 때 그 답이 나온 횟수 비율". 직접 강도보다 **돌아가는 길까지 합친 걸음 기반 거리**가 사람 판단을 더 잘 맞힘. (단 자유 상수 α가 있음 — 저항 거리에는 없음.)
  3. "관객이 늘면 모양이 사라진다"의 표준 해법: 굵은 선부터 얹으며 고리의 **수명**을 봄(Petri 2014, Sizemore 2018, 원문). 순위만 쓰므로 문턱 불필요. 단 Petri의 "발판" 그림은 불변량이 아니라고 저자가 명시 → 정의에는 고리의 생김·메워짐 시점만.
  4. (가) 굵기 없음에도 선례 있음(Abbott 2012 — 균등 모형도 같은 현상 재현). 단 낱말 수천 개짜리 듬성한 그물.

- 17축·VAD는 부정확해서가 아니라 **다른 것을 재서** 안 맞음(감정 닮음 ≠ 떠올림). 버리지 않고 나란히 놓아 어긋나는 쌍을 본다(11-06 +0.355).
- 거리표를 채우는 **재료는 둘**: 걸음(있음) / 직접 묻기(없음). 저항 거리·D4는 걸음을 거리로 바꾸는 **규칙**, 열린 목록 저장은 걸음 재료를 **깨끗하게 하는 일**. 셋을 같은 종류로 적으면 안 됨.
- 자리 뽑는 계산(고전적 다차원 척도법): 거리표 → 무게중심을 원점으로 옮김 → 가장 길게 퍼진 방향 셋을 축으로 → 넷째부터 버림(버린 만큼이 틀어짐). 같은 표 → 같은 그림(돌리기·거울상만 다름), 고르는 숫자 없음. 틀어짐 = 앞 세 축의 퍼짐 ÷ 전체 퍼짐 + 78쌍 대조표.
- 조건·한계: 거리가 양쪽에서 같아야 함(방향은 화살표·색으로 따로) / 모든 쌍에 거리가 있어야 함(외톨이 씬 불가) / 퍼짐이 음수인 축이 나오면 어떤 차원에도 정확히 안 놓임 → 크기 보고 / 축에 뜻 붙이기 금지 / 13점은 적으므로 관객 단위 다시 뽑기로 흔들림 확인.
- 다른 계산법: 틀어짐이 줄 때까지 점을 조금씩 미는 방법. 시작 자리를 위 결과로 고정해야 "같은 그물 → 같은 그림" 유지.

### 12.4 읽기 정정 — 걸음은 떠올림이 아니었다 (사용자 지적)
사용자: "이 씬을 보면 무슨 씬이 떠오르냐는 처음 보는 사람들은 알 수가 없고 이미 이야기를 알고 있는 사람만 가능한 거 아냐?"
- 맞음. 그리고 §4.3의 읽기("걸음 = 떠올림의 기록")도 함께 무너짐. 처음 보는 관객은 도착할 씬을 본 적이 없다.

| | 무엇 | 누구에게서 | 자료 |
|---|---|---|---|
| 가 | 보기 전부터 아는 관습(흉기 → 살인자) — **임현의 것** | 누구나, 작품을 안 봐도 | 없음 |
| 나 | 보는 중의 끌림(3을 겪고 7의 단서로 감) | 처음 보는 관객 | 걸음 179개 |
| 다 | 본 뒤의 떠올림(3을 보면 7이 떠오름) | 이미 본 사람 | 없음 |

- 길 셋(**미결정**): 1) 나를 조각 거리로 — 이름을 "끌림"으로 바로잡아야 하고, 고르는 순간 화면에 무엇을 보여 주느냐가 곧 기구가 재는 것 / 2) 다를 조각 거리로 — 떠올림에 가장 가깝지만 작품 밖 설문, 걸음 그물과 따로 놂 / 3) 둘 다 재서 비교 — 같으면 걸음이 떠올림을 미리 보여 줌, 다르면 "겪은 뒤 기억이 다시 짜인다"의 자기 자료.
- 덧붙임: 가를 직접 재는 길(안 본 사람에게 씬 하나를 보여 주고 자유 연상 → 다른 씬 내용과 겹침). 겹침 판정자가 새 문제.
- 세 길을 가르는 물음: 조각이 보여 주려는 것이 "지나간 자국"인가 / "머릿속에 남은 것"인가 / "둘이 같은가"인가.
- 사용자: 플레이 화면은 뜯어고칠 예정이라 지금 화면에서 관객이 무엇을 보고 고르는지는 조사 보류.

### 12.5 사용자 제안 — 소설을 먼저 읽히고 플레이
- 읽은 관객은 씬을 알므로 걸음이 "떠올림을 발로 한 것"이 됨. 나와 다가 합쳐지고 설문이 따로 필요 없음. 이본 전승의 꼴(들은 사람이 자기 순서로 다시 풀어놓음)과 같음.
- 새 문제: ① 소설의 순서가 걸음에 배어듦(순서대로 본 것은 바로 다음 것을 이어 떠올리는 버릇 — **작업자 기억에 의한 서술, 원문 미대조**). 대신 기준이 생김: "소설 순서 그대로"에서 벗어난 걸음이 잡아낼 것 ② "원본 맞히기 시험"이 될 위험(안내 문구가 중요) ③ 안개 원칙(§6.5-5)과 어긋남 ④ 읽기와 플레이 사이 시간이 결과를 바꿈 ⑤ 기억 정도의 개인차 ⑥ 부담 ⑦ 엔진이 여는 것의 영향이 더 커짐 ⑧ 임현의 "읽기 전"은 여전히 아님.
- 읽은 무리와 안 읽은 무리를 견주면 길 3이 작품 안에서 이루어짐.

### 12.6 사용자 설계안 (4단계)
1. 소설 전체를 읽게 한다. 2. 플레이 전 "뭐가 떠올라?"로 이 소설을 어떻게 기억하는지 묻는다. 3. 답에 따라 시작 장면을 다르게 한다. 4. 여러 시작점의 사람들을 그대로 플레이시킨 뒤 연결 고리를 확인한다.
- 얻는 것: 2번의 답에서 **말한 순서**가 엔진이 안 낀 떠올림의 실 한 가닥 / 말과 걸음을 한 사람에게서 얻어 서로 맞춰 봄 / 시작점이 흩어져 그물이 고르게 참 / 원칙 6(서술이 첫 체험)과 맞음.
- 걸리는 것: **답을 씬으로 옮기는 규칙**(가장 큼 — 사람 판정이면 해석, 기계면 버릇, 목록에서 고르게 하면 "알아봄"을 재게 됨) / 시작점이 두세 씬에 몰릴 것 / 묻는 것이 기억을 바꿈 / 첫 걸음의 지위 / 소설 순서 / 엔진이 여는 것 / "연결 고리 확인"을 자료 보기 전에 못 박을 것 / 부담.
- 정할 것 여섯: 옮기는 규칙 · 답에서 남길 범위(첫 마디 / 전부와 순서) · 안 맞는 답 처리 · 읽기와 질문 사이 시간 · 시작 뒤 엔진이 여는 것 · 무엇을 세고 무엇과 견주나.
- 덧붙임: 플레이 뒤 같은 질문을 한 번 더 하면 전후 차이가 "걷는 일이 기억을 어떻게 바꿨나"의 기록.

### 12.7 사용자 제안 — 합평회에서 시킨다
- 풀리는 것: 읽기 부담(이미 꼼꼼히 읽고 옴) / 사람 모으기 / 질문의 어색함.
- **순서 필수**: 물음은 토론 전에, 각자 따로, 글로. 토론이 시작되면 방 안의 합의가 됨. 토론 전·후로 두 번 물으면 "남의 해석을 듣고 내 기억이 어떻게 바뀌었나"가 기록됨(이 프로젝트의 핵심 주제).
- 순서안: 읽고 옴 → 토론 전 글로 답 → 각자 플레이(서로 화면 안 보이게) → 토론 → 토론 후 다시 답.
- 걸리는 것: **동의서 선결**(지난 거절 사유) + 선생님 허락 + 빠질 자유 / 훈련된 독자이며 "거리감" 개념을 이미 배웠을 수 있음 / 작가가 그 자리에 있음(이름 없이 받을 것) / 한 번·한 작품·적은 인원 = 첫 시험 / 시간과 기기 / 옮기는 규칙은 그대로 / 화면을 고치기 전 자료는 고친 뒤와 섞지 못함.

### 12.8 임현 작가 한예종 졸업논문 — 못 찾음
- 확인된 학력: 전남대 국어국문학과(학사) → 한국예술종합학교 연극원 극작과 서사창작전공(예술전문사). 2014 『현대문학』 등단.
- 뒤진 곳: RISS 0건 / 광주대 문예창작과 교수 소개(학력·논문 칸 비어 있음) / 나무위키·출판사 소개 / 인터뷰 / `E:\-\` 자료 — 전부 논문 언급 없음. 한예종 도서관(lib.karts.ac.kr)은 로그인으로 넘어가 열지 못함.
- 창작 전공은 작품으로 졸업했을 가능성 있음(졸업 요건 공식 자료 미확인). 가장 확실한 길 = 선생님께 직접 여쭙기(정의 출처와 함께).

### 12.9 씬을 자르는 기준 — 현황과 사용자 구술
- 하나로 정해진 기준은 없었음. 있는 것: 대화 자르기 = 감정 소강(확정, era 이론) / 발췌 길이 2~4문장·30~100자(확정, 길이지 자리 아님) / 소설 통째 = 시간·장소·행동·시점·감정 전환 + 작가 경계 존중([[공간무대_구현검토-261107]] §11.4 B3, **추천안**) / 실제로는 대표 기억 13씬·권역 15씬 모두 손으로 잘랐고 적어 둔 기준 없음.
- 왜 중요한가: 씬이 그물의 점이라, 자르는 자리에 따라 점·그물·거리표·조각이 전부 달라짐. 합평회에서는 사람들이 떠올리는 덩어리와 자른 덩어리가 어긋나면 답을 씬으로 못 옮김.
- **사용자 구술(11-14)**: "작가 건 지가 알아서 자르게 두기로 했지. 기억 엄밀하게 자르는 건 연구용으로." → [[기억의_정의_v1-261105]] §7 `D15-가름` 행과 B3 칸에 기록. 둘을 가른 문장은 이전 문서에 없었음.
- 귀결: 작가가 자른 씬은 "작가가 준 것"(원시 개념) / 논문 한계에 명기 / 작품끼리 모양 비교는 불가, 한 작품 안 관객끼리는 가능.
- 대안 메모: 토론 전 답을 먼저 모아 **사람들이 떠올린 덩어리를 보고** 자르는 방법(칼질의 근거가 독자에게서 나옴. 합평회 두 번 필요).

### 12.10 정의 내려야 할 것 목록 (급한 순, 전부 미결정)
D4 굵기 → D6-조 재는 법 → **조각 거리가 가·나·다 중 무엇인가(12.4, 새로 생김)** → D3 접촉 → D5 되접힘 → D8 문구 → D13 새 감정 낱말 → D1 확인 한 줄. 무대 쪽(D14~D26)은 [[공간무대_구현검토-261107]] §11.

### 12.11 사용자의 다음 방향 (구술)
"일단 플레이할 수 있게 만들어야지. 소설 넣으면 자동으로 만들어 주는 건 잠시 미뤄 두고, 작가님들 소설 하나를 여러 장면으로 쪼개서…" — 합평회용으로 작가 소설 하나를 손으로 올리는 쪽. 플레이 화면은 고칠 예정.
