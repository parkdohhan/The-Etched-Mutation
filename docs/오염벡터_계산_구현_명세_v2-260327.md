**기준 엔진:** 별이엔진 V4 (궤적 기반 정렬도)  
**기준 이론:** 기억유전학 v0.3 (6연산 체계)  
**작성일:** 2026-03-27  
**상태:** 시뮬레이션 검증 대기

---

## 0. 이 모듈의 성격

**이것은 "진실 모델"이 아니라 "연출 제어 모델"이다.**

오염 벡터는 기억의 객관적 상태를 측정하는 계측기가 아니다. 관객이 기억의 변이를 체감할 수 있도록 프론트엔드에 제어 신호를 보내는 장치다. 따라서 각 축의 공식은 "이론적으로 가장 정확한가"가 아니라 "표현에 유용한가"가 기준이다.

이 구분이 중요한 이유: 오염 벡터의 값이 "틀릴" 수는 없다. 오염 벡터는 기억의 물리적 속성이 아니라, 연출 강도를 결정하는 제어 변수이기 때문이다. 다만 "체감이 약하다"거나 "너무 빨리 포화한다"는 문제는 있을 수 있고, 이것은 상수 튜닝으로 해결한다.

```

  → alignment, level, shape, void_mod, transition_pattern,
    mismatch_type, fixation_level 출력

오염 벡터 계산기 (이 문서)
  → V4 출력을 입력으로 받아
  → memory 단위 오염 벡터 증분 업데이트

  → stage_weights + 원본 데이터를 받아
  → 텍스트 변형, 시각 표현, 사운드스케이프 연출
```

별이엔진은 건드리지 않는다.

## 5. 상수 정의

```javascript
const DECAY_RATE = 0.05;
const FIXATION_CONV_WEIGHT = 0.4;
const HIGH_CONV_WEIGHT = 0.15;
const MID_CONV_WEIGHT = 0.03;
const HETERO_SCALE = 4.0;
const DEPTH_THRESHOLD_S2 = 5;
const MIN_DEPTH_FOR_CONVERGENCE = 3;   // 신규: convergence 누적 최소 조건
const FIXATION_THRESHOLD = 0.85;
const RECOMBO_HETERO_THRESHOLD = 0.5;
const RECOMBO_DEPTH_THRESHOLD = 5;
```

## 6. 증분 공식

### 6.1 depth

```javascript
depth += 1;
```

### 6.2 divergence

기억유전학 대응: 편향적 변이(2), 파괴적 복제(1).

shape이 낮으면 궤적이 갈라진 것, level이 낮으면 감정 수준이 다른 것.

```javascript
const effectiveShape = shape_active ? shape : 1.0;
const delta_div = (1 - effectiveShape) * (1 - level);
const decay = 1 / (1 + depth * DECAY_RATE);
divergence = Math.min(divergence + delta_div * decay, 1.0);
```

shape_active = false이면 delta_div = 0. 궤적 데이터 없이 발산을 판정하지 않는다.

### 6.3 convergence

기억유전학 대응: 과잉 수선(5).

**v2 변경: `MIN_DEPTH_FOR_CONVERGENCE` 게이트 추가.**

v1의 문제: shape_active = false인 초기(장면 1~2개)에도 alignment >= 0.5이면 convergence가 쌓였다. divergence는 0으로 고정되는데 convergence만 올라가서, 초기에 Stage 3이 즉시 지배적이 되는 버그.

v2 수정: depth가 `MIN_DEPTH_FOR_CONVERGENCE`(기본 3) 미만이면 convergence를 쌓지 않는다. 궤적이 충분히 관찰되기 전에는 "수렴하고 있다"고 판정하지 않는다.

```javascript
let delta_conv = 0;

if (depth >= MIN_DEPTH_FOR_CONVERGENCE) {
  if (fixation_level >= FIXATION_THRESHOLD) {
    delta_conv = alignment * FIXATION_CONV_WEIGHT;
  } else if (effectiveShape >= 0.7 && level >= 0.7) {
    delta_conv = alignment * HIGH_CONV_WEIGHT;
  } else if (alignment >= 0.5) {
    delta_conv = alignment * MID_CONV_WEIGHT;
  }
}

const decay = 1 / (1 + depth * DECAY_RATE);
convergence = Math.min(convergence + delta_conv * decay, 1.0);
```

### 6.4 heterogeneity

Welford 온라인 분산. alignment의 분산을 추적.

```javascript
const n = depth;
const d1 = alignment - _cont_align_mean;
_cont_align_mean += d1 / n;
const d2 = alignment - _cont_align_mean;
_cont_align_m2 += d1 * d2;

if (n >= 2) {
  const variance = _cont_align_m2 / (n - 1);
  heterogeneity = Math.min(variance * HETERO_SCALE, 1.0);
} else {
  heterogeneity = 0;
}
```

## 7. Stage 혼합 비율

```javascript
const raw_1 = divergence * (1 - convergence);
const raw_2 = heterogeneity * Math.min(depth / DEPTH_THRESHOLD_S2, 1.0);
const raw_3 = convergence * (1 - heterogeneity);

const total = raw_1 + raw_2 + raw_3;
if (total > 0) {
  stage_1 = raw_1 / total;
  stage_2 = raw_2 / total;
  stage_3 = raw_3 / total;
} else {
  stage_1 = stage_2 = stage_3 = 0;
}
```

## 8. 전체 업데이트 함수

```javascript
function updateContaminationVector(memory, engineOutput) {
  const {
    alignment, level, shape, shape_active, fixation_level
  } = engineOutput;

  // 1. depth
  memory.cont_depth += 1;
  const n = memory.cont_depth;
  const decay = 1 / (1 + n * DECAY_RATE);
  const effectiveShape = shape_active ? shape : 1.0;

  // 2. divergence
  const delta_div = (1 - effectiveShape) * (1 - level);
  memory.cont_divergence = Math.min(
    memory.cont_divergence + delta_div * decay, 1.0
  );

  // 3. convergence (depth 게이트)
  let delta_conv = 0;
  if (n >= MIN_DEPTH_FOR_CONVERGENCE) {
    if (fixation_level >= FIXATION_THRESHOLD) {
      delta_conv = alignment * FIXATION_CONV_WEIGHT;
    } else if (effectiveShape >= 0.7 && level >= 0.7) {
      delta_conv = alignment * HIGH_CONV_WEIGHT;
    } else if (alignment >= 0.5) {
      delta_conv = alignment * MID_CONV_WEIGHT;
    }
  }
  memory.cont_convergence = Math.min(
    memory.cont_convergence + delta_conv * decay, 1.0
  );

  // 4. heterogeneity (Welford)
  const d1 = alignment - memory._cont_align_mean;
  memory._cont_align_mean += d1 / n;
  const d2 = alignment - memory._cont_align_mean;
  memory._cont_align_m2 += d1 * d2;
  if (n >= 2) {
    memory.cont_heterogeneity = Math.min(
      (memory._cont_align_m2 / (n - 1)) * HETERO_SCALE, 1.0
    );
  }

  // 5. Stage 비율
  const r1 = memory.cont_divergence * (1 - memory.cont_convergence);
  const r2 = memory.cont_heterogeneity * Math.min(n / DEPTH_THRESHOLD_S2, 1.0);
  const r3 = memory.cont_convergence * (1 - memory.cont_heterogeneity);
  const tot = r1 + r2 + r3;
  if (tot > 0) {
    memory.cont_stage_1 = r1 / tot;
    memory.cont_stage_2 = r2 / tot;
    memory.cont_stage_3 = r3 / tot;
  } else {
    memory.cont_stage_1 = memory.cont_stage_2 = memory.cont_stage_3 = 0;
  }

  memory.cont_last_updated = new Date().toISOString();
  return memory;
}
```

## 13. 레트로바이러스 계통역학에 의한 3축 정당화

### 13.1 왜 이 3축인가

오염 벡터의 3축(divergence, convergence, heterogeneity) + depth는 임의 설계가 아니다. HIV-1 계통역학(phylodynamics)에서 바이러스 진화를 추적하는 표준 메트릭과 구조적으로 동일하다.

| HIV 계통역학 메트릭 | 오염 벡터 축 | 수학적 대응 |
|---|---|---|
| **Root-to-tip divergence** (기준 서열로부터의 누적 거리) | **divergence** | 원본으로부터의 감정적 거리 누적 |
| **Convergent evolution rate** (독립 계통이 동일 변이로 수렴하는 비율) | **convergence** | 반복 고정렬 플레이로 인한 과잉 수렴 |
| **Intra-patient diversity (π)** (한 환자 내 변이체 간 유전적 다양성) | **heterogeneity** | 한 기억에 대한 해석 간 정렬도 분산 |
| **Serial passage count** (계대 배양 횟수) | **depth** | 해석 반복 횟수 |

### 13.2 depth — Muller's Ratchet

무성 생식 집단에서 해로운 변이가 비가역적으로 축적되는 현상(Muller, 1964). 레트로바이러스에서 실제로 관찰됨.

```
Muller's Ratchet:  변이 축적은 비가역 — 되돌릴 수 없다
오염 벡터:         depth += 1, 감소 없음 (단조 증가)
```

depth가 단조 증가하는 설계 판단은 Muller's Ratchet의 직접적 구현이다.

### 13.3 divergence — 분자시계 포화 모델

HIV 계통수에서 root-to-tip divergence는 시간에 따라 증가하되, 분자시계(molecular clock)의 포화 효과로 증가율이 점차 둔화된다.

```
HIV:       divergence ∝ 1 - e^(-μt)        (포화 곡선)
오염 벡터:  decay = 1/(1 + depth × 0.05)    (초기 업데이트가 크고 점차 둔화)
```

DECAY_RATE = 0.05의 감쇠 함수는 분자시계의 포화 모델과 동일한 형태다. 초기 해석이 오염에 더 큰 영향을 미치고 후기 해석은 점차 둔화되는 현상을 포착한다.

### 13.4 heterogeneity — Eigen의 준종(Quasispecies) 이론

Eigen & Schuster (1977)의 준종 이론: 높은 변이율을 가진 자기복제자 집단은 단일 서열이 아니라 변이체의 구름(cloud of mutants)으로 존재하며, 이 구름의 폭(width)이 집단의 적응적 다양성을 결정한다.

```
Quasispecies:  diversity = variance of sequence space
오염 벡터:     heterogeneity = Welford_variance(alignment_scores) × HETERO_SCALE
```

heterogeneity를 분산(variance)으로 계산하는 것은 준종 이론의 "구름 폭 측정"과 동일한 수학적 조작이다. Welford 온라인 분산(Welford, 1962)은 바이러스학에서 intra-patient diversity(π)를 single-pass로 계산하는 것과 같은 통계적 도구다.

HETERO_SCALE = 4.0은 오염 벡터의 분산을 [0, 1] 범위로 정규화하는 스케일링 계수이며, 준종 이론에서 변이 구름의 폭을 적응도 지형(fitness landscape)의 크기에 대해 정규화하는 것에 대응한다.

### 13.5 convergence — 면역 압력 하의 수렴 진화

HIV에서 서로 다른 환자의 바이러스가 독립적으로 동일한 약제 내성 변이(예: M184V)를 획득하는 현상. 면역 압력(=숙주 환경)이 변이를 같은 방향으로 수렴시킨다.

```
HIV:       면역 압력 → 독립 계통이 같은 변이로 수렴 → "가짜 복원"
오염 벡터:  반복 고정렬 → convergence 축적 → Stage 3 과잉완성 → "가짜 원본"
```

Stage 3(과잉완성)의 정당화: HIV에서 수렴 진화는 "원래 서열로 돌아가는 것"이 아니라 "선택 압력에 의해 강제된 새로운 고정"이다. 마찬가지로 기억의 과잉 수렴은 원본 복원이 아니라 해석자 편향의 고정이며, 기억유전학 Op 5(과잉 수선)의 메커니즘이다.

### 13.6 Stage Mixing — 바이러스 적응도 지형에서의 경쟁적 배제

Stage mixing의 곱셈 구조:
```
stage_1 = divergence × (1 - convergence)      // 발산만, 수렴 없음
stage_3 = convergence × (1 - heterogeneity)   // 수렴만, 다양성 없음
stage_2 = heterogeneity × min(depth/5, 1.0)   // 다양성이 깊이와 함께 증가
```

이 구조는 바이러스 적응도 지형(fitness landscape)에서의 세 가지 진화 국면에 대응한다:

| 진화 국면 | 바이러스 상태 | Stage | 오염 상태 |
|---|---|---|---|
| **변이 확산기** (초기 감염, 면역 회피 전) | divergence 높음, convergence 낮음 | Stage 1 | 기억이 한 방향으로 기울어짐 |
| **준종 평형** (다양한 변이체 공존) | heterogeneity 높음, depth 깊음 | Stage 2 | 다수 해석이 병기 |
| **클론 고정기** (약제 내성 고정, 단일 클론 우세) | convergence 높음, heterogeneity 낮음 | Stage 3 | 과잉 완결된 "가짜 원본" |

Stage 1과 Stage 3이 반상관(anti-correlated)인 것은 바이러스 집단에서 확산기와 고정기가 동시에 일어나지 않는 것과 같은 구조적 제약이다.
