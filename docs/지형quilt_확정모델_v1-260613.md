## 0. 한 줄

장면 하나하나가 **각자 완결된 고유 지형**이다. 플레이에 따라 **각 지형의 크기**와 **지형들 사이의 거리(관계)** 만 달라진다. 지형의 **생김새는 절대 안 변한다.** 그래서 같은 작품인데 사람마다 다른 지형 묶음이 남는다.

---

## 1. 확정된 그림 (동결)

1. **장면 = 각자 완결된 고유 지형.**
   - 봉우리 같은 "점"이 아니다. 장면 1은 장면 1만의 풍경 전체(산맥/사막/잠긴 골짜기 등)를 통째로 가진다. 장면 수만큼 서로 다른 지형이 따로 존재.
   - 생김새는 **그 장면 감정에서 자동 생성되어 고정**(작가 수제 폐기 — Record 호환, 2026-06-14). 같은 감정 → 같은 모양(결정론), 장면마다 감정 달라 모양 고유. 누가 플레이해도 안 망가짐.

2. **크기만 동적 (모양은 불변).**
   - 구현 감각: 지형 덩어리를 **그룹으로 묶어 잠그고, scale(크기)만** 키웠다 줄였다.
   - 공명하면 그 장면 지형이 그룹째 커지고, 스치면 작아짐.
   - 모양 자체를 부풀리거나 비틀지 **않는다.**

3. **관계도 동적.**
   - 장면 지형들끼리 어떤 사람한텐 가까이 맞붙고, 어떤 사람한텐 멀어짐.
   - "무엇이 그 거리를 정하는가"는 §5에서 브레인스토밍.

4. **사람마다 고유.**
   - 같은 장면 집합으로 시작해도, 크기·배치가 사람마다 달라져 전체 지형 묶음이 고유해짐.
   - 작품 철학의 **이본론**(같은 기억이 사람마다 다른 판본이 됨) 그 자체.

---

## 2. §14에서 바뀐 것 — "모양 변형" 폐기

`LUMEN_DEMO_SCOPE-260427.md` §14-2 는 매 회차마다 **모양 자체가 변형**된다고 적었다:
> 관객 공명 ↔ 모양 변형 (부풀음/수축/회전), transition_pattern ↔ 변형 종류 (echo_follow=호흡, contradiction=반전, …)

**이 계획은 폐기.** 변하는 것은 딱 두 가지 — 각 지형의 **크기**, 지형들 사이의 **거리**. 생김새는 영원히 보존.

이건 축소가 아니라 **단순화이자 철학 강화**다 (§3).

## 3. 철학 정합성

| 철학 기둥 | 확정 모델과의 관계 |
|---|---|
| **변이는 부산물** ([Platform Direction]) | 감정에서 계산된 원형(생김새)은 보존되고, 변이는 크기·배치라는 *부산물*로만 나타남. 정확히 일치. |
| **작가 통제는 정체성 아님** ([Avoid Authorial-Control Framing]) | 원형(생김새)은 *감정 계산*이 정함 — 작가는 안 만지거나 선택적 잠금만. 크기·배치도 플레이가 정함. 통제가 더 옅어짐 → 명제 **강화**. |
| **이본론** ([Theoretical Framework]) | 같은 원형이 사람마다 다른 크기·배치로 펼쳐짐 = 같은 base, 다른 판본. |
| **오염 ≠ 열화** | 지형이 커지든 작아지든, 가까워지든 멀어지든 좋고 나쁨이 아니라 그냥 변형. |
| **의존적 복제자** (v0.4 지형설계) | 변형의 연료는 시간이 아니라 플레이(=생태계 활동). 사람이 안 건드리면 안 변함. |

## 4. 폐기·승계 정리

- **폐기:** §14-2 "모양 변형(부풀음/수축/회전/반전)".
- **폐기:** 다리(섬을 잇는 인공 연결물) 비유 — 관계는 다리가 아니라 지형들 사이 **거리**로 표현.
- **승계:** §14-2 "씬=고유 모양", "메모리=모양들의 quilt", "정적 원형(감정 계산) / 동적(플레이)". (원형 출처: 작가 수제 → 감정 자동 생성, 2026-06-14.)
- **승계:** v0.4 지형설계 §7 능선/골짜기/끊김(관계의 시각 어휘) — 단 "모양 변형" 아닌 "거리 변형"으로 재해석 필요(§5에서 확정).

## 5. 관계 모델 — 확정 (2026-06-13 브레인스토밍)

관계는 두 요소로 갈라진다:

1. **거리 = 얼마나 엮였나.** 멀다 = 상관없음(안 거치거나 피함), 가깝다 = 깊이 엮임.
2. **사이 생김새 = 어떻게 엮였나.** 매끄럽게 붙음(능선) / 갈라진 틈(골짜기) / 나란히 어긋남.

거리·사이 생김새는 **새로 계산하지 않는다.** 별이엔진이 매 전이마다 이미 분류하는 `transition_pattern`(6종)을 지형 위로 **번역만** 한다.

| transition_pattern | 거리 | 사이 생김새 |
|---|---|---|
| echo_follow / bridge (따라감·이음) | 가까움 | 매끄러움 (능선) |
| contradiction (거스름) | 가까움 | 갈라진 틈 (골짜기) |
| displacement (옮김) | 가까움 | 나란히 어긋남 |
| avoidance / 안 거침 (피함) | 멂 | 끊김 |
| fixation (붙박임) | 거리 아님 | 그 지형만 계속 커지며 고립 (크기 쪽 일) |

핵심 원칙:
- **엮이면 가까워지고, 안 엮이면 멀어진다.** 사이좋게(따라감)든 부딪히며(거스름)든, 엮이면 둘 다 가까워짐. **멀어짐 = 무관심이지 갈등이 아니다.**
- 능선/골짜기/어긋남은 **지형 사이 공간**에서 벌어진다. 각 지형 덩어리는 여전히 생김새 고정 + 크기만 변함 (§1-2와 무모순).
- v0.4 지형설계 §7(echo_follow→능선, contradiction→골짜기, avoidance→끊김)과 일치. 단 "모양 변형"이 아니라 "거리·사이 변형"으로 확정.

## 6. 거리 공식 — 확정 (2026-06-13 브레인스토밍)

**무대:** 한 사람의 한 판. 거리는 **이번 플레이 안에서만** 계산(누적 DB 불필요). 매 사람 작가 원형에서 출발, 끝나면 그 사람 결과로 남고 다음 사람은 다시 원형부터.

**한 전이당 계산:**
- 각 장면 쌍은 거리값을 가짐 (0 = 딱 붙음, 멀수록 큼). 시작 = **작가 원형 거리**.
- 결(`transition_pattern`)이 **목표**를 정함: 따라감·이음·거스름·옮김 → 가까운 목표 / 피함 → 먼 목표.
- 거리가 목표 쪽으로 **고무줄식 수렴**(EMA):
  ```
  새 거리 = 현재 거리 + α · 강도 · (목표 − 현재 거리)
  ```
  - `강도` = 그때의 `alignment`(공명 강도). 강하면 확, 약하면 살짝.
  - `α` = 기본 당김 계수 (ContaminationTracker EMA 재료화, 숫자는 §7 튜닝).
  - 처음 건널 때 크게 변하고, 이미 가까운 쌍은 미미 (자연 수렴 — 목표를 넘지 않아 clamp 자동).
- **안 거친 쌍은 원형 유지.**

**사이 생김새도 같은 고무줄 원리:** 따라감 강도 → 능선 높이 / 거스름 강도 → 골짜기 깊이 / 옮김 강도 → 어긋남 정도. 각각 목표로 EMA 수렴.

**재료 출처:** `transition_pattern` + `alignment` = 별이엔진이 이미 산출. EMA = ContaminationTracker 방식. **신규 계산식 0개** ([feedback_reuse_existing_assets_first] 정합).

→ 이 동결로 작업②(관계 로직)의 의존성 뿌리가 풀림. 병렬 착수 조건 충족.

## 7. 아직 미정 (숫자·시각 튜닝 차원)

비전·공식은 동결. 남은 건 손맛(숫자·시각)뿐:
- **크기 동역학의 양** — 공명 1회 = scale 얼마나? `alignment`를 크기로 번역하는 비율.
- **나란히 어긋남**(옮김)의 시각 어휘 — 화면에서 어떻게 보일지.
- `α`(당김 계수)·목표값·강도 정규화의 실제 숫자 (튜닝).
- 크기와 거리가 한 화면에서 동시에 출렁일 때의 시각 조율.

> 위는 구현·튜닝 중에 정해도 됨. 단 거리 공식(§6)·관계 모델(§5)은 동결 — 코드 착수 가능.
