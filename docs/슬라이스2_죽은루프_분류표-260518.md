## 연쇄 정리 대상

- **expInterview.js** — 파일 전체. 호출처 = 죽은 `makeChoice`(archive.js:1615) + 휴면 `live.js`(1732·1740). live.js가 휴면이라 **삭제보다 "휴면 처리" 권장** — index.html의 `<script src="js/expInterview.js">` 로드 줄 제거, 파일은 live.js처럼 보존. (CLAUDE.md §6.6 패턴)
- **index.html** — `expInterview.js` 로드 `<script>` 줄.
- **index.js** — 죽은 함수들의 import(67~80줄) + window 노출 줄(`filterByCategory` 652, `backToList` 700, `saveArchiveEmotionToPlays` 816 등). `selectMemory`(707)·`filterMemories`(710)는 LIVE — 유지.
- **archive.js** — 죽은 26개 본체 삭제 + export 블록(2097~2145) 정리. 죽은 함수만 쓰는 내부 헬퍼(export 안 된 것, 예: `startWaveAnimation`/`stopWaveAnimation` 등)는 삭제 turn에 같이 추적.
- **Visualizer.js `renderArchiveEmotionWave` 메서드 · UIManager.js `updateAlignmentDisplay` 메서드** — archive 죽은 함수만 소비하면 고아가 됨. 별도 검토(이번 범위 밖 가능).
