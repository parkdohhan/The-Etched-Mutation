## 연출 규칙 (사용자 결정 260709)

1. **입장**: 스폰 주변(반경 14)만 걷힘 + 접근 가능 핀마다 회랑(반폭 5)이 파임.
   지역은 **도착해야 개화** (플레이어가 핀 7m 안 → 반경 16 원이 3초 개화).
   가 본(visited) 핀 지역은 즉시 걷힌 채 시작.
2. **턴**: 씬 완료 → 맵 복귀 시 새로 열린 핀마다 현재 위치에서 회랑 + 도착 개화.
   기존 3D trace line 은 안개 ON 이면 생략 (회랑이 길잡이).
3. **이동**: 소프트 차단 — 걷힘 0.35 아래부터 감속, 0에서 정지("아무리 걸어도 나아가지지 않는다").
   더 맑은 쪽 걸음은 항상 통과 (갇힘 방지).
4. **막다른 곳**: 남은 접근 핀 0 → `liftAll()` — 안개 전부 걷혀 지나온 길이 드러남 (설계 원칙 4).
5. **유령**: 안개 속 = `visible:false` (클릭 레이도 자동 차단). 개화 중 = opacity 비례 등장.
   접근 가능 유령은 회랑 끝에 항상 희미하게 보임 — 목적지 유도 (의도).
6. **미니맵**: 걷힘 0.5 미만 핀은 점 안 찍음 (원칙 5 — 플레이어는 안개를 본다).

## ★★ 260712 최종 — 안개 = 벽 (아래 "공기 중 안개" 절의 볼륨 판은 **폐기**)

사용자 최종 정정:
> "내 눈앞에 안개가 있는 게 아니라, 안개가 **벽처럼 내가 볼 수 없는 영역을 확실하게 가릴 수 있게**.
>  눈앞 안개는 안개가 아니라 **디지털 풍화**같이 생겼을 뿐이니 삭제. 그리고 안개로 다가갔을 때 못 가게."

### (1) 볼륨 판 7겹 — 삭제
카메라 앞 빌보드 판으로 눈앞을 뿌옇게 하던 것. 노이즈 텍스처가 화면에 얹혀 **디지털 아티팩트**로 읽힘.
코드 전체 제거 (텍스처 생성·ShaderMaterial·프레임 갱신·detach). 하늘 돔은 존치 — 지평선을 녹여
안개 벽이 하늘까지 이어져 보이게 하는 역할이라 성격이 다르다.

### (2) 안개 = 벽 (핵심)
**폐기된 모델**: 안 열린 곳도 `1 - exp(-(density·거리)²)` — **거리** 기반 heavy fog.
→ 안 열린 땅이 **코앞에 있으면 거의 안 뿌옇다**(거리 0 → 안개 0). 그래서 벽으로 안 읽혔다.
**지금 모델** (`tem_af_strata_terrain.js` `_sfPatchShader`):
```
_sfW  = (1 - reveal) · _sfWall          // 0 = 열림, 1 = 벽. 거리 무관.
_sfFf = fogC + _sfW · (1 - fogC)        // 열린 곳은 원래 거리 안개 그대로
색   = mix(fogColor, _sfSky·(1+grain), _sfW)
```
`_sfWall` = 0.985 (uniform `uWall`, 예전 `uHeavyD` 폐기). liftAll 시 0 으로 사라짐.
벽 안쪽은 느린 fbm 결(`grain`)이 돌아 평면 매트가 아니라 안개 덩어리로 보인다.

### (3) 이동 차단 — 소프트 감속 → **벽**
예전 `moveSlowBelow` 감속은 벽으로 안 읽혔다 (느려질 뿐 계속 들어가짐).
지금 `moveBlockBelow: 0.15` — 걷힘이 그 아래인 자리로는 **못 간다**. 끼임 방지 2종:
- **벽면 슬라이드**: 걷힘의 기울기 = 벽 법선. 벽 성분을 제거해 벽을 따라 미끄러진다.
- **탈출 보장**: 더 맑은 쪽으로 가는 걸음은 언제나 통과.

`revealAt()` 을 셰이더와 같은 **smoothstep** 곡선으로 맞춤 — 보이는 안개 경계와 막히는 벽이 어긋나지 않게.
경계 fbm 일렁임 진폭도 `min(4.0, r·0.35)` 로 절제 (예전 `min(7.0, r·0.5)`).

**검증(260712)**: 스폰에서 8방위로 30칸 직진 시뮬 → 전 방향이 걷힘 0.11~0.18(= 벽)에서 정지.
안개 속(걷힘 0)까지 뚫고 들어간 방향 0개. 회랑 방향은 회랑을 따라 20~30칸 진행(정상).
화면: 안 열린 지형이 균일한 회색 덩어리로 완전히 가려지고, 회랑만 벽을 뚫고 나 있음.

## 공기 중 안개 (260709~12 — 볼륨 판 부분은 위에서 폐기, 하늘 돔만 유효)

사용자 지적: "안개가 땅에만 칠해진 느낌, 공기 중에 안개가 없다."
원인 — 셰이더 마스크는 **지형 표면 픽셀**만 물들인다. 하늘·허공엔 그릴 물체가 없어 아무 일도 안 일어남.
→ 지평선이 칼같이 끊기고 산 실루엣이 검은 하늘에 딱 박혀 보였다.

세 겹으로 해결 (`airFog: true`, 끄면 예전 동작):

1. **하늘 돔** (`_skyDome`) — 반경 300 구, BackSide, `renderOrder -10000`.
   `mix(uZenith, mix(uHorizon, uZenith, smoothstep(-0.03,0.40,dir.y)), uAmt)`
   → **지평선만 안개색, 머리 위는 원래 감정 하늘 + 별**. 배경색을 통째로 물들이면 밤하늘이 죽는다 (검증 완료).
   `uZenith` 는 매 프레임 `scene.background` 를 따라감 → `_tickSeedGrp` 의 감정 하늘 보존.
2. **볼륨 판** (`_airGrp`, 7겹) — 카메라 빌보드, 깊이 3~19.
   `depthTest:true` → 가까운 지형이 판을 가림 = **발밑은 맑고 멀수록 뿌옇다** (거리 비례 자연 감쇠).
   무늬는 **셰이더가 프래그먼트의 세계 좌표로 직접 샘플** (§아래 참조).

### ★ "앞으로 가면 안개가 위로 올라간다" — 세계 고정으로 전환 (260712 사용자 지적)

**증상**: 전진하면 안개가 화면 세로로 미끄러져 올라가고, 후진하면 내려옴. 헤치고 나아가는 느낌 X.

**원인**: 무늬를 `map.offset` 으로 **화면 좌표계**에서 밀었다.
`offset.x = -camX/CELL`(화면 가로), `offset.y = -camZ/CELL`(화면 **세로**).
→ 전진하면 세계 Z 가 변하고, 그게 화면 **세로** 축에 물려 있으니 안개가 위아래로 미끄러진다.
빌보드 판의 UV 축(카메라 right/up)에 세계 축(X/Z)을 억지로 물린 것 자체가 틀린 모델.

**해법 — 안개를 세계에 붙박이 3D 덩어리로.**
판은 그 덩어리를 자르는 **단면**일 뿐. `ShaderMaterial` 로 교체하고 프래그먼트의 **세계 좌표**(`vWPos`)로 노이즈를 뽑는다:
```
p = vWPos / uCell
a = tex(p.xz + drift)                      // 수평 투영
b = tex(p.zy·, p.xy· + seed)               // 다른 평면 투영 — 섞어서 3D 결 흉내(세로 압출 방지)
n = smoothstep(0.16, 0.86, 0.62a + 0.38b)
h = 1 - smoothstep(uLowY, uHighY, vWPos.y) // 낮을수록 짙다 — 지면에 깔린 안개
alpha = n · h · uOpacity
```
결과:
- **전진** → 판이 덩어리를 뚫고 나아가며 안개가 갈라져 스쳐 간다 (세로 미끄러짐 없음)
- **회전** → 안개는 세계 제자리. 고개 돌려도 안 따라온다
- **오르막** → 안개층 위로 솟는다 (`h` 가 자연히 줄어듦). 산꼭대기 = 안개 위
- 시차 계수·offset 손계산 **전부 삭제** — 기하가 알아서 맞춘다

**교훈: 볼류메트릭은 화면 좌표로 밀지 말 것. 세계 좌표로 샘플하면 모든 6-DOF 가 저절로 맞는다.**

옵션: `volumeCell 16`(무늬 크기), `volumeLowY -6` / `volumeHighY 24`(안개 높이대), `volumeDrift`(미풍).

### ★ 하늘에 세로줄 — 원인 2개 (260712 사용자 지적, 둘 다 수정)

**(1) 타일 이음매.** 노이즈 텍스처를 `RepeatWrapping` 으로 깔았는데 **주기 노이즈가 아니었다.**
좌우 끝이 안 맞물려 타일 경계마다 하드 엣지(직선)가 생기고, offset 이 흐르며 화면을 쓸고 다녔다.
→ `_pn2(x, y, per)` — 격자 좌표를 주기로 wrap 하는 periodic value noise 로 교체.
   fbm 도 lacunarity 2 + 옥타브마다 주기 2배 → 전체가 완벽 타일링.
   **교훈: RepeatWrapping 텍스처는 반드시 주기 노이즈로 구울 것.**

**(2) 판 모서리가 화면 안에 들어옴.** FP 카메라 **fov 는 50 이 아니라 90**.
고정 크기(depth × 2.8)로는 aspect 1.95 에서 필요 반폭(depth × tan45° × 1.95 = depth × 1.95) 에 한참 못 미쳐
판 경계 자체가 세로줄로 보였다.
→ 매 프레임 `hH = depth·tan(fov/2)·1.12`, `hW = hH·aspect` 로 스케일. 어떤 창 비율·화각에서도 덮음 (검증: 7겹 전부 covers=true).
→ 무늬 밀도는 `repeat = 판크기 / volumeCell(20)` 로 세계 기준 고정 → 깊은 판일수록 무늬가 잘게 보이고,
   시차가 자동으로 **1/깊이 비례** (가까운 층이 빨리 스쳐 감). 별도 층별 계수 불필요.
3. **scene.fog 색** — 유령·스프라이트용 거리 안개도 같은 색으로 lerp. 안 하면 유령만 딴 색으로 뜬다.

**안개량 두 갈래** (핵심):
- `distFog` — 링 샘플(8방위 × 34/64칸 = 16점)로 "내 주위 **멀리**가 안개인가". → 하늘 돔.
  걷힌 자리에 서서 안개 낀 산을 볼 때도 하늘이 뿌예야 하므로 카메라 로컬만으론 부족했다.
- `camFog` — "내가 **선 자리**가 안개인가". → 볼륨 판 짙기.
  `volumeAmbient: 0.3` — 걷힌 자리라도 멀리 안개가 있으면 옅은 대기감은 남는다.
