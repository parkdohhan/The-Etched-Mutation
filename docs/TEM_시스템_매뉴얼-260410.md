## 0. 작품 정의

**TEM (The Etched Mutation)**은 기억 오염 체험 시스템이다. 누군가의 기억을 다른 사람이 체험하면, 그 기억은 체험자의 감정으로 오염되기 시작한다.

### 세 가지 역할

| 역할 | 행동 | 결과 |
|---|---|---|
| **기억 제작자 (Curator)** | RECORD — 기억을 말로 털어놓는다 | 기억이 장면 묶음으로 변환되어 아카이브에 침전 |
| **체험자 (Player)** | PLAY — 타인의 기억을 감정으로 따라간다 | 매 체험마다 기억이 오염되고, 감정 흔적이 Strata에 쌓임 |
| **관찰자 (Admin)** | admin.html — 감정 공간 전체 지도를 본다 | 관리, 모더레이션, 장면 오버라이드 |

### 분류
**인터랙티브 미디어 아트 / 디지털 픽션 / 기억 시뮬레이션**.
게임이 아니다. 상품이 아니다. 작품으로 분류한다.

## 1. 철학과 핵심 원칙

### 1.1 작품의 명제

1. **기억의 "원본"은 존재하지 않는다.** Record 시점의 서술이 telling_trajectory일 뿐이다.
2. **오염은 나쁜 것이 아니다.** 기억이 살아있다는 증거다.
3. **기억은 원래 남이 했던 말을 내 것이라고 착각하는 것이다.** (Cryptomnesia / 잠재기억)
4. **체험자는 안개 속에 있어야 한다.** 전체 지도를 보는 순간 게임이 된다.
5. **침묵(VOID)은 결손이 아니다.** 의미 있는 데이터다.

### 1.2 엔진 원칙

- **엔진은 판단하지 않는다.** 관찰하고 수치를 반환할 뿐이다.
- **별이엔진은 변경하지 않는다.** 모든 후속 모듈(SceneNavigator, ContaminationTracker, 사운드, 시각)은 엔진 출력을 *소비*한다.
- **오염 벡터는 진실 모델이 아니라 연출 제어 신호다.** "틀릴 수 없는" 변수다.
- **결정론.** 같은 기억·같은 오염 상태에서 다시 플레이해도 동일한 오염 패턴이 보인다 — 시드 기반 PRNG. 오염이 기억에 "고정"된다는 감각.

### 1.3 작품의 톤

- 침묵, 파편, 감각, 애매함이 무기.
- 진단·해석·권고 금지.
- 텍스트는 짧게. 설명은 적게. 관객이 스스로 의심하게 둔다.
- 안전 메시지조차 시스템 경고가 아니라 "또다른 나"의 내면 독백으로 전달.

## 2. 이론적 기반

**기억유전학 (Mnemonic Genetics) v0.3** — 기억을 유전 물질로 보는 이론.
**기억 집단유전학 v0.4** — 그 위에 사회·집단 차원을 얹은 확장. Strata 지형 설계의 근거.

### 2.1 6연산 (v0.3)

| # | 연산 | 유전학 대응 | 기억에서의 실제 | 방향 |
|---|---|---|---|---|
| 1 | 파괴적 복제 (Destructive Replication) | 반보존적 복제 | 회상이 원본을 덮어씀. `R(M)=M', M ≠ M', M은 사라짐` | 발산 |
| 2 | 편향적 변이 (Biased Mutation) | 무작위 돌연변이 | 감정·맥락·사회압력이 변이 방향을 결정. 라마르크주의 동형 | 발산 |
| 3 | 의도적 선택 (Intentional Selection) | 자연선택 | 검열·신화화·큐레이션 | 발산/필터 |
| 4 | 무규칙 번역 (Ruleless Translation) | 코돈 테이블 | 매체 전환에 고정 코드북 없음. 비재현성 | 형태 변환 |
| 5 | 과잉 수선 (Aberrant Repair) | DNA 수선 | 복원 시도가 새 변이를 생성. **수선 자체가 병리를 만든다** | 수렴 시도 → 발산 |
| 6 | 기억 재조합 (Mnemonic Recombination) | 유전적 재조합 | 서로 다른 기억/해석이 교차해 제3의 기억 생성 | 합성 |

**축 분리:**
- **Intra-engram (1~5)**: 한 기억 단위 내부의 변형. → 오염 벡터로 처리.
- **Inter-engram (6)**: 복수의 기억/해석 교차. → 잔상 시스템 + 재조합 트리거로 처리.

### 2.2 집단유전학 매핑 (v0.4)

| 집단유전학 | 기억 집단유전학 | TEM에서의 표현 |
|---|---|---|
| 유전적 부동 | 기억 부동 — 소수 play가 전체 분포를 흔듦 | 기억이 적을 때 지형 변동 큼 |
| 유전자 흐름 | 감정 흐름 — 사용자가 여러 기억을 거치며 감정이 운반됨 | 한 기억의 감정색이 다음 기억에 묻어남 |
| 선택 압력 | 주의 경쟁 — 매력적 기억이 더 많이 play됨 | play 누적이 지형을 풍부하게 |
| 간섭 억압 | AF 근접 기억의 상호 약화 | 같은 영역의 기억 봉우리가 서로를 깎음 |
| 창시자 효과 | 최초 기록자의 감정 궤적이 기반암 결정 | **Record = First Play** |
| 근친 교배 약화 | 해석 단일화 → 경직 (hypercompletion) | 봉우리가 비정상적으로 뾰족해짐 |

## 7. 세 가지 핵심 흐름

### 7-1. RECORD (Record Flow V3, `docs/Record_flow_v3-260405.md`)

**3단계: 무대(Staging) → 공명(Resonance) → 침전(Sedimentation)**

#### Phase A — 무대 (60-90초)
1. 검은 안개. 시스템 텍스트(타이프라이터): "눈을 감아봐. 그 장소에 서 있어."
2. **감각 칩 3종 순차** — 냄새 → 소리 → 촉감.
   - 냄새: 배경 색조 틴트 변화 (rain_heavy/dust/hospital/grass/nothing)
   - 소리: 앰비언스 사운드 레이어 시작 (rain/silence/crowd/wind/nothing)
   - 촉감: 화면 질감 변화 (cold_air/sweat/someones_hand/hard_floor/nothing)
3. **앵커 오브젝트** 자유 텍스트 입력 → 안개 속 앵커로 떠오름 (opacity ~0.3)
4. AI: "거기 서 있으니까, 뭐가 떠올라?" → Phase B로 전환 (사용자에게 안 보임)

#### Phase B — 공명 (3-7턴)
- Phase A에서 세팅된 감각 무대 위에서 대화.
- **이중 레이어 감지**:
  - Layer 1 (0ms): 클라이언트 사전 패턴 매칭 — "뭔가 감지됐다" 즉각 시각 신호
  - Layer 2 (1-3s): Claude(`collect-memory`)로 정밀 분류 → 보정
- **구성요소 5종**: 장소/배경, 인물, 사물, 감정, 신체감각. 각각 다른 시각·청각 반응.
- AI는 행동 나열을 감지하면 감각 질문으로 전환.
- 사용자가 `[USER_SEAL_REQUEST]`("여기까지" 등)를 말하면 마무리 질문 1개 → `[SCENE_COMPLETE]`.

#### Phase C — 침전
- `generate-scene-from-conversation` 호출 → 장면 텍스트 + 감정 벡터.
- 장면 검토(`showSceneReview`) → 제목 입력 + **공개 동의 체크박스** ("이 기억의 조각이 누군가의 장면 끝에 떠올라도 좋다.")
- `saveRecordMemory()` → memories + scenes 저장.
- **`saveUtteranceCandidates()`** — Record 대화에서 발화 후보 5개 추출. PII 자동 필터(이메일/전화/주민번호/URL/긴 숫자/소셜 핸들). `is_public`은 동의 여부, `moderation_status='pending'`.
- **`_autoCreateFirstPlay()`** — Record = First Play 원칙. 기록자의 감정으로 alignment=1.0 play를 장면 수만큼 생성.
- 매장 애니메이션(`burialAnimation.js`) → 아카이브 진입 또는 strata 보기.

## 8. 별이엔진 V4

`js/core/ByeoriEngine.js` · `docs/별이엔진_V4-궤적기반_정렬도-260327.md`

### 8.1 측정하는 것
> **A가 기억을 말했다. B가 그 기억을 읽고 반응했다. A와 B의 경험이 얼마나 비슷한가?**

0~1 사이 alignment score로 산출. **진단·해석·권고는 안 한다.** 상태 정보만 반환.

### 8.2 최종 공식

```
shape_raw = (scenes_played >= 3)
            ? cosine(flatten(delta_user), flatten(delta_original))
            : 1.0
shape     = max(0, shape_raw)
level     = mean(scene_scores)
void_mod  = (user_void && !original_void) ? 0.7 : 1.0

alignment = level × shape × void_mod
```

| 변수 | 의미 |
|---|---|
| `scene_score` | 장면별 체험자↔원본 감정 코사인 유사도 |
| `level` | scene_score 평균 — "장면마다 얼마나 비슷했는가" |
| `shape` | delta 궤적 코사인 유사도 — "감정이 어느 방향으로 움직였는가" |
| `void_mod` | 체험자 VOID이고 원본은 감정 있을 때 ×0.7 |

### 8.3 transition_pattern

| 패턴 | 발생 조건 |
|---|---|
| `echo_follow` | alignment ≥ 0.7 |
| `bridge` | alignment 0.4~0.7 |
| `contradiction` | 감정 미스매치 + shape < 0.3 + 3장면 이상 |
| `displacement` | level ≥ 0.5 AND shape < 0.3 AND 3장면 이상 |
| `avoidance` | alignment < 0.4 AND 최근 void 발생 |
| `fixation` | 이전 버킷 FIXATED OR 복합 신호 (유사도 > 0.85 + 반복 귀인 + 낮은 탐색률) |

> **고착은 횟수 카운트로 판단하지 않는다.** `fixationCounts >= 2`는 설계 위반.

### 8.4 mismatch_type
`void_mismatch` / `attribution_mismatch` / `target_displacement` / `emotion_mismatch` / `null`

### 8.5 bucket
HIGH (≥ 0.7) / MID (0.4~0.7) / LOW (< 0.4) / FIXATED (별도 감지).

### 8.6 감정 좌표
- **17감정 앵커** (`js/shared/math.js` `DEFAULT_EMOTION_ANCHORS`)
- VAD 3D (Valence × Arousal × Dominance)로 투영
- 입력은 6D (`{fear, sadness, anger, joy, longing, guilt}`) — 17D 공간에 부분 매핑. 의도적 근사. (차원 통일은 백로그)

## 10. 오염 시스템

`js/core/ContaminationTracker.js` · `docs/오염벡터_계산_구현_명세_v2-260327.md` (3축으로 진화)

### 10.1 성격
> **이것은 진실 모델이 아니라 연출 제어 모델이다.**
> 오염 벡터의 값은 "틀릴" 수 없다. 표현 강도를 결정하는 제어 변수다.

### 10.2 3축

| 축 | 변수 | 6연산 대응 | 의미 |
|---|---|---|---|
| **Divergence** | `cont_divergence` | 1, 2 (파괴적 복제, 편향 변이) | 궤적이 갈라짐 |
| **Convergence** | `cont_convergence` | 5 (과잉 수선) | 수렴/과선명/고착 |
| **Heterogeneity** | `cont_heterogeneity` | 6 단초 (재조합) | alignment 분산 — 해석 다양성 |

### 10.3 상수
```
DECAY_RATE              = 0.05
FIXATION_CONV_WEIGHT    = 0.4
HIGH_CONV_WEIGHT        = 0.15
MID_CONV_WEIGHT         = 0.03
HETERO_SCALE            = 4.0
DEPTH_THRESHOLD_S2      = 5
MIN_DEPTH_FOR_CONVERGENCE = 3   // v2: 초기 Stage 3 폭주 방지
FIXATION_THRESHOLD      = 0.85
RECOMBO_HETERO_THRESHOLD= 0.5
RECOMBO_DEPTH_THRESHOLD = 5
```

### 10.4 증분 공식 (세션 종료 시 1회)

```javascript
depth += 1
decay = 1 / (1 + depth * DECAY_RATE)
effectiveShape = shape_active ? shape : 1.0

// divergence
delta_div = (1 - effectiveShape) * (1 - level)
divergence += delta_div * decay     (cap 1.0)

// convergence (depth >= 3 게이트)
if depth >= 3:
  if fixation_level >= 0.85:  delta_conv = alignment * 0.4
  elif effShape >= 0.7 and level >= 0.7:  delta_conv = alignment * 0.15
  elif alignment >= 0.5:  delta_conv = alignment * 0.03
convergence += delta_conv * decay   (cap 1.0)

// heterogeneity (Welford)
d1 = alignment - mean
mean += d1 / depth
d2 = alignment - mean
m2 += d1 * d2
if depth >= 2:
  variance = m2 / (depth - 1)
  heterogeneity = min(variance * 4.0, 1.0)
```

### 10.5 Stage 혼합 비율

```
raw_1 = divergence * (1 - convergence)
raw_2 = heterogeneity * min(depth / 5, 1.0)
raw_3 = convergence * (1 - heterogeneity)
total = raw_1 + raw_2 + raw_3

stage_1 = raw_1 / total   // 편향적 기울어짐 (biased_inclination)
stage_2 = raw_2 / total   // 해석 병기 (juxtaposed_interpretations)
stage_3 = raw_3 / total   // 과잉 완결 (hypercompletion)
```

### 10.6 텍스트 렌더링

`js/app/contaminationPresenter.js`가 담당. 로컬 처리(Edge Function 호출 X).

| Stage | 텍스트 변환 | 방향 |
|---|---|---|
| stage_1 (`biased_inclination`) | 단어 사이 `·` 침식 (강도 비례) | divergence |
| stage_3 (`hypercompletion`) | 단어 일부 반복 + `░▒▓` 글리치 | convergence/과선명 |

**시드**: `(sceneIndex × 2654435761) XOR (contDepth × 40503)` → 같은 기억·같은 오염 상태에서 동일 패턴 보장.

> Stage 3 추가 스타일 (`js/contamination.js`): Glitch (`░▒▓█▪▫` 35%) / Redact (`████` 40%) / Dissolve (글자 → 공백 55%).

### 10.7 NPC 내면 독백

`js/ui/contaminationMonologue.js`. 단계 × 감정 × 강도 밴드(weak/medium/strong) 매트릭스.
발화 확률: weak 20%, medium 45%, strong 70%. 시드 동일.

예:
- biased_inclination + anger + weak → "…이게 이렇게 뜨거웠었나."
- hypercompletion + strong → "너무 잘 기억나. 그래서 이상해."
- void_mismatch + strong → "분명히 있었는데. 그게 뭐였는지만 안 떠올라."

### 10.8 재조합 트리거

```

```
조건 충족 시 6연산 6번(재조합) 활성화 가능. (트리거 자체는 구현, 후속 연출은 백로그)

## 13. 잔상 시스템

`docs/잔상_시스템_설계-260409.md` · `js/lib/afterimage.js` · `js/ui/afterimage.js`

### 13.1 작품 테제
> "기억은 원래 남이 했던 말을 내 것이라고 착각하는 것이다."

피드백 #4의 위화감을 버그가 아닌 작품 메시지로 승격. **Cryptomnesia** (잠재기억)의 시뮬레이션.

### 13.2 설계 원칙
1. **먼저 말하지 않는다.** 씬 종료 후 정적이 흐를 때만.
2. **드물어야 한다.** 50% 게이트, 세션당 최대 2회.
3. **절대 확신할 수 없다.** 일부는 본인의 말, 일부는 타인. 비율 비공개.
4. **한 번에 하나만.**
5. **설명하지 않는다.** "…네가 한 말이야" 한 줄은 첫 1-2회만 (로컬스토리지 카운트).
6. **허락받은 말만 쓴다.** 명시적 공개 동의 + 관리자 승인 utterance만.

### 13.3 매칭 (RPC `match_afterimage`)

```
score = keywords∩candidate_keywords × 3
      + emotion_tags∩candidate_tags  × 2
      + (2 - |Δaxis_x| - |Δaxis_z|)  × 1
      + (본인 발화면 +4)
      + random() × 0.3

→ 상위 5개 → 그중 1개 랜덤 픽
→ 이미 본 utterance 제외 (afterimage_events dedupe)
```

**진실 30% / 타인 70% 전략**: 클라이언트가 `preferOwn=true`로 호출하면 본인 발화에 +4 가중. 확실한 본인 매칭이 있으면 우선됨.

### 13.4 수집 파이프라인

Record 종료 시 `saveUtteranceCandidates()`:
1. user 메시지 추출 → 시스템 마커(`[...]`) 제거
2. 길이 필터 (3~280자)
3. **PII 자동 reject**: 이메일, KR/국제 전화, 주민번호, URL/도메인, 10자리 이상 숫자, 소셜 핸들
4. SKIP_WORDS 가중치 감산 ("응", "yes", "ok" 등)
5. 상위 5개만 저장
6. `is_public`은 사용자 동의 체크박스, `moderation_status='pending'`

### 13.5 모더레이션
admin.html의 `잔상` 탭. pending/approved/rejected 필터 + 언어 필터 + 개별 승인/거절/공개토글/삭제. RLS로 일반 사용자는 텍스트 변경 불가 (트리거).

### 13.6 연출 (`js/ui/afterimage.js`)

## 16. 안전 시스템

`js/safety.js` · `docs/안전_설계-260324.md`

### 16.1 3단계 필터링

| 단계 | 동작 | 키워드 예 |
|---|---|---|
| `BLOCK_HIGH` | 즉시 세션 중단 + 위기 대응 리소스 | 자살, 살인, 강간, 성착취 |
| `BLOCK_MID` | 경고 다이얼로그 + 계속 여부 선택 | 죽여버리, 학교 폭력 |
| `MONITOR_ONLY` | 통과 + 로그 (TEM의 핵심 소재) | 우울해, 사라지고 싶어, 허무해 |

### 16.2 N회차 트리거 + 시제 감지 (피드백 #23/#25)
- 단발 트리거어로 즉시 블락 안 함
- 시제 분석 ("죽었었어" vs "죽고 싶어") + n회 누적
- 누적 후 에스컬레이션 → BLOCK
- 블락 후 3초 후 복귀 + 컨테이너 정리

### 16.3 페르소나 — "또다른 나"
모든 안전 메시지는 시스템 경고가 아니라 **거울 속의 내가 속삭이는 톤**.

| 카테고리 | 예 |
|---|---|
| 위기 반응 | "...아냐, 이건 너무 날카로워." / "이 이상 파고들면, 내가 다쳐." |
| 침묵 반응 | "그래, 굳이 입 밖으로 낼 필요 없어." / "침묵도 대답이 될 수 있어." |
| 악의 반응 | "상처만 내서는 닿을 수 없어." / "이렇게 부수기만 해서는... 아무것도 안 보여." |

### 16.4 침묵 = 데이터
"말하지 않음"을 시스템 이탈이 아닌 **의미 있는 여백(VOID)**으로 처리. 별이엔진의 `void_mod`로 전달됨.

## 17. i18n / 설정

`js/lib/i18n.js`

### 17.1 규칙
- **UI 크롬만** 번역 (메뉴, 버튼, 알림, 플레이스홀더)
- **기억 내용**(장면 텍스트, 선택지)은 번역 안 함 — 작성자 언어 그대로
- **"또 다른 나" 목소리**는 체험자 언어 설정을 따름
- 기본 언어는 **영어**. 브라우저 로케일 자동 감지 없음.

### 17.2 `t(key)` 동작
1. 현재 언어에서 탐색
2. 없으면 English 폴백
3. 거기도 없으면 key 그대로

`data-i18n` attribute가 있는 DOM은 자동 갱신. `tem:languagechange` 이벤트로 동적 렌더링 모듈 반응.

### 17.3 밝기
`document.documentElement.style.filter = brightness(v)`. 0.5~1.5 범위. localStorage 저장.
