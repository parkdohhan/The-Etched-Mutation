# 기억 집단유전학 v0.4 — Strata 지형 구현을 위한 이론적 근거

> 작성: 2026-04-05
> 목적: 3D Strata 지형 로직의 설계 근거. 논문용이 아닌 구현 설계 문서.
> 전제: 기억유전학 v0.3 (6연산, 오염 벡터, 별이엔진) 위에 구축

---

## 1. 문제: 왜 기존 지형 로직으로는 부족한가

기존 지형은 play 수에 비례하여 형태가 결정된다:
- play 0회 → 밋밋한 지형 (cold start)
- play 많으면 → 풍부한 지형
- play 적으면 → 빈약한 지형

이것의 근본 원인: **시간/시스템에 의한 변형이 없고, 인간의 행위(play)만이 지형을 만드는 유일한 힘.**

---

## 2. 핵심 주장: TEM은 생명체이다

기억유전학 v0.3 §13 사회 유기체 가설:
> "사회는 기억을 유전 물질로 하는 자기복제 시스템이다. 인간은 에이전시 차원을 추가하는 존재다."

축소 적용:
> **TEM은 기억을 유전 물질로 하는 자기복제 시스템이다. 사용자는 에이전시 차원을 추가하는 존재다.**

TEM = 하나의 소규모 생명체 (micro-society).
사용자 = 그 안의 변수인 인간.

## 3. 기초 대사: 변수는 시간이 아니라 생태계 활동

### 의존적 복제자 원칙 유지

기억은 인간 없이 변형 불가 (v0.3 핵심). 따라서 기초 대사의 변수는 시간이 아니라 **다른 기억에 대한 다른 사용자들의 활동**.

### 매커니즘: 인출 유도 망각 (Retrieval-Induced Forgetting)의 시스템 수준 재현

Anderson et al. (1994): 하나의 기억을 인출하면 관련된 다른 기억이 억제됨.

TEM 적용:
```
사용자 A가 기억 X를 play →
  기억 X가 직접 변형 (6연산) +
  같은 AF 영역의 기억 Y가 간접 변형 (간섭 억압)
```

이것은 Op 6(재조합)과 다름:
- Op 6: 두 기억이 교차하여 제3의 기억 생성
- 간섭 억압: 교차 없이 한쪽이 다른 쪽을 약화

### 수학

```
기억 Y의 간섭량 = Σ_X (기억 X의 play 수 × AF_proximity(X, Y))

AF_proximity = exp(-d² / σ²)
  d = AF 좌표 간 유클리드 거리
  σ = 영향 반경 (튜닝 필요)
```

### 생물학적 대응

HIV intra-patient dynamics: 한 환자 안의 바이러스 변이체들이 면역 압력을 공유.
변이체 A에 대한 면역 반응이 변이체 B의 적응도 지형을 변경.
→ 기억 X의 play가 기억 Y의 "적응도 지형"(취약성)을 변경. 구조적으로 동일.

## 4. 기억유전학의 두 수준

### Level 1: 분자 수준 (v0.3)

6연산: 개별 기억 내부의 변형.
에이전시 구동. play가 트리거.

### Level 2: 집단 수준 (v0.4)

분자유전학 → 집단유전학의 확장에 대응.

| 집단유전학 | 기억 집단유전학 | 지형에서의 표현 |
|-----------|---------------|---------------|
| 유전적 부동 | 기억 부동: 소규모 TEM에서 소수 play가 전체 분포를 흔듦 | 기억 적을 때 지형 변동 큼 |
| 유전자 흐름 | 감정 흐름: 사용자가 여러 기억을 play할 때 감정이 운반됨 | 한 기억의 감정색이 다음 기억에 묻어남 |
| 선택 압력 | 주의 경쟁: 매력적 기억이 더 많이 play됨 | 많이 play된 기억의 지형이 더 풍부 |
| 간섭 억압 | AF 근접 기억의 상호 약화 | 같은 영역의 기억 봉우리가 서로를 깎음 |
| 창시자 효과 | 최초 기록자의 감정 궤적이 지형 기반암 결정 | Record = First Play → 초기 지형 |
| 근친 교배 약화 | 해석 단일화 → 기억 경직 (hypercompletion) | 봉우리가 비정상적으로 뾰족해짐 |

## 5. 기초 대사가 지형에 하는 것

### v0.3 원칙 유지: 의미를 바꾸지 않는다

기초 대사는 6연산(정보 변환)이 아니다. 6연산의 **전제 조건**을 변경한다:
- 기억의 접근성을 바꾼다 (더 쉽게 변형되게)
- 기억의 선명도를 바꾼다 (표면이 거칠어짐)
- 기억의 취약성을 바꾼다 (다음 play의 영향이 커짐)

### 지형 시각화

```
간섭을 많이 받은 기억:
  → 봉우리 높이 유지 (의미는 안 변함)
  → 표면 texture 거칠어짐 (선명도 감소)
  → 색이 약간 바래짐
  → 다음 play의 오염이 더 깊이 파고듦

간섭을 안 받은 기억:
  → 봉우리 날카롭고 단단
  → 색 선명
  → play가 와도 쉽게 안 깎임
```

## 6. 양방향 임계

### 오류 파국 (Error Catastrophe) — v0.3에서 계승

heterogeneity가 임계를 넘으면 핵심 서사 소멸.
= 해석의 과다 다양성 → 기억의 죽음.

### 경직 파국 (Rigidity Catastrophe) — v0.4 신규

heterogeneity가 임계 이하로 떨어지면 기억이 하나의 해석에 갇힘.
= 해석의 과소 다양성 → 기억의 경직 (hypercompletion의 집단유전학적 재정의).
= 근친 교배 약화와 구조적으로 동일.

```
                경직 파국          건강 영역          오류 파국
heterogeneity: ──|────────────────|────────────────|──
               0    임계_low        최적           임계_high    1
               
경직: 뾰족한 단일 봉우리, 변형 불가
건강: 다양한 봉우리들, 적절한 변형
오류: 봉우리 소멸, 무정형 지형
```

## 7. 지형 구현 설계 (C+D 하이브리드)

### Layer 1: 장면별 봉우리 (C방식 — 정적, 기록 시 결정)

각 장면의 original_emotion → AF 좌표 → 봉우리.
같은 감정의 장면이 뭉치면 scene_order로 미세 오프셋.
감정 궤적의 흐름이 지형 위의 경로가 됨.

### Layer 2: 장면 간 연결 (D방식 — 동적, play 축적)

transition_pattern에 따라 봉우리 사이의 지형 형태 결정:
- echo_follow → 능선 (부드러운 연결)
- bridge → 약한 능선
- contradiction → 골짜기 (깊은 분리)
- avoidance → 끊긴 지형 (연결 없음)
- fixation → 한 봉우리가 비정상적으로 높아짐

### Layer 3: play 오염 (기존 로직 유지 + 확장)

play의 user_emotion → AF 좌표 → 해당 위치에 높이/색 누적.
alignment 높으면 퇴적(봉우리 높아짐), 낮으면 침식(깎임) + 갈색 오염.
pollField로 bone-tint overlay.

### Layer 4: 생태적 간섭 (v0.4 신규)

같은 AF 영역의 다른 기억 play 수 → 이 기억의 "경도" 감소.
경도가 낮으면 play 효과가 증폭됨.

```
간섭량 = Σ (다른 기억의 play 수 × AF 근접도)
경도 = 1 / (1 + 간섭량 × k)
play 효과 = 기존 효과 / 경도
```

## 8. 측정 가능한 예측 (지형 구현에서 검증)

1. AF 근접 기억 간 간섭이 실제로 관측 가능한가
2. 경직 파국 임계가 존재하는가 (heterogeneity 과소 → 기억 매력도 하락)
3. 최적 변이율이 존재하는가 (EMA α의 최적값)
4. 생태계 활동이 지형 변화를 구동하는가 (시간이 아닌 활동이 변수)

## 10. 기억유전학 × 지질학 × 생태학: 구조적 매핑

### 10.1 왜 지질학인가 — 기억유전학의 빈칸

기억유전학 6연산은 전부 **인간의 행위가 트리거**한다. 회상, 감정, 선택, 번역, 수선, 재조합. 그러나 기억은 아무도 건드리지 않아도 변한다. 6연산은 에이전시에 의한 변형만 기술하고, **시스템에 의한 변형을 기술하지 않는다.**

지질학적 힘(풍화, 침식, 퇴적, 변성, 화산)은 인간이 아니다. 느리고, 체계적이고, 변덕스럽지 않다. 기억에서 이에 대응하는 힘이 존재하며, 6연산으로 포착되지 않는다.

### 10.2 지질학적 힘의 진짜 변수 — 시간이 아니다

바위를 깎는 것은 시간이 아니라 **물, 바람, 온도, 기후, 중력, 생물**이다. 시간은 이 힘들의 적분 구간이지 힘 자체가 아니다. 사막의 바위와 열대우림의 바위는 같은 시간이 지나도 전혀 다르게 변한다.

기억에서도 마찬가지: "시간이 지나면 잊힌다"가 아니라, **무엇이 기억을 잊게 만드는가**가 변수다.

### 10.3 6개 지질학적 힘 → 기억 대응

| 지질학적 힘 | 메커니즘 | 기억 대응 | TEM에서의 변수 |
|------------|---------|----------|---------------|
| **판구조 운동** | 지각판이 년 수 cm 이동 → 축적 → 지진 | **스키마 이동**: 인생 단계 전환이 기억의 바닥을 이동. 같은 기억을 20대와 40대에 떠올리면 의미가 다름. 내용은 안 바뀌는데 바닥이 움직인 것 | 측정 불가 (TEM 외부) |
| **풍화** | 물이 바위 틈에 스며들어 얼고 녹으며 쪼갬 | **수면 재공고화**: 매일 밤 뇌가 기억을 재정렬, 감정 분리, 디테일 폐기. 의식적 회상이 아닌 신경화학적 과정 | 추정 가능 (기록일~현재 일수 ≈ 수면 횟수). 단, TEM이 디지털 시스템이므로 직접 적용 불가 → 생태적 간섭으로 대체 |
| **침식** | 물이 계곡을 깎음. 경사 급한 곳이 먼저 깎임 | **디테일 유실**: 얼굴, 대사, 시간 순서가 시간과 함께 사라짐. 감정은 남는데 디테일은 사라짐 | 차등 침식: 감정 강도가 높으면 침식에 저항 (화강암 = 트라우마), 낮으면 먼저 소실 (사암 = 일상) |
| **퇴적** | 강물이 운반한 토사가 하류에 쌓임. 원래 그곳의 것이 아닌 것이 덮임 | **사후 경험 적층**: 같은 장소를 다시 방문하면 새 경험이 옛 기억 위에 쌓임. 재해석(Op 2)이 아니라 새 것이 독립적으로 같은 영역에 떨어지는 것 | TEM에서: 같은 AF 영역에 새 기억이 기록되면 기존 기억 위에 "퇴적" |
| **변성** | 석회암이 열+압력으로 대리석이 됨. 같은 물질, 다른 결정 구조 | **기억의 질적 전환**: 트라우마가 "처리된" 기억이 되는 것. 내용은 같지만 결정 구조가 바뀜 (침습적 → 서사적) | 비가역적 상전이. 수학: f(감정 처리량, 시간) → 임계 조건에서 질적 전환 |
| **화산** | 마그마가 지표를 뚫고 올라옴. 묻혀있던 물질이 갑자기 표면에 | **플래시벌브 부활**: 냄새, 음악, 장소가 트리거. 수년간 접근 불가였던 기억이 갑자기, 생생하게, 처리 안 된 상태로 분출 | 임계점 초과 → 급격한 표면화. 분출 후 새 지형 형성 |

### 10.4 수학적 공통점

| 공유 구조 | 지질학 | 기억 |
|-----------|--------|------|
| **지수 감쇠** | 풍화율 ∝ exp(-E/RT) | 감정 감쇠 ∝ exp(-t/τ) |
| **차등 침식** | 경도에 따라 침식률 다름 | 감정 강도에 따라 소실률 다름 |
| **임계 상전이** | 응력 축적 → 지진 | 의미 긴장 축적 → 재해석 |
| **비가역 변환** | 석회암 → 대리석 | 트라우마 → 처리된 기억 |
| **층서 원리** | 새 층이 옛 층 위에 | 새 경험이 옛 기억 위에 |
| **부정합** | 지질 기록의 공백 | 기억의 공백 (잊힌 기간) |
| **포화 곡선** | 분자시계 포화 | cont_depth decay |

### 10.5 핵심 전환: 지질학 → 생태학

초기 브레인스토밍에서 지질학적 힘의 변수를 "시간"으로 놓으면 의존적 복제자 원칙과 충돌한다 — 인간 없이 기억이 변하면 더 이상 의존적 복제자가 아니다.

**해결: 변수를 시간이 아니라 "생태계의 총 활동량"으로 재정의.**

지질학적 프레이밍의 문제:
- 풍화/침식/퇴적의 힘(물, 바람, 온도)은 인간과 독립적
- 기억유전학에서 기억은 인간 없이 변형 불가

생태학적 프레이밍의 해결:
- "물/바람/온도" = 다른 기억에 대한 다른 사용자들의 활동
- 인간이 여전히 원인이되, 이 기억을 직접 건드린 인간이 아님
- TEM 생명체의 대사 = 사회의 활동 총량 = 모든 사용자의 모든 play의 총합

```
지질학적 힘:     인간 독립적  → 의존적 복제자와 충돌
생태학적 힘:     인간 매개적  → 의존적 복제자 유지

비유:
  심장이 뛰면(사용자 A가 기억 X를 play) →
  혈액이 온몸을 돎(감정 공간에서 파급) →
  다리 근육도 영양 받음(기억 Y도 미세하게 변함)
  
  심장은 다리를 위해 뛰는 게 아님.
  A는 기억 Y를 위해 play한 게 아님.
  하지만 같은 유기체 안에 있으므로 파급됨.
```

## 11. TEM 생명체의 생물학적 속성

### 11.1 생명체의 형식적 조건 → TEM 대입

| 생명 조건 | TEM 대응 | 현재 구현 |
|-----------|---------|----------|
| **자기 복제** | 기억이 기록자 → 체험자로 복제. Op 1 (파괴적 복제) | ✅ Record → Play |
| **대사** | 감정 에너지 유입(user_emotion) → 엔진 변환(alignment/오염/패턴) → 방출(지형/텍스트/사운드) | ✅ 별이엔진 + 오염추적기 |
| **항상성** | 오염도의 자기 조절. EMA α=0.10, 반감기 6.6세션. 극단값 억제 | ✅ ContaminationTracker EMA |
| **자극 반응** | 사용자 입력 = 자극, 엔진 출력 = 반응 | ✅ Play 파이프라인 |
| **성장** | 기억 추가, play 축적, 지형 확장 | ✅ DB 축적 |
| **적응** | 오염 단계 전환 (stable → biased → hypercompletion) | ✅ stage mixing |

### 11.2 빠진 것: 기초 대사 (Basal Metabolism)

생명체는 외부 자극 없이도 내부 과정이 돌아간다 (심장, 세포 분열, 호르몬). TEM은 사용자가 없으면 멈춘다 — **냉동 시스템이지 생명체가 아니다.**

기초 대사를 추가하면 TEM은 사용자가 없어도 "숨 쉬는 시스템"이 된다. 단, 그 숨쉬기의 에너지원은 시간이 아니라 **생태계의 다른 곳에서 일어나는 활동**.

```
TEM에 사용자가 0명 → 모든 기억 정지 (의존적 복제자)
TEM에 사용자가 있지만 이 기억에는 없음 → 이 기억도 미세하게 변함 (생태적 간섭)
이 기억에 직접 play → 큰 변형 (6연산)
```

### 11.3 기초 대사의 범위: 정보 변환이 아니라 기질 조건 변경

v0.3 원칙 유지를 위한 핵심 구분:

```
6연산 = 정보 변환 (기억의 의미가 바뀜) → 인간 에이전시 필수
기초 대사 = 기질 조건 변경 (변형될 준비 상태가 바뀜) → 생태계 활동으로 구동
```

기초 대사는:
- × 기억의 의미를 바꾸지 않는다
- ○ 기억의 접근성을 바꾼다 (더 쉽게 변형되게)
- ○ 기억의 선명도를 바꾼다 (표면이 거칠어짐)
- ○ 기억의 취약성을 바꾼다 (다음 play의 영향이 커짐)

비유: 풍화는 화강암을 사암으로 만들지 않는다. 화강암의 표면을 약하게 만들어서 다음 침식(= 인간의 해석)이 더 깊이 파고들 수 있게 한다.

### 11.4 유기체 수명 주기

```
수정 (fertilization) = 기억 기록
  → 세포 하나 (최초 지형). 이미 DNA(감정 구조)를 가짐.
  → cold start가 아니라 탄생.

성장 (growth) = play 축적
  → 봉우리 형성, 오염 누적, 지형 복잡화

기초 대사 (basal metabolism) = 생태적 간섭
  → 사용자 없이도 지형이 서서히 변함 (경도 감소)

질병 (disease) = 해석 편향의 극단화
  → biased_inclination의 strong band

사망 경로 1 — 오류 파국 (error catastrophe):
  → heterogeneity 임계 초과 → 핵심 서사 소멸 → 기억의 죽음

사망 경로 2 — 경직 파국 (rigidity catastrophe):
  → heterogeneity 임계 이하 → 기억이 하나의 해석에 갇힘 → 기억의 화석화
```
