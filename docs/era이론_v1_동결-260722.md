## 0. 역할 경계 (2026-07-28 사용자 결정)

**저자가 하는 것은 프레임워크 제시까지다. 증명은 후속 연구자의 몫이다.**

이 이론의 완성 관문 두 개(실인간 데이터, 실제 수학)는 모두 **저자여야만 하는 이유가
없는 일**이다. 반면 이 질문을 잴 수 있는 **작동하는 장치**를 만드는 일은 저자만 할 수
있다. 따라서 기여 유형을 "증명"이 아니라 **장치·시험대·사전등록된 예측 세트**로 확정한다.

| 저자 몫 (남김) | 후속 연구자 몫 (넘김) |
|---|---|
| 프레임워크 문서 고정 (인용 가능한 형태) | 층·사이트의 수학적 구성, 정리, 증명 |
| 사전 등록 제약 강화 (§6) | 환원 반론 정면 방어 |
| **정렬도 실측 1회** (§2-1 간극 해소의 최소 조건) | 피험자 규모 인간 검증 |
| 도구·데이터 재현 가능 형태로 공개 | 이중 절편 형식화 (§7) |
| §5 = "여기부터 당신 차례" 목록 | era 이론 독립 논문 게재 |
| 작품이 계속 데이터를 낳는 구조 | |

**단 하나의 조건**: 정렬도를 한 번도 측정하지 않은 채 "정렬도로 경계를 찾으라"고
넘기면 그것은 프레임워크가 아니라 숙제다. §2-1의 간극을 최소 1회 실측으로 메우는 것이
넘기기 위한 전제다. 결과가 이론에 불리해도 무방하다 — 실패한 실측도 후속 연구의
출발점으로 유효하다.

## 1. 존재론 (확정)

- **기억은 발화 공간의 존재다.** 머릿속의 것은 측정 불가능한 무엇으로 이론 **바깥**.
  기억은 A가 B에게 언어로 발화하면서 나타나고, B의 해석과 언어-머릿속-언어 재토출
  과정을 거치며 궤적(모양)을 바꾼다. 이론은 발화 공간의 측정치 위에서만 양화한다.
- **era** = 완결된 기억 조각. 형식 서명 = **(n, 요동 궤적, p)의 닫힌 모양**:
  정렬도 n에서 열려, 요동치며 몸통을 만들고, p로 수렴하며 닫힌다.
- 수렴값 p가 era 전체의 색을 라벨링한다. 완결 ≠ 이해 — 이해 못 한 채(낮은 p),
  공명하며(높은 p), 의심스러운 채(중간 p) 닫힐 수 있다. 완결 = 관계의 안정화.
- **형태 불변의 의미**: 완결된 era는 닫힌 모양이며, 이후의 발화는 그 era를 편집하는
  것이 아니라 **새 era를 낳는다** (파괴적 복제와 합류). 영원한 원본 주장 아님 —
  발화-시점 상대적 불변. 순수 원본 부재 공리와 충돌 없음.
- **맥락은 정의하지 않는다** (사용자 확정). 인식되기만 하면 맥락이므로 맥락=전부이고,
  전부인 항은 이론에서 무의미(프레임 문제 회피). 맥락은 이론 외부의 경계 조건이며,
  이론에 남는 그림자는 Δ 하나뿐 (§3).

## 2. 경계와 내부 (원 핸드아웃 §5의 수정)

- **소강 = 경계.** 정렬도의 진폭이 0으로 수렴하는 지점 = era가 스스로 닫히는 곳 =
  자연스러운 절단점. 조작적 정의: 국소 분산이 영모형 아래꼬리(P5↓)로 떨어지는 구간
  ("단 한순간"이 아니라 창(window) 기반 — 진폭은 창 없이 정의 불가).
- **요동 = 내부.** 자르면 변질되는 곳. 조작적 정의: 인접 델타가 영모형 위꼬리(P95↑)
  초과. (원 핸드아웃은 "요동=경계=절단 후보"로 썼으나 이는 §6 "요동 관통=변질"과
  이중이었음. E1·E2 데이터가 수정판을 지지: 의미 보존 절단 = 매끄러운/소강 인접
  이음매, 변질 절단 = 요동 관통.)
- 할머니 사례의 재서술: 1(요리)·2(혼남)에서 끊는 것은 아직 닫히지 않은 몸통을 찢는 것.
  1·2·3(화해)까지가 닫힌 era.

### 흔한 오독 3종 (2026-07-28 추가 — 저자 본인이 미끄러진 자리)

1. **"정렬도가 0" ≠ "정렬도의 진폭이 0".** 소강이 보는 것은 값의 높이가 아니라
   **평평해짐**이다. 정렬도가 최저인 지점은 오히려 요동 한복판일 수 있다
   (예: 0.78 → **0.29** → 0.71 — 값은 최저지만 절대 잘라선 안 되는 몸통 속).
   심전도 비유: 선이 낮은 것과 선이 평평해지는 것은 다른 사건이다.
2. **값이 낮은 채로 잠잠해도 소강이다.** 0.05가 다섯 턴 이어지면 닫힌 것이다 —
   끝까지 안 통한 채로 완결된 era. §1 "완결 ≠ 이해"의 측정 판본. 닫힘은
   "잘 됐다"가 아니라 "더는 움직이지 않는다"이다.
3. **경계는 점이 아니라 구간이다.** 단일 턴에는 진폭이 정의되지 않는다(사진 한 장에
   속도가 없는 것과 같다). 잠잠한 **띠**를 검출한 뒤 대표점을 찍는 것이지, 순간을
   찍는 것이 아니다. §4 창 길이 규칙 참조.

## 2-1. 정렬도의 두 항 — 무엇과 무엇을 대는가 (2026-07-28 신설)

이론 전체가 정렬도 위에 서 있는데 v1 동결본은 **대는 두 항을 명시하지 않았다.**
그 결과 이론이 쓰는 정렬도와 구현이 계산하는 정렬도가 다른 물건인 채로 남았다.

### (1) 왜 정렬도인가 — 존재론에서 연역된 것

§1이 머릿속을 이론 밖으로 내보낸 순간 잴 수 있는 것은 **관계**뿐이다. 대안은 전부
탈락한다: 화자 감정 강도(한 사람 안에서 완결 → §1 자폭) · 주제 이동 거리(감정 소실) ·
발화 리듬/침묵(말버릇에 지배, 관계 무관). 또한 §1이 완결을 **"관계의 안정화"**로
정의했으므로, 관계를 재는 양이 아니면 "닫혔다"는 술어 자체가 성립하지 않는다.
정렬도는 편의가 아니라 강제다.

### (2) 이론판과 구현판이 어긋나 있다

| | 이론 (핸드아웃 §4) | 구현 (`js/core/ByeoriEngine.js` V4) |
|---|---|---|
| 왼쪽 | 화자의 발화 | 플레이어가 고른 감정 |
| 오른쪽 | **살아있는 청자 B의 수용** | **저장된 original(첫 서술 궤적)** |
| 시간 | 실시간 상호작용 | 비동기 (기록 대 현재) |
| 단위 | 발화 턴 | 씬 |

구현판 = `level × shape × void_mod`, 판단 좌표계는 260727 기억별 좌표계
(씬 anchor > 기억 저작 어휘 > 판단 기본 17축). **이것도 관계이긴 하나 비동기 관계다.**

### (3) 검증 데이터에 정렬도가 없다

`plays.dialog_turns` 각 턴 = `{turn, raw_text, fingerprint, ts}`
(마이그레이션 `20260503000000_v21_ghost_variants_and_dialog_turns.sql`).
fingerprint는 SeekerMatchEngine 매칭용 감정 지문이지 정렬도가 아니다.
**§6 예측 1·2를 돌리려면 "턴마다 무엇과 대는가"를 먼저 확정해야 한다.**

### (4) 대는 상대 후보와 결정

| 후보 | 판정 |
|---|---|
| ① 턴 ↔ 해당 기억의 original | ⚠️ **덫.** 한 씬 안 여러 턴에서 오른쪽이 상수 → 진폭이 전부 왼쪽에서만 발생 → 사실상 화자 자기상관으로 퇴화. (1)에서 탈락시킨 "화자 감정 강도"와 같은 물건이 된다. 겉보기엔 정상 작동하므로 발견이 어렵다 |
| ② **턴 ↔ 직전 상대 발화** | ✅ **채택.** 오른쪽이 매 턴 갱신되어 발화-수용 쌍 정의에 부합. 유령/Another Me가 청자 B 역할. 필요 배선 = 상대 발화의 감정 벡터를 턴마다 산출·누적 (`ghost_variants.emotion_vec` 재료 존재, 실시간 배선 없음) |
| ③ 턴 ↔ 자기 직전 턴 | ❌ 관계 부재. §1 위반 |

**미해결로 남기는 것**: 청자가 사람이 아닐 때(②의 상대가 AI일 때) 이 정렬도를
사람-사람 정렬도와 같은 양으로 볼 수 있는가. 이론 내부에서 답이 없다.

### (5) 그리고 이것이 실증 해석을 제약한다

E1·E2는 요동을 **작가측 감정 델타**로 대리했다(E1 §3-1 자백). 즉 두 실험은
**관계적 존재론(§1·§3)을 통째로 지워도 그대로 성립한다** — 검증된 명제는
"이음매가 거친 절제가 전역 감정 절편을 더 이동시킨다"이며, 이는 콘텐츠 배열 명제이지
관계 명제가 아니다. **이 이론 고유의 항(정렬도)은 아직 한 번도 측정되지 않았다.**

> 발표·논문에서 E1·E2를 "관계 이론이 입증됐다"로 요약하는 것은 오진술이다.
> 정확한 진술: **"절단 의미론은 예비 지지를 받았고, 관계적 측정 축은 아직 미검증이다."**

## 3. 연산과 상속 (확정)

- **연산 2종**: ① **제한**(끝점 절단 — 부분구간 위 절편, 바탕 공간 불변)
  ② **봉합**(중간 절제 — 씬 제거 + 원래 없던 인접 변 생성 = 바탕 공간 수술).
  이음매 거칠기 = 새 변에 걸리는 전이 제약 위반량 (Track B 변 제약과 동일물).
- **상속**: era 사슬에서 **Δ = n_{k+1} − p_k (점프량)**. 맥락의 유일한 관측치.
  Δ≈0 = 매끄러운 상속, 큰 Δ = 맥락 개입 사건. "모든 것은 물려받는다"는 정의상
  참이라 반증 불가 — 반증 가능한 내용은 Δ 통계에만 있음 (§6-③).
  점프의 결 분류는 새 어휘 금지 — 기존 transition pattern 6종 재사용.
- 바탕 공간의 도출: 꼭짓점 = 소강점, 변 = era. Track B가 가정한 씬 그래프를
  본 이론이 동역학에서 도출하는 구조 (상류-하류 관계 완성).

### 창 길이 규칙 (2026-07-28 추가 — v1의 누락 보완)

v1은 "창 기반"이라고만 쓰고 **창 길이를 정하지 않았다.** 창 길이는 자유
파라미터이며, 바꾸면 소강 위치가 바뀐다(3턴 창의 소강이 7턴 창의 요동 한복판일 수
있음). 아래꼬리 P5도 창 길이에 의존한다. 결과를 보고 창을 고를 수 있으면 그 자체가
연구자 자유도이므로, 데이터 접촉 전에 다음을 고정한다.

1. **주 분석 창 = 3턴** (진폭 정의의 최소값). 사후 변경 금지.
2. **민감도 분석 의무**: 3·5·7턴 전부 돌리고 **전부 보고**한다. 세 창에서 결론이
   갈리면 "창 의존적"으로 보고하며, 유리한 창만 고르는 것을 금지한다.
3. 대화 길이가 창의 4배 미만인 세션은 분석에서 제외 (제외 건수도 보고).

## 6. 사전 등록 예측 (2026-07-22 동결 — 베타 데이터 확보 전)

베타 실관객 dialog_turns (run_id 배선 완료, 커밋 57220d0) 턴 단위 정렬도 시계열에서:

1. **감쇠 예고**: 자연 종결된 발화/회차는 종결 직전 정렬도 진폭(국소 분산)의 유의한
   감소를 보인다. 외부 중단된 발화는 감쇠 없이 끊긴다 (미완결감의 정량 정의).
2. **소강 경계**: 소강 지점에서 자른 재제시가, 요동 관통 재제시보다 전역 인상
   (감정 분포·한 문장)을 유의하게 덜 이동시킨다 (E1·E2의 실인간 복제).
3. **Δ 상속**: 연속 era의 (p_k, n_{k+1}) 쌍 거리가 셔플 짝짓기 영모형보다 유의하게

예측이 기각되면 해당 관절을 기각한다 — 골대 이동 금지.

### 제약 강화 (2026-07-28 추가 — 베타 데이터 미확보 상태)

예측 1~3의 **문구·방향은 수정하지 않았다.** 아래는 통과를 어렵게 만드는 방향의
추가 제약이며, 느슨화가 아니므로 사전 등록 원칙에 위배되지 않는다.

**(가) 창 길이** — 예측 1·2에 §4 창 길이 규칙(주 분석 3턴 + 3·5·7 전수 보고)을
구속 조건으로 부가한다.

**(나) 예측 3의 영모형 교체** — 전역 셔플 대조는 **너무 약하다.** 정렬도가 시간에
대해 부드러운 신호이면 인접 쌍이 임의 쌍보다 가까운 것은 자기상관만으로 거의 자동
성립한다(기온의 인접 시각이 임의 시각보다 가까운 것과 같음). 그대로 두면 예측 3은
통과해도 아무것도 입증하지 못하고 사실상 반증 불가능해진다. 따라서:

1. **주 영모형 = 등거리 쌍 대조.** (p_k, n_{k+1}) 거리를 **같은 세션 내에서 시간
   간격이 동일한 임의 쌍**의 거리 분포와 비교한다. 자기상관을 대조군에 흡수시켜
   "인접해서 가까운 것"과 "물려받아서 가까운 것"을 분리한다.
2. **보조 영모형 = 블록 셔플.** era 단위 덩어리째 순서를 섞어, 국소 연속성을 보존한
   채 사슬 구조만 파괴한다.
3. 기존 전역 셔플 대조는 참고치로만 보고한다. **주 판정 = 1번.**

**(다) 판정 순서 고정** — 예측 3은 (나)-1을 통과할 때만 성립으로 본다. 전역 셔플만
통과하고 등거리 쌍 대조에서 떨어지면 **기각**으로 기록한다.
