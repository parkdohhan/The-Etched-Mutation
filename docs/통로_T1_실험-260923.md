## 7. 알려진 한계 · 본 코드 수정이 필요한 항목

**실험 자체의 한계**
- 장면 프리셋 5는 가상 17축 벡터. 실제 별이엔진 출력(패턴·정렬도·오염)은 안 불렀다 — 사람이 조절판으로 고른다. 실 DB 씬으로 돌리면 mN·r2 분포가 다를 수 있다.
- 길이 규칙 L* 는 echo_follow 에만 정확히 성립한다(§2.2). bridge·contradiction 은 형태상 최소 길이가 있어 정렬도가 높을 때 길이가 정렬도에 반응하지 않는다. contradiction HIGH 는 상한 1.6 을 넘는다(×1.62).
- contradiction 세 쌍의 되돌림이 바닥값에 걸려 거의 같다(§4.2·§5 #3). "같은 라벨 다른 기하"는 현재 avoidance 쌍과 contradiction 중간 불룩에서만 성립.
- 1인칭에서 contradiction 은 꺾이는 방향이 거의 안 보이고, 05 입구 컷은 "언덕 사이 골"로 보인다. 카메라 높이·안개 벽 대비 재검토는 미착수.
- avoidance 1인칭은 "길처럼 보이는데 막힘"(§4.5). 의도("소리만 있는 통로")와 관객 경험이 어긋날 수 있다.
- 1인칭 힌트에 도착 장면명이 회랑 열리기 전에도 떠 있다(실험 편의, 관객 화면 기준으로는 정보 노출).
- 발산 0.9 잔떨림 <2px 은 6줄 중 4줄에서만 확인, 1줄 3px, 1줄 측정 오류. 더 정밀한 측정은 안 했다.
- 수준별 폭(HIGH/LOW/FIXATED)·이질 0.9 폭 얼룩 캡처는 없다(실측 수치만 §2.2). 동작 중간 프레임(0.8/1.5/2.2초)은 scratchpad 에만 있고 문서 폴더에 없다.
- 조감 자동 프레이밍이 헐렁하고 되돌림 깊은 쌍(a≤0.7)에서 지형 가장자리(밝은 띠)가 보인다.
- 헤드리스 SwiftShader 렌더라 실제 GPU 화면과 밝기가 다를 수 있다. 판정은 가능하면 페이지를 직접 열어서.

**무대(본 코드)로 옮기려면 수정이 필요한 것** — 이번 실험은 전부 페이지 안에서 해결했고 본 코드는 0줄
- 결 uniform(가장자리 일렁임 배수·주파수·벽 결·이질 얼룩·벽 얇아짐)은 페이지 셰이더 전용 — 본 지형 셰이더(`js/shared/tem_af_strata_terrain.js` `_sfPatchShader`)에 같은 uniform 이 없다.
- avoidance 의 방향성 있는 벽 얇아짐 — 안개 모듈 `setOptions.wallStrength` 는 전역이라 페이지 셰이더(`_t1Thin*`)로 구현했다. 이동 벽은 모듈 revealAt 기준이라 그대로 막힌다.

- 마디 순차 carve(1.4초 간격)·B 개화 지연 — 현행 무대는 회랑 1개 직선 + 즉시 개화라 호출부에 순차 로직이 필요.
