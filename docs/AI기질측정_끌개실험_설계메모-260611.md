## 0. 한 줄 요약

멘토의 "AI를 플레이시켜라"가, v0.6 끌개 수학이 필요로 하던 **긴 사슬(표본)**을 공급하고, 동시에 끌개 수학이 멘토 아이디어의 막연한 생사 질문을 **정량 측정 절차**로 바꿔준다. 두 트랙이 서로의 빈자리를 메운다.

```
멘토 아이디어 (무엇을 재나)   →  AI 기질 = 해석 성향의 차이
끌개 수학    (어떻게 재나)   →  전이행렬 → 정상분포 π → 분포 간 거리 + 순열검정
persona-sim  (재는 장치)     →  AI를 맨몸으로 플레이시켜 상태 사슬 생성
```

## 1. 생사 질문 → 끌개 통계 대응표

원래 질문(2026-06-10): **"AI들이 실제로 서로 다르게, 그리고 각자 일관되게 플레이하는가?"**

| 막연한 질문 | 정량 측정 (v0.6 §1 절차 번호) |
|---|---|
| 모델끼리 다른가 | 모델 A의 끌개 π_A vs 모델 B의 π_B — 분포 간 거리(총변동거리) + **순열검정** (§8-6) |
| 모델 안에서 일관된가 | 같은 모델 반복 플레이의 π **부트스트랩 신뢰구간** — 좁으면 일관 (§8-7) |
| "AI 기질"이 뭔가 | 에이전시 축 **a**-공간 위의 좌표. 모델마다 다른 점 → 다른 끌개 π(**a**) (§7) |

**판정 시나리오** (실험 전에 미리 박아두는 기준):

1. **π가 모델 간 다르고 + 모델 내 일관** → 측정 도구 성립. 논문 한 편 + 작품 확장 둘 다 감.
2. **다르긴 한데 들쭉날쭉** (신뢰구간 넓음) → 측정은 불성립. 구경거리·아카이브 시드로는 여전히 유효.
3. **전부 비슷한 끌개로 수렴** → AI 기질 아이디어 폐기. "선택지 설계가 변별력 없음" 진단만 회수.

수학은 답할 길을 줄 뿐, 답이 1번이라고 보장하지 않는다. 시나리오 3이면 깨끗하게 접는다.

## 2. 장치 — persona-sim 개조 4종 (2026-06-10 진단 재확인)

기존 `tools/persona-sim`은 배관(프롬프트→감정 출력→JSON→DB)은 완성품이나, 그대로 돌리면 "가상 인물 연기의 자가 채점표"가 나와 측정이 안 된다. 기존 스크립트는 안 건드리고 **옆에 새 스크립트**로:

| # | 개조 | 왜 | 규모 |
|---|---|---|---|
| 1 | **가면 끄기** — 페르소나 주입 없이 모델이 자기 자신으로 플레이 | 가면 쓰면 측정되는 건 대본이지 모델이 아님 | 작음 |
| 2 | **채점을 엔진으로** — AI 자가 채점(`out.alignment` 직접 수신, `3_simulate_plays.js:162-163`) 폐지 → 감정 입력만 받고 ByeoriEngine이 계산 | 답안지를 학생이 채점하면 시험이 아님. 엔진은 5-18 단일 모듈화(415c012)로 Node 호출 가능 | 중간 |
| 3 | **낱장 읽기 → 순서 있는 플레이 루프** — 현재는 무작위 4~7장 독립 읽기. scene_order 순회 + 직전 감정 기록을 다음 씬에 전달 | 기질은 궤적에서 드러남. 낱장으론 전이 자체가 안 생김 | 중간 |
| 4 | **다중 모델 호출부** — Anthropic 외 타사 모델 SDK 추가, 호출 정규화 | 모델 간 비교가 실험의 본체 | 작음 |

산출: 모델 × 반복판 × 씬 순회 = **상태 사슬 묶음** → 끌개 추정 입력.

## 3. 실험 최소 설계 (MVP)

- **기억**: 공개 기억 1개 (씬 수·choices 감정 분포가 고른 것 선정).
- **모델**: 3종 내외 (자사 1 + 타사 2).
- **반복**: 모델당 5판 이상 (부트스트랩 가능 최소선; 비용 보고 증감).
- **상태 정의**: v0.6 §1-1 — 오염 4축 bin × 감정 군집. K는 표본 규모에 맞춰 작게 시작 (희소성 §8-1).
- **측정**: 전이 카운트 → 평활 추정(α 교차검증) → 1차 마르코프 검정 → π·스펙트럼 간극 γ·엔트로피 H(π) → 모델 간 순열검정 + 모델 내 부트스트랩.
- **비용**: 모델당 몇 달러 수준 (기존 persona-sim 실측 기준 외삽).
- **롤백**: 기존 persona-sim 무손상. 새 스크립트 + 새 데이터 파일만 추가.

**주의 — AI 사슬 ≠ 인간 사슬.** AI 데이터는 ① 표본 공급원 ② 별도 측정 대상의 두 역할이지, 인간 끌개의 대체물이 아니다. "AI 끌개 = 인간 끌개"인지는 그 자체로 부분집단 검정 대상이며, 보통은 다를 것. 다르면 그것대로 결과다.

## 4. 경계 — 이 실험이 다루지 않는 것

1. **흥행·플랫폼 트랙** (콜드스타트 채우기, AI 플레이 구경거리, only-human 채널) — 멘토 아이디어의 절반이지만 끌개 수학과 무관. 별도 판단.
2. **"컨텍스트 이식 문제 해결"** — 2026-06-10 진단대로 과장. 장면화 출력은 컨텍스트가 아니라 "AI가 남긴 이본". 이 프레임은 채택 안 함.
3. **사업화** — 해자 얇음(낮음 판정). 작품+연구 하이브리드 트랙만 유효.
