# 세션 핸드아웃 — 유령 응답 "살아있음" 브레인스토밍 (2026-05-06)

## 문제

자유대화 매 턴 유령 응답이 *작가 손 풀*에서 픽되어 사용자 입력 내용과 *맞물리지 않음*. 사용자 체감 = "어쩌라고?". 5-19 데모 핵심 체험 자리에 영향.

스크린샷 사례 (2026-05-06):
- 사용자: "할머니"
- 유령: "할머니. 그 자리에 있었지. 부엌에서 국을 끓이던 손이."
- → 사용자 의도와 무관하게 *고정 풀*에서 픽한 응답.

## 현 자리 (코드)

| 응답 자리 | 출처 | 살아있음? |
|---|---|---|
| `scene_context` (씬 도입) | 작가 손 풀 OR LLM 캐시 | X (회차 전 박힘) |
| `ghost_intro` | 작가 손 풀 | X |
| `choice.ghost_reply` (객관식 후 응답) | 작가 손 풀 | X |
| `free_dialog_open` (첫 질문) | 작가 손 풀 | X |
| **자유대화 매 턴** | `LumenGhostResponse.pickResponse` — 결마다 *고정 풀* deterministic pick | **X** ← 본 자리 |
| **흡수 응답** (slot 매치) | `SlotAbsorber` Haiku LLM 런타임 생성 | O |

자유대화 풀 (`lumen_ghost_response.js` DEFAULTS):
```
resonancePool: ['그래, 그렇단 말이지.', '맞아. 너도 그랬구나.', ...]
vaguePool:    ['그랬었나... 확신이 안 서.', ...]
dissonancePool: ["'____'라고? ... 내 기억과는 다른데.", ...]
```

→ 사용자 입력 *내용 무관*, *결*만 보고 픽. 흡수 슬롯 매치 시에만 입력이 응답에 반영됨.

## 설계 명제 vs 한계

§6.5 #6 — *엔진은 판단하지 않음, 관찰만*. 풀 픽 = 명제 정합. 단:
- **흡수 매치 비율이 낮음** = 대부분 풀 픽 응답 → 살아있음 약함
- 같은 결 풀 내 *변주 적음* = 같은 톤 반복 체감
- 사용자 입력 *내용*이 응답에 *반영되는 자리*가 거의 없음 (흡수 자리 외)

## 브레인스토밍 자리 (다음 세션 입력)

### A. 살아있는 응답 비율 늘리기

1. **slot 풀 확장** — V2.1.2 박힌 slot pool (`resonanceSlotPool`, `vagueSlotPool`) 변주 추가. 슬롯 매치 비율↑ → LLM 응답 비율↑.
2. **slot 매치 임계 완화** — 휴리스틱 NER 임계 낮춰 *더 많은 입력이 슬롯 후보*. (false positive 비용 vs 살아있음 vs 5-2 결정 번복)
3. **dissonance quoting 확장** — 현재 `'____'` 마커 풀 1~2개. 충돌 결 응답에 *사용자 입력 단어 인용* 자리 늘림.

### B. 풀 자체 *내용 반응* 늘리기

4. **풀 응답에 placeholder 더 박음** — `'____'`처럼 입력 일부 차용. 단순 단어 추출은 V3.
5. **모티프 사전 활용** — 사용자 입력에 *그 메모리 모티프 단어* 들어 있으면 *모티프 변주 풀* 픽. (모티프 사전 컬럼 자체 마이그레이션 필요 — 다른 세션 의존)

### C. 런타임 LLM 비율 늘리기

6. **자유대화 *전 턴* LLM** — 슬롯 매치와 무관하게 매 턴 LLM. 비용↑ + 캐시 어려움. 데모 자리 vs 본 시스템 자리.
7. ***저렴한 모델* 풀 응답** — Haiku 외 더 저렴한 추론 모델 매 턴. 응답 톤 일관성 검증 필요.

### D. 응답 *없음* 자리 만들기

8. **침묵 응답 비율↑** — 풀에 `...` 같은 *침묵 어휘* 박음. 살아있지 않은 자리 = *살아있지 않다는 사실* 인정 — 작품적 자리.
9. **`urge`(다음 씬 권유)로 빠르게 빠져나감** — 자유대화 턴 수 줄임. 풀 픽 노출 최소화.

### E. *작가 손 풀*을 *기억 단위*로 박는 자리

10. **메모리마다 다른 풀** — 발자국 메모리에 발자국 톤 풀, 병원 메모리에 병원 톤 풀. *그 메모리 안에서만* 안 어색함. 작가 손 작업량↑.
11. **씬마다 다른 풀** — 더 세밀. 작업량↑↑.
