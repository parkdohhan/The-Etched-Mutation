### [L2-04] 🔴 씬 생성이 사용자 입력("자전거")을 무시하는 문제 — 원인은 **추출 단계**다 (프롬프트 아님)
- 파일: [js/app/confession.js:1219-1226](../../js/app/confession.js#L1219-L1226), [supabase/functions/generate-scene-from-conversation/index.ts:71-81](../../supabase/functions/generate-scene-from-conversation/index.ts#L71-L81)
- 판정: 씬 생성 함수는 **대화 원문을 한 글자도 받지 않는다.**

- 결론: **프롬프트 문제 아님 / 계약 문제.** 씬 생성 프롬프트를 아무리 고쳐도 입력에 없는 단어는 나올 수 없다.
