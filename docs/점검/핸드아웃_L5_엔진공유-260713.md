## 알려진 부패 패턴 (오늘 실제로 잡힌 것들)

1. **표기·키 불일치**: 17축 정본 키셋(fear…awe)이 파일마다 같은가 — math.js, geo_map 앵커,
   ghost_presets, 엔진 입·출력. 12축(claude-scene)→17축 변환 자리 존재 여부.
2. **문서-코드 어긋남**: 문서가 약속한 공식과 코드 구현 대조 —
   `alignment = level × shape × void_mod`, shape 는 3+씬 델타 코사인, void_mod 0.7,
   transition 6패턴, FIXATED 판정.
3. **원칙 위반 (CLAUDE.md §6.5 — 협상 불가 8개)**:
   - 패턴이 **기하(중심 이동)** 을 바꾸는가, 반경만 바꾸는가 (원칙 1) — SceneNavigator/접근 계산 실코드 확인
   - 오염이 축별(방향성)인가 스칼라 환원인가 (원칙 2)
   - fixation 이 count 임계인가 복합 신호인가 (원칙 3 — 미구현 TODO 로 알려짐, 현황 확정)
   - VAD 가 시각화 전용 원칙을 지키는가 — **판단 경로에 VAD 가 스민 곳** 전수
4. **죽은 수식·이중 구현**: 같은 계산이 두 벌(예: cosine, VAD 투영, 등고선)로 존재해 서로
   드리프트하는 곳. 엔진 단일화(5-18) 이후 잔존 구식 경로.
5. **테스트 화석**: 폐기된 동작(예: 옛 stage 이름, scene_link, 선택지)이 스냅샷에 박제되어
   미래 수정을 막는 자리 — "이 테스트는 현행 설계가 아니라 과거를 지킨다" 목록.
6. **단위·스케일**: 지형 SZ(112) 상수 중복, FBX cm↔m, 등고선↔미니맵 좌표 일치.
