### [L3-01] 🔴 무인증 공개 함수 2개가 DB·유료 API를 임의 트리거

`verify_jwt=false` + 코드 내 인증 검사 0 인 함수:

- **`record-drift-cumulative`** (verify_jwt=false) — `memoryId` + 임의 감정벡터를 받아 **`memories.cumulative_emotion_vec` 를 UPDATE**. memoryId 존재만 확인하고 소유권/세션 검증 없음. 즉 anon key만 있으면 **아무나 아무 기억의 누적 변위 벡터를 오염**시킬 수 있음. 이 벡터는 `pickDriftUtterance` 의 글로벌 좁힘 입력이라, 오염되면 그 기억의 유령 발화 선택이 통째로 왜곡됨.
- **`contaminate-text`**, **`generate-reveal`** (둘 다 verify_jwt=false, 코드 검사 0) — DB 쓰기는 없지만 호출 1건마다 Anthropic 크레딧 소모. 완전 공개 엔드포인트라 크레딧 고갈(비용) 벡터.

- 근거: 배포 설정 verify_jwt=false + 세 함수 모두 `_shared/auth.ts` 의 `verifyAuth`/`verifyServiceRole` 미호출.
