# 전체 기능 점검 — 지휘 문서 (2026-07-13)

> 배경: 7-13 하루에만 "작가 오염 텍스트가 한 번도 표출된 적 없음", "플레이 기록 6개월 증발",

## 구조 (3-Phase)

- **Phase A — 정적 병렬 스캔 (지금)**: 워커 5세션(Opus)이 각자 핸드아웃대로 읽기 전용 감사.
  파일 수정 0 → 충돌 원천 차단. 산출물 = 레인별 발견 보고서 5개.
- **Phase B — 취합·동적 재현 (지휘 세션)**: 5개 보고서를 지휘 세션(Fable)이 취합·오탐 판정,
  의심 항목을 브라우저 실기 재현. 브라우저는 1개뿐이라 순차.
- **Phase C — 수정 배분**: 확정 버그만. 충돌 규칙 3개 적용 (아래).

## Phase C 충돌 규칙 (수정 단계에서만 적용)

1. **진입점 3형제(play-test.html · index.html · admin.html)는 한 번에 한 세션만.**
2. **Edge Function 배포·DB 마이그레이션은 L3 담당 세션 단독.**
3. 각 세션은 자기 레인 파일만 수정. 남의 레인이 필요하면 멈추고 지휘 세션에 보고.
