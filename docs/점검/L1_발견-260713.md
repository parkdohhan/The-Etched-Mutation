## 요약 (한 문단)

7-13 커밋 `f2bce54` 는 오염 트래커 **내부**의 stage 표기만 정규화했다. 그런데 실제 상영 경로 —
play-test.html 의 `terrain_shape === 'circular'` → **유령 대화(lumen_dialog_phase1)** — 에는
작가 오염 텍스트(`text_stage_1/2/3`)를 읽는 코드도, 오염 혼잣말을 띄우는 코드도 **처음부터 없다**.
`applyStageText` 와 `getMonologue` 는 둘 다 대화 분기가 `return` 으로 빠져나간 **뒤**의 줄에만 있다.
즉 "작가 오염 텍스트가 독자에게 도달하지 못하던 버그"는 아직 살아 있다. 고쳐진 건 상류(트래커)이고,
끊긴 마디는 하류(표출)다. 여기에 더해 오염을 **먹이는** 쪽도 두 군데가 끊겨 있다 (L1-03·L1-04).
`npm test` 는 534개 전부 초록인데, 위 다섯 건 중 **하나도** 잡지 못한다.
