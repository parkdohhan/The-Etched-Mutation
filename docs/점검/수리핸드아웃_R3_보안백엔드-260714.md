## 수리 항목

### R3-1 (F1 안전벨트 🔴 최우선) FK CASCADE 해체
- 실측 확정: `plays_scene_id_fkey`, `trajectory_bridges_scene_id_fkey` = ON DELETE CASCADE. 씬 삭제 시 관객 기록·공명 브릿지가 통째 증발.
- 마이그레이션: 두 FK 를 **ON DELETE SET NULL** 로 교체 (`plays.scene_id`·`trajectory_bridges.scene_id` nullable 확인 — plays 는 이미 null 34행 존재). `choices_scene_id_fkey` 의 CASCADE 는 유지(선택지는 씬 부속).
- 검증: pg_constraint 재조회로 confdeltype='n' 확인.

### R3-2 (D1 🔴) record-drift-cumulative 무인증 쓰기
- 먼저 프론트 호출부 grep (읽기만): 익명 관객이 부르는지 확인. **익명 호출이 필요하면 verify_jwt 켜지 말고** 함수 내부 방어로: ① memoryId 존재 + 그 기억에 최근 plays 행 존재 확인 ② 감정 벡터 키 화이트리스트(12/17축 외 거부) + 값 범위 [0,1] + 벡터 norm 상한 ③ 요청 크기 제한. 재배포.
- contaminate-text / generate-reveal (무인증 크레딧 소모): 입력 텍스트 길이 상한 + stage/필드 화이트리스트 추가 재배포. (완전 차단은 익명 관객 플로우를 죽이므로 금지.)

### R3-3 (D2 🔴) 고아 함수 정리
- `generate-lumen-narration` (service_role Storage 쓰기 열림, 저장소가 "폐기" 선언) → **undeploy(delete)**.

### R3-4 (D4 🟡) absorb-slot 역드리프트 + 깨진 한글
- 배포판 v2 로직(규칙 7·후처리 replace 등)을 저장소 파일에 역반영하되, **배포판의 깨진 한글 3곳은 정상 표기로**: "그러셍을 지도"→"그랬을지도", "씀 컨텍스트"→"씬 컨텍스트", "엄마 손이 그러죠 것 같아"→"엄마 손이 그랬던 것 같아". 저장소=정본 상태를 만든 뒤 재배포.
- `generate-scene-from-conversation`: 저장소가 1글자 최신 — 그대로 재배포(동기화).

### R3-5 (D3 🟡) plays UPDATE 전면 개방 좁히기
- 현재 정책 "allow stamp update on plays" = anon 이 임의 컬럼 UPDATE 가능.
- 수리: play-test 의 도장 UPDATE 호출부를 grep 으로 읽어(수정 금지) 실제 갱신 컬럼을 특정한 뒤, **컬럼 단위 GRANT** 로 좁히기: `REVOKE UPDATE ON plays FROM anon, authenticated;` + `GRANT UPDATE(도장컬럼들) ON plays TO anon, authenticated;` (RLS 정책은 유지). 봉인 도장 기능이 계속 되는 게 완료 조건 — 보고서에 R2 에게 "도장 기능 브라우저 재확인 요청" 남길 것.
- 중복 정책 정리: plays 의 INSERT 3중·SELECT 3중을 각 1벌로.
