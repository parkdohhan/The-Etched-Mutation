2. **`plays_scene_id_fkey` = ON DELETE CASCADE 확정** (pg_constraint 실측). L4-01이 "유력"으로 남긴 대목이 최악의 방향으로 확정 — **편집화면 [저장] = 그 기억의 관객 플레이 기록 전량 삭제.** "플레이 기록 6개월 증발"의 진범. `trajectory_bridges.scene_id`·`choices.scene_id`도 CASCADE(브릿지 동반 사망). `utterances.scene_id`는 SET NULL(잔상은 살아남되 씬 연결만 끊김). 참고: plays에는 memory_id FK 자체가 없음 → L3의 고아 plays 24행과 정합.
