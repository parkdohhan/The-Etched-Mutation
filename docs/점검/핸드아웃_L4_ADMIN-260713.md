# 점검 핸드아웃 L4 — ADMIN (저작 도구)

> 전체 맥락: docs/점검/00_전체점검_지휘-260713.md. 너는 5개 병렬 점검 레인 중 L4다.
> 미션: 작가 저작 도구를 **읽기만** 하고 깨진 곳의 **완전한 목록**을 만든다.
> 관점: "지금 작가가 admin 만으로 새 기억 하나를 풀기능으로 저작할 수 있는가?"
> (기준 문서: docs/데모기억_풀기능_체크리스트-260707.md — 그 14단계 중 admin 이 담당하는
> 단계마다 실제 UI·저장 경로가 살아있는지 코드로 확인)

## 절대 규칙 (위반 = 세션 실패)

1. **읽기 전용.** 코드·문서·DB 수정 금지, 커밋 금지, 배포 금지, 서버·브라우저 금지.
2. 유일한 쓰기 예외: 보고서 **`docs/점검/L4_발견-260713.md`** 하나.
3. 고치지 마라. 가치는 **목록의 완전성**이다.
4. grep/read/`node --check` 허용.

## 내 구역

- `admin.html` (63KB, 인라인 포함), `admin_recovery.html`
- `js/admin.js`, `js/admin-trajectory.js`, `js/admin-recovery.js`
- `js/admin/**` (emotion_extract_helper, ghost_variants_editor)

## 알려진 부패 패턴 (오늘 실제로 잡힌 것들)

1. **표기·키 불일치**: admin 이 저장하는 값 vs 런타임이 읽는 값 (cont_stage `inclination`
   문제의 **원산지가 admin/시드일 가능성** — admin 이 쓰는 stage 문자열 전수 확인).
   감정 축 개수(6축 슬라이더 vs 17축 엔진), original_vector 자유 키.
2. **은퇴 모델명**: admin 에서 직접 부르는 LLM(emotion_extract_helper, contaminate-text 호출부).
3. **죽은 UI**: Feedback.md Phase 4에 "이관 후 제거 예정"으로 남은 editorScreen 잔재들
   (contamination 폼, 사운드 5곡, 데이터 내보내기, 잔상 모더레이션 위치) — 지금 어느 쪽이
   진실의 원천인지 (Canvas vs editorScreen 이중 편집 → 서로 덮어쓰는 경로 있는지).
4. **저장 유실**: Canvas 씬 편집 저장이 meta 를 통째로 교체해서 다른 키(pin_override,
   dialog_choices, object_tags, ghost_name, object_lines…)를 지우는지 — **jsonb 병합 vs 교체**
   전수 확인. (런타임 신기능들이 전부 meta 에 사니, admin 저장 한 번에 몰살될 수 있다.)
5. **최근 신설 필드의 저작 자리 부재**: ghost_name(7-09)·object_tags(7-13)·object_lines·
   sound_url/volume/radius — admin 에서 편집 가능한가? 불가면 "저작 불가 필드" 목록으로 보고.
6. **RLS/권한**: admin 쓰기가 어떤 키(anon? service?)로 나가는지, 실패를 삼키는 자리.

## L4 전용 점검 항목

- [ ] 풀기능 체크리스트 14단계 × admin 커버리지 표: 각 단계별로
      "편집 UI 있음/없음 → 저장 경로 → 실제 컬럼" 3열. 없는 것은 SQL 수작업 의존으로 표기.
- [ ] ghost_variants_editor: 본 발화/변주/자동 결 분류 미리보기 — insert-ghost-variant 계약과
      일치? emotion_vec 추출 호출이 살아있는 모델인지.
- [ ] admin-trajectory(Canvas): 핀 드래그 pin_override 저장(meta 병합 여부 재확인),
      author_bridges CRUD, 페르소나 재생.
- [ ] contaminate-text 파이프라인: admin 에서 text_stage_1/2/3 생성 버튼 → 저장 → 실제 컬럼.
      (오염 텍스트가 한 번도 표출 안 되던 버그의 상류 — admin 이 애초에 생성/저장을 제대로
      하고 있었는지.)
- [ ] admin_recovery.html: 아직 유효한 도구인지, 위험한 원클릭 파괴 동작이 있는지.
- [ ] strata 미리보기 버튼 등 L1 구역 모듈을 부르는 자리: 계약(window.*)이 아직 맞는지
      (모듈 내부는 L1 소관 — 여기선 admin 쪽 호출부만).
