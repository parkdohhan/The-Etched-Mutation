## ② 봉인 도장 (R3 이관) — ✅ 초록불

play-test 실 회차 (사본, `?memory=` 진입, 대화 경로 V2.1): 유령 대화 1턴 실응답 →
씬 종료 시 plays INSERT(12축 감정 + alignment 0.535) → 퇴장문 경로 봉인.

- **도장 3종 실측**: final_drift_vector ✓ · sky_stains ✓ · dialog_turns ✓ — R3 가 좁힌
  plays UPDATE 정책에 침묵 차단 없음.
- **오염 영속화(R6)**: 콘솔 "contamination persisted: 26컬럼" + record-drift-cumulative
  ok:true. depth 는 max() 보존(9 유지, R6 정정대로).
- **관찰 2 (설계 확인)**: 사본의 plays 를 검증 중 비웠더니 봉인 시 stage 가중치가
  (0.604/0.122/0.274)→(0,0,0) 으로 재계산·저장됨 — 버그 아님. 7-09 결정(오염은 plays
  재생으로 재계산, 저장값은 캐시)의 정확한 귀결. 영속 파이프라인 끝단까지 실기 증명.

의미 있는 조건을 제조: 오염 텍스트 6/6 보유 + plays 0 (= depth 0 인구). 씬 1 구분자
