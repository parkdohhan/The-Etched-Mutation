2. 유일한 쓰기 예외: 보고서 **`docs/점검/L1_발견-260713.md`** 하나만 작성한다.
3. 고치고 싶어도 고치지 마라. 이 작업의 가치는 수리 솜씨가 아니라 **목록의 완전성**이다.
4. 다른 레인 구역은 참조(읽기)는 허용, 발견 보고는 아래 내 구역 것만.
5. grep/read/`node --check` 는 자유. `npm test` 실행은 허용(읽기성).

## 이 코드베이스의 알려진 부패 패턴 (오늘 실제로 잡힌 것들 — 같은 냄새를 찾아라)

1. **표기·키 불일치**: DB 는 `inclination`, 코드는 `biased_inclination` 비교 → 조용히 0 처리.
   감정 키셋(6축/12축/17축), ko/en 문자열, stage 이름 등 양쪽 표기를 대조하라.
2. **빈 배열/null 의미 오판**: `[]`(명시적 없음)를 length 검사로 "미지정" 취급 → 엉뚱한 폴백.
3. **진입점 누락 배선**: 기능이 play-test.html 에만 붙고 index.html 에 없음(또는 반대).
   같은 함수 호출 자리를 전수 grep 하라.
4. **하드코딩 플레이스홀더가 실데이터인 척**: ghost_presets 혼잣말("냄새가 남아있어")처럼
   기억과 무관한 고정 문구가 표출되는 자리.
5. **죽은 코드가 살아있는 척 / 폐기 결정과 코드 잔존 불일치**: 문서상 폐기된
   rewind/return_mode/return_events, SoundscapeBeta, live 계열이 아직 로드·실행되는지.
   UIManager.js·Visualizer.js 가 아직 어디서든 쓰이는지 (호출 0이면 그것도 보고).
6. **회차 경계에서 안 닦이는 상태**: 전역/모듈 상태·sessionStorage·setInterval·render wrap 이
   기억 전환/회차 종료/재진입에서 리셋되는지. (FP 퇴장 지점은 play-test 에 4곳 있다 —
   `_destroyAmbientWave()` 검색.)
7. **render wrap 중첩**: mannequins·objects·dialog cam 등 여러 모듈이 renderer.render 를 겹겹이
   랩한다. attach 가 두 번 불리면 이중 랩 되는 구조인지, 순서 의존이 있는지.
8. **캐시버스터 없는 script 태그**: 최근 수정된 js 인데 `?v=` 없는 것.
9. **window.* 전역 계약**: 모듈 A가 기대하는 window.X 를 아무도 안 만드는 경우 (가드 없이 터지는지).
10. **좌표·단위 혼선**: VAD/세계좌표/화면좌표 섞임, FBX cm↔m 스케일.

## L1 전용 점검 항목 (기능별로 끝까지 추적)

각 기능에 대해 "데이터 → 계산 → 표출"이 실제로 이어지는지 확인:

- [ ] **유령(마네킹)**: FBX 로드 실패 시 폴백? accessibleOnly 재구축 시 응시(seen)·기욺(lean) 상태 유실?
      대화 중 마주보기 회전과 gaze LERP 이중 적용 문제?
- [ ] **유령 대화(lumen_dialog_phase1)**: RPG 넘김/SKIP/나가기 상태머신에 낀 상태 조합
      (예: 나가기 직후 advance 잔존? ff 가 다음 씬으로 새는가?), 키 리스너 해제 누수,
      i18n(_STR) 커버리지, 이름 드러남(sessionStorage) 기억 전환 시 오염 여부.
- [ ] **얼굴 속 글자·카메라 줌**: _temDialogCam 해제 실패 경로(예외 시), 줌 중 ESC/퇴장하면?
- [ ] **사물(lumen_scene_objects)**: setInterval 폴링이 attach 실패/재호출 시 중복? 라벨 문장
      추출 정규식(`(?<=[.!?。])`)이 구형 브라우저에서 SyntaxError 로 모듈 전체를 죽이는지.
- [ ] **되새김(lumen_recalled_anchors)**: 기억 전환 clear 조건, 화면 앵커 상한, dialog 감광 타이머.
- [ ] **오염 표출 사슬**: cont_* → getPresentationState → applyStageText → 화면. normalizeStage
      수정(7-13) 이후에도 남은 소비자 불일치가 없는지 전수 (contaminationPresenter, monologue 포함).
- [ ] **파동(ambient wave)**: pulseResonance 계약, z-index/포인터 이벤트, 회차 종료 정리.
- [ ] **안개(lumen_replay_fog / lumen_spatial_fog)**: 둘의 관계(중복? 승계?), 기본 ON 이후 회귀.
- [ ] **잔상(afterimage)**: 시드 0개일 때 동작, PII 필터 경로, endScreen 외 호출.
- [ ] **공간음향(spatialAudio 소비측)**: sound_url 없는 씬에서의 동작, 정리(cleanup).
- [ ] **미니맵·핀 접근 규칙 표출**: accessiblePinIds 와 실제 클릭 가능 상태 일치.

심각도: 🔴 기능 불능·데이터 손실 / 🟡 작동하나 어긋남·의도 위반 / 🟢 사소.
