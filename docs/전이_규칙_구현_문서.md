## 버킷 판정 전이 규칙

### 위치
- 파일: `js/shared/math.js`
- 함수: `getBucket(alignment, previousBucket, emotionHistory)`

### 전이 규칙

#### 1. FIXATED 우선 판정
```
조건: emotionHistory의 마지막 3개가 모두 동일
→ FIXATED 반환
```

#### 2. 히스테리시스 규칙 (이전 버킷 유지)
```
이전 버킷이 HIGH이고 alignment >= 0.45
→ HIGH 유지

이전 버킷이 LOW이고 alignment <= 0.25
→ LOW 유지
```

#### 3. 기본 판정 규칙
```
alignment >= 0.55 → HIGH
alignment < 0.35 → LOW
그 외 → MID
```

### 코드 구현
```javascript
export function getBucket(alignment, previousBucket = null, emotionHistory = null) {
  // FIXATED 체크
  if (emotionHistory && emotionHistory.length >= 3) {
    const last3 = emotionHistory.slice(-3);
    if (last3[0] === last3[1] && last3[1] === last3[2]) {
      return 'FIXATED';
    }
  }
  
  // 히스테리시스 적용
  if (previousBucket === 'HIGH' && alignment >= 0.45) return 'HIGH';
  if (previousBucket === 'LOW' && alignment <= 0.25) return 'LOW';
  
  // 첫 판정 또는 MID
  if (alignment >= 0.55) return 'HIGH';
  if (alignment < 0.35) return 'LOW';
  return 'MID';
}
```

### 버킷 상태
- **HIGH**: 정렬도 >= 0.55 (또는 이전 HIGH에서 >= 0.45)
- **MID**: 0.35 <= 정렬도 < 0.55
- **LOW**: 정렬도 < 0.35 (또는 이전 LOW에서 <= 0.25)
- **FIXATED**: 마지막 3회 감정이 모두 동일

## Live 세션 Phase 전이

### 위치
- 파일: `js/index.js`
- 변수: `currentPhase`

### Phase 상태
- `'scene'`: 장면 생성/확인 단계
- `'emotion'`: 감정 입력/확인 단계
- `'complete'`: 완료 단계

### 전이 규칙

#### Scene → Emotion
```
조건:
1. 사용자가 장면 텍스트 입력
2. AI가 장면 생성
3. 사용자가 "예" 확인
→ currentPhase = 'emotion'
```

#### Emotion → Scene
```
조건:
1. 사용자가 감정 입력
2. AI가 감정 분석
3. 사용자가 "예" 확인
4. 감정 저장 완료
→ currentPhase = 'scene'
→ liveSceneNum 증가
```

#### Scene/Emotion → Complete
```
조건:
- 모든 장면 완료
- 세션 종료
→ currentPhase = 'complete'
```

### 코드 위치
- `handleUnifiedSubmit()`: Phase 전이 로직
- `sendChatMessage()`: Phase별 처리
- `startLiveSession()`: 초기 Phase 설정 (`currentPhase = 'scene'`)

## 체험자 Phase 전이

### 위치
- 파일: `js/index.js`
- 변수: `expCurrentPhase`

### Phase 상태
- `'waiting'`: 장면 대기 중
- `'interpret'`: 감정 해석 입력 중

### 전이 규칙

#### Waiting → Interpret
```
조건:
1. 화자가 장면 생성
2. 장면이 체험자에게 전달
3. displaySceneForExperiencer() 호출
→ expCurrentPhase = 'interpret'
```

#### Interpret → Waiting
```
조건:
1. 체험자가 감정 입력
2. 감정 분석 완료
3. 사용자가 "예" 확인
4. 감정 저장 완료
→ expCurrentPhase = 'waiting'
```

### 코드 위치
- `displaySceneForExperiencer()`: Waiting → Interpret
- `handleExpConfirm()`: Interpret → Waiting

## 기억 등록 시스템 Phase 전이

### 위치
- 파일: `js/index.js`
- 객체: `memoryRegistrationState.phase`

### Phase 상태
- `'collecting'`: 기억 수집 중
- `'reviewing'`: 수집된 기억 검토 중
- `'complete'`: 등록 완료

### 전이 규칙

#### Collecting → Reviewing
```
조건:
- 한 장면의 정보 수집 완료
- [SCENE_COMPLETE] 태그 수신
→ phase = 'reviewing'
```

#### Reviewing → Collecting
```
조건:
- 사용자가 다음 장면 수집 계속
→ phase = 'collecting'
```

#### Reviewing → Complete
```
조건:
- 모든 장면 수집 완료
- 사용자가 등록 확인
→ phase = 'complete'
```

### 코드 위치
- `startMemoryRegistration()`: 초기 Phase 설정
- 메모리 수집 AI 응답 처리: Phase 전이 로직

## The Confession Step 전이

### 위치
- 파일: `js/index.js`
- 객체: `confessionState.currentStep`

### Step 상태
- `0`: 감각 선택 (온도, 냄새, 소리)
- `1`: 앵커 오브젝트 선택
- `2`: 행동 선택
- `3`: 갈등 선택
- `4`: 감정 단어 입력
- `5`: 생성된 장면 확인

### 전이 규칙

#### Step N → Step N+1
```
조건:
- 현재 Step의 입력 완료
- renderStep(N+1) 호출
→ currentStep = N+1
```

#### Step 5 → Complete
```
조건:
- 생성된 장면 확인 완료
- 사용자가 저장/다음 진행
→ 세션 종료 또는 다음 단계
```

### 코드 위치
- `renderStep(step)`: Step 렌더링 및 전이
- `startConfessionFlow()`: 초기 Step 설정

## 정렬도 레벨 전이

### 위치
- 파일: `js/index.js`
- 함수: `getAlignmentLevel(alignment)`

### 레벨 상태
- `'FIXATED'`: 정렬도 >= 0.95
- `'HIGH'`: 정렬도 >= 0.8
- `'MID'`: 정렬도 >= 0.5
- `'LOW'`: 정렬도 < 0.5

### 전이 규칙
```
alignment >= 0.95 → FIXATED
alignment >= 0.8 → HIGH
alignment >= 0.5 → MID
alignment < 0.5 → LOW
```

### 코드 구현
```javascript
function getAlignmentLevel(alignment) {
  if (alignment >= 0.95) return 'FIXATED';
  if (alignment >= 0.8) return 'HIGH';
  if (alignment >= 0.5) return 'MID';
  return 'LOW';
}
```

### 사용 위치
- 파동 애니메이션 스타일 결정
- 시각적 피드백 제공

## 아카이브 플레이 전이

### 위치
- 파일: `js/index.js`
- 함수: `startArchivePlay()`, `showConsentSequence()`, `showWordSentenceSequence()`

### 전이 흐름

#### 1. 기억 선택 → 동의 시퀀스
```
조건:
- selectMemory(index) 호출
→ showConsentSequence(memoryIndex) 호출
```

#### 2. 동의 시퀀스 → 단어/문장 시퀀스

조건:

```

```
조건:
- 모든 장면 플레이 완료

## 참고사항

### 히스테리시스 (Hysteresis)
버킷 판정에서 히스테리시스를 적용하여 상태 전이 시 플리커링을 방지합니다:
- HIGH → MID: 정렬도가 0.45 이하로 떨어져야 전이
- LOW → MID: 정렬도가 0.25 이상으로 올라가야 전이

### FIXATED 우선순위
FIXATED 판정은 다른 모든 규칙보다 우선 적용됩니다. 마지막 3회 감정이 모두 동일하면 즉시 FIXATED로 전이됩니다.

### Phase 초기화
각 모드 시작 시 해당 Phase가 초기화됩니다:
- Live 세션: `currentPhase = 'scene'`
- 체험자: `expCurrentPhase = 'waiting'`
- 기억 등록: `phase = 'collecting'`
