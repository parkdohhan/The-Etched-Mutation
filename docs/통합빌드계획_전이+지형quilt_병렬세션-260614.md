## 2. 소프트 충돌 — 확인 끝 (어떻게 흡수되나)

퀼트가 장면 크기·위치를 바꾸면 그 위 유령/마네킨이 따라와야 함. 확인: 마네킨은 핀 좌표를 *rebuild 시점에 굽는다*(매 프레임 추적 X). 단 `rebuild()`가 public 메서드 → **퀼트 기하가 핀을 옮긴 직후 `play-test.html`(=W)이 `rebuild()` 한 번 부르면 따라온다.** 이 상호작용은 *모듈 코드*가 아니라 *배선(W)*에 산다. W는 단독 직렬이라 충돌 없음. **모듈 병렬화 안전 확정.**

## 3. 공유 약속 (이것만 맞추면 세션끼리 속 안 봄)

- **T:** `getGhostDrift(sceneId)` → `{strength, input}` | null [T0 완료]. `pickDriftedLine({ 원래대사, 강도, 입력, 모드 })` → 문자열 (모드 = murmur/redialog) [**T1 정의**].
- **Q:** `quilt_geometry` (신규) — `recordTransition(fromId, toId, pattern, alignment)` 로 먹이고, `getSceneScale(sceneId)` / `getPairDistance(a, b)` / `getSeam(a, b)` 로 읽음 [**Q1 정의**].
- **W:** 엔진 출력을 T0(`recordDialogTurn`, 이미 됨)·Q1(`recordTransition`)에 먹이고, T·Q getter 읽어 적용 + 핀 이동 시 `rebuild()`.

- **목표:** 둘 다 한 판에서 작동.
- **시나리오:** 어긋난 말 → 2장면 → 재조우: 혼잣말(다가가면) + 재대화 변형 + 자세 기욺. / 공명 → 그 장면 지형 커짐. / 거스름 → 사이 골짜기. / 피함 → 멀어짐. 스크린샷 박음.
- **합격선:** 전이 2단 노출 + 퀼트 크기·거리 패턴별 변화 둘 다 육안 확인.
