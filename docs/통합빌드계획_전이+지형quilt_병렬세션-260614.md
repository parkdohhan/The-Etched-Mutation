### A. 핵심 피벗 — distinctness = 객체, 감정 지형 아님 (실측 근거)
- **감정으로 장면을 못 구분한다.** 실제 DB 감정 + 실제 지형 수식으로 측정: 같은 군집 0.58 vs 다른 군집 0.75 **겹침**. 노이즈 고침 3개(표 벌리기/전체벡터 해시/ridged) 전부 무효(비율 1.28 고정). 근본 = VAD 2D 투영이 17축을 부정-쏠림 한 점으로 뭉갬.
- ⇒ **§0·§9 H·Q2의 "감정→고유 지형" *distinctness* 주장 폐기.** 장면 *모양*은 안 갈려도 됨.
- **distinctness는 객체(사물지형)가 진다** — 모티프→3D 모델을 지형에 얹음. 슬리퍼≠장화≠아스팔트. 감정은 *색·분위기*로만.

### B. 2층 구조 (확정)
- **바닥(base plate):** 장면별 지형 plate. *모양 distinctness 불필요*(감정 기반이어도 OK). 서로 *잇음*(거리 + 능선/골짜기).
- **객체(사물지형):** 그 plate 위 3D 모델 = 정체성. 어떤 장면엔 있고 없고, 크기·색 변형. 유령은 객체 근처 배치.

### C. 밑둥 빌드 완료 ✅ (Q1 + Q2 — 커밋 57a94d7, 테스트 통과, 실제 앱 시각검증)

### D. 잇기(Q4) = gap-fill-noise (확정 설계, 미빌드)
- 두 plate *사이 빈 공간의 바닥*을 채우는 절차 띠. **다리(연결물) X** — 퀼트 §4 폐기 정합. `getSeam`으로 구동.
- echo_follow/bridge→능선(↑) / contradiction→골짜기(↓+틈) / avoidance→끊김(띠 없음) / displacement→**어긋남 = 아직 씨앗(미설계)**.
- Q1+Q2 의존. gH는 Q2가 떠안음(actors는 plate 중심에만 앉아 seam과 무관).

### E. 객체 트랙 (신규 — 옛 §들에 없음)
- 모티프→3D 모델 에셋 라이브러리(유한·재사용). plate 위 배치. Record는 모델 없으면 그냥 없음(graceful).
- **설계 미완** — 에셋 출처/매핑 미정.

### F. 설계 미완 4개 (핸드아웃 보류 — 회의 먼저)
1. **T1/T3 per-person 대사** — `text_stage` 재활용은 *강도별*이지 *사람별*이 아님(같은 강도면 모두 같은 대사). 그 사람 입력이 대사를 빚는 설계 미완.
2. **물듦 누적·전달** — 사람마다 다른 방향 물듦이 다음 사람에게 어떻게 누적/전달되나((가) 척추). 미설계.
3. **객체 에셋 파이프라인**(E) — 모델 출처/매핑.
4. **어긋남(displacement) 잇기** — 시각 어휘 미정.
