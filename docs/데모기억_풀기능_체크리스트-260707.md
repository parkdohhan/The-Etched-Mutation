# 데모 기억 풀기능 저작 체크리스트 (2026-07-07)

> 목적: 기억 1개를 만들어 **현재 살아있는 기능 전부**를 데모에서 보여주기 위한 단계별 체크리스트.
> 전신: [lumen_memory_authoring_checklist-260421.md](lumen_memory_authoring_checklist-260421.md) (Lumen 폐기분 제외하고 계승) + 유령/전이 계열 통합.
> 견본 기억: [docs/memory/발자국.md](memory/발자국.md) + [tools/insert_footprints_memory.js](../tools/insert_footprints_memory.js) — 유령까지 갖춘 유일한 완성 예시. 새 기억은 이 구조를 복제.
>
> 작성 순서: **서사 → 감정 → 유령 → 공간 → 흔적 → 검증**

---

## 1. 기억의 뼈대 (`memories`)

- [ ] `title` — 입구 카드 이름. 10자 내외.
- [ ] `code` — 내부 식별자. 예: `E-DEMO-001`.
- [ ] `lang` — `'ko'` | `'en'` 하나로 고정.
- [ ] `completed_sentence` — "이건 ~한 기억이었다" 한 문장. 입구 호버 혼잣말 재료.
- [ ] `memory_words` — 키워드 3~6개. 잔상 매칭·검색 인덱스.

## 2. 장면 3~5개 + scene_role (`scenes`)

- [ ] 장면당 `text` 60~200자, `scene_order` 1부터.
- [ ] **장면 3개 이상 필수** — 별이엔진 shape(궤적 모양 비교)가 3씬부터 켜짐.
- [ ] `scene_role` 배분 — 유령 실루엣 타입이 여기서 결정됨:
  - `anchor` 1개 이상 → **Core 유령** (최초 경험자. 감각 화법)
  - `residual` 1개 이상 → **Contaminated 유령** (확언조. 비뚤어진 확신)
  - `void_info.sceneVoid=true` 1개 → **Bridge-deferred 유령** (침묵)
  - **Echo 유령**은 콘텐츠가 아니라 plays 기록(약하게 해석한 플레이)에서 나옴 → §12에서 재료 생성.

## 3. 감정 데이터

- [ ] 장면별 `original_emotion` — **17축** 감정 벡터. 강도 이미 반영 (`vector_weight` 금지).
      **장면 간 고저차를 일부러 크게** — 전부 비슷하면 HIGH/MID/LOW 차이를 시연 못 함.
- [ ] 장면별 `original_reason_vector` — attribution(self/other/fate) + core_fear, 각 합 1.0. Strata AF 좌표 결정.
- [ ] 장면별 `anchor_emotions` — 내면 독백 트리거 감정 2개 내외.
- [ ] 기억 수준 `original_vector`(17축) + `original_reason_vector` + `sensory_anchor`(첫 30초 감각 무대).

## 4. 오염 초기값 (`memories.cont_*`)

- [ ] `cont_depth` 0 (신선) 또는 2~3 ("이미 몇 번 해석된" 입장감).
- [ ] `cont_divergence` / `cont_convergence` / `cont_heterogeneity` — 기본 0.
- [ ] `cont_stage_1/2/3` — 합 1.0 근사.
- [ ] 레거시 금지: `cont_drift`, `cont_fixation`, `cont_stage`, `sound_map`.

## 5. 연출 레버 4종

- [ ] `meta.echo_words` — 장면당 공명 단어 3~5개.
- [ ] `meta.motif_tags` — 입구 "맞춤 기억 찾기" 매칭 시그널.
- [ ] `void_info` — VOID 장면 설계 (§2의 sceneVoid 씬). 안개 감각 + 회피 감점(×0.7) 시연용.
- [ ] `choices` — 장면당 2~3개. 감정 라벨(17감정 중 1) + intensity만. **next_scene_id 없음(의도).** 하나는 침묵/회피 선택지.

## 6. 오염 텍스트 3종 (top-level 컬럼)

- [ ] `text_stage_1` — 편향적 기울어짐. `·` 침식.
- [ ] `text_stage_2` — 두 해석 병기.
- [ ] `text_stage_3` — 과잉 완결. 글리치 + 반복 확신.
- 자동 생성 파이프라인(Edge Function v2) 연결돼 있음 → 생성 후 **품질 눈으로 확인** 필수.

## 7. 유령 정체성 + 응답 풀 (`ghost_variants`)

기준 문서: [유령응답풀_가이드_v1-260504.md](유령응답풀_가이드_v1-260504.md)
편집 도구: `js/admin/ghost_variants_editor.js` (admin)

- [ ] **본 유령 1마리** — 본 발화 1개 (kind=`drift`, `is_seed=true`). 이 발화의 emotion_vec = 유령 정체성 중심점.
- [ ] **speciation 시드 1마리** — 별도 유령, 별도 본 발화. (발자국 = 본 유령 1 + 시드 1 = 2유령)
- [ ] **유령당 변주 12~15개** — 작가는 변주만 쓰면 됨. resonance/vague/dissonance 3결은 본 발화와의 cosine 유사도로 **자동 분류** (≥0.85 / 0.5~0.85 / <0.5). admin에서 분포 확인 + 필요시 수동 override.
- 이 변주 풀이 **전이(물듦) 발현 대사의 재료이기도 함** — "생각해보니… 그런 것 같기도 해" 계열 변주를 반드시 포함.

## 8. 씬별 유령 대화 (`scenes.meta.dialog_choices`)

- [ ] 장면당 ~10 변주: `ghost_intro`(첫마디) / `choice_select`(선택 버튼) / `choice_reply`(응답) / `free_dialog_open`(자유 대화 열기).
- [ ] 화법: 4종 모두 **회상 실패자 화법** ("~했던 것 같아 / 왜 이게 기억나지"). 전달자 화법("~였대") 금지.
- [ ] 타입별 톤 힌트: Core=감각 서술 / Contaminated=확언조 / Echo=조각 trail-off / Bridge-deferred=침묵·반언어.

## 9. 유령 위치 배치 = 씬 핀 배치

**유령은 별도 오브젝트가 아니라 씬 핀 그 자체.** 위치는 감정 좌표에서 자동으로 나온다.

- [ ] VAD 투영 자동 좌표로 일단 확인 (admin Canvas → Strata 미리보기).
- [ ] 자리가 마음에 안 들면 **"위치 stage" 탭에서 배치** → `scenes.meta.stage_position` 저장 (실제 반영 경로).
  ⚠️ (R1 2026-07-14 정정) 터레인 모드 핀 드래그의 `meta.pin_override` 는 **죽은 레버** — 저장은 되지만 소비자가 없어 화면에 반영 안 됨.
- [ ] **override 예산 10~15%** — 전 씬을 드래그로 옮기면 엔진이 장식이 됨 (원칙 8).
- ❌ `ghost_condensation_points` (유령 응집 좌표) — Lumen 폐기분. 채우지 말 것.

## 10. 소리 (씬별 공간음향)

- [ ] `meta.sound_url` — 장면별 mp3.
- [ ] `meta.sound_volume` (0~1) / `meta.sound_radius` (기본 15).
- 지형에서 가까이 가면 커지는 HRTF 공간음향 (`js/shared/spatialAudio.js`). 레거시 `sound_map` 5곡 건드리지 말 것.

## 11. 작가 원본 궤적 시딩 (`plays`) — 빠뜨리기 최다

어드민/SQL로 만든 기억은 이게 자동으로 안 생김. **없으면 정렬도 기준이 없어 엔진 전체가 헛돎.**

- [ ] 장면당 1행: `user_emotion` = 씬 `original_emotion` 그대로, `user_reason` = 씬 귀인 그대로, `alignment` = 1.0, `mismatch_type` = NULL.

## 12. 흔적 쌓기 — 테스트 플레이 3~5회

각 회차에 목적을 부여해서 돌 것:

- [ ] **약한 감정으로 1회** → 그 씬에 **Echo 유령** 등장 재료.
- [ ] **크게 어긋난 감정으로 1회** → **전이(물듦)** 재료. 접촉 후 장면 2개 경과 × 오염도로 발현.
- [ ] **접촉 사건 1회** (여정 중 유령과 겹치는 드문 순간, 승리 아님) → `trajectory_bridges`(접촉 기록) + **직전 전달자 유령**(개인 아바타) 재료. <!-- 260716 이본지층: 공명 엔딩→접촉 재정의 -->
- [ ] 나머지 회차는 감정 결 다양하게 → 오염 누적 + strata 플레이 마커 다수.

## 13. 전역 자산 (기억 밖 준비물)

- [ ] **잔상 시드 코퍼스** — `data/seed_utterances.csv` 작가 목소리 파편 50~100개 (Feedback.md S-1, 미완). 비어 있으면 잔상 자체가 안 뜸.
- [ ] 다른 기억 1~2개 존재 — AF 좌표가 서로 다른 사분면에 오도록 (이본 시연 근거).

## 14. 검증 한 바퀴

기존 §8 계승 + 유령/전이 추가:

- [ ] admin 로드 → 장면 수·감정 벡터 확인
- [ ] Strata에서 AF 좌표 위치가 기대와 맞나 / stage_position 반영되나 (pin_override 아님 — R1 정정)
- [ ] 체험 첫 30초 안에 핵심 감정 전달되나
- [ ] 오염 단계 수동 변경 → text_stage_1/2/3 전부 렌더되나
- [ ] VOID 장면 정상 처리되나
- [ ] 입구 키워드 입력 → 이 기억이 매칭 후보에 뜨나
- [ ] **유령 4종 실루엣** 구분되어 보이나 (Core/Contaminated/Bridge-deferred + 테스트 플레이 후 Echo)
- [ ] 유령 접근 시 혼잣말 → 대화 → 작별이 공명도(≥0.7 / 0.35~0.7 / <0.35)에 따라 갈리나
- [ ] **전이 확인**: 씬1 유령에 어긋난 입력 → 씬 2개 진행 → 씬1 재방문 → 짧은 혼잣말로 유도 → 다시 말 걸면 이야기가 조금 바뀌어 있나
- [ ] 공명 도달 후 다음 플레이에서 직전 전달자 흔적/브릿지 보이나
- [ ] 공간음향: 핀 접근 시 소리 커지나 (1인칭 걷기 F 토글로 체감)
