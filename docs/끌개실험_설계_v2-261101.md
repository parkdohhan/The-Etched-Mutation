## 2. 결정 기록

### 결정 1 — 상태(구멍) 정의 (2026-11-01, 사용자 결정)

**1차 = (가) 최강 감정 1축 라벨링.** 각 씬의 `user_emotion`에서 점수 최고 축 하나를 상태 이름으로 쓴다. 희소 축(출현 빈도 낮은 것)은 '기타'로 묶는다. 예상 칸 수 6~7.

- 근거: 점 216개(전이 ~180쌍)에 자유 파라미터 0 — "결과 보고 칸을 바꿨다"는 의심 차단. 1차 목표는 "구멍이 보이기나 하나" 확인이라 읽기 쉬운 자가 맞음.

**⚠ 종국 = (나) 다차원 군집화가 필수다. (가)는 임시 자.**

- 이유: (가)는 2등 이하 감정을 버린다. 슬픔 0.75·외로움 0.74 와 슬픔 0.75·두려움 0.1 이 같은 칸이 된다. 이는 기억유전학·지형모델의 재료 원칙 **"감정 분포를 뭉개지 않는다"**(`docs/생성형_지형모델_v2-260619.md`, CLAUDE.md §4 emotion_dist 정정)과 정면 충돌한다. (가)로 나온 구멍 지도는 **"가장 센 감정의 지도"**일 뿐 감정 지형이 아니다.
- **전환 조건**: ① 사슬 점 500개 이상 확보 시(AI 2차 포함), 또는 ② (가) 결과에서 한 칸 안에 2등 감정으로 갈라져야 할 덩어리가 육안으로 보이면 그 전에라도.
- **(나) 설계 시 규칙**: 칸 개수(K)는 **데이터 접촉 전에 사전 등록**하고, 인접 K(예: 4·5·6) 전부 돌려 전부 보고한다 (era 이론 §4 창 길이 규칙 준용 — 유리한 K만 고르기 금지).
- **(가) 결과를 어디에 쓰든 "임시 자(최강 감정 라벨)" 고지를 붙인다.** 논문·발표에서 이를 "감정 끌개"로 부르는 것은 오진술.

### 결정 2 — 구슬 위치에 씬을 포함하나 (2026-11-01, 사용자 결정)

**(ㄷ) 상태 = 감정만. 단 점마다 씬 꼬리표(`scene_id`/`scene_order`)를 반드시 함께 기록한다.**

- 기각 (ㄱ) 감정만·꼬리표 없음: 작가가 파 놓은 씬 자리와 플레이어가 머무는 자리를 구분 못 함.
- 기각 (ㄴ) 감정×씬 결합 상태: 칸 6~7 × 씬 13 ≈ 90칸 vs 전이 ~180쌍 → 희소. 현 N에서 불가(N 확대 후 재검토 가능).
- (ㄷ)이 공짜로 주는 검사 — **작가 구멍 / 플레이어 구멍 판별**: 각 상태(구멍)에 모인 점들의 씬 분포를 본다.
  - 한 씬에 쏠림 → 작가가 판 구멍(씬 내용이 끌어당긴 것). 플레이어 끌개 아님.
  - 여러 씬에서 옴 → 씬과 무관하게 돌아오는 자리. 진짜 끌개 후보.
  - 결정 4 영모형에서 "씬을 섞어도 같은 구멍이 나오나"로 재사용.
- 부기: 회차의 씬 순서가 사람마다 다르다(지형이 접근 가능 씬을 열어 줌; 예 2→1→9→5→10→4→3…). 따라서 "k번째 씬에서의 상태" 비교는 무의미하고, 비교 가능한 것은 **전이(직전 상태→다음 상태)**만이다.

### 3.1 탐색 단계 (지금) — "그냥 그려 본다"

- 입력: UNDW-001 실관객 회차 216점 (감정 15축 + 씬 꼬리표 + 회차·시각).
- 그림: ① 점 지도(15축→2D 투영, 색=최강 감정, 모양/표시=씬) ② 같은 회차 점을 시간순으로 이은 선 ③ 뭉친 자리별 구성(감정·씬 분포).
- 읽는 법: 뭉친 데 있음 → 구멍 후보 → 그 안의 감정·씬 구성 읽기. 고르게 퍼짐 → 평평(끌개 없음 후보).
- 산출: 지도 1장 + 본 것 메모. **통계 판정 없음.**

#### 3.1.1 1차 실행 (2026-11-01) — 산출

- 지도: https://claude.ai/artifact/TA53URzzksZVzKoZg7NF47 (「모래밭 지도 첫 장」 — 점 지도·구멍별 구성·씬별 구성·걸음표·본 것·주의). 데이터 뽑기 스크립트는 세션 스크래치패드 `sandbox_pull.cjs` (DB 읽기만; persona-sim의 .env 열쇠 사용). 저장소 미반영.
- 입력 확인: 216점 · 37회차 · 179걸음 · 축 15(출현 30% 미만 4축 제외) · 2D 투영은 흩어짐의 33.5%+20.1%=53.6%.
- **본 것 (판정 아님)**:
  1. 큰 구멍 둘 — 슬픔 45점, 죄책감 32점. 둘 사이 길 있음(슬픔→죄책감 8, 죄책감→슬픔 9). 179걸음 중 40(22%)이 슬픔에서 끝남.
  2. 둘 다 씬 11~12곳에서 모임 → 사람이 돌아오는 자리에 가까움. 단 씬 공급분 존재(슬픔 29%=9번 씬, 죄책감 47%=13·7번 씬).
  3. 그리움 31점 = 입구 구멍(2·3번 씬 초입), 머묾 4/21, 슬픔(6)·두려움(5)으로 유출.
  4. 분노 16점 = 작지만 가장 끈적(머묾 6/15=40%), 유출은 혐오(4).
  5. 희망 10·다정함 8 = 구멍 아님(머묾 각 1).
  6. 작가 감정 ≠ 사람 감정인 씬: 9(두려움→슬픔 13/23), 4(외로움→슬픔 8/17), 1(두려움→혐오 3/10), 12(수치→슬픔 3/7). 일치: 2·3(그리움), 7·13(죄책감).
  7. **임시 자 한계 즉시 노출**: 최강 감정 라벨링에서 '그 외' 9종 = 70점(32%). 결정 1 전환 조건 ② 신호.
