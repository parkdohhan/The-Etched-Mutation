# 유령 대화 — 마네킹 줌인 + 얼굴 속 글자 + 하단 자막 (v2, 2026-07-08)

> **v1 → v2 (같은 날):** v1은 "화면 우측 오버레이에 2D 얼굴 윤곽 + floatingAnchor 파편"이었다. **폐기.**
> 사용자 재정의: 유령의 몸은 지형에 이미 서 있는 **3D 마네킹**(ybot)이다. 별도 2D 얼굴을 그리는 게 아니라 —
> ① 대화 진입 시 **카메라가 그 마네킹으로 줌인**하고, ② **그 마네킹의 얼굴을 들여다보면 글자가 속에서 떠다니고**,
> ③ 검은 반투명 대화 박스는 지우고 **자막을 마네킹 아래(하단 중앙)** 에 띄운다.

## 0. 한 줄

유령과의 대화 = **그 앞에 다가서서(줌인), 기억이 떠다니는 얼굴을 들여다보며, 자막으로 듣는 것.** UI 패널이 아니라 공간 속 마주함.

## 1. 세 조각과 담당 파일

| 조각 | 내용 | 파일 |
|---|---|---|
| **카메라 줌인** | 대화 시작 시 카메라가 유령 머리 앞 ~1.15m 로 1.2초 트윈. 종료 시 0.8초 복귀. FP 이동은 overlay 존재 검사로 이미 freeze. | [play-test.html](../play-test.html) `_enterLumenDialogPhase1` + `_runCamTween` |
| **얼굴 속 글자** | 머리 본(headBone) 주변·내부를 단어 스프라이트가 느리게 궤도 부유. 마네킹이 xray(additive) 머티리얼이라 글자가 머리 "속"에 겹쳐 보임. 대화 중 그 유령의 혼잣말 스프라이트는 숨김. | [lumen_scene_mannequins.js](../js/ui/lumen_scene_mannequins.js) `dialogFocus` 계열 API |
| **하단 자막 + 최소 입력** | 화면 절반 패널 폐기. 자막은 하단 중앙(파동 위 300px)에 **영화 자막식 — 글자 폭만큼의 검투명 띠 박스**(1.45rem, 가운데 정렬), 단어 페이드 캐스케이드. 플레이어 발화·선택지·입력도 가운데 정렬 + 옅은 검투명 배경. | [lumen_dialog_phase1.js](../js/ui/lumen_dialog_phase1.js) 표시층 |

## 2. 자막 리듬 규칙 (260709 개정 — RPG식 수동 넘김)

1. 단어 단위 페이드 캐스케이드 (타자기 X). 캐스케이드가 끝나면 줄 끝에 ▾ 깜빡임.
2. **RPG식 수동 넘김 (260709 사용자 결정)** — 유령 대사는 자동으로 안 넘어감. 클릭(화면 아무 데나)/Space/Enter: 출력 중이면 즉시 완성, 완성 후면 다음 줄. 플레이어 발화만 짧게 자동 진행.
3. **선택지 폐기 (260709 사용자 결정)** — 대화는 자유 입력만. `dlg.choices` 데이터·생성 파이프라인은 유지(미표시), 되살리려면 턴1 호출부 `[]` → `dlg.choices` 원복.
4. **입력 게이트** — 마지막 대사를 넘겨야 입력창 등장 ("듣기" 강제).
5. 자막 나가는 동안 얼굴 속 글자 가라앉음(listening=false), 플레이어 차례에 일렁임.
6. ~~첫 조우 스킵 불가/재조우 스킵~~ — 수동 넘김이 읽기 페이스 그 자체라 폐기.
7. **대화 중 유령은 반드시 카메라를 마주봄** — gaze 조건과 별개의 보장 회전 (등 보이는 채 대화 방지, lumen_scene_mannequins `_dlgUpdate`).

## 3. 얼굴 속 글자 사양

- **소스 3종**: 씬 `meta.motif_tags` + `echo_words`(top-level/meta) 최대 5개 + **흡수된 플레이어 명사** (등장 플래시와 함께 유입, 상한 8).
- **결 반응** (`dialogMood`): resonance → 또렷(×1.0) / vague → 옅음(×0.8) / dissonance → 흐리고 미세 떨림(×0.5 + jitter).
- 스프라이트: depthTest off, renderOrder 999 — 줌인 시 머리 메시에 안 가림. 궤도 반경 0.09~0.18m, 카메라 쪽으로 0.07m 당김.
- 대화 종료(`dialogEnd`) → 페이드아웃 후 자체 dispose. `_clear()`(유령 철거)에서도 즉시 정리.

## 4. 신호 배선

```
play-test (_enterLumenDialogPhase1)
  ├─ 진입: mq.dialogFocus(sceneId, words) → headWorld → 카메라 트윈
  ├─ window.LumenGhostFaceFX = { mood, absorb, activity }   ← 대화 모듈이 호출
  └─ 종료(then/catch): dialogEnd + 카메라 복귀 + FaceFX 해제

lumen_dialog_phase1 (표시층)
  ├─ 자막 시작 → activity(false) / 입력 등장 → activity(true)
  ├─ 매 턴 결 확정 → mood(alignment, resonance)
  └─ 슬롯 흡수 성공 → absorb(word)
```

어댑터 없으면 (테스트 하네스, 마네킹 미로드) 전부 무해한 no-op.
