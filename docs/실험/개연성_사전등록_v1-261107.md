## 0. 한 문단

관객이 씬 i에서 한 상호작용(감정 벡터 u)이 이 기억의 각 점 k와 얼마나 개연성 있는지를 재는 수 P(i,k)의 후보 세 식(M1 자율 조향 코사인, M2 변이 벡터 공명, M3 감정 시간맥락)을, 옛 엔진 아래서 모인 37회차 걸음 자료에 대 본다. 이기는 기준은 "정답률"이 아니라 **관객 발화를 쓰지 않는 영모형들(특히 작가 감정 닮음 N3와 관객 감정만 N6)보다 실제 다음 씬을 더 위에 놓는가**, 그리고 **같은 씬에 온 다른 사람의 말로 바꿔 끼우면 점수가 떨어지는가**(N5)다. 못 넘으면 "상호작용이 연결을 정한다"는 가설로 내려가고 무대는 N3로 열되 새 식은 기록만 남긴다.

## 1. 질문과 가설

| 번호 | 가설 | 식 | 지위 |
|---|---|---|---|
| H1 | 씬 i에서의 관객 감정으로 조향한 중심과 점 k의 각도가, 작가 감정 닮음(N3)·관객 감정만(N6)보다 실제 다음 씬을 더 위에 놓는다 | **M1** | 주 |
| H1' | 관객이 씬 i에서 감정을 튼 **방향**과 i→k의 감정 변화 방향의 일치가 N3·N6보다 실제 다음 씬을 더 위에 놓는다 | **M2** | 주(공동) |
| H2 | 회차 안에서 쌓인 감정 맥락(목도리)이 순간 감정만 쓴 M1보다 실제 다음 씬을 더 위에 놓는다 | **M3**(ρ 고정) | 보조(별도 가설군) |

H1과 H1'은 같은 가설군(다중비교 보정 m=2). H2는 "이력이 더하는가"라는 다른 질문이라 별도 가설군(보정 없음, 단 보조라고 표기). M4(다중 장부 곱셈)는 이번에 등록하지 않는다(저작 데이터·단서 추출기 부재, 패키지 §6.0).

## 4. 식 (항마다 이름, 자유 파라미터 명시)

### 4.1 M1 자율 조향 코사인
- 즉각 공명비 α = max(0, cos(u, o_i)).
- 공백 지시 ν ∈ {0,1} = 그 걸음의 관객 공백 플래그(§2 is_void). 없으면 0.
- 공백 축 벡터 v_void = 기억 축 중 {emptiness, numbness}에 1을 둔 단위벡터. 둘 다 없으면 공백 씬(`void_info.sceneVoid`)의 ô. 그것도 없으면 전 축 균등 단위벡터.
- 조향 중심 c = (1−ν)(α ô_i + (1−α) û) + ν v_void.
- **P1(i,k) = cos(c, ô_k)**. 범위 0~1(비음수). 0 = 겹치는 감정 성분 없음.
- 영벡터 규칙: û = 0이면 c = ô_i(= N3).
- 자유 파라미터 0.

### 4.2 M2 변이 벡터 공명
- 기억 평균 ō = unit(Σ_m ô_m) (13씬 전부).
- 중심화 공명비 ã = (1 + cos(û − ō, ô_i − ō)) / 2.
- 기준점 r = (1−ã) ô_i + ã ō.
- 관객 변이 d_user = û − r. 후보 변위 d_k = ô_k − r.
- **P2(i,k) = (1 + cos(d_user, d_k)) / 2**. 범위 0~1. 0 = 정반대 방향.
- 영벡터 규칙: û = 0, 또는 |d_user| < 1e−9, 또는 cos의 분모가 0이면 그 자리는 0.5(정보 없음).
- 자유 파라미터 0. **명시**: ō가 점 집합에 의존하므로 점이 늘면(관객 장면 추가, D8) 기존 쌍의 P2가 바뀐다.

### 4.3 M3 감정 시간맥락 (보조)
- 맥락 갱신 m_1 = û_1, m_t = unit(ρ m_{t−1} + √(1−ρ²) û_t). 영벡터 û는 건너뜀.
- 점의 첫 실 저장 맥락: 작가 순서 π = scene_order 오름차순. e_{π1} = ô_{π1}, e_{πs} = unit(ρ e_{πs−1} + √(1−ρ²) ô_{πs}).
- α_t = max(0, cos(m_t, e_i)). c = unit(α_t e_i + (1−α_t) m_t).
- **P3(i,k) = cos(c, e_k)**.
- 영벡터 규칙: m_t = 0이면 P3 = cos(e_i, e_k).
- 자유 파라미터 1: **ρ = 0.6, 임의 고정**(문헌 기본값이라는 근거 없음). 민감도 ρ = 0.4, 0.8을 함께 보고하되 판정엔 0.6만 쓴다.
- **명시**: e_k가 작가 순서를 품으므로 M3는 "작가 순서가 식에 들어간" 안이다(11-06 실측 "순서 칸 수 무관"과 긴장). 그래서 보조.

## 6. 옛 엔진 재생 (구획 A의 재료) — 규칙과 한계

목적: 그 걸음에서 **어떤 문이 열려 있었나**(제시 집합 O_i)를 복원한다. 복원이 틀리면 구획 A가 틀리므로 충실도를 먼저 보고한다.

- **재생 규칙** = play-test.html 2026-07-27 0.5단계 이후 코드 그대로: 엔진 스텝(기억별 자, level×shape×void, 히스테리시스 bucket, FIXATED ≥0.85, mismatch 규칙, 패턴 6종) → `PATTERN_CENTER` 중심 이동(17축 혼합 후 AF 2D 투영 / contradiction = 핀 무리 중심 대칭 / avoidance = 공백 핀 / fixation = 현재 씬) → 적응 반경(패턴 상수 × 핀 산포, 산포 0.08~1) → 미방문 핀 중 반경 안 → 없으면 ×1.85 → 없으면 가장 가까운 1 → 상한 2 → avoidance·contradiction이면 공백 핀 추가. 핀 좌표 = `original_emotion`의 AF 투영 + 씬 id 해시 흩뿌림(`mapCoordsSpread`). 잠금(`exclusions`)은 emotion_threshold·emotion_below만 평가, 다른 종류는 "지원 안 함"으로 세고 안 잠근 것으로 둔다.
- **판본 경계**: 커밋 33cb120(2026-08-10 17:11 KST) 이전 걸음은 "fixation이면 원점 핀만" 특례를 적용(pre0810), 이후는 적용 안 함(post0810). 그 밖의 코드 변경은 접근 집합에 영향 없음으로 가정(기록된 커밋 목록으로 확인, 공간무대 검토 세션).
- **관객 공백 플래그**: 옛 엔진은 분류기의 is_void를 썼는데 plays엔 저장되지 않았다. `dialog_turns` 마지막 턴의 지문에서 찾고, 없으면 0으로 둔다(한계).
- **방문 집합**: 그 회차의 plays 행이 있는 씬(현재 씬 포함). 회차 일지의 `visit_order`가 있으면 첫 plays 행 앞의 방문을 보탠다(프롤로그 씬은 plays 행이 없을 수 있음).
- **충실도 보고(판정 아님)**: ① 실제 다음 씬 j ∈ O_i 비율(전체·판본별) ② 회차 일지가 있는 걸음에서 재생 패턴 = 기록 패턴 비율 ③ |O_i ∩ 미방문| 분포(0/1/2/3). ①이 낮으면 구획 A는 "근사 재생" 꼬리표를 달고, 판정에서 구획 A 기준(§8-④)을 뺀다. 그 문턱은 정하지 않는다 — 수치를 적고 사용자가 읽는다.

## 7. 구획과 지표 (예측 정확도 채점 아님 — 영모형 대비 상대 비교만)

- **Ω_i(구획 B)** = 그 회차에서 아직 안 간 씬 전부(현재 씬 제외). 실제 다음 씬이 Ω_i에 없으면(되돌아감) 그 걸음은 B에서 빠지고 개수를 보고한다.
- **구획 A** = 재생된 O_i 중 미방문이 2개 이상이고 j가 그 안에 있는 걸음. **A2** = 정확히 2개인 걸음(쌍대).
- 지표(모형 M마다, 자(스케일) 무관한 것만):
  1. **B 순위 백분위** = Ω_i 안에서 j의 점수 백분위(0 = 꼴찌, 1 = 1등; 동점은 반씩). 걸음 평균.
  2. **B 1등률** = j가 최고 점수인 비율(동점은 1/동점 수).
  3. **A 1등률** = O_i ∩ 미방문 안에서 j가 최고인 비율. **A2 쌍대 적중률** = 둘 중 j가 높은 비율.
  4. **N5 p값** = 교체 1,000회에서 지표 1(B 백분위)이 관측값 이상인 비율, (1 + 횟수)/(1 + 1,000).
  5. **절반 안정성** = 다중 걸음 회차를 무작위 절반으로 500회 나눠, 각 절반에서 Δ = 백분위(M) − 백분위(N3)의 **부호가 전체와 같은** 비율. N6에 대해서도 같은 것.
- 로그 점수는 쓰지 않는다(코사인은 확률이 아니라 자에 묶임 — 패키지 §6.2 #2).
- 난수 씨앗 261107(mulberry32). 모든 무작위는 이 씨앗에서.

## 8. 판정 기준과 출구 (데이터 접촉 전 고정)

**M1, M2 (가설군 1, α = 0.05/2 = 0.025)** — 다음 넷을 **모두** 만족하면 "통과":
1. B 백분위(M) > B 백분위(N3) **그리고** > B 백분위(N6).
2. N5 p < 0.025.
3. 절반 안정성(N3 대비) ≥ 0.80.
4. 구획 A 걸음 수 ≥ 30이면 A 1등률(M) > A 1등률(N3). 30 미만이면 이 항은 "보고만"으로 두고 1~3으로 판정.

**M3 (가설군 2, 보조, α = 0.05)** — "이력이 더한다"는 B 백분위(M3, ρ=0.6) > B 백분위(M1) 그리고 N5 p < 0.05. 통과해도 M3를 주 식으로 올리지 않는다(작가 순서 의존 명시). 다음 사전 등록의 입력.

**출구**
- M1 또는 M2 통과 → 통과한 식(둘 다면 B 백분위 높은 쪽)을 `js/stage2/plausibility.js`의 1차 식으로 올린다. 단 무대 길이·밝기 매핑은 D28 결정 뒤(패키지 §6.4).
- 둘 다 실패 → "관객 상호작용이 다음 연결의 개연성을 정한다"를 **가설**로 강등해 THEORY §3에 적고, 무대 첫 판은 N3(작가 감정 닮음)로 열되 M1·M2를 **그림자 모드**(계산·기록만, 무대 미반영)로 병행한다. 새 무대 자료가 쌓이면 v2 사전 등록.

3. 추출(읽기 전용): `node tools/plausibility/pull.mjs` → `tools/plausibility/out/raw-<날짜>.json`(원문 0자, 커밋 안 함).
4. 실행: `node tools/plausibility/run_backtest.mjs --raw tools/plausibility/out/raw-<날짜>.json` → `tools/plausibility/out/metrics-<날짜>.json` + `docs/실험/개연성_백테스트_결과-<날짜>.md`.
5. 결과 문서의 "판정" 절을 이 문서 §10에 요약 추기(날짜·커밋 해시·통과/강등·충실도 ①②③).
6. 커밋: `실험: 개연성 백테스트 v1 결과 (<날짜>)` — 결과 md + metrics json + 이 문서 §10. raw는 제외(.gitignore). 푸시.
7. 사용자에게 보고: 표 한 장(모형 × 지표) + 판정 한 줄 + 충실도 세 줄 + 다음 결정(D27·D28 또는 v2 사전 등록).

## 11. 한계 (정직 칸)

- 자료는 옛 엔진(2D 거리·상한 2)이 열어 준 문 안에서 고른 **검열된 선택**이다. 구획 B의 "Ω 전체 순위"는 옛 엔진의 제약이 섞여 있다. 구획 A가 더 공정하나 재생이 근사다.
- 기준선 N3의 11-06 수치(−0.30)도 옛 엔진이 섞인 값이다. 이번엔 같은 걸음 단위·같은 지표로 다시 잰다(실 35 ≠ 걸음 179).
- 걸음은 회차 안에 묶여 독립이 아니다. p값은 교체 영모형(N5)에서만, 참고로 읽는다.
