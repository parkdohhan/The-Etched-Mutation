## 2. 작업 순서

### 1단계 — 자가 검증 먼저 (필수)

명세 구현이 맞는지 **합성 데이터로 먼저 증명**한다:
1. **무뒤틀림 세계**: §11.7 N2 방식으로 합성(전역절편 + 회차 오프셋 + 잡음)
   → 파이프라인 통과 시 ρ ≈ 0 이어야 함 (기준: ρ < 0.05).
2. **뒤틀림 주입 세계**: 위 합성에 인위적 순환 성분(고리 하나에 상수 뒤틀림 벡터)
   추가 → ρ 가 뚜렷이 상승하고 Exhibit A 탐지가 그 고리를 찾아야 함.

둘 다 통과 못 하면 실데이터로 넘어가지 않는다. 통과 결과를 보고서에 기록.

### 2단계 — MM23L 실행

- 입력: `tools/persona-sim/data/MM23L_plays.json`
  (UTF-8로 읽을 것 — PowerShell JSON 파서는 이 파일에서 깨진 전례 있음, node 사용)

  영모형 2종 각 1,000회.
