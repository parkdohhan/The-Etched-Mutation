## A-2. 구조 후보 분석

### (가) 지속행동 후보 — 평면도 그리기는 행동으로 작동하는가
- 평면도가 실제로 **손에 들려 있는 장면**: 1·2·5·16·17 (현1, 도입 2쪽) → 68(빈칸 떠올림, 손에 없음) → 74·75 (결말, 선 하나 더 + 실 묶기). **중간 8쪽(계곡·대표 메일·버스·혼인신고·인도·카페)에는 평면도가 0회.** 즉 도입과 결말의 **액자**이지 장면을 전환시키는 엔진이 아님.
- 평면도가 장면을 **분기**시킨 자리: 없음. 분기를 만든 건 전부 **외부 사건**: 6(경택 전화) → 65(경택 고백 + "고성에 가보고 싶어") → 67(중개사) → 68~70(빈집 입장). 임현이 "뒤에 변하긴 하거든요. 만나러 가긴 하는데"라 한 것이 이 65~70 자리.
- 실제로 글을 끌고 가는 **더 큰 행동 단위**는 "경택과 주말 속초→고성 당일치기"(44~77, 전체의 40%). 이것이 임현이 요구한 "장면이 전환될 정도의 시간이 흐르는 행동"에 가장 가깝지만, 평면도와 **병행**이 아니라 결말에서만 합류.
- **소파 역할 후보(반복 사물)**: ① **모래시계** — 현재 속초행 버스(44)와 과거 고성행 버스(53)에 "그때도"로 두 번, 결말 별자리(73)에 세 번째. 기다림·측정이라는 행동을 품고 있어 '남은 여름' 소파에 가장 가까움. ② **잠자 씨** 고양이(47·67·77) 세 번. ③ 검은 비닐봉지→빈 봉지(60·77). ④ 붉은 실/새끼발가락(22·74·75). 평면도보다 이 넷이 더 "행동 패턴"으로 읽힘.

### (나) 비밀·반전 후보
- 이 글에 숨긴 비밀의 **반전은 없음**. 휘주 사망은 29에서 한 문단으로 선고되고 36에서 비명으로 끝남(사고 장면 자체는 생략). 독자가 뒤집어 읽을 정보가 없음.
- 유일한 '정보 역전': **혼인 신고서**. 7("혼인신고는 못 했지만")·50(사라진 신고서)·52(공무원 "미혼")·56(경택 놀람) → 65(경택 "나, 진짜 혼인신고 했거든… 행정 착오"). 결혼이 '없었던 것'이 될 수도 있다는 **기록의 불확실성**이 평면도(없는 집을 그리기)와 같은 모티프. 반전이라기보다 모티프 반복.
- 계곡의 검은 안개 "더 무서운 게 남아 있단다, 애야"(33)가 사망 **예고**로 쓰인 복선. 단 한 번만 쓰여 회수 없음.

### (다) 믿을 수 없는 화자의 앵커(확정 키워드)
- 화자는 믿을 수 없는 화자가 아니라 **기억을 잃는 화자**. 확정 키워드는 **있음**: 24 "감당하기 어려운 순간이 오면… 도망치는 습관 / 이해가 어렵거나 복잡하면 일단 물러났다" → 42 "이번에는 그럴 수 없다" → 65 "고성에 가보고 싶어" → 76 "내일은 바다에 갈 거야". 이 한 줄이 글 전체의 **성격 규정 + 결말 방향**을 확정. 임현은 이 자리를 짚지 않았고, 대신 행동 부재를 문제 삼음(아래 A-3 #21).
- 부수 앵커: 8 "기억이 통째로 사라지는 시간", 57 "그 후로 경택과 연락한 적은 없다. 내 기억으로는 그렇다." — 기억 불신 선언이 두 번.

### (라) 제3의 이야기 후보 (임현 '웃는 남자'의 '아버지 자리' = 이해할 수 없는 것 옆에 놓을 "이해할 수 있는 것")
1. **전 직장 대표·저작권·낮은 의자·내용증명**(37~42) — 키워드가 애도와 가장 멀고(브리오니 양복·츄르·마통), 화자가 "이번에는 물러나지 않겠다"고 **처음 결심하는 사건**. 현재 미완(메일만 받고 끝). 가장 유력.
2. **구 선배와 개 하니**(62·63) — 관절염·신약 주사·"네가 우선 행복하면 돼". 돌봄의 거울.
3. **혼인 신고서 행정**(50·52·53·65) — 공무원·모래시계·"행정 착오". 기록 vs 기억.
4. **잠자 씨**(47·67·77) — 휘주가 이름 붙인 고양이가 새끼로 대체됐을 가능성.
5. 부모의 34평·협궤열차(49·51).
- 임현 시연 틀로 대입하면: 이해할 수 없는 것 = 휘주의 죽음(1~2쪽 분량이어야) / 이해하는 통로 = 1번(대표 사건)을 키워 분량 차지 / 골방 정적 행동 = 평면도.

### A-4. 임현 수정 시연 → 사건 목록 복원

**시연 A — 일주일 틀 (평면도 병행형)**
1. 월: 산책 — 중간에 비, 홀딱 젖음, 옷·신발 말린 뒤 **마지막에 평면도를 떠올림**
2. 화: 동창회 — 술 마시고 귀가, **아무것도 못 함(평면도 못 그림)**
3. 수: 부동산 사람 방문 — 오후에 집 둘러봄, **평면도 그리던 중에 찾아옴**
4. 목: 이사 준비 / 집 내놓음
5. 금: 다시 산책 — 마무리
(수강생 제안 요일 예: 낚시·병원. 장면당 15~20매. 행동끼리 무관해도 됨, 평면도가 꿰는 실)

**시연 B — '남은 여름' 구조 대입**
1. 도입: 버려진 소파 + 죽은 친구의 책 (행동 예고, 사연은 한 문단)
2. 다음: 소파에서 책 읽는데 추 팀장(전 직장 상사) 끼어들어 대화 — 죽은 친구 얘기는 조금씩
3. 이후: 행동 유지 + 매 장면 하나씩 상황 추가
4. 종결: 소파가 치워짐 = 행동 패턴 소멸
→ 평면도 대입: 평면도 = 소파. 그리는 자리에 **타인이 끼어드는** 장면이 있어야 함.

**시연 C — '웃는 남자' 구조 (이해 불가 ↔ 이해 가능)**
1. 핵심 사건(1~2쪽): 연인 버스 사고 사망, 나는 손 대신 가방을 잡았다
2. 거리 두기 1단계: 장례식장 → 무조림
3. 거리 두기 2단계: "나는 그 죽음을 이해할 수 없다" ↔ 이해할 수 있는 것 = 아버지 (분량 대부분: 둘리·화장실·고기 식사·공장 직원 사고 "가만히 있어")
4. 가장 안쪽: 골방에 누워 생선 씹기(정적 행동)
→ 평면도 대입: 휘주 죽음 1~2쪽 / 이해 통로 = 제3 인물(A-2(라) 1번 대표 사건 유력) / 골방 = 평면도.

**대안 D — 정적 유지형 (킥보드 소설)**
- 일관 행동 하나만(킥보드) + 무관한 일상 키워드 빼곡히(작은아버지 문병·10만 원 봉투·접촉사고·편의점 도시락·마술·금붕어·한식 뷔페·삼겹살·마늘장아찌) + 후반 사건(다리 골절·젊은 남자).
- 평면도에 적용 시 조건: 키워드가 지금보다 몇 배 많아야 하고 서로 무관해야 함. 현재 키워드(고성·속초·양양·바다·비·캠핑)는 전부 동질.

### (가) 유리의 지속행동 후보
- **돌봄 루틴**(23·24·25): 유치원 마중·간식·교자 털 빗기·씻기기·원복. 글의 중반 한 쪽에 **요약 진술**로만 있고 장면화된 날은 오늘 하루뿐.
- **교자(고양이) 돌보기**(2·22·23·37·39·40·41): 밥그릇 확인 → 냉장고 위 회상 → 털 빗기 → **몰래 간식 준 것(사나 주장)** → 간식 주기 → 껍데기 버리기. 글 전체에서 **유일하게 분기(반전)를 만드는 행동**. 단 '몰래 간식 줬다'는 사실 자체는 본문에 장면이 없고 사나 말로만 존재 → 임현의 "앞에 던져놔야 되는 키워드가 없다"와 정확히 일치.
- **운전·라디오**(3·4·8): "평소라면 전혀 하지 않았을 행동" = 오늘 하루의 일탈 행동. 공항까지만 쓰이고 귀가 후 소멸.
- **거짓말하기/비밀 쌓기**(4·6·25·34): "나도 거짓말을 해볼까요" 선언 후 실제로 사나에게 하는 거짓말은 없음(마지막 41 '모르는 척'이 유일). 행동이 아니라 **태도**.
- **골뱅이 무침 만들기**(32): 사나 좋아하는 음식. 1회.
→ 임현 처방 "나는 사나이 집에서 뭘 하는데 사실 이게 이 이야기야" = 이 돌봄 루틴을 장면 단위 행동으로 키우라는 것. 시연은 **피크닉**.

### B-4. 임현 수정 시연 → 사건 목록 복원

**시연 A — 믿을 수 없는 화자 작동법**
1. 첫 문장에 **확정 키워드**: "이 이야기는 내 딸을 체벌한 선생에게 사과받는 이야기야" (의심 불가 사실 하나)
2. 본문: 그 사실을 훼손하지 않고 전개
3. 후반: **믿을 수 없는 요소 하나만** 추가 (범인이다 → 범인이 아닐 수 있는 증거 하나)
4. 결과: 열린 결말
→ 「사나」 대입: 1단계 부재. 후보 — "나는 옛 애인의 아내 집에서 그 아이를 돌본다"(11) 또는 "나는 교자에게 몰래 간식을 준다"(장면으로).

**시연 B — 2인칭 고백체에 맞는 소재 (전형 2개 포개기)**
1. 화자: 실수로 사람을 죽였다 (단조로운 고백)
2. "너"의 정체: 어릴 때 나를 때리던 학폭 가해자
3. 본문 분량: 학폭 피해자 관점의 이야기
4. 결말 반전: "난 널 이해할 수 있을 것 같아. 어쩌면 실수였을지도. 나도 사람 죽인 거 실수였어."
→ 핵심 고백은 조금, 분량은 다른 전형이 채움. 「사나」는 핵심(임신·옛 애인)이 사적이고 비전형이라 이 틀이 안 맞는다는 진단.

**시연 C — 1인칭 목표 지향형**
1. 설정: 나는 가사도우미로 이 집에 있다. 가족처럼 대해 준다. 남편은 한국.
2. 사건: 일본인 모자(사나·노아)와 한국인 나의 **피크닉**
3. 피크닉 진행 중 비밀이 드러남 → 거리감 적절
→ 지금 글의 '공항 마중→저녁'을 피크닉 같은 **목표 있는 외출**로 바꾸고, 회상은 그 행동 사이에 배치.

**레퍼런스 작품 구조(미술 선생·불륜·2인칭)**
1. 표면(열고 끌고 감): 딸을 체벌한 미술 선생에게 사과받으러 감
2. 주 분량: 두 사람이 그림 그리며 친했던 과거
3. 핵심(최소 분량): 프랑스 유학 중 미술 선생의 남자친구와 바람 → 의절
4. 결말: "나는 사과했으니 너도 사과해" → 차로 쳐버림
→ 「사나」 대입: 표면 = 만우절 거짓말(미달) / 주 분량 = 정훈·교회·엄마 회상 / 핵심 = 임신(그러나 1/4 지점에 자진 공개되어 핵심의 '최소 분량·후반 배치' 원칙 위반).

# C. 두 작품 교차 — 임현 진단의 공통 뼈대

| 항목 | 평면도 그리기 | 사나 |
|---|---|---|
| 표면 행동 | 평면도 그리기 (정적, 도입·결말 액자) | 만우절 거짓말 / 사나 집 돌봄 (진술로만) |
| 핵심 사건 분량 | 휘주 죽음 1문단+비명 (적절) | 임신 1문장, 상실 1구절 (적절하나 **너무 일찍**) |
| 빠진 것 | 그리움 외의 **행동 하나** (더 큰 행동 단위) | 설정 외의 **에피소드 하나** (같은 규모) |
| 거리감 | 죽은 남편의 집을 그림 = 0 | 유년→임신 인과 사슬 = 0 |
| 키워드 밀도 | 동질(고성·속초·바다·비) → 적음 | 적음(이야기 개수 자체가 적음) |
| 화자 앵커 | 있음(24 도망 습관 → 42 → 65) | 없음(6이 전부를 의심시킴) |
| 결말 | 행동이 사라지지 않고 **추가**(선 하나 더) — 소파 원리 역행 | 반전이 분위기만, 공모로 봉합 |
| 처방 | 병행 행동(일주일 틀) 또는 키워드 빼곡 | 제2 이야기 추가 또는 1인칭 목표 지향(피크닉) |
| 레퍼런스 | 윤단 '남은 여름'(소파), 킥보드 소설, '웃는 남자'(디디·아버지·골방·세월호), '어느 밤' | 미술 선생·불륜 2인칭 소설(제목 미언급), 살인자/학폭 시연 |
