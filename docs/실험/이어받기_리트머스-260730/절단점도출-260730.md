# 절단점 도출 프로브 — "아무도 찢지 않는다" (260730)

> 사용자 문제 제기: 절단점을 작가 편집 감각으로 정하는 것 거부. 이론에서 도출할 것.
> 배경: era이론 §2·§3 (요동=내부, Δ=상속 점프) + 촉발 3조건 (결핍·하전·정체성).
> 데이터: 씬 18개 → 문장 122개 단독 분류 (배포 claude-scene, 기억 축) → 인접 델타.
> 동결: `절단프로브.json` (1차) · `절단프로브_2차규칙.json` (2차) · `test/tools/stem_derive_{probe,refine}.mjs`

## 1. 규칙 두 개

- **1차 (순수 결핍)**: 절단점 = argmax Δ (최대 상속 점프의 이음매).
  **실측 결함**: 몸통이 쌓이기 전 첫 이음매에서 찢음 (도입 서술→첫 하전 문장의 델타 스파이크.
  footprints 0·1·4, UNDW 8·11). era가 열리지도 않은 곳의 절단 — 하전 조건 위반.
- **2차 (촉발력, 채택 후보)**: **촉발력(j) = Δ(j) × Σ_{i<j} Δ(i)** — 결핍 × 하전.
  소문 공식 R ≈ 중요도 × 모호성과 동형. j=0이면 하전 0이라 절단 불가 (이론적으로 옳은 배제).

- 불일치 중 상당수는 **2차가 손보다 나은 자리를 찾은 사례**다 (작가 감수 대상):

  - UNDW#3: "광대뼈가 높고, 입술이 두껍고, 눈 밑이 처진. →" 감춰지는 도약 =
    **"아주, 내가 아주 보고 싶어 한 얼굴."** (인식 자체를 플레이어가 공급)
  - UNDW#11: "죽었구나. →" 감춰지는 도약 = **"확실하지 않았지만 나는 그렇게 정했다."**
    (죽음을 '정하는' 행위를 플레이어가 공급)

  않는다" 원칙과의 경계. 자문(自問)은 청자를 향한 질문이 아니므로 허용으로 해석하되 기록.
