## 1. 동결하는 결정 3건 (2026-07-30 사용자 승인)

### 결정 1 — 형식 전환 + 측정 의미 전환의 명시 채택

- **플레이 형식**: 유령은 자기 era(소강~소강, 닫힌 기억 조각)의 화자다. 유령의 발화는
  era를 **요동 한복판에서 찢고 멈춘다**(미완결 지문). 관객이 연결사를 골라 문장을 이어
  **자기 p로 era를 닫는다**. 닫힌 판본이 이본이다.
- **측정 의미**: 이 형식에서 정렬도가 재는 것은 "관객의 감정이 원본 감정과 닮았는가"
  (공감)가 아니라 **"관객이 재구성한 이야기가 원본 서술과 닮았는가"(재구성 충실도)**다.
  Bartlett 연쇄 재생산 전통과 정합 — 격하가 아니라 채택된 의미 전환임을 명시한다.
- 존재론 가드 불변: 유령은 관객에게 응답하지 않는다. 마이크는 관객→기억 방향으로만 넘어간다.

### 결정 2 — 형식 epoch 경계

- 입력 형식이 바뀌면 발화 자체가 비교 불가능해지므로(원시 벡터 소급 재측정으로도 못 잇는
  단절), 데이터에 형식 꼬리표를 상시 기록한다.
- 배선: `plays.dialog_turns[]` 각 턴 객체에 `input_form` 키.
  `'free_v1'` = 자유 대화(현행, 2026-07-30부터 명시 기록). 이어받기 배포 시 `'cont_v1'`.
  키 없는 기존 행 = free_v1 유산으로 해석.
- **전/후 혼합 집계 금지.** 분포·문턱·통계는 form 단위로만.

### 결정 3 — 알파 경로 A

- 형식 전환을 알파 **전**에 완료하고, 알파는 새 형식의 질적 검증으로 쓴다 (실관객 3회차를
  결함 확정된 옛 형식 검증에 쓰지 않는다 — critic 좌표계의 "측정 수술 선행" 원칙).
- 본 실험의 잠정 문턱으로 접촉·버킷을 재설정하되, 알파 동안 접촉 연출은 보수 운영
  (잠정 문턱 신뢰 낮음 — 난발 조짐 시 작가 수동 감수로 전환). 최종 문턱 = 알파 분포.

## 3. 지문(stem) 절단 규칙 (era이론 §2 적용)

1. **요동 내부에서 끊는다.** 씬 텍스트에서 하전이 오른 채 해소가 안 착지한 지점 —
   인식/반전/화해가 완결되기 **직전**. 소강(닫힌 끝)에서 끊으면 완결 대사가 되어
   실험 무효 (그건 현행 형식이다).
2. **정체성 보존.** 씬의 골격(장소·인물·사건)은 지문 안에 남긴다 — 두 파국 사이 조건.
3. 말끝은 흐린다 (`…` / "그건…" / 미완 문장). 질문 금지 — 유령은 묻지 않는다.
4. **한계 명기**: era의 조작 정의는 발화 턴 시계열 위인데 씬 내부 턴 시계열은 없다.
   절단점은 **텍스트 근사**이며 본 실험 지문은 실행 세션(LLM)이 저작 — **작가 스팟 검수 잔여**.

era 프로브 결과 (씬 간 델타, 단일 델타 근사 — 창 기반 아님, 참고용):
- footprints: 완만한 활 (Δ 0.26~0.56). 소강 후보 1→2, 2→3.
- UNDW-001: 3→4, 4→5, 12→13에서 Δ=1.000 (인접 씬 감정축 완전 직교 — era 경계 + 큰 상속
  점프 후보). 유령 경계 재획정(씬 묶음)은 본 실험 범위 밖, 형식 배포 설계의 입력으로 넘긴다.
