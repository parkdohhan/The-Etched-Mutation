## 0. 판정 — **GO (시뮬 세계 예비 신호)**

핸드아웃의 두 주장이 모두 시뮬 세계에서 성립:

1. **끝점이 전역 의미를 결정한다** (할머니 사례) — 15/15 페르소나, p=0.00003.
2. **어디를 자르느냐가 결정한다 — 같은 양을 잘라도** (층 이론 고유 주장) —
   요동 지점 절제가 정합 구간 절제보다 전역 절편을 유의하게 더 이동시킴,
   p=0.019 (감정 분포) / p=0.006 (착색 이동량).

2번이 핵심. "내용을 빼면 당연히 달라진다"는 자명한 반론을 통제한 상태(양쪽 다 씬
1개 제거)에서 **절단 위치 효과가 독립적으로 검출**됐다. 순환성 없음 — 절단은
조작 변수이므로 Track B C3류 순환 문제가 원리적으로 발생하지 않는 유일한 검증 경로.

## 1. 설계

**재료**: MM23L 「당신에게」 씬 0~9 (씬 10 스텁 제외, Supabase 스냅샷
`data/MM23L_scenes_snapshot-260722.json`).

**요동(경계) 판별 — 작가측 감정 벡터의 인접 씬 L1 델타**:

```
0→1: 1.4   1→2: 1.1   2→3: 1.5 ★최대(죽음)   3→4: 1.1   4→5: 0.8
5→6: 0.9   6→7: 0.8   7→8: 0.8              8→9: 0.7
```

- 씬 3(엄마의 죽음) = 최대 요동 접합부에 낀 씬. 절제 시 생기는 이음매 2→4 = 1.1 (거침).
- 씬 4(영안실) = 슬픔 고원 내부. 절제 시 이음매 3→5 = **0.7 (전체 최소급, 매끄러움)**.

**조건 5종 × 페르소나 15명 = 75셀** (셀당 1표본):

| 조건 | 구성 | 검증 대상 |
|---|---|---|
| FULL | 씬 0~9 | 기준선 |
| END5 | 씬 0~5 (죄책 "미안했어요"에서 끝) | 끝점 — 화냄에서 절단 |
| END8 | 씬 0~8 (짜사이 재회에서 끝) | 끝점 — 화해까지 포함 |
| CUT3 | 0~9 − 씬3 | **요동 관통 절제** |
| CUT4 | 0~9 − 씬4 | **정합 구간 절제** (동량 대조) |

측정(전역 절편 대리): 17축 global_emotion 분포 + warmth(−1 어두움 ~ +1 따뜻함) +
한 문장 요약 + 잔감. 씬 번호는 조건마다 연속 재부여(빈칸 감지 차단). 감정 정답
참조(original_emotion) 미노출. 모델 claude-sonnet-4-6, temperature 0.3.

## 2. 결과

**warmth 조건별 평균**:

| 조건 | mean | sd |
|---|---|---|
| END5 | **−0.546** | 0.057 |
| CUT4 | −0.306 | 0.039 |
| FULL | −0.290 | 0.071 |
| CUT3 | −0.235 | 0.072 |
| END8 | **−0.067** | 0.189 |

**가설 검정 (일측 부호 검정, 쌍별)**:

| 가설 | 방향 | 결과 | p |
|---|---|---|---|
| H1 | warmth(END8) > warmth(END5) | **+15 / −0** (평균차 +0.479) | **0.00003** |
| H2 | 분포이동 L1(CUT3,FULL) > L1(CUT4,FULL) | +10 / −2 / 동점3 (0.244 vs 0.163) | **0.019** |
| H2w | \|Δwarmth\|(CUT3) > \|Δwarmth\|(CUT4) | +10 / −1 / 동점4 | **0.006** |
| S1 | warmth(END8) > warmth(FULL) | +13 / −0 / 동점2 (평균차 +0.223) | **0.00012** |

**S1의 함의**: FULL은 END8에 씬 9(현관문이 쳐닫힘) 하나를 더한 것뿐인데 전원이
다시 어두워짐. 끝점 효과는 특정 절단 하나의 산물이 아니라 **모든 접미사에서
작동**한다 — "마지막 장면이 전체를 다시 착색한다"의 정량 판본.

**질적 전시 (Exhibit)** — p03의 한 문장 요약:

- FULL: "이 기억은 말하지 못한 것들이 쌓인 채로 끝내 닫혀버린 문에 관한 기억이다."
- CUT4: **글자까지 동일한 문장.** → 정합 구간 절제 = 전역 절편 보존.
- CUT3: "말하지 못한 것들이 몸의 감각으로만 돌아오는 이야기다." → 요동 절제 = 전역 절편 변경.
- END5 ↔ END8 대비 (p03): "쌓인 채로 **끝나버린 관계**" ↔ "결국 **짜사이 한 접시로
  돌아오는** … 어긋난 채로 이어지는 기억" — 종결 서사가 지속 서사로 반전.

## 3. 한계 (정직 고지)

1. **요동의 대리 측정**: 핸드아웃 §5의 요동은 발화자-청자 **정렬도**의 요동인데,
   본 실험은 작가측 감정 델타로 대리했다(재료를 조작해야 하므로). 관계적 정렬도
   기반 본판정은 베타 실관객 + `dialog_turns` 턴 단위 데이터에서 (Track B Level-E와
   같은 게이트).
2. **요동-사건성 교락**: 씬 3은 감정 델타 최대 지점이면서 서사적 중심 사건(죽음)
   이다. "플롯 핵심을 뺐으니 당연하다"는 반론이 가능. 이론의 답은 "접합 지점이
   곧 사건"이지만, 분리 설계(사건성 낮고 델타 큰 지점을 가진 다른 기억으로 복제)가
   후속으로 필요.
3. **LLM 페르소나 편향** — Track A §7.2, Track B §9와 동일 한계. warmth 절대값의
   군집(sd 0.04~0.19)은 LLM의 일관성 산물일 수 있음. 부호 검정은 방향만 쓰므로
   완화되지만 소거는 아님.
4. **셀당 1표본, temperature 0.3** — 반복 표집 없음. 15쌍 부호 검정으로 충분한
   신호였으나 효과 크기 추정은 불안정.
