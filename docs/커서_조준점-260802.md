# 아스키 커서 + 조준점 — (2026-08-02)

> 사용자 결정: "1인칭 중 가운데 점 잘 보이게 + 대화(연결사 클릭 등)에서는 게임 자체 포인터만."
> 방향 정정(같은 날): 고딕 → **아스키 느낌**. RECORD 아스키 문·Courier 공명 단어와 같은 결.

## 1. 조준점 (1인칭 포인터 잠금 중)

- 자리: [play-test.html](../play-test.html) `_ensureCrosshair` / `_setCrosshairAiming` — **신규 아님**, 기존 4px 단색(투명도 50%)이 안 보여서 보강.
- 2중톤: 밝은 심(뼈색 rgba(236,224,200,0.95)) + 어두운 테두리(box-shadow 1.5px) + 은은한 금색 광.
  밝은 경사면/시커먼 골짜기 어디서든 읽힌다. 조준 시(유령·사물·문) 금색으로 커지는 기존 동작 유지.
- 표시·숨김 배선은 기존 그대로 (대화창 열리면 숨고, 1인칭 복귀하면 나옴).

## 2. 아스키 커서 (게임 안 전용 포인터)

- 파일: `assets/cursor/tem_cursor.svg` (2.8KB, 20x32 — Chrome 커서 상한 32px 준수).
  터미널 픽셀 화살표: 2px 블록 계단, 금색(#c8a87a) 윤곽 + 어두운(#16121c) 속, crispEdges.
- 적용: play-test.html 스타일 끝 `html, body, * { cursor: url(...) 1 1, auto !important; }`
  — pointer/help/text 등 OS 커서 전부 대체 ("게임 안에서는 그것만"). 핫스팟 = 화살촉 (1,1).
- 1인칭 포인터 잠금 중에는 브라우저가 커서를 아예 숨기므로 이 규칙과 무관 — 그때는 §1 조준점.
- 모양 수정하려면: 픽셀 지도만 고치면 됨 — 생성기 스크립트는 이 문서 하단 참조.

## 3. 롤백

- 조준점: `_ensureCrosshair`/`_setCrosshairAiming` 의 260802 주석 두 곳을 종전 값으로.

## 4. 유의

- 커서 SVG를 나중에 수정하면 `url('assets/cursor/tem_cursor.svg?v=날짜')` 로 캐시버스터 필요.
- index.html(오프닝·메뉴)에는 아직 미적용 — 상영(play-test)만. 오프닝까지 넓힐지는 작가 결정.
- 픽셀 지도 생성기 (수정 시 재생성용):

```js
// node gen.cjs — MAP 의 O=금색 윤곽, F=어두운 속, 공백=투명. 행 16개 x 2px = 32px 상한.
const MAP = ['O         ','OO        ','OFO       ','OFFO      ','OFFFO     ','OFFFFO    ',
  'OFFFFFO   ','OFFFFFFO  ','OFFFFFFFO ','OFFFFFFFFO','OFFFFOOOO ','OFFOFFO   ',
  'OFO OFFO  ','OO  OFFO  ','     OFFO ','      OO  '];
const B=2,GOLD='#c8a87a',DARK='#16121c';let rects='';
MAP.forEach((row,y)=>{let x=0;while(x<row.length){const c=row[x];if(c===' '){x++;continue;}
  let x2=x;while(x2+1<row.length&&row[x2+1]===c)x2++;
  rects+=`<rect x="${x*B}" y="${y*B}" width="${(x2-x+1)*B}" height="${B}" fill="${c==='O'?GOLD:DARK}"/>`;x=x2+1;}});
require('fs').writeFileSync('assets/cursor/tem_cursor.svg',
  `<svg xmlns="http://www.w3.org/2000/svg" width="20" height="32" viewBox="0 0 20 32" shape-rendering="crispEdges">${rects}</svg>`);
```
