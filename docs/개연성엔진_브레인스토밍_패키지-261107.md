# 개연성 엔진 P(i,k) — 브레인스토밍 패키지 (2026-11-07)

> 결정 항목: 공간무대 구현검토 §11.4 **A10 / D23** "개연성 P(i,k)의 식·단위·0·반증 — 심리 모델 후보 중 선택 뒤 사전 등록, 37회차로 백테스트".
> 이 문서는 그 결정을 **다른 AI나 사람과 브레인스토밍할 때 들고 가는 꾸러미**다. 세 부분으로 되어 있다.
> §1 사전지식(TEM 안에 있는 것 + 바깥 심리학 후보) · §2 맥락(왜 지금, 무엇에 묶여 있나, 백테스트로 할 수 있는 것과 없는 것) · §3 붙여넣기용 프롬프트.
> 코드·DB 변경 0. 숫자는 전부 저장소 문서에서 가져왔고 출처를 붙였다. 출처 없는 숫자는 없다.

## 0. 한 문단 요약

관객이 씬 i에서 유령·사물과 한 상호작용(말·빈칸 채우기·사물 응시)을 보고, 엔진이 "이 상호작용이 이 기억의 각 점 k와 얼마나 개연성 있나"를 **숫자 P(i,k)** 로 잰다. 그 숫자가 새 연결실의 후보와 통로의 길이·밝기를 정한다(사용자 모델, 11-07). 지금 코드에도 이 자리에 식이 있지만 **"지도 위 2D 거리가 반경 안이면 열림, 상위 2개"** 라는 이진 규칙이고, 자(座標系)도 틀렸다(기억별 코사인이어야 하는데 2D 지도 거리). 그래서 새 식이 필요하다. 식은 심리학 모델 중 하나를 골라 세우고, **데이터를 보기 전에 식·파라미터·영모형·판정 기준을 문서로 고정(사전 등록)** 한 뒤, 이미 쌓인 UNDW-001 37회차 216점으로 **옛 모형들보다 나은지** 본다. 백테스트는 "맞다"를 증명하지 못하고 "옛 것보다 못하면 버린다"만 할 수 있다.

## 1. 사전지식

### 1.1 결정 대상 — P(i,k)가 무엇인가 (정의 규율 §3.10 순서로)

| 단계 | 내용 |
|---|---|
| **원시 개념** | 점 k = 이 기억의 씬(작가가 만든 것 + 11-07 허용된 관객 추가분). 상호작용 = 관객이 씬 i 안에서 한 일의 기록(장부). 회차 = 입장~종료. |
| **정의역** | 쌍 (i의 상호작용 장부, 점 k). i는 지금 씬, k는 집합 안 모든 점(방문 여부 포함 — 되접힘 결정 D5에 따라 방문 점 제외 여부가 갈림). |
| **무엇의 관계인가** | "방금 한 상호작용"과 "점 k의 장부" 사이의 **개연성** — 이 상호작용 다음에 k가 떠오르는 것이 얼마나 말이 되나. 정답 아님, 추천 아님. |
| **같음부터** | 두 상호작용이 "같다" = 같은 자로 잰 벡터·단서가 같음(분류기 반복성 안의 유사 — 정의 v1 D2의 통역 "같음"과 같은 처리). 두 점이 "같다" = 같은 사건 식별자(A1). |
| **수량** | 범위·단위·0의 뜻을 **후보마다 적어야 함**. 예: 확률(집합 위 합 1) / 코사인(−1~1, 비음수 벡터라 실상 0~1) / 단서 겹침 수(정수). |
| **반증** | 사전 등록한 영모형보다 못 맞히면 폐기. |

주의: "거리"는 P의 무대 표현(통로 길이)이지 독립 값이 아님(공간무대 §9 D6). P를 "거리"라 부르지 말 것.

### 1.2 지금 코드가 하는 일 — 현행 식을 정직하게

흐름(play-test.html, `onSceneEnd` → `byeoriCalculateStep` → `updateAccess`):

1. **분류**: 관객 발화 → 외부 분류기(`claude-scene` emotion_analysis) → 그 기억의 축(기억별 좌표계: 씬 anchor > 기억 어휘 > 기본 17축)으로 감정 벡터 u_i + 이유(귀인 self/other/fate, 핵심 공포, 공백 여부).
2. **별이엔진 V4** (`js/core/ByeoriEngine.js`): level = 씬별 코사인(u, 원본 o)의 평균 / shape = 감정 변화 방향(델타)의 코사인(3씬부터, 그 전 1.0) / void_mod(회피 0.7) → alignment = 곱 → bucket(HIGH ≥0.50, 히스테리시스, FIXATED = 최근 3감정 쌍 코사인 ≥0.85) → mismatch_type(void / attribution / target_displacement / emotion) → **transition_pattern 6종**: fixation(FIXATED) / displacement(level≥.5 & shape<.3, 3씬+) / echo_follow(HIGH) / bridge(MID) / LOW이면 mismatch 종류 따라 avoidance·displacement·contradiction·bridge.
3. **접근 집합** (`updateAccess`, 2127~2218행):
   - 중심 = `PATTERN_CENTER[pattern]`로 **17축 공간에서 원본·관객을 섞은 뒤 AF 2D 지도로 투영**(echo_follow 원본 .7 : 관객 .3 / bridge .5:.5 / displacement .3:.7 / contradiction = 지도 위 핀 무리 중심 기준 대칭점 / avoidance = void 영역 / fixation = 현재 씬).
   - 반경 = 패턴별 상수(0.09~0.24) × 이 기억 핀 산포.
   - **미방문 핀 중 2D 지도 거리 ≤ 반경** → 없으면 반경 ×1.85 → 그래도 없으면 가장 가까운 1개(Fallback B) → **상한 2개** → 불빛 → 관객이 고름.

즉 현행 **P(i,k) = 1[ dist2D(center(pattern, u_i, o_i), pin_k) ≤ r(pattern)·spread ]**, 상위 2개 컷. 결함 세 가지:

| 결함 | 왜 문제인가 | 근거 |
|---|---|---|
| 자가 2D 지도 거리 | AF 투영은 17축을 2수치로 누르는 가중평균이라 다른 감정이 같은 자리에 겹침. 이미 "감정 공간의 반대가 지도의 반대가 아니었다"며 contradiction 반전을 폐기한 선례가 코드 주석에 있음 | play-test.html 2021~2030행 주석, 기억별_좌표계_결정 §2 |

### 1.4 이미 잰 수치 — 백테스트의 바닥과 기준선 (출처: THEORY §4, 기억의_정의 §3)

- **자료**: UNDW-001(대표 기억, 13씬) 실관객 **37회차 216점 179걸음**(2026-07-30~09-30). 익명 25 + 관리자 계정 12(그중 7회차는 1점짜리). 관리자 제외해도 수치 거의 그대로.
- **걸음의 결**: 첫 실(작가 순서) 방향 20 = 11%, 거꾸로 27, 새 실 132. 실 74종(무향 54), 고리 42, **되돌아감 0/37**(엔진이 방문 씬을 안 열어서 — 데이터가 아니라 엔진의 성질).
- **기준선 ①(강함)**: 회전 실험 2(11-06) — "거리 = 작가 감정 거리 1−cos(o_i,o_k)"가 먼 쌍일수록 덜 밟힘, 가중 순위상관 **−0.30 [p 0.03], 실 n=35**. 들어온 다리의 감정 거리 vs 작가 이탈 **+0.355 [0.000]**. **이 모형은 관객 발화를 전혀 안 쓴다.** 새 P가 이것을 못 넘으면 "상호작용이 연결을 정한다"에 측정 근거가 없는 것.
- **기준선 ②(무관)**: "거리 = 작가 순서 칸 수"는 어긋남·무게 전부 r_s ≈ 0 → 순서 칸 수는 쓸모없음.
- **작가 각도의 특권 안 보임**: 작가 이웃 입구 47 vs 징검다리 132에서 코사인 0.413 vs 0.441 [p .39] — 차이 우연 범위(검정력 낮음, 없음의 증명 아님).
- **끌개 지도 1차**: 구멍(머묾) 슬픔 45·죄책감 32·그리움 31·두려움 22·분노 16, 슬픔↔죄책감 길 8/9, 분노 머묾 40%. 작가 감정 ≠ 사람 감정인 씬 4·9·1·12.

- **외부 비판 기록**: 친구(수학) — 문턱 자의성·"점수 조용 ≠ 구조 불변"; ICIDS 2026 거절 — 제목(궤적·오염) vs 증거(순간 level만), 다중비교·CI 없음, 동의서 없음.

### 1.6 바깥 지식 — 심리·인지 모델 후보

읽는 법: 한 줄 요지 → TEM 대응 → P로 쓰면 어떤 식 → 들어가는 재료 → 함정. **전부 후보이지 추천 아님.** 세 "구조형"으로 묶인다 — (가) 각도형 (나) 맥락형 (다) 단서형. 혼합은 가능하나 §3.10 9번(이름 하나 뜻 하나)을 지켜 항마다 이름을 따로 붙일 것.

#### (가) 각도형 — "지금 감정과 닮은 점이 떠오른다"

**가-1. 기분 일치 기억 / 감정 연결망 이론** — Bower, G. H. (1981). Mood and memory. *American Psychologist* 36(2).
- 요지: 감정은 기억망의 마디다. 지금 느끼는 감정 마디가 켜지면 같은 감정이 붙은 기억이 더 쉽게 떠오른다.
- TEM 대응: 현행 echo_follow의 중심(원본 .7 : 관객 .3)과 level 계산이 이 모델의 가장 단순한 구현. 논문 초안 §배경에 이미 인용.
- 식 뼈대: P(i,k) ∝ cos(u_i, o_k) (기억 축). 또는 중심 c = 패턴 가중 혼합 뒤 cos(c, o_k).
- 재료: u_i, o_k만. 저작 추가 비용 0.
- 함정: 관객이 원본과 다를수록 "닮은 점"이 없어져 P가 전부 낮아짐 → 폴백 빈발. 또 비음수 벡터 코사인은 0에 거의 안 닿아 LOW 분기가 죽음(기억별_좌표계 §4 기록). 이본론 위반 위험: 원본 닮음을 우대.

**가-2. 평가 이론(appraisal)** — Ortony, Clore & Collins (1988) *The Cognitive Structure of Emotions*; Scherer (2001) Component Process Model; Lazarus (1991) *Emotion and Adaptation*.
- 요지: 감정은 사건을 "누구 탓인가·통제할 수 있나·규범에 맞나·목표에 이로운가" 같은 **평가 차원**으로 읽은 결과다.
- TEM 대응: `reason_analysis`의 귀인(self/other/fate)·핵심 공포·공백 = 평가 차원의 일부. 현행 mismatch_type이 이 축으로 어긋남을 분류.
- 식 뼈대: P에 감정 각도 항과 **평가 일치 항**을 따로 둠. 예: 귀인 같음 1 / 다름 0, 핵심 공포 같음 여부. displacement(같은 감정, 다른 대상)가 자연스럽게 나옴.
- 재료: 관객 이유 + 씬 원본 이유(`original_reason`, void_info). 이미 있음.
- 함정: 분류기가 이유를 틀리게 뽑으면 P가 흔들림(페르소나 리트머스: target_displacement 82% 지배 = 분류기 편향 의심). 평가 차원을 몇 개로 할지는 자유 파라미터.

#### (나) 맥락형 — "방금까지의 흐름이 다음을 당긴다"

**나-1. 시간 맥락 모델 TCM → CMR → eCMR** — Howard & Kahana (2002) *J. Math. Psychology* 46; Polyn, Norman & Kahana (2009) *Psych. Review* 116; Talmi, Lohnas & Daw (2019) *Psych. Review* 126. 선례 측정 lag-CRP = Kahana (1996) *Memory & Cognition* 24(선행연구 조사 11-05에 이미 인용).
- 요지: 머릿속에 천천히 바뀌는 **맥락 벡터**가 있다. 항목을 겪을 때마다 맥락이 조금씩 섞여 흐른다. 회상할 때는 **지금 맥락과 각 항목이 저장될 때의 맥락이 얼마나 닮았나**로 다음에 떠오를 항목이 정해진다. 그래서 자유회상은 "방금 떠올린 것의 이웃"으로 잘 옮겨간다(lag-CRP). eCMR은 **감정을 맥락의 한 축**으로 넣어 감정이 회상 전이를 어떻게 휘는지 설명.
- TEM 대응: **P(i,k)의 직계 조상**. "전이 확률 모델" 그 자체이며, "씬2가 아니라 씬7로도 간다"가 모델의 기본 출력. 회차 안에서 맥락이 흐른다 = shape(델타)와 fixation(최근 3감정 유사)이 이미 반쯤 잡고 있는 것. era 이론의 소강·요동(맥락 급변 = 절단)과 같은 모양.
- 식 뼈대: 맥락 c_t = ρ·c_{t−1} + β·u_t (ρ, β 자유 파라미터). 점 k의 맥락 c_k = 저작 시(작가 첫 플레이) 또는 그 점이 놓인 서술 맥락. P(i,k) = softmax_τ( c_i · c_k ) (τ 자유). 작가 첫 플레이가 **각 점의 "저장 맥락"을 새기는 절차**가 되어 D6'(첫 실)의 역할이 식 안에 생김.
- 재료: 회차 이력 h 전부 + 점별 맥락 벡터(저작 시 생성). 저작 추가 비용 = 작가 첫 플레이 1회(이미 계획됨).
- 함정: 파라미터 3개 이상(ρ, β, τ) → 37회차로는 과적합. 사전 등록에서 값을 문헌 기본값으로 고정하거나 분위수로만. "저장 맥락"을 작가 플레이로 새기면 그게 "원본"으로 격상될 위험(마스터 크랙) → "첫 실의 맥락"이라 불러야 함.

**나-2. 확산 활성화 / ACT-R 활성화 식** — Collins & Loftus (1975) *Psych. Review* 82; Anderson & Schooler (1991) *Psych. Science* 2; Anderson & Lebiere (1998) *The Atomic Components of Thought*.
- 요지: 항목 k의 활성화 A_k = 기저 활성화(최근성·빈도) + Σ_j W_j·S_jk (지금 켜진 단서 j에서 k로 흘러드는 연결 강도). 가장 활성화된 항목이 떠오름.
- TEM 대응: "단서에서 점으로 흐른다"는 틀은 (다)와 같고, **기저 활성화(빈도) 항이 바로 흔적**이다.
- 식 뼈대: A_k = B_k + Σ_j W_j S_jk, P = softmax(A). **단, B_k에 집단 빈도를 넣으면 C7 위반(쏠림)**. 개인 회차 안 최근성만 허용하면 되접힘(D5)과 fixation이 자연스럽게 나옴.
- 함정: 쏠림 강화의 교과서적 식. 넣더라도 "개인 안"으로 선 긋고 사전 등록에 명시.

#### (다) 단서형 — "겹치는 단서 수가 개연성"

**다-1. 부호화 특수성 / 단서 겹침** — Tulving & Thomson (1973) *Psych. Review* 80; 표본 추출 규칙 SAM = Raaijmakers & Shiffrin (1981) *Psych. Review* 88.
- 요지: 기억은 **저장될 때의 단서와 지금 단서가 겹칠수록** 떠오른다. SAM은 이를 확률로 썼다: P(k | 단서들) = Π_j S(q_j,k)^{w_j} / Σ_m Π_j S(q_j,m)^{w_j} — 집합 위에 정규화된 선택 확률(Luce 규칙).
- TEM 대응: 단서 = 관객 발화의 어휘·연결사·응시한 사물; 점의 단서 = `echo_words`·`motif_tags`·사물·본문 어휘. **세는 정의**라 §3.10 6번(문턱 없이 세기)에 가장 유리. "막대(여러 씬을 꿰는 공명 단어·모티프)" 측정 후보(THEORY §7)와 같은 재료.
- 식 뼈대: P(i,k) = (겹친 단서 수 + 감정 각도 항)을 Luce 정규화. 단서 종류별 가중은 자유 파라미터.
- 재료: echo_words는 이미 있으나 **관객 발화 쪽 단서 추출기**가 필요(로컬 형태소 분석 또는 임베딩 384 — 잔상용 임베딩 자산 있음). 사물 응시 로그는 8-02부터.
- 함정: 겹침 0인 점이 많아 희소 → 감정 항과 혼합 필요. 발화 단서 추출을 외부 LLM에 맡기면 전송 경계 확대.

**다-2. 사건 색인 모델 + 인과 연결망** — Zwaan, Langston & Graesser (1995) *Psych. Science* 6; Zwaan & Radvansky (1998) *Psych. Bulletin* 123; Trabasso & van den Broek (1985) *J. Memory & Language* 24.
- 요지: 독자는 이야기를 **시간·공간·인물·인과·의도** 다섯 색인으로 상황 모델에 꿴다. 색인을 많이 공유하는 사건끼리 잇기 쉽다. 인과 연결망에서는 **인과 연결 수가 많은 사건일수록 회상·요약에 남는다.**
- TEM 대응: 자동 절단 기준(시간·장소·행동·시점·감정 전환, 결정 B3)과 **같은 다섯 축**. 즉 저작 때 색인을 달면 절단과 P가 한 재료를 쓴다.
- 식 뼈대: P(i,k) ∝ 공유 색인 수(0~5) × 감정 각도. 또는 인과 연결 여부를 작가가 표시(첫 실이 그 역할).
- 재료: **저작에 색인 태그 요구**(씬당 5칸). 비용 큼. 관객 쪽 색인은 발화에서 추출해야 함.
- 함정: 작가가 단 색인이 P를 지배하면 "작가 통제"로 기울어 이본론·feedback_avoid_authorial_control_framing 위반. 색인은 점 장부일 뿐, 가중은 관객 상호작용이 정하게 선을 그어야 함.

#### (라) P 자체가 아니라 P의 **곁**에 있는 모델 (헷갈리지 않게)

| 모델 | 요지 | TEM의 자리 | P와의 관계 |
|---|---|---|---|
| 재응고 — Nader, Schafe & LeDoux (2000) *Nature* 406; Hupbach et al. (2007) *Learning & Memory* 14 | 회상하면 기억이 불안정해져 지금 맥락과 함께 다시 저장됨 | 이본지층 "재응고", 되접힘(D5), 장부 갱신 | P가 아니라 **방문 뒤 점 장부가 바뀌는 규칙** |

#### 피해야 할 틀 (이름만 보고 끌리기 쉬운 것)

- **"다음 씬 예측 정확도"로 P를 채점** — 정답이 있다는 틀. 접촉 ≠ 보상, 엔진은 판단하지 않는다에 위반. 영모형 대비 비교만 허용.
- **추천 시스템·강화학습(많이 간 길을 더 열기)** — 쏠림 그 자체.
- **집단 빈도 항** — 위와 같음(C7).
- **반경·문턱으로 열닫기** — 이진 잠금(D7).
- **VAD·AF 2D 평면에서 거리 재기** — 시각화 자를 판단에 씀(폐기된 결정).
- **원본 닮음 = 좋음** — 이본론 위반. P는 닮음이 아니라 개연성. 반대 감정도 개연성이 높을 수 있다(contradiction은 패턴이지 벌점이 아님).

## 2. 맥락

### 2.1 사용자 모델 원문 요지 (11-07, 2차 교정)

> 작가는 점(씬) 집합만 설정한다. 그것이 연결관계의 집합(위상)이 되려면 실이 필요하므로 **작가가 첫 관객이 되어 첫 통로를 만든다.** 다음 진짜 첫 관객이 와서 씬 1에서 인터랙션하면, **그 인터랙션이 집합 안의 점들과 얼마나 개연성이 있는지 분석하는 엔진**이 새 연결실을 만든다 — 작가가 2번으로 둔 씬이 아니라 7번으로도 갈 수 있다. 그 실들이 쌓여 굵기가 된다.

따라서 엔진 = 개연성 분석기. 통로 길이·밝기 = P의 무대 표현. 미리 그린 지도 없음.

### 2.2 왜 이 결정이 먼저인가

P의 식이 정해져야 다음이 정해진다:
- **점 장부에 무엇을 저장할지**(저작 화면의 데이터 모양) — (가)면 감정만, (나)면 맥락 벡터, (다)면 단서·색인.
- **후보 개수 규칙 C2** — P가 확률이면 "상위 3"이 아니라 "누적 확률"로 자를 수도 있음.
- **문 앞 예고 C5** — P의 근거(어떤 단서가 당겼나)를 보여줄지 말지.
- **통로 길이 L*** — T1b의 길이 규칙은 정렬도 입력. P로 바꾸면 규칙 재작성.
- **패턴 6종의 지위(D1)** — P에서 파생되는지, 별도 입력인지.

### 2.3 백테스트 — 할 수 있는 것과 없는 것 (정직 칸)

**자료의 성질**
- 37회차는 **구 엔진 아래서 수집**됐다(2D 거리·상한 2·미방문만). 관객은 제시된 ≤2개 중에서만 골랐다 → "실제 다음 씬"은 **검열된 선택**. P가 집합 전체 위에서 맞히는지 보면 구 엔진의 제약이 그대로 섞인다.
- **제시된 후보 집합은 저장되지 않았다.** 재계산은 원리상 가능(엔진은 이력만으로 결정적)하지만 엔진 코드가 7-27·8-10에 바뀌어 회차별 판본을 맞춰야 하는 근사.
- plays에는 패턴·bucket이 없다(run_traces는 8-02 이후만). 벡터에서 재계산해야 함(선례: 기억별 좌표계 백테스트).
- 익명 25의 중복 여부 확인 불가. 동의서 없음 → **내부 탐색용**. 논문 주장 불가(ICIDS 지적).
- 점은 회차 안에 묶여 **독립 아님**. p값은 섞기(permutation)로만, 그것도 참고.

**할 수 있는 것**
1. **순위 비교**: 각 걸음(i→실제 다음 j)에서 P(i,·)가 j에 준 순위·로그 점수를 영모형과 비교. 공정 비교는 "재계산한 제시 집합 안"에서, 거친 비교는 "미방문 전체"에서 — 둘 다 보고.
2. **중심 이동 검증**: 패턴별로 실제 u_{i+1}−u_i 방향이 PATTERN_CENTER의 방향과 맞는가(현행 상수의 첫 실측).
3. **다음 씬 정렬도와의 관계**: P가 높았던 전이에서 다음 씬 level이 달랐나(해석 조심 — 높으면 좋다가 아님).
4. **안정성**: 절반 표본으로 P 파라미터를 맞추고 나머지에서 순위가 유지되나(회차 모양 PCA에서 축이 54° 흔들린 선례 — 같은 검사).
5. **기준선 ①을 넘나**: 관객 발화를 안 쓰는 "작가 감정 거리" 모형(−0.30)보다 나은가. **못 넘으면 "상호작용이 연결을 정한다"는 아직 측정 근거 없음**으로 적는다.

**할 수 없는 것**: 인과("상호작용이 연결을 만들었다") · 사람 일반화 · 유의성 주장 · 새 무대(방+통로)에서의 행동 예측(무대가 다르면 분포가 다름).

**영모형(사전 등록 필수)**: ① 제시 집합 안 균등 ② 작가 순서(다음 번호) ③ 작가 감정 거리 1−cos(o_i,o_k) ④ 현행 엔진 재계산(2D 거리) ⑤ 회차 순서 섞기.

### 2.4 사전 등록이란 — 이 저장소의 선례대로

데이터를 돌려 보기 **전에** 문서 한 장에 고정: 식(항마다 이름) · 자유 파라미터 목록과 고정값(문헌 기본값 또는 분위수) · 영모형 · 측정 지표 · 판정 기준("영모형 ③을 로그 점수에서 못 넘으면 폐기") · 제외 규칙(1점짜리 회차, 관리자 회차 포함 여부) · 다중비교 처리. 선례: 페르소나 리트머스 §2 원칙 3(필요조건만·절대 임계 금지·비독립 명기), 끌개실험 설계 v2, era 사전 등록. 문서가 먼저, 스크립트는 그 문서를 그대로 옮긴 것이어야 한다.

### 2.5 외부 전송 경계

분류기(발화→벡터)는 이미 외부(Claude). **P 자체는 저장된 벡터·단서만으로 도는 로컬 산술**이어야 한다. (다)형이 발화 단서 추출을 요구하면 로컬 형태소 분석 또는 로컬 임베딩으로 — 외부 LLM을 또 부르는 설계는 경계 확대이므로 따로 표시.

### 2.6 이 결정이 풀리면

저작 화면의 점 장부 칸이 확정되고, `js/stage2/plausibility.js`(공간무대 §5, 약 180줄, 미작성)의 입력·출력이 정해지며, T1b 통로 길이 규칙을 P 기준으로 다시 쓴다. 백테스트 스크립트는 `tools/topo-piece/` 선례(DB 읽기만)를 따라 읽기 전용으로.

아래 블록을 통째로 브레인스토밍 상대(GPT·Claude·사람)에게 준다. 상대가 저장소를 읽을 수 있으면 "참고 문서" 줄을 살리고, 못 읽으면 지워도 자립한다.

```
[역할]
너는 인지심리학·기억 연구와 계산 모델링에 밝은 공동 연구자다. 우리는 "기억이 사람 사이를 건너며 변하는 과정"을 체험하게 하는 웹 작품 TEM의 엔진 한 부분을 설계한다. 네 일은 식을 정해 주는 것이 아니라 **후보를 정의 규율에 맞춰 세우고, 각 후보가 어디서 깨지는지 먼저 말해 주는 것**이다.

[정할 것]
P(i,k): 관객이 씬 i에서 한 상호작용(말·빈칸 채우기·사물 응시)이, 이 기억의 각 점 k(씬)와 얼마나 **개연성** 있는가를 재는 수. 이 수가 새 연결실의 후보와 통로의 길이·밝기를 정한다. 정답·추천·채점이 아니다.

[세계의 규칙 — 넘으면 무효]
1. 작가는 점(씬) 집합만 만든다. 연결은 작가가 첫 관객이 되어 만든 첫 통로 하나와, 그 뒤 관객들의 상호작용에서 생긴다. 작가 순서는 "원본"이 아니라 첫 번째 실이다.
2. 변이는 열화가 아니라 재창조다. 원본과 닮을수록 좋다는 항은 금지. 반대 감정도 개연성이 높을 수 있다.
3. 엔진은 관찰·보고만 한다. 높은 P는 승리가 아니다.
4. 이진 잠금 금지: 문턱으로 길을 열고 닫거나 접근 개수를 고정하는 규칙은 식에 들어가지 않는다. 후보 상한 3은 무대 쪽 자유 파라미터다.
5. 앞 회차 사람들의 흔적(어느 길을 많이 갔나)은 P에 넣지 않는다(쏠림 방지). 한 사람의 같은 회차 안 이력은 넣어도 된다.
6. 자(좌표계) = 그 기억의 씬들이 쓰는 감정 어휘 위의 코사인. 2D 투영 거리는 금지.
7. 패턴 6종(echo_follow / bridge / contradiction / displacement / avoidance / fixation)은 숫자에서 파생되는 라벨이어야 한다. 라벨이 먼저 오고 라벨별 상수로 돌아가는 구조는 피한다. 단 "패턴은 반경이 아니라 중심(기하)을 옮긴다"는 성질은 지켜야 한다.
8. P는 저장된 벡터·단서만으로 도는 로컬 계산이어야 한다. 외부 언어모델을 또 부르는 항은 따로 표시한다.
9. 정의 규율: 원시 개념 → 같음(동치) → 다름 → 수량(단위·범위·0의 뜻) → 반증 조건 순서로 쓴다. 문턱·상수는 정의에 넣지 않는다. 이름 하나에 뜻 하나. 정의·측정·연출을 한 문장에 섞지 않는다.

[쓸 수 있는 재료]
- 상호작용 장부(i): 관객 감정 벡터 u_i(그 기억의 축, 예: 11축 anger/confusion/emptiness/fear/guilt/isolation/joy/longing/numbness/sadness/shame), 이유(귀인 self/other/fate, 핵심 공포, 공백 여부), 발화 원문, 연결사 이어쓰기 입력, 응시한 사물 목록, 시각.
- 점 장부(k): 작가 원본 감정 o_k(같은 축), 원본 이유, 공명 단어, 모티프 태그, 본문, 작가 순서, 사물 목록. (저작 때 더 달 수 있지만 비용이 든다 — 요구하면 명시할 것.)
- 회차 이력: 이번 회차의 방문열, 이전 u들, 정렬도 열.
- 현행 엔진 출력: level(코사인 평균), shape(감정 변화 방향 코사인, 3씬부터), void 벌점, alignment = 곱.

[이미 잰 수치 — 백테스트 바닥]
- 한 기억(13씬) 실관객 37회차 216점 179걸음. 작가 순서 방향 11%, 거꾸로 27, 새 실 132. 실 74종, 고리 42. 되돌아감 0(엔진이 방문 씬을 안 열어서).

[후보 지식 — 출발점일 뿐, 다른 것도 내라]
(가) 각도형: 기분 일치 기억(Bower 1981) / 평가 이론(OCC 1988, Scherer 2001)
(나) 맥락형: 시간 맥락 모델 TCM·CMR·eCMR(Howard & Kahana 2002; Polyn 외 2009; Talmi 외 2019) / 확산 활성화·ACT-R 활성화 식(Collins & Loftus 1975; Anderson)
(다) 단서형: 부호화 특수성 + SAM 표본 추출 규칙(Tulving & Thomson 1973; Raaijmakers & Shiffrin 1981) / 사건 색인 모델·인과 연결망(Zwaan 외 1995; Trabasso & van den Broek 1985)
곁: 재응고(Nader 2000), 사건 분절(Zacks 2007), 반추·회피(Nolen-Hoeksema 1991; Hayes 1996), 서사적 개연성(Bruner 1986; Fisher 1984), 누적 이득(Salganik 2006 — 넣으면 안 되는 것의 근거).

[요청 — 이 순서로, 빠짐없이]
1. "개연성"이라는 말부터 정의하라. 이야기 안 정합(점끼리)과 관객 충실(상호작용↔점)을 섞지 말고, P가 어느 쪽을 재는지 이름을 갈라라.

3. 비교표 한 장: 후보 × (파라미터 수 / 저작 비용 / 37회차 검증 가능성 / 쏠림 위험 / 이본론 정합 / 무대 표현 용이성).
```

### 6.3 명시해야 할 것 (틀린 건 아니나 숨어 있음)

- **M2의 불변성**: 기억 평균 ō가 점 집합에 의존 → D8(관객 장면 추가)로 점이 늘면 기존 쌍의 P2가 전부 바뀜. §3.10 5번(배치에 기대지 않는 정의)과 긴장. 기억별 좌표계 정신("기억 하나 = 우주")과는 맞으니 **명시하고 가면 됨**.
- **M3의 e_k(첫 실 저장 맥락)**: 작가 순서가 식 깊숙이 들어옴. 11-06 실측(작가 순서 칸 수 무관, 작가 각도 특권 안 보임)과 방향이 어긋남. "비용 0"이 아니라 첫 실을 저장 맥락으로 격상하는 존재론 비용(마스터 크랙 재발 위험). 사전 등록하면 그 자체가 검증이 되니 **보조 가설로만**.
- **구획 A 재계산의 난이도**: 엔진 판본 셋(7-27·8-10 변경) + 핀 좌표에 수동 배치(stage_position) 섞임 → 근사. **먼저 "후보 2개였던 걸음 수"를 세고**, 적으면 검정력 없음을 보고(판정 아님).
- **기준선 ① 자체도 구 엔진 오염**: THEORY §4 주석 "지형 엔진이 접근 씬 공동 결정". −0.30은 사람 성향 + 엔진의 2D 거리 선택이 섞인 값. "기준선 ①을 넘어라"는 구획 A 안에서만 뜻이 있다.
- **맹점 3(밝기 넛지)은 정당**하나 "길이 = 감정 낙차"는 그 AI의 제안이지 결정이 아님. 이 패키지 §0·§2.1의 "통로 길이·밝기 = P의 무대 표현"은 **내 문구**였고 사용자가 확정한 건 "P → 새 연결실 후보, 실이 쌓여 굵기"까지. → **새 매듭 D28**: P가 정하는 것 = 후보 집합 + 결(색·소리) / 길이·밝기를 P의 단조 함수로 둘지. 추천 = 후보 선정은 P, **길이는 P 단조 금지**(안 그러면 C7을 지켜도 무대가 1순위로 쏠리게 함).
- "관객의 70~80%는 밝고 가까운 문을 따라감"은 출처 없는 숫자 → 무시.
