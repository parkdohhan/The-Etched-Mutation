# THEORY — TEM 이론 한 장 (2026-11-05 기준)

> **이 파일의 역할**: 다른 세션·다른 모델(GPT 등)·수학 친구·임현 선생님이 **이것 하나만 읽고** TEM이 지금 어떤 이론 위에 서 있고, 무엇이 확정이고 무엇이 가설이며, 어디가 막혔고, 무슨 후보를 들고 있고, 곁가지로 뭘 뒤적였는지 한 번에 파악하게 하는 문서. 각 항목은 요지 + 정본 경로. **정본과 충돌하면 정본이 이긴다** — 이 파일은 지도이지 정본이 아니다.
> **갱신 규칙**: 이론·결정·측정이 바뀌면 이 파일의 해당 표와 §12 변경 로그를 같이 고친다. 날짜는 전부 절대 날짜.
> **쉬운 판**: §10의 만화 1~6권·외전이 이 파일의 그림 판이다. 처음 보는 사람은 만화 1권 → 4권 → 5권 순서.

## 0. 한 문장과 한 그림

**TEM은 기억이 남들의 해석을 거치며 변하는 과정을 겪게 하는 웹 이머시브 시어터이고, 그 변화를 재는 장치다.** 관객의 발걸음이 건물을 짓고, 그 건물의 모양을 잴 수 있다.

**기억의 정의 v1 (2026-11-05 정본 승격)**: 기억은 사건(씬)들 위에 사람들이 그은 **실의 그물**이다. 점만으로는 더미이고 실이 얹혀야 모양이 된다. 실 하나로는 모양이 없고, 실이 겹쳐 고리가 생길 때 기억은 처음으로 모양을 가진다. 중심(원본)은 없다 — 작가의 순서는 "첫 실"일 뿐.

**그림 사전(만화 어휘)**: 모래밭 = 지형(무대) · 구슬 = 한 사람의 감정 상태 · 구멍 = 끌개(사람들이 모이는 감정) · 구슬 하나 영상 = era(한 발화 안의 궤적) · 모래밭이 변하는 사건 4종 = 모스 사건(생김·잠김·붙음·갈라짐) · 집과 길과 통역사 = 층(씬마다 장부, 실마다 통역) · 실 = 한 회차가 걸은 길 · 등뼈 = 많이 밟힌 실 · 샛길 = 한두 명만 밟은 실 · 갈라진 틈 = 고리를 돌면 장부가 안 맞는 자리.

**데이터 사슬 (원시 → 정의 → 측정)**: 작가 텍스트(원시) → 작가가 씬으로 자름 → **씬**(CLAUDE.md §4, scenes) / 관객 발화 원문(원시, `plays.dialog_turns.raw_text`) → 분류기(측정 장비, 페르소나 리트머스 v3로 검증) → **장부**(`plays.user_emotion`, 기억별 좌표계) / **회차**(`plays.run_id`, 절편·도장·궤적의 단위) → **실**(회차 안 이웃 씬 쌍) → **통역**(이웃 씬 장부의 차) → ρ·켄달·고리 수. 정본: `docs/자료스키마_명세_v1-260717.md`, `docs/기억별_좌표계_결정-260727.md`.

## 1. 작품 — 무엇을 만들었나 (이론이 서는 바닥)

- 웹 1인칭 체험. 작가가 기억 하나를 씬들로 저작(대표 기억 UNDW-001 「팬티만 입은 내여자」 13씬, GWON-001 「권역」 15씬). 관객은 안개 속에서 접근 가능한 씬을 골라 걷고, 씬마다 유령(앞사람들의 잔향)과 대화·이어쓰기를 하며 감정이 기록된다. 회차가 끝나면 지형(strata)에 침식·퇴적이 반영되어 다음 관객이 물려받는다.
- 스택: Vanilla JS, Supabase, Three.js. 엔진: 별이엔진 V4(정렬도 = 높이×모양×회피), SceneNavigator(패턴별 접근 중심 이동), ContaminationTracker(오염 3축+깊이, 연출 제어), 이본지층 엔진(`js/shared/tem_variant_strata.js`).
- 설계 원칙 8 (CLAUDE.md §6.5, 협상 불가): 패턴은 기하(→위상)를 바꾼다 / 오염은 방향적 / 고착 = 지속 / 대체엔 서사 / 플레이어는 안개·작가는 지도 / Record = 첫 플레이 / 첫 서술 궤적 ≠ 원본 / 덮어쓰기 15% 이하.
- 전체 매뉴얼: `docs/TEM_시스템_매뉴얼-260410.md`, 코드 읽기 교재 `docs/코드읽기_교재-261019.pdf`.

### 6.2 외부 비판에 답해야 할 것

1. **문턱 자의성**(친구) → 세는 자로 전환(켄달·고리·ρ·바코드). 남은 정수 문턱(샛길 1~2명)은 지속 바코드로 대체 가능.
2. **점수 조용 ≠ 구조 불변**(친구) → era 소강의 구조판 후보 = 구슬이 같은 구멍에 머무름. 등식 검증 사전 등록 필요(길 ①실측/②구조 기준/③주장 약화 — 미결정).
3. **층 "정의로 증명"**(친구) → 통역 규칙 3후보 중 선택 + (가)공통 자 vs (나)기억별 자+통역 비교 표 1장.
4. **정렬도의 두 항 불일치·미측정**(era §2-1) → 턴 ↔ 직전 상대 발화로 1회 실측(저자 몫, 미완).
5. **ICIDS 2026 거절 사유 8**: 작품 내용 0줄 / 제목(궤적·오염) vs 증거(순간 level만) / 193 표기 / 재현 세부 / 윤리·동의 / 다중비교·CI / 그림 없음 / 참고문헌(FearNot!, Terminal Time). 재투고 = 2027 본 논문.

### 6.3 구조적 막힘

- **되접힘 불가**: 엔진이 방문 씬을 다시 안 열어 C단계 관찰 불가. 엔진 수정 + "안개" 원칙 충돌 검토 선결.
- **소멸 긴장**: 연결 합집합은 완전 그래프로 수렴(고리 64%). 무게(가닥 수)로 보면 해소. 위상 층의 "융기"가 무엇인지 이론에 없음(무대 규칙 후보).
- **인지 모델 부재**(연구 명세).
- **수학 형식화 0**(층·사이트·정리) — 역할 경계상 후속 연구자 몫, 단 "국소 정합·전역 불접합" 사례 탐색은 저자 몫 → 11-05 ρ 0.50이 전역 쪽 첫 사례(국소 정합 쪽은 w=1 때문에 약함).
- **작품 쪽 혈**(기획서 약속): Live 1:1·화자 붕괴·기억의 죽음·마지막 선택·"음각" 용어 — 전부 그대로(`docs/메모/기획서_대조_성장-261101.md`).
