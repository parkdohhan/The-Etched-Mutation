# 지형 질감 3단계 수술 — 그림자·살결·바위 (2026-08-02)

> 사용자 지적: "지형 질감이 너무 싼마이다. Tripo로 방안 없나."
> 진단 결과 Tripo 로 고칠 수 있는 건 일부였고, 진짜 원인은 코드 쪽 3가지.
> 이 문서 = (a) 무엇을 고쳤나 (b) Tripo 바위 뽑아서 넣는 법 (c) 튜닝 손잡이 (d) 롤백.

---

## 0. 싼마이의 원인 4가지 (진단)

| # | 원인 | 처방 |
|---|---|---|
| 1 | 그림자 기능을 켜 놓고 **받는 쪽/드리우는 쪽 지정이 0줄** — 바위가 스티커처럼 떠 보임 | 1단계 |
| 2 | 잡티가 **밝기만 ±6%** 흔듦 — 빛 반사 방향은 그대로라 "때 탄 매끈한 면" | 2단계 |
| 3 | 지형 전체가 **단일 재질** (거칠기 0.82 고정) — 능선/골짜기/절벽이 같은 광택 | 2단계 |
| 4 | 파편 = **정사면체 4장**, 결정 = 원뿔 — 종이접기 실루엣 | 3단계 |

격자(160칸/112유닛 ≈ 칸당 70cm) 자체는 문제가 아니었다 — 법선 요철이 격자보다 잔 결을 만들어 준다.

## 1. 무엇이 바뀌었나

### 1단계 — 그림자 스위치 ([js/shared/tem_af_strata_terrain.js](../js/shared/tem_af_strata_terrain.js))

- 지형(단일메쉬·plate 양쪽): `castShadow + receiveShadow` — 산이 제 그림자를 드리우고 받음
- 파편 바위·고착 결정: `castShadow` — 땅에 "박혀" 보임
- 그림자 카메라 ±50 → **±75** (지형 반경 56을 못 덮어 모서리가 잘리던 결함), 해상도 1024 → **2048**
- `PCFSoftShadowMap` (부드러운 가장자리) + bias/normalBias (여드름·줄무늬 방지)
- 사물 조형([lumen_scene_objects.js](../js/ui/lumen_scene_objects.js)): **불투명도 연동 그림자** — 또렷할 때만 드리우고, 거리 페이드로 사라지면 그림자도 걷힘
- 출구문 GLB([play-test.html](../play-test.html) 문 로더): castShadow

### 2단계 — 살결 셰이더 (`_rockPatchShader`, 단일메쉬·plate 공용)

종전 인라인 패치를 함수로 추출하며 3가지 보강. **지층 밴드·오염 uniform·공간안개 B안은 그대로.**

1. **법선 요철** — 잡티가 밝기 대신 **빛이 튀는 방향**을 흔든다. 격자 한계 무시하고 잔 결이 조명에 반응.
2. **결 3겹** — 굵은 얼룩(~3m) / 중간 결(~60cm) / 잔 알갱이(~7cm). 멀리서도 가까이서도 결이 보임.
3. **높이·경사별 거칠기** — 골짜기=젖은 듯 반들(0.60), 능선=메마름(0.95), 절벽면=중간(0.78) + 얼룩 편차.

부수 교정 2건:
- 경사 계산이 **뷰(카메라) 기준**이라 궤도를 돌리면 무늬가 따라 돌던 결함 → 월드 법선(vWNorm) 기준으로.
- 잡티가 **덧셈**이라 어두운 감정색이 회백색으로 뜨던 것 → **곱셈**으로 (색 유지).
- plate 재질은 종전에 살결 패치가 **아예 없었음** (공간안개만) → 이제 동일 적용.

### 3단계 — 흩뿌림 바위 2층 구조

- **1층 폴백 (즉시 적용, 자산 0개)**: 정사면체 → **절차 바위**. 정이십면체 꼭짓점을 위치 해시로 밀고
  당겨 만든 각진 낮은 폴리 돌 4종. 바닥 22% 파묻힌 원점이라 "박힌 돌"로 보임.
- **2층 업그레이드 (Tripo GLB)**: `assets/terrain_rocks/manifest.json` 에 파일명을 적으면
  `_upgradeScatter` 가 이미 세운 폴백을 **그 자리에서** 실물로 교체 (좌표·회전·크기 유지).
  로드가 지형 구축보다 늦어도/빨라도 수렴. 파일 없으면 콘솔 소음 0으로 폴백 유지.

## 2. Tripo 바위 뽑아서 넣는 법 (작가용)

1. Tripo 에서 바위 3종 + 결정 1종 생성. 프롬프트 예 (영문 권장):
   - `weathered dark basalt boulder, rounded, single rock, game asset, PBR, low poly` (둥근 것)
   - `sharp angular granite rock fragment, single rock, game asset, PBR, low poly` (모난 것)
   - `flat layered sedimentary stone slab, single rock, game asset, PBR, low poly` (넓적한 것)
   - `dark smoky quartz crystal cluster, pointed shards, game asset, PBR, low poly` (결정)
   - 톤은 어두운 무채색 계열이 무대에 맞음. 밝게 나와도 로더가 자동으로 15% 어둡게 눌러줌.
2. GLB 로 내보내서 `assets/terrain_rocks/` 에 넣는다. 파일명 자유 (예: rock_a.glb).
3. 같은 폴더의 `manifest.json` 을 연다:
   ```json
   { "rocks": ["rock_a.glb", "rock_b.glb", "rock_c.glb"], "crystal": "crystal_a.glb" }
   ```
   `rocks` 목록에 적은 파일만 로드된다 (여러 개일수록 다양해짐). 비워두면 절차 바위 유지.
4. 하드 리프레시 (Ctrl+Shift+R). 끝. 코드 수정 없음.

크기·회전·개수는 신경 안 써도 된다 — 자동 표준화(최장변 기준) + 기존 흩뿌림 규칙 그대로.

## 3. 튜닝 손잡이 (전부 tem_af_strata_terrain.js)

| 뭘 바꾸고 싶나 | 어디 | 기본값 |
|---|---|---|
| 요철 세기 | `_rockPatchShader` 법선 블록 `* 0.55` | 0.55 (0.3=은은, 0.8=거침) |
| 결 3겹 진폭 | `_grain` 줄의 0.16 / 0.13 / 0.07 | 굵은/중간/잔 순 |
| 골짜기↔능선 거칠기 | `mix(0.60, 0.95, _rHgt)` | 0.60 젖음, 0.95 메마름 |
| 그림자 해상도 | `dl.shadow.mapSize.set(2048, 2048)` | 낮은 사양이면 1024 |
| 파편 개수 | `heterogeneity * 40` | 오염 이질성 비례 |
| 파편 크기 | `dScale = (0.5 + rng() * 1.5) * 0.3` | 최장변 0.15~0.6 유닛 |
