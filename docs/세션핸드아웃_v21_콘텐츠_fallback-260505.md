## 작업

### A. 코드 fallback (lumen_dialog_phase1.js)

**자리 1 — `start()` 진입 자리에 fallback 추가**:

```js
async function start(input) {
  input = input || {};
  var sceneData = input.sceneData;
  if (!sceneData) throw new Error('[ldp] sceneData required');
  var meta = sceneData.meta || {};
  var dlg = meta.dialog_choices || null;

  // V2.1.2 fallback (2026-05-05) — 작가 손 콘텐츠 X 시 자동 생성
  if (!dlg) {
    dlg = _autoGenerateDialogChoices(sceneData);
    console.log('[ldp] auto-fallback dialog_choices generated for sceneId=' +
      (sceneData.id || '').slice(0, 8) + '…');
  } else {
    if (!dlg.scene_context && sceneData.text) {
      dlg.scene_context = _splitSceneText(sceneData.text);
    }
    if (!dlg.choices || !dlg.choices.length) {
      dlg.choices = _defaultChoices();
    }
  }
  // ... (기존 흐름)
}
```

**자리 2 — 헬퍼 함수**:

```js
function _splitSceneText(text) {
  if (!text) return [];
  // 마침표/물음표/느낌표 분리. 한국어 종결어미 자리.
  return text.split(/(?<=[.!?。])\s+/)
    .filter(function (s) { return s.trim().length >= 5; })
    .slice(0, 6);  // 첫 5~6 문장
}

function _defaultChoices() {
  // 작품 톤 균일 자리 (V3 작가 손 갱신 자리)
  return [
    {
      label: '어디였어?',
      ghost_reply: ['거기였어. 너도 그런 자리 알아?'],
      free_dialog_open: ['너에게도 비슷한 자리 있어?'],
    },
    {
      label: '어떤 자리였어?',
      ghost_reply: ['그런 자리였어. 그게 다였어.'],
      free_dialog_open: ['너는 그 자리에서 뭘 봤어?'],
    },
    {
      label: '......',
      ghost_reply: ['그래. 침묵도 대답이지.'],
      free_dialog_open: ['뭐가 떠올라?'],
    },
  ];
}

function _autoGenerateDialogChoices(sceneData) {
  return {
    scene_context: _splitSceneText(sceneData.text || ''),
    ghost_intro: [],
    choices: _defaultChoices(),
  };
}
```

## 결정할 자리

**(a) `_defaultChoices` 톤** — 모든 메모리에 *균일* 박음. 단 작품 톤 깨짐 자리. 권장 = 균일 OK (MVP). V3 작가 손 갱신.

**(b) gameplay 가드 갱신** = `scene.meta.dialog_choices` 검사 폐기 vs *그대로 두고 fallback 안*에서만 박음. 권장 = 갱신 (모든 메모리 V2.1 Phase 1 발동).

**(c) absorption_slots 글로벌 디폴트 vs 메모리 진입 시 fallback** — 권장 = 글로벌 디폴트 (lumen_ghost_response.js DEFAULTS).

**(d) ghost_variants drift 변주 풀 fallback** = 다른 메모리에 ghost_variants row 박혀 있나 확인 필요. SQL:
```sql
SELECT m.code, COUNT(g.id) AS variants
FROM memories m
LEFT JOIN ghost_variants g ON g.memory_id = m.id
WHERE m.code != 'footprints'
GROUP BY m.code;
```
0개면 — `pickResponse` 글로벌 디폴트 풀 픽 (lumen_ghost_response.js DEFAULTS). OK.
