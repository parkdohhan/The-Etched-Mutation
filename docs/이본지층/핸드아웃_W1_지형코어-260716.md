## 작업 항목

### W1-1 모듈 뼈대 + 바닥(제0판)
- `js/shared/tem_variant_strata.js` 신설, §6 API 그대로 노출.
- 이식: `tem_replay_terrain.js`에서 물방울 침식(§9.4 특수화 3종 포함)·비탈 무너짐 패스·씨앗 난수·simplex — **복사 이식** (원본 파일 무수정, 은퇴는 W4 몫).
- 섬/공허/조각 배치 코드는 가져오지 않는다. **연속 대륙**: 바닥 = 기존 `computeAfTerrainFields` 결과(원본 지형)를 출발점으로 쓰되, 씬 융기(로브)는 `meta.stage_position` 좌표를 중심으로 새김 — 작가 배치가 지형의 닻. stage_position 없는 씬은 기존 감정 투영 폴백.
- 결정론: 같은 memoryData → 바닥 완전 동일 (테스트로 못박기).
- 발자국 실데이터로 바닥 1회 생성해 스크린샷을 보고서에 (시뮬 페이지에서).

### W1-2 발길 지도 + 작용 3종 (§3 사양 그대로)
- 발길 지도(높이맵과 같은 격자), 물 경유 칸 누적, 저장 시 0~1 정규화.
- 강화: 침식력 `× min(2, 1 + k_reinforce·발길)`. 기본 k_reinforce=0.6.
- 망각: `lerp(높이, 이웃8평균, k_forget·(1−발길))`, 기본 k_forget=0.005/봉인. 바닥이 아니라 **현재 땅**에 적용.
- 재응고: 이웃 높이차 > τ_rough 칸만 비탈 무너짐 국소 적용. 기본 τ_rough = 바닥 평균 이웃차 × 3.
- 질량 로그(§9.6 승계): 침식·무너짐 전후 흙 총량 보존 검증 (망각은 lerp라 보존 예외 — 로그에 별도 표기).
- 파이프라인 순서 고정: 침식→망각→재응고→불변량→serialize.

### W1-3 위상 자 (물 채우기 특징 세기)
- union-find 서브레벨 필트레이션으로 지속도 ≥ p_min 봉우리 수 + (부호 뒤집어) 분지 수. p_min 기본 = 바닥 높이 범위의 8% (시뮬로 보정).
- `getInvariants()` → {features, relief, roughness, mass}.
- 단위 테스트: 합성 지형(봉우리 3개 인공 생성) → features=3±0 검증, 잡음 추가해도 불변 검증.

### W1-4 시뮬레이터 + 500명 리트머스
- 독립 페이지에서: 발자국 바닥 → 가짜 관객 500명(여정 프리셋 5종 랜덤 혼합, 씨앗 고정) 순차 봉인 → 매 봉인 불변량 기록.
- 통과 기준(전부 그래프로 보고서에): ① features 밴드 유지(밴드 초기값 = 바닥 features ±60%, 이탈 시 손잡이 조정 후 근거 기록) ② 500명 후 바닥과 RMS 차이 유의 ③ 셔플 리트머스(같은 관객들 순서만 섞으면 다른 땅) ④ 발자국·당신에게 두 기억이 500명 후에도 서로 다른 땅(RMS 비교) ⑤ 질량 로그 이상 0.
- 스냅샷 직렬화: `serializeLayer()` + 높이맵 스냅샷 JSON 출력 (저장은 W2/W4 몫 — 여기선 포맷 확정과 크기 실측만: 목표 <150KB/장).

### W1-5 복구 도구
- `rebuildFromPlays(playRows)`: (user_id, 30분 간격) 세션 군집 → 시간순 베이트 근사 → 전체 재굽기. 근사임을 반환값에 명시. 단위 테스트 1개(합성 rows).
