## 4. 지휘 승인 W1 예외 — computeFields delta·generation 보존 ([tem_variant_strata.js:886](../../js/shared/tem_variant_strata.js))

**계약 불일치(실측 확정):** W1 `computeFields`(입구 훅 렌더)가 내부에서 `buildBase` 를 호출하는데, `buildBase`(427행)가 `_delta`·`_generation` 을 리셋한다. 노드 실행으로 확정 — `loadLayer` 로 실은 델타(Σ|Δ|=158.87)가 `computeFields` 직후 **0으로 소거**, 렌더=바닥과 동일(diff 0). 이러면 W4-1(물려받은 땅)·W4-3(목격) 이 바닥만 보이고, generation 리셋으로 다음 봉인이 409(누적 실패).

## 5. 발견·수정 — 다중 해상도 뒤집힘 버그 (play-test 구역 내 수정)

**증상:** 재진입 시 델타 로드는 성공하나 엔진 `_G` 가 48↔160 을 오가며 2304셀 델타가 무효화(다중 봉인·재빌드 시 물려받은 땅 소실).

**원인:** 앱이 변형 엔진(단일 `_G`/`_base`/`_delta` 상태)을 **두 해상도로 렌더**한다 — rt 3D 지형 `buildTerrain`(정본, G=160) vs 미니맵 `_cacheContourBackground`(G=48). 뒤에 도는 쪽이 `_G` 를 뒤집고, 다른 해상도 델타는 `buildBase` 리셋 후 복원 조건(길이 일치)에 걸려 소거.

**수정(play-test, 플래그 ON만 — 롤백 불변):**
1. 미니맵을 rt 정본 해상도 **G=160** 으로 맞춤([play-test.html:7402](../../play-test.html)) → 엔진이 G=160 단일 상태로 정착.
