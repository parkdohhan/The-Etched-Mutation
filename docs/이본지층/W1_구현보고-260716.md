## 3. 항목별 구현 (W1-1 ~ W1-5)

### W1-1 모듈 뼈대 + 바닥(제0판)
- `buildBase(memoryData, opt)` — 결정론 연속 대륙. 씬 감정 분포(안 뭉갠 17축)가 자기 로브에 융기,
  패치 중심(닻) = `meta.stage_position`, 없으면 감정 VA 투영 폴백.
- 물방울 침식(§9.4 특수화 3종: 태어나는 자리=전이 경로, 초기 방향=이동 벡터, 순서=재생 순서)·
  비탈 무너짐·씨앗 난수·simplex **복사 이식**. 섬/공허/조각 배치 코드는 안 가져옴(연속 대륙).
- **결정론 못박음**: 단위 테스트 `같은 memoryData → 바닥 RMS 차이 = 0` 통과.
- **실데이터 바닥**: 발자국(6씬) 실 `original_emotion` + `stage_position` 으로 바닥 1회 생성.
  → `W1_스크린샷/바닥_발자국.png` (features=6 = 씬 6개 봉우리).

### W1-2 발길 지도 + 작용 3종 + 질량 로그
- 발길 지도(높이맵과 같은 격자). 물 지난 칸 누적, 저장 시 0~1 정규화.
- **강화**: 침식력 `× min(2, 1 + k_reinforce·발길)` (dropOne 안에서 셀별).
- **망각**: `lerp(높이, 이웃8평균, k_forget·(1−발길))`, **현재 땅**에 적용.
- **재응고**: 이웃 높이차 > τ_rough 칸만 국소 무너짐(질량 보존).
- **질량 로그(§9.6)**: 침식·재응고 전후 흙 총량 보존 검증(허용오차). 망각은 lerp라 예외 — `forgetDrift` 별도 표기.
- **파이프라인 순서 고정**: ①침식(강화) → ②망각 → ③재응고 → ④불변량 → serialize.

### W1-3 위상 자
- union-find 서브레벨 필트레이션. 지속도 ≥ p_min 봉우리(초레벨)·분지(서브레벨) 개수.
  `peaks = 극값(−field)` (전역 최고봉 포함) + `basins = 극값(field, 전역 '바다' 제외)`.
- `getInvariants() → {features, peaks, basins, relief, roughness, mass}`.
- **단위 테스트**: 합성 봉우리 3개 → `features=3` (peaks=3, basins=0), 잡음 추가해도 불변. 통과.

### W1-4 시뮬레이터 + 500명 리트머스
- 독립 페이지. 발자국 바닥 → 가짜 관객 500명(여정 프리셋 5종 랜덤 혼합, 씨앗 고정) 순차 봉인 →
  매 봉인 불변량·RMS 기록. 리트머스 5종 그래프 + 스냅샷 크기 실측.
- 결과: **§5 리트머스 표** 참조. 전부 통과.

### W1-5 복구 도구
- `rebuildFromPlays(playRows)` — (user_id, 30분 간격) 세션 군집 → 시간순 베이트 근사 → 전체 재굽기.
  반환값에 `approximate:true` + note 명시. 단위 테스트 2개(세션 3분할·결정론) 통과.

## 6. 손잡이 최종값 + 근거 (밴드 이탈 → 조정 기록)

**초기값으론 밴드를 이탈했다.** 설계 초안값(k_forget 0.005, τ=평균×3, 원본 물리)으로 500명 돌리니
**features 6 → 1 붕괴**(rms 1.41 ≈ 바닥 std — 원본을 통째로 갈아엎음). 핸드아웃 W1-4 지시대로
손잡이/물리를 조정하고 근거를 남긴다.

### 6.1 진단 (스윕으로 범인 격리)
- erosion_scale 0.5→0.15 낮춰도 rms 1.41→1.39 **거의 불변** → 물방울 개수는 주범 아님.
- 각 패스 격리: **물방울(erosion_scale=1) 단독 → features 1**, 망각 단독 → 3, "거의 아무것도 안 함" → 5.
- 핵심 통찰: **순수 침식은 복원력이 없어(우상향 융기 없음) 어떤 비율이든 500번이면 평탄 끌개로 수렴.**
  비율은 *속도*만 정하고 *끝점*(평탄)은 같다 → 관객 예산(500) 안에서 살아남으려면 관객당 침식이 얇아야 함.
- 부차 범인 2개: (a) 전이마다 돌던 전역 `thermal`(500명×~5전이×2 = ~5000회 확산) — 1회 굽기용 잔재,
  (b) τ_rough=평균×3=0.64 가 성긴 봉우리 경사(~3)보다 낮아 재응고가 매 봉인 봉우리를 먹음.

### 6.2 최종값 + 근거
| 손잡이/상수 | 초안 | 확정 | 근거 |
|---|---|---|---|
| `k_reinforce` | 0.6 | **0.6** | 유지 |
| `k_forget` | 0.005 | **0.0008** | 500 봉인 누적 시 잔주름만 지우고 실루엣 보존 |
| `tau_rough_mult` | 3 (평균 기준) | **1.0 (p98 기준)** | τ 기준을 '평균 이웃차'→'이웃차 p98'로 변경. 평균은 매끈한 대륙에 눌려 봉우리를 먹음. p98(≈1.57)은 바닥 자연 경사 위 → 침식이 새로 판 절벽만 굳힘 (§3-3 "모래는 절벽 불가" 원의미에 더 충실) |
| `erosion_scale` (신규 §9.5) | — | **0.012** | 봉인당 물방울 총량 배율. 관객당 침식을 얇게 해 500명이 밴드 안(features 4~7)에서 이본화하되 무형태로 안 가게 하는 창 |
| 전역 `thermal` | 전이마다 2회 | **폐기** | 누적 모델에서 500× 확산 = 평탄화. 비탈 무너짐은 §3 ③재응고(1회/봉인)만 |
| `PHYS.erode/deposit/capacity/maxSteps` | 0.35/0.3/6/80 | **0.06/0.10/4/48** | 원본은 1회 굽기용. 누적 모델용으로 물방울 하나를 얕게(§9.5 "1회 보정 후 고정") |

전부 `TemVariantStrata.HANDLES` + `PHYS` 상단 주석에 근거 기록. 손잡이는 시뮬 슬라이더로 실시간 조정 가능.

## 10. 설계 계약 해석·편차 (정직 기록)

4. **위상 자 features 정의** — peaks(전역 최고봉 포함) + basins(전역 '바다' 제외). 합성 3봉우리에서 정확히 3.

## 11. 못 한 것 (필수 기록)

   훅은 default OFF·에러 폴백만 검증(브라우저 = 시뮬 페이지 한정 규칙 준수, play-test 안 엶).
3. **비정규 감정축** — 발자국 실데이터에 canonical 17축 밖 `emptiness` 존재. 엔진은 무시(안전).
   17축 통일은 별도 대기(설계 §8).
4. **변형층 저장 인코딩** — 251KB(G=96). W2 희소/타입드 인코딩 제안만(계약 밖, DB 쓰기 금지).
5. **당신에게 바닥 스크린샷** — 리트머스 ④ 수치(RMS 0.892)로만 검증. 별도 스크린샷은 생략(발자국 중심).

### 13.2 융기 사양
- **재료** = 관객의 그 씬 감정 17축(안 뭉갬), **자리** = 그 씬 로브(stage_position 닻 기준, buildBase 와 동일 기하),
  **세기** = 분포 강도 비례(축 w당 진폭 = k_uplift·w).
- **파이프라인 내 자리 = 봉인 파이프라인 맨 앞(⓪)**, beat 즉시 아님. 근거: (a) 관객은 "느끼며 퇴적"한 뒤
  "이동하며 침식"한다(§9.1 관객판) — 융기 먼저가 buildBase 와 일관. (b) 소급 변경은 스케줄이 아니라
  물리(§9.9), 같은 로그 = 같은 땅 — beat 은 로그만 쌓고 지형 변형은 봉인 1회로 모은다(순수 재계산·결정론).

### 13.3 질량 예산 ≈ 0 (로그로 증명)
- **국소 해자** 방식: 봉우리(양 가우시안, σ) 올림 + 둘레 얕은 해자(음 가우시안, σ_out=2.2σ, 진폭 amp/2.2²)
  팜 → 양·음 부피 동일 → **국소 net≈0**("산이 솟으며 둘레에서 흙을 끌어옴", 먼 벌판 불변). 그리드 절단 잔차만
  미세 균일 보정. **첫 시도(균일 침강)는 벌판을 영구 침하시켜 RMS 단조 발산 → 폐기**, 국소 해자로 교체.
- 실측(1명 봉인): uplift.pos **71.49**, neg **−69.94**, net **−8.4e-5** (tol 0.17). massLog.ok=true.
  스크린샷 `W16_1봉인전/후` — **mass 1702 → 1702** (숫자 불변 = 질량 예산 시각 증명).
