## 작업 항목

### W2-1 마이그레이션 (파일 1~2개)
- **terrain_layers 신설**: memory_id uuid pk (fk memories, on delete cascade), height_delta jsonb, foot_map jsonb, generation int not null default 0, updated_at timestamptz. RLS ON: SELECT anon/authenticated 허용, INSERT/UPDATE/DELETE 정책 없음(= Edge service role 전용. **정책 부재가 침묵 통과되는 함정 확인**: 익명 UPDATE가 200-0행으로 조용히 지나가는지 실측해 보고서에 기록 — R6 때 scenes에서 발견된 패턴).
- **Storage 버킷 `terrain_snapshots`**: 비공개(서비스 롤 쓰기 전용, 읽기는 authenticated). 정책 포함.
- **trajectory_bridges ALTER**: `contact_utterance text`, `contact_turn int` 추가. 컬럼 주석으로 "2026-07-16 접촉 기록 전용(轉用) — 정본화 없음" 명시. 기존 컬럼·admin 읽기(status='live') 비파괴.

### W2-2 Edge `record-erosion` (신규)
- 입력: { memoryId, height_delta, foot_map, generation, snapshot? }.
- 방어 (record-contamination 판례 + 지형 특화):
  1. 본문 상한 512KB (스냅샷 포함분 — W1 실측 크기 반영해 조정, 보고서에 근거)
  2. memoryId UUID + **최근 180분 내 그 기억의 plays 행 존재**
  3. generation = 서버 보관 generation + 1 만 허용 (역행·점프 거부 → 동시 봉인 경합 시 한쪽 409, 클라이언트는 조용히 포기하고 콘솔 로그 — plays 장부로 재구성 가능하므로 유실 아님)
  4. 델타 값 범위 상한(|값| ≤ 바닥 높이 스케일 20의 ±100%), foot_map [0,1], **변화 예산**: 직전 저장분과의 총 차이 Σ|Δ| ≤ 예산(관객 1명 몫 상한 — W1 시뮬 실측치 ×3, 근거 기록)
  5. 모르는 키 무시 (거부 아님 — R3-2 판례)
- 쓰기: service role로 terrain_layers upsert + snapshot 있으면 Storage `terrain_snapshots/{memoryId}/{generation}.json` (스냅샷 실패는 삼키되 응답에 표기 — 봉인을 막지 않음).
- 검증: 익명 REST 공격 6종(무플레이/generation 점프/역행/범위 밖/예산 초과/모르는 키) 전부 기대 응답 확인 표.

### W2-3 Edge `record-contact` (신규)
- 입력: { memoryId, sceneId, utterance, turn }.
- 방어: UUID 2종 + scene이 그 memory 소속 + 최근 플레이 존재 + utterance 500자 상한 + **회차 중복 차단**(같은 memoryId로 30분 내 기존 contact 행 있으면 409 — 회차당 1회 게이트의 서버측 보강).
- 쓰기: service role로 trajectory_bridges INSERT (status='contact', entry_emotion 등 기존 not null 컬럼은 스키마 실측 후 합리적 기본값 — 실측 결과를 보고서에).
- 검증: 익명 REST 정상 1 + 공격 3종.

### W2-4 generate-reveal 확장 (이본 명명 + 접촉 언어)
- 입력 추가(선택 필드, 하위호환): `variant_summary: { alignment_avg, dominant_mismatch, fixation_level }`, `contact: { occurred, scene_text?, utterance? }`.
- 프롬프트에 마지막 단락 지시 추가 — **초상화 규칙**:
  - "이 여정이 어떤 판본(이본)이 되었는지 한 단락으로 묘사하라. 서열·평가·성공/실패 언어 금지 ('잘했다/아쉽다/거의 도달' 류 금지). 성격만."
  - contact.occurred=true 면: "여정 중 유령과 정말 겹친 순간이 있었음을 '성취'가 아니라 '일어난 사건'으로 한 문장 언급" (utterance 인용 허용).
  - ko/en 양쪽.
- 기존 입력만 오면 기존 출력 유지 (하위호환 — W4 배선 전 배포돼도 무해).
- R3가 넣은 입력 상한 보존, variant_summary/contact 필드도 상한·타입 검증 추가.
- 검증: 실호출 3종(구형 입력/신형 정상/접촉 포함) 출력을 보고서에 인용 — **서열 언어가 안 나오는지 눈으로 확인**.
