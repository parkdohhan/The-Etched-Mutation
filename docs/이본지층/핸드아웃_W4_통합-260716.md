## 작업 항목 (순서대로)

### W4-1 지형 배선
- script 태그 추가(`?v=` 캐시버스터), 진입 시 플래그 ON이면: terrain_layers SELECT → `loadLayer()` → `buildBase()` 훅 경유 지형 렌더. 층 없으면 바닥만(제0판).
- `beginRun`/`beat` 배선: 옛 TemReplayTerrain.beat 자리(insertPlay 상단)와 동일 지점에 TemVariantStrata.beat. 인구 규칙은 라이브 run이라 무관(이번 관객).
- **옛 플래그 청소**: `tem_replay_terrain` localStorage 키 제거 코드 1줄 + 옛 모듈 4형제(replay_terrain script 태그·attach·getPiecePos 우선순위 블록) 제거. 파일은 보존. `?replay_terrain=` URL 처리도 중립화.

### W4-2 봉인 파이프라인
- sealBtn 흐름(오염 갱신·record-contamination 호출 인접)에 추가: `applyVisitorErosion()` → `{delta, footMap, generation, invariants}` → `record-erosion` 호출(스냅샷 포함). 실패는 크게 console.error (조용한 실패 금지) — 봉인 자체는 진행.
- generation 409(동시 봉인 경합) 처리: 포기 + 로그 (설계 §5 — plays 장부가 진실).
- invariants 콘솔 출력 (전시장 디버깅용 한 줄).

### W4-3 목격의 순간 v1 (소박하게)
- 봉인 직후, 퇴장 전: 침식 적용된 지형 재빌드를 **카메라가 보는 앞에서** 1회 (기존 재빌드 경로 재사용) + 자막 한 줄(ko/en) — "네가 지나간 자리가 굳는다" 결. 파티클·고도 연출 금지 (10월).
- 플래그 OFF면 이 연출 전체 스킵.

### W4-4 접촉 공식화 (lumen_dialog_phase1.js)
- 기존 이름-드러남 트리거(resonance 순간)에: ① **회차당 1회 게이트** (이미 nameRevealed 로직 있음 — 회차 전역 게이트로 확장: 이름 드러남 이후의 추가 resonance는 접촉 이벤트로 재발화하지 않음) ② 접촉 발생 시 `record-contact` 호출(발화·씬·턴) ③ 게이트/발화율 콘솔 로그(W3 측정 보완용).
- 임계값은 **건드리지 않는다** — W3 권고안이 있어도 변경은 지휘·작가 결정 후 별도 커밋.
- 접촉 정보를 회차 상태에 보관 → 봉인 시 reveal 입력으로.

### W4-5 reveal 배선 (이본 명명)
- generate-reveal 호출부에 `variant_summary`(게임 상태의 정렬 평균·지배 어긋남·fixation — R2가 만든 세션 집계 재사용)와 `contact` 추가. 구형 응답과의 하위호환 확인.
- 표시 문구 주변에 위계 어휘 잔재 있으면 교체 (W3의 잔재 지도 참조).

### W4-6 e2e 실증 (보고서의 심장)
플래그 ON, 발자국으로:
1. 진입 → 바닥+기존 변형층 로드 확인 (콘솔+스크린샷)
2. 대화 2~3씬 → 봉인 → ① record-erosion 200 + terrain_layers generation 증가 (SELECT 실측) ② 목격 연출 발화 ③ reveal에 이본 명명 단락 (스크린샷)
3. 재진입 → **아까 굳은 변형이 물려받아져 있음** (지형 차이 스크린샷 비교)
4. 접촉 유도(공명 결 응답) → 이름 드러남 + trajectory_bridges에 contact 행 1개 (SELECT)
5. 플래그 OFF 재진입 → 기존 지형 완전 동일 (롤백 검증)
6. 회귀: 사물·되새김·미니맵·안개·오염 텍스트 표출이 플래그 ON에서도 정상 (각 1스크린샷)
