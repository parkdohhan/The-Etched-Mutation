## 3. 기억 작용 3종 (8″ 상세)

땅 = 모눈종이 2장: **높이맵**(기존) + **발길 지도**(신규 — 물이 지난 칸마다 누적 +1, 0~1 정규화 보관).
봉인 1회의 파이프라인: ①침식(강화 포함) → ②망각 → ③재응고 → ④불변량 기록·스냅샷 → ⑤저장.

1. **강화** (산책로): 물방울이 칸을 깎을 때 `깎는 힘 × min(2, 1 + k_reinforce·발길)`. 물이 지난 칸 발길 +1. 밟힌 경로가 골로 응집.
2. **망각** (바람 부는 모래): 전 칸 `새높이 = lerp(높이, 이웃8평균, k_forget·(1−발길))`. 이웃 평균으로 당기므로 실루엣 보존, 잔주름만 소멸. k_forget ≈ 0.005/봉인.
3. **재응고** (모래는 절벽 불가): 이웃과 높이차 > τ_rough 인 칸만 → 기존 **비탈 무너짐 패스**(열 침식, 질량 보존) 국소 적용. 원본 쪽이 아니라 "그럴듯함" 쪽으로 굳음. (옵션 v1+: 세기 × cont_stage_3 가중 — 오염=연출 제어 신호 원칙과 정합.)

손잡이 3개 = k_reinforce / k_forget / τ_rough — 10월 튜닝 대상. 물리 상수(§9.5)는 기존 값 승계.

## 4. 위상 자 (형태 불변량)

**보장: 땅은 원본에서 무한히 멀어질 수 있으나, 무형태로는 갈 수 없다.**

- 측정 = **물 채우기 특징 세기**: 수위를 올리며(내리며) 지속도(persistence) ≥ p_min 인 봉우리·분지 개수. union-find 서브레벨 필트레이션, O(n log n), ~200줄.
- 불변량: `K_min ≤ 특징 수 ≤ K_max` (초기값 밴드는 바닥 지형 실측 ±로 설정, 시뮬로 보정).
- 보조 디버그 지표로 강등: 대비(p95−p5)·거칢(이웃차 평균).
- **스냅샷 로깅**: 매 굽기의 높이맵을 Storage에 저장 → 본격 위상 분석(지문·표류 곡선·족보)은 10월 오프라인. v1은 개수 세기까지만 (금지선).
- 검증 리트머스 (시뮬레이터): 가짜 관객 500명 통과 후 ① 특징 수 밴드 유지 ② 바닥과 RMS 차이 유의(이본 발생) ③ 셔플 리트머스(순서 섞으면 다른 땅) ④ 서로 다른 기억은 서로 다른 땅 유지. 질량 로그(§9.6) 승계.

## 5. 데이터 설계

- **terrain_layers** (신규 테이블): memory_id(pk, fk), height_delta(jsonb, 소수2자리 반올림), foot_map(jsonb), generation(int, 단조 증가), updated_at. RLS: 읽기 공개, 쓰기 없음(Edge service role 전용).
- **스냅샷**: Storage 버킷 `terrain_snapshots/{memoryId}/{generation}.json` (높이맵 전체). 실패해도 봉인은 진행(스냅샷은 연구 자료).
- **접촉 기록**: trajectory_bridges ALTER — `contact_utterance text`, `contact_turn int` 추가. status='contact'.
- **재굽기(복구)**: plays를 (user_id, 30분 간격) 세션 군집으로 근사 재구성 → 시간순 베이트. 근사임을 도구 출력에 명시.

## 6. 레인 계약 (W1 산출 API — 동결)

`window.TemVariantStrata` (js/shared/tem_variant_strata.js):
- `isEnabled()/setEnabled(v)` — 플래그 `tem_variant_strata` (URL ?variant_strata=1/0, localStorage). 옛 tem_replay_terrain 키는 읽지 않음.
- `buildBase(memoryData)` → 결정론 바닥 (scenes[{emotion_dist|original_emotion, meta.stage_position, scene_order}] 입력).
- `beginRun(memoryId)` / `beat(memoryId, {sceneId, sceneEmo, userEmo, isVoid})` — 기존 계약 승계.
- `applyVisitorErosion()` → 이번 run을 파이프라인(§3)으로 적용, `{delta, footMap, generation, invariants}` 반환.
- `loadLayer({height_delta, foot_map, generation})` / `serializeLayer()`.
- `rebuildFromPlays(playRows)` — 복구 도구 (호출측이 인구 필터).
- `getInvariants()` → `{features, relief, roughness, mass}`.
- `computeAfTerrainFields` 입구 훅: tem_af_strata_terrain.js 에 guarded block (플래그 OFF → 원본 경로 그대로, 실패 → 원본 폴백. replay_terrain 훅 전례와 동일 방식).
