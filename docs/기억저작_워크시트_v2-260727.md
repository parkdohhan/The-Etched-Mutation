
**역할 규칙 (7월 신설 — v1에 없음)**:

## 3. 장면별 상세 (장면마다 이 블록 복제) → admin 「씬 카드」

### Scene N

#### 3-1. 본문 텍스트 — 60~200자
> _______________________________________________________

- 긴 문단보다 **파편**이 낫다. 시제는 현재형 권장.
- 감각 디테일 1~2개 (소리, 빛, 촉감, 냄새, 공간 배치).

#### 3-2. 감정 — 두 경로 중 하나 (⚠️ **모든 씬에 필수** — 빈 씬은 시딩 때 엔진이 헛돈다)

- **간단 경로**: 씬 카드 「감정 결 선택지(choices)」 펼침 → 선택지 2~3개 →
  각각 감정(17축 드롭다운) + 강도. **저장 시 emotion_dist 자동 계산.**
- **정밀 경로**: Canvas 탭 → 해당 씬 → 17축 original_emotion 직접 입력.

선택지 설계 (간단 경로 쓸 때 여기 계획):
```
choice 1: text ______________  감정 ______  강도 ___
choice 2: text ______________  감정 ______  강도 ___
choice 3 (선택): "..."  — 침묵/회피 옵션. VOID 유도 (v1 원칙 유지)
```
choice는 다음 장면을 결정하지 않는다. **감정 결만 기록** (불변 원칙).

#### 3-3. 유령 이름 + 유령 대사 (7월 신설 — 접촉 연출의 절정)

```
유령 이름: ______   (관객이 공명할 때 "ghost" → 이 이름으로 드러남. 비우면 익명 유지)
```

「유령 대사(dialog_choices)」 접이식 편집기에 채울 것:
```
도입부:        ______________________________
장면 맥락:     ______________________________
선택지별 응답: ______________________________
```
**화법 규칙**: 회상 실패자 화법 — "~했던 것 같아", 단정하지 않기.
(⚠️ 언어 주의: "트루엔딩·보상" 어휘 금지. 접촉은 승리가 아니라 **드물게 일어나는 사건**.)

#### 3-4. VOID 설계 (침묵도 연출이다 — v1 원칙 유지)
```
sceneVoid / emotionVoid / reasonVoid: true/false,  voidLevel: low/high
```
전체 장면 중 2~4개를 VOID로 두면 기억의 "안개" 감각이 선다.
⚠️ **7-27 실측·부분 이식**: 현행 1인칭+이본지층 경로에서 **지형 구덩이는 작동**
(7-27 이식 완료 — 침묵 씬의 감정 좌표 자리가 함몰). ∅ 핀·침묵 유령·타이머는
아직 레거시 뷰 전용이라 화면 효과 없음. 상세 = `docs/실험/VOID_실측기록-260727.md`.

#### 3-5. 씬 meta
```
echo_words: [_____, _____]   (장면 주변에 떠오를 핵심 단어 2~3개)
motif_tags: [_____, _____]   (§1-5 모티프와 연결 — 같은 태그끼리 감각적 연속성)
```

## 4. 기억 수준 감정·오염 → admin 「AF 섹션」·「오염 섹션」

### 4-1. AF 좌표 (Strata 지형에서 이 기억의 위치. X=귀인, Z=핵심공포)

```
귀인 (합 1.0):     self ___ / other ___ / fate ___
핵심공포 (합 1.0): abandonment ___ / rejection ___ / powerlessness ___ / loss ___
```
admin에 **합=1 정규화 버튼** 있음. 장면별 AF는 기억 전체와 미묘하게 달라도 된다.

### 4-2. 17축 감정 팔레트 (기억 전반 — 장면별 감정은 §3-2에서 따로)

```
fear ___  sadness ___  anger ___  joy ___  longing ___  guilt ___  shame ___
numbness ___  disgust ___  surprise ___  pride ___  hope ___  envy ___
contempt ___  tenderness ___  loneliness ___  awe ___
```
- 주 감정 **3~5개만 0.4 이상**, 나머지 0.0~0.2. 전부 높으면 밋밋해진다.
- **17축 고정. 6축/VAD 섞지 말 것** (6·VAD는 시각화 배치 전용).

### 4-3. 감각 앵커 (sensory_anchor — 기억 전체를 관통하는 전신 감각. 레버 살아있음)
```
modality: smell/sound/touch,  content: ______(한 단어),  weight: 0.7~0.9
```
장면 하나에만 나오는 감각이면 쓰지 말 것. 예: 편지 = 발소리(sound, 0.85).

### 4-4. 오염 초기 상태
```
cont_depth: ___        (0=신선 / 5~10=이미 해석 누적된 채 입장. 편지는 8)
divergence·convergence·heterogeneity: 기본 0
stage_1/2/3: 기본 0.33/0.33/0.34  (특정 결 강조 시 편향, 합=1 정규화 버튼)
```
depth를 올리면 첫 방문부터 오염 판본 텍스트로 표출된다.

## 7. 마감 3종 (순서 고정 — 이걸 안 하면 "저장은 됐는데 엔진이 헛도는" 기억이 된다)

1. **[저장]** — 편집기에 머물며 토스트 "저장됨 — 씬 N개" 확인. 자주 눌러도 안전
   (씬 id 보존 diff 저장). 판본 이력·휴지통·30초 자동저장 안전망 있음.
2. **[작가 궤적 시딩]** — 씬마다 정렬도 1.0 기준 궤적을 심는 버튼. **필수.**
   이게 없으면 관객 정렬도를 비교할 기준이 없다. author-seed로 격리되어
   실관객 데이터·논문 분석엔 안 섞인다 (7-18 감사 실증). 재실행 시 교체(중복 없음).
3. **재생 확인** — `play-test.html?memory={기억id}&variant_strata=1`로 열어:
   - 씬 진입 시 내가 쓴 유령 도입부가 나오는가 (저작→소비 연결)
   - 유령 이름이 공명 시점에 드러나는가
   - 봉인까지 완주 → run_id·대화·도장·지형·오염이 한 회차로 쌓이는가
