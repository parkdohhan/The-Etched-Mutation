# Contamination Presentation Spec v1

**문서 목적:** contamination 상태값을 받아 프론트 연출 반응을 구현하기 위한 규칙 문서  
**작성일:** 2026-03-27  
**상태:** MVP 연출 구현용

---

## 0) 문서 선언

- 이 문서는 **계산 문서가 아니라 프론트 연출 문서**다.
- 프론트는 이미 계산된 contamination 상태를 소비만 한다.
- stage 재판정, drift/fixation 재계산은 하지 않는다.

---

## 1) 입력값 계약

### 필수 입력

- `cont_stage` (`stable` | `biased_inclination` | `hypercompletion`)
- `cont_drift` (0~1) — 얼마나 틀어졌는가 (스칼라)
- `cont_fixation` (0~1) — 얼마나 고착됐는가 (스칼라)
- `drift_direction` (`{ valence, arousal, dominance }`) — 어느 감정 방향으로 끌려가는가 (벡터)
- `dominant_emotion_label` (`anger` | `sadness` | `excitement` | `calm` | `neutral`)

### 선택 입력

- `cont_last_pattern`
- `cont_last_mismatch`

### 입력값 구조 해석

`cont_drift`와 `drift_direction`은 분리된 역할이다:

- **`cont_drift`** = 얼마나 (강도 스칼라). Stage 판정과 강도 밴드에 사용.
- **`drift_direction`** = 어디로 (방향 벡터). 독백 선택, 시맨틱 변이 방향, 사운드 텍스처에 사용.
- **`dominant_emotion_label`** = 방향 벡터의 사분면 요약. 독백 풀 인덱싱에 직접 사용.

예: `cont_drift = 0.6` + `dominant_emotion_label = 'anger'` → "이 기억은 분노 방향으로 중간 강도로 틀어지고 있다."

## 2) Stage별 반응 규칙

## 2.1 stable

- **텍스트**
  - 원문 유지
  - 문장 단위 변형 없음
  - 단어 단위 미세 흔들림만 허용
- **시각**
  - 지형/표면 안정 유지
  - 노이즈 최소
  - 윤곽선 변형 없음
- **사운드**
  - 기본 ambient 유지
  - 특정 대역 과강조 금지
- **사용자 체감 목표**
  - "아직 오염이 강하지 않다"

## 2.2 biased_inclination

- **텍스트**
  - 핵심 단어만 `drift_direction` 방향으로 치환/보정
  - 치환 방향은 `dominant_emotion_label`로 결정 (anger→분노 강화, sadness→슬픔 강화 등)
  - 문장 전체 재생성 금지
  - 애매한 표현을 약한 확정 표현으로 이동
- **시각**
  - 지형의 방향성 기울기 적용
  - contour를 한쪽 방향으로 소폭 편향
  - 핀 위치/내비게이션 정보는 유지
- **사운드**
  - 스펙트럼 tilt 적용
  - 특정 대역 소폭 강조
  - 채널 불균형은 약하게 시작
- **사용자 체감 목표**
  - "기억이 한 방향으로 틀어지고 있다"

## 2.3 hypercompletion

- **텍스트**
  - 누락된 연결 문구/확정 표현을 제한적으로 추가
  - 가능성 표현을 확정 표현으로 밀어붙이는 강도 증가
  - 과잉 디테일 삽입은 길이 제한 내에서만 허용
- **시각**
  - 표면 패턴 반복 고정
  - 유동성 축소, 루프성 강조
  - 동일 패턴 재현율 증가
- **사운드**
  - 짧은 모티프 반복
  - 잔향 tail 고착
  - 반복성 누적 강화
- **사용자 체감 목표**
  - "기억이 스스로 답을 확정하고 있다"

## 3) 강도별 반응 원칙

강도는 각 stage별 대표 축으로 조절한다.

- `biased_inclination`: `cont_drift` 기준
- `hypercompletion`: `cont_fixation` 기준

### 약함 (0.00 ~ 0.33)

- 텍스트: 단어 1~2개 수준 변경
- 시각: 미세 왜곡/약한 방향성
- 사운드: 감지 가능한 최소 변형

### 중간 (0.34 ~ 0.66)

- 텍스트: 문장 핵심어 중심으로 변형 확대
- 시각: contour/패턴 변화 체감 가능
- 사운드: 대역 강조/반복성 명확화

### 강함 (0.67 ~ 1.00)

- 텍스트: 확정적 문구 빈도 증가 (문장 구조 유지)
- 시각: 방향성/반복성 강한 고정
- 사운드: 반복 락인 뚜렷

## 4) 금지 규칙

- 문장 전체 재생성 남발 금지
- 프론트에서 stage를 다시 판단하지 않기
- 프론트에서 drift/fixation을 재해석하거나 재계산하지 않기
- 입력값 없는 추정 기반 연출 과적용 금지

## 5) 체감 전달 원칙: 기억의 독백

오염의 존재를 사용자에게 **보여주지 않는다.** 원문 대비, 차이점 하이라이트, "이 부분이 변형되었습니다" — 이런 것은 전시 캡션이지 체험이 아니다.

대신 **기억이 스스로 의심하게** 한다:

- 독백은 "Another Me"의 톤 — 시스템 메시지가 아니라 기억의 내면
- 비교를 보여주지 않아도, 기억 자신의 의심이 오염의 존재를 알려줌

### 5-1) 독백 위치: PLAY 중 vs strata — 결정됨 (2026-03-30)

> ✅ **두 위치 공존으로 결정.** PLAY 중 독백과 strata 독백은 서로 다른 텍스처로 공존한다. strata 독백은 MVP 구현 대상.

**PLAY 중 독백의 논리:**
- 체험 도중 "뭔가 잘 안 맞는다"는 감각이 들어야 자신이 오염의 주체임을 감각할 수 있다.
- 독백 텍스처가 간접적이라면 (직접 분석 노출 아님) 몰입을 깨지 않는다.
- 현재 구현이 이 방식 (`contaminationMonologue.js` — 장면 로드 시 1.5초 지연 트리거).

**strata 독백의 논리:**
- strata는 체험이 끝난 후 기억의 누적 오염을 되돌아보는 공간.
- "내가 이 기억에 무슨 짓을 한 거지"라는 사후 인식 텍스처에 더 맞다.
- 원래 스펙이 이 방식.

**결정:** 두 위치에 서로 다른 텍스처의 독백이 공존한다.
- PLAY 중 = 체험 중 이상한 감각 ("…이게 이렇게 뜨거웠었나")
- strata = 회고적 인식 ("내가 이 기억에 무슨 짓을 한 거지")

strata용 독백 풀은 MVP 구현 대상 (우선순위 섹션 8 참조).

### 5-2) 독백 선택에 drift direction 사용

독백 풀은 `dominant_emotion_label` × 강도 밴드로 인덱싱한다:

| `dominant_emotion_label` | 독백 예시 |
|--------------------------|----------|
| `anger` | "내가 그렇게 원래 화가 나있었나? 아니었던 거 같아..." |
| `sadness` | "이렇게까지 슬펐었나. 아니, 이건 내 슬픔이 아닌 것 같기도..." |
| `excitement` | "이렇게 뜨거웠었나. 기억이 과장하고 있는 건 아닌지..." |
| `calm` | "이건 너무 고요해. 원래 이렇게 무덤덤했던 건 아닌데..." |
| `neutral` | "뭔가 달라진 것 같은데... 뭐가 달라졌는지 모르겠다." |

hypercompletion 구역은 방향과 무관하게 고정 독백:
> "이건 너무 선명해. 기억이 이렇게 깔끔할 리가 없어."

void 구역(`cont_last_mismatch === 'void_mismatch'`)도 방향 무관:
> "여기엔 뭔가 있었는데... 지금은 비어 있다."

## 6) 텍스트 반응 방향성 — 현재 구현 vs 이상

### 6-1) 현재 구현 (client-side, seeded PRNG)

`contaminationPresenter.js`가 로컬에서 처리:

| 단계 | 방식 | 방향 |
|------|------|------|
| `biased_inclination` | 단어 사이 `·` 삽입 (침식 효과) | 손상 (divergence) |
| `hypercompletion` | 단어 반복 + `░▒▓` 블록 삽입 | 과선명 (fixation) |

결정론적: 시드 = `(sceneIndex × 2654435761) XOR (contDepth × 40503)`. 동일 기억 재플레이 시 동일 패턴.

### 6-2) contaminate-text Edge Function의 단방향성 갭

> ⚠️ **contaminate-text Edge Function(Gemini Flash)은 손상 방향만 구현되어 있다.**

현재 구현된 방향:
- Stage 1 (0.3~0.6): 객관화 — 1인칭 → 3인칭, 감각 디테일 흐릿해짐 (divergence)
- Stage 2 (0.6~0.9): 추상화 — 파편화, 대상 소거 (divergence)

**빠진 방향:**
- hypercompletion (과선명, 강렬화) — 오염이 "더 선명해지고 더 확정된다"는 방향. 현재 client-side 글리치로만 처리.

오염 문서(오염벡터 v2)의 세 축 중 convergence/fixation 방향이 Edge Function에 없다. AI 생성 오염 텍스트로 전환 시 이 방향 추가 필요.

### 6-3) 시맨틱 변이 (앵커 기반 슬롯 교체) — 아이디어 단계

drift direction이 있으면 "이 단어를 어느 방향으로 치환할 것인가"가 성립한다:

1. **baseline** = 원문 씬의 감정 톤
2. **direction** = `drift_direction` (누적 해석이 미는 방향)
3. **intensity** = `cont_drift` (얼마나 강하게)

조합 예: "조금 화가났어" → drift_dir anger + cont_drift 0.6 → "분노에 미쳤어."

LLM 전체 재작성이 아니라, 감정 동사 / 귀인 대상 / 확신도 마커를 방향 벡터에 따라 치환하는 방식. 상세 설계는 MVP Spec v3.2 §6 참조.

## 7) 기억 점유 레이어 — 아이디어

> **상태:** 브레인스토밍 완료. 구현 보류.

### 개념

"사용자의 입력이 다음 텍스트를 생성하는 것이 아니라, 기존 기억 데이터베이스가 사용자의 목소리를 점유해 다음 응답을 대신 말한다."

체험자가 expInterview(감정 칩 인터뷰)를 완료하면, 시스템이 사용자의 답변 자리에 **DB 안에 이미 존재하던 타인의 기억 문장**을 꺼내 표시한다. 생성이 아니라 재배열. 사용자가 자신의 감정을 표명했는데, 그 자리를 기억층이 먼저 점유한다.

심심이와 닮은 구조이지만 다른 것: 심심이는 "정답 응답"을 반환한다. TEM의 점유 레이어는 "오염된 응답 점유"여야 한다. 약간 엇나간 결의 문장이어야 "내가 말한 것 같지만 사실은 기억층이 나를 대신해 말했다"는 감각이 생긴다.

### 소스 풀

AI 새 생성 없이 DB에서 꺼낸다:
- `scenes.scene_text` + `scenes.original_emotion` (벡터 매칭용) — 현재 memory 제외한 타 기억
- 향후: 과거 체험자들의 감정 서술 파편

### 단계별 검색 중심

| 단계 | 검색 중심 | 효과 |
|------|----------|------|
| `biased_inclination` | 사용자 벡터 + drift 방향 블렌드 | 감정 방향은 맞지만 톤이 살짝 빗나감 |
| `hypercompletion` | 사용자 벡터 그대로 | 너무 완벽하게 일치 (uncanny) |
| `void_mismatch` | 최저 유사도 조각 | 가장 이질적인 파편 |

### UI 원칙

- NPC 다이얼로그 toast가 아니다.
- 장면 텍스트 영역 하단에 페이드인. 사용자 인터뷰 결과 자리를 밀어낸다.
- 폰트·색상: 장면 텍스트 스타일 그대로. 시스템 메시지처럼 보이지 않아야 함.
- `"…"` 외에 출처 표시 없음. 어디서 왔는지 모르는 것이 핵심.
- 4초 후 자동 소멸 또는 탭/클릭으로 즉시 넘어감.
- 발화 확률: weak 20% / medium 45% / strong 70% (monologue와 동일 PRNG 패턴).

### 기억유전학과의 연결

"기억 재조합 — 기억들이 서로 오염된다 (inter-engram 작동)." 제6원칙이 이 레이어를 이론적으로 지지한다. 체험자가 기억을 오염시키면서 동시에 기억에 오염되는 피드백 루프.

## 8) 구현 우선순위

1. 텍스트 반응 구현 ✅ (client-side: seeded PRNG, 침식/에코 글리치)
2. 사운드 반응 구현 ✅ (setContaminationStage — biased_inclination 페이드, hypercompletion 스냅백)
3. PLAY 중 독백 구현 ✅ (contaminationMonologue.js — 장면 로드 시 트리거)
4. strata 지형 탐험 + strata 독백 레이어 구현 ⬜ **[MVP]**
5. contaminate-text Edge Function — hypercompletion 방향 추가 ⬜ **[MVP]**
6. 시각 반응 구현 (지형 표면 오염 흔적) ⬜
7. 기억 점유 레이어 구현 ⬜ (아이디어 단계)
8. 시맨틱 변이 (앵커 기반 슬롯 교체) ⬜ (아이디어 단계)

## 9) QA 체크리스트

- 동일 입력에 동일 반응이 재현되는가 (seeded PRNG로 보장)
- stage 전환 시 연출이 급격히 깨지지 않는가
- 강도 구간(약/중/강)별 체감 차이가 분명한가
- 텍스트 가독성이 유지되는가
- 독백이 시스템 메시지가 아닌 기억의 내면으로 읽히는가
- 점유 레이어 문장이 "너무 정확"하거나 "너무 무관"하지 않은가 (약간 엇나간 결)
