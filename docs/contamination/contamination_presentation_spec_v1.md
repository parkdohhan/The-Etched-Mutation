# Contamination Presentation Spec v1

**문서 목적:** contamination 상태값을 받아 프론트 연출 반응을 구현하기 위한 규칙 문서  
**작성일:** 2026-03-27  
**상태:** MVP 연출 구현용

---

## 0) 문서 선언

- 이 문서는 **계산 문서가 아니라 프론트 연출 문서**다.
- 프론트는 이미 계산된 contamination 상태를 소비만 한다.
- stage 재판정, drift/fixation 재계산은 하지 않는다.

---

## 1) 입력값 계약

### 필수 입력

- `cont_stage` (`stable` | `biased_inclination` | `hypercompletion`)
- `cont_drift` (0~1) — 얼마나 틀어졌는가 (스칼라)
- `cont_fixation` (0~1) — 얼마나 고착됐는가 (스칼라)
- `drift_direction` (`{ valence, arousal, dominance }`) — 어느 감정 방향으로 끌려가는가 (벡터)
- `dominant_emotion_label` (`anger` | `sadness` | `excitement` | `calm` | `neutral`)

### 선택 입력

- `cont_last_pattern`
- `cont_last_mismatch`

### 입력값 구조 해석

`cont_drift`와 `drift_direction`은 분리된 역할이다:

- **`cont_drift`** = 얼마나 (강도 스칼라). Stage 판정과 강도 밴드에 사용.
- **`drift_direction`** = 어디로 (방향 벡터). 독백 선택, 시맨틱 변이 방향, 사운드 텍스처에 사용.
- **`dominant_emotion_label`** = 방향 벡터의 사분면 요약. 독백 풀 인덱싱에 직접 사용.

예: `cont_drift = 0.6` + `dominant_emotion_label = 'anger'` → "이 기억은 분노 방향으로 중간 강도로 틀어지고 있다."

## 2) Stage별 반응 규칙

## 2.1 stable

- **텍스트**
  - 원문 유지
  - 문장 단위 변형 없음
  - 단어 단위 미세 흔들림만 허용
- **시각**
  - 지형/표면 안정 유지
  - 노이즈 최소
  - 윤곽선 변형 없음
- **사운드**
  - 기본 ambient 유지
  - 특정 대역 과강조 금지
- **사용자 체감 목표**
  - "아직 오염이 강하지 않다"

## 2.2 biased_inclination

- **텍스트**
  - 핵심 단어만 `drift_direction` 방향으로 치환/보정
  - 치환 방향은 `dominant_emotion_label`로 결정 (anger→분노 강화, sadness→슬픔 강화 등)
  - 문장 전체 재생성 금지
  - 애매한 표현을 약한 확정 표현으로 이동
- **시각**
  - 지형의 방향성 기울기 적용
  - contour를 한쪽 방향으로 소폭 편향
  - 핀 위치/내비게이션 정보는 유지
- **사운드**
  - 스펙트럼 tilt 적용
  - 특정 대역 소폭 강조
  - 채널 불균형은 약하게 시작
- **사용자 체감 목표**
  - "기억이 한 방향으로 틀어지고 있다"

## 2.3 hypercompletion

- **텍스트**
  - 누락된 연결 문구/확정 표현을 제한적으로 추가
  - 가능성 표현을 확정 표현으로 밀어붙이는 강도 증가
  - 과잉 디테일 삽입은 길이 제한 내에서만 허용
- **시각**
  - 표면 패턴 반복 고정
  - 유동성 축소, 루프성 강조
  - 동일 패턴 재현율 증가
- **사운드**
  - 짧은 모티프 반복
  - 잔향 tail 고착
  - 반복성 누적 강화
- **사용자 체감 목표**
  - "기억이 스스로 답을 확정하고 있다"

## 3) 강도별 반응 원칙

강도는 각 stage별 대표 축으로 조절한다.

- `biased_inclination`: `cont_drift` 기준
- `hypercompletion`: `cont_fixation` 기준

### 약함 (0.00 ~ 0.33)

- 텍스트: 단어 1~2개 수준 변경
- 시각: 미세 왜곡/약한 방향성
- 사운드: 감지 가능한 최소 변형

### 중간 (0.34 ~ 0.66)

- 텍스트: 문장 핵심어 중심으로 변형 확대
- 시각: contour/패턴 변화 체감 가능
- 사운드: 대역 강조/반복성 명확화

### 강함 (0.67 ~ 1.00)

- 텍스트: 확정적 문구 빈도 증가 (문장 구조 유지)
- 시각: 방향성/반복성 강한 고정
- 사운드: 반복 락인 뚜렷

---

## 4) 금지 규칙

- 문장 전체 재생성 남발 금지
- 프론트에서 stage를 다시 판단하지 않기
- 프론트에서 drift/fixation을 재해석하거나 재계산하지 않기
- 입력값 없는 추정 기반 연출 과적용 금지

## 5) 체감 전달 원칙: 기억의 독백

오염의 존재를 사용자에게 **보여주지 않는다.** 원문 대비, 차이점 하이라이트, "이 부분이 변형되었습니다" — 이런 것은 전시 캡션이지 체험이 아니다.

대신 **기억이 스스로 의심하게** 한다:

- 봉인 후 strata 지형 탐험 시, 오염 핫스팟 근접 시 기억의 독백이 떠오름
- 독백은 "Another Me"의 톤 — 시스템 메시지가 아니라 기억의 내면
- 비교를 보여주지 않아도, 기억 자신의 의심이 오염의 존재를 알려줌

### 독백 선택에 drift direction 사용

독백 풀은 `dominant_emotion_label` × 강도 밴드로 인덱싱한다:

| `dominant_emotion_label` | 독백 예시 |
|--------------------------|----------|
| `anger` | "내가 그렇게 원래 화가 나있었나? 아니었던 거 같아..." |
| `sadness` | "이렇게까지 슬펐었나. 아니, 이건 내 슬픔이 아닌 것 같기도..." |
| `excitement` | "이렇게 뜨거웠었나. 기억이 과장하고 있는 건 아닌지..." |
| `calm` | "이건 너무 고요해. 원래 이렇게 무덤덤했던 건 아닌데..." |
| `neutral` | "뭔가 달라진 것 같은데... 뭐가 달라졌는지 모르겠다." |

hypercompletion 구역은 방향과 무관하게 고정 독백:
> "이건 너무 선명해. 기억이 이렇게 깔끔할 리가 없어."

void 구역(`cont_last_mismatch === 'void_mismatch'`)도 방향 무관:
> "여기엔 뭔가 있었는데... 지금은 비어 있다."

### 시맨틱 변이에서의 drift direction 역할 (향후)

drift direction이 있으면 "이 단어를 어느 방향으로 치환할 것인가"가 성립한다:

1. **baseline** = 원문 씬의 감정 톤 (씬 메타데이터)
2. **direction** = `drift_direction` (누적 해석이 미는 방향)
3. **intensity** = `cont_drift` (얼마나 강하게)

이 셋의 조합으로: "조금 화가났어" → drift_dir가 anger 방향 + cont_drift 0.6 → "분노에 미쳤어."

이것은 앵커 기반 슬롯 교체이다. LLM 전체 재작성이 아니라, 감정 동사/귀인 대상/확신도 마커를 방향 벡터에 따라 치환한다.

상세 설계는 MVP Spec v3.2 §6 (drift direction vector) 참조.

---

## 6) 구현 우선순위

1. 텍스트 반응 구현 ✅ (client-side fallback: seeded PRNG, 방향성 침식/에코 글리치)
2. 지형 탐험 + 독백 레이어 구현
3. 시각 반응 구현 (지형 표면 오염 흔적)
4. 사운드 반응 구현 (drift→톤 기울기, fixation→모티프 반복)

---

## 7) QA 체크리스트

- 동일 입력에 동일 반응이 재현되는가 (seeded PRNG로 보장)
- stage 전환 시 연출이 급격히 깨지지 않는가
- 강도 구간(약/중/강)별 체감 차이가 분명한가
- 텍스트 가독성이 유지되는가
- 독백이 시스템 메시지가 아닌 기억의 내면으로 읽히는가
