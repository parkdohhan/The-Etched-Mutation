# Contamination Presentation Spec v1

**문서 목적:** contamination 상태값을 받아 프론트 연출 반응을 구현하기 위한 규칙 문서  
**작성일:** 2026-03-27  
**상태:** MVP 연출 구현용

---

## 0) 문서 선언

- 이 문서는 **계산 문서가 아니라 프론트 연출 문서**다.
- 프론트는 이미 계산된 contamination 상태를 소비만 한다.
- stage 재판정, drift/fixation 재계산은 하지 않는다.

---

## 1) 입력값 계약

### 필수 입력

- `cont_stage` (`stable` | `biased_inclination` | `hypercompletion`)
- `cont_drift` (0~1)
- `cont_fixation` (0~1)

### 선택 입력

- `cont_last_pattern`
- `cont_last_mismatch`

---

## 2) Stage별 반응 규칙

## 2.1 stable

- **텍스트**
  - 원문 유지
  - 문장 단위 변형 없음
  - 단어 단위 미세 흔들림만 허용
- **시각**
  - 지형/표면 안정 유지
  - 노이즈 최소
  - 윤곽선 변형 없음
- **사운드**
  - 기본 ambient 유지
  - 특정 대역 과강조 금지
- **사용자 체감 목표**
  - "아직 오염이 강하지 않다"

## 2.2 biased_inclination

- **텍스트**
  - 핵심 단어만 편향 방향으로 치환/보정
  - 문장 전체 재생성 금지
  - 애매한 표현을 약한 확정 표현으로 이동
- **시각**
  - 지형의 방향성 기울기 적용
  - contour를 한쪽 방향으로 소폭 편향
  - 핀 위치/내비게이션 정보는 유지
- **사운드**
  - 스펙트럼 tilt 적용
  - 특정 대역 소폭 강조
  - 채널 불균형은 약하게 시작
- **사용자 체감 목표**
  - "기억이 한 방향으로 틀어지고 있다"

## 2.3 hypercompletion

- **텍스트**
  - 누락된 연결 문구/확정 표현을 제한적으로 추가
  - 가능성 표현을 확정 표현으로 밀어붙이는 강도 증가
  - 과잉 디테일 삽입은 길이 제한 내에서만 허용
- **시각**
  - 표면 패턴 반복 고정
  - 유동성 축소, 루프성 강조
  - 동일 패턴 재현율 증가
- **사운드**
  - 짧은 모티프 반복
  - 잔향 tail 고착
  - 반복성 누적 강화
- **사용자 체감 목표**
  - "기억이 스스로 답을 확정하고 있다"

---

## 3) 강도별 반응 원칙

강도는 각 stage별 대표 축으로 조절한다.

- `biased_inclination`: `cont_drift` 기준
- `hypercompletion`: `cont_fixation` 기준

### 약함 (0.00 ~ 0.33)

- 텍스트: 단어 1~2개 수준 변경
- 시각: 미세 왜곡/약한 방향성
- 사운드: 감지 가능한 최소 변형

### 중간 (0.34 ~ 0.66)

- 텍스트: 문장 핵심어 중심으로 변형 확대
- 시각: contour/패턴 변화 체감 가능
- 사운드: 대역 강조/반복성 명확화

### 강함 (0.67 ~ 1.00)

- 텍스트: 확정적 문구 빈도 증가 (문장 구조 유지)
- 시각: 방향성/반복성 강한 고정
- 사운드: 반복 락인 뚜렷

---

## 4) 금지 규칙

- 문장 전체 재생성 남발 금지
- 프론트에서 stage를 다시 판단하지 않기
- 프론트에서 drift/fixation을 재해석하거나 재계산하지 않기
- 입력값 없는 추정 기반 연출 과적용 금지

---

## 5) 구현 우선순위

1. 텍스트 반응 구현
2. 시각 반응 구현
3. 사운드 반응 구현

---

## 6) QA 체크리스트

- 동일 입력에 동일 반응이 재현되는가
- stage 전환 시 연출이 급격히 깨지지 않는가
- 강도 구간(약/중/강)별 체감 차이가 분명한가
- 텍스트 가독성이 유지되는가
