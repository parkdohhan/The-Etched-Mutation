## 0. 결과 한 줄

실험 페이지 `test/corridor-3d-test.html`(+ 빌더 `corridor-3d-build.js` · 소리 `corridor-3d-audio.js`)로, 어제 규칙 파일의 중심선을 14 m 로 축척해 그 위에 천장까지 닫힌 관 + 벽의 작은 문 + 실물 크기 문 둘을 세우고, 방 A 에서 걸어 들어가 방 B(fixation 은 같은 방의 옆문)까지 6패턴 전부 실제 경로로 도착하는 것을 확인했다(콘솔 오류 0). 세 렌즈 검토에서 결함 27건이 나와 그중 high 5 · medium 9 를 포함한 대부분을 고쳐 정지 42장 + 영상 2편을 다시 찍었다. t=0·0.5 컷은 어제의 "골"이 아니라 "통로"로 읽히고, 같은 패턴·다른 쌍은 색·사물·밝기로 갈린다. 남은 것은 avoidance 가 "보이지만 막힌 통로"가 아니라 "검은 허공"이라는 점, contradiction·fixation 의 불가능 공간(단면에서 그대로 노출), 소리의 실제 청취 검증 0 — §6·§8에 적었다.

### 3.3 델타가 닿는 곳 (라벨 단독 금지의 경로)

`deltaInfo`(dom·side·r2·mN)가 실제로 바꾸는 것 = **중심선(곡률·되돌림·옆 밀림) · 상징 사물 수 · 사물 놓이는 쪽(side) · 걸음 기울기 폭·주기**. **벽색·빛색·소리·바닥재·씨앗**은 델타가 아니라 **장면 프리셋(쌍)** 으로 갈린다. 쌍이 다르면 프리셋이 다르므로 통로는 갈리지만, "델타가 재료·소리에도 들어간다"고 읽으면 과장이다(검토 low, 문구만 정정).

## 7. 사용자 판정 — 세 질문

캡처(또는 페이지를 직접 열어 조절판으로 바꿔 가며)를 보고 답한다. 관객이 보는 건 1인칭(§5.1~5.4)이고 단면(§5.5)은 검토용이다.

1. **1인칭에서 "통로"로 읽히는가, 그리고 어두운 결(Linear, 42 왼쪽 값)과 밝은 결(sRGB, 42) 중 어느 쪽이 무대 톤인가?** — §5.1 열여덟 장 + 42. 어제의 "골" 인상이 사라졌는지, 벽·천장·작은 문·손잡이가 Among the Sleep 의 복도 결에 닿는지.
2. **패턴 이름 없이 걷는 동안 6종이 서로 다른 통로로 겪어지는가, 같은 패턴이 쌍마다 다른 통로가 되는가?** — §5.1 세로줄 비교 + §5.2 서명 구간 + §5.3 세 쌍. t 0.5 한 자리에서는 echo/contradiction·bridge/fixation 이 가까웠고, 수정 후에도 구분 근거는 폭·결·되풀이 사물·바닥빛이다.
3. **avoidance 를 어떻게 둘 것인가** — 지금은 벽·천장 없는 검은 띠 + 짙은 안개이고 걸어서 통과된다(13~15). 조사 체크리스트 9는 "보이지만 막힌 통로"(뿌리·쌓인 사물로 끝을 막고 벽의 작은 문 하나로 우회)를 제안한다. 어제 T1 은 정반대 극단(길처럼 보이는데 막힘)이었다.

## 8. 알려진 한계 · 무대 이식 시 본 코드 수정 항목

**실험 자체의 한계**
- 장면 프리셋 5는 가상 17축 벡터·가상 재료 세트. 실 DB 씬·실 별이엔진 출력은 안 불렀다.
- 중심선 길이 규칙은 T1 과 같은 한계를 그대로 물려받았다(echo 만 정렬도에 정확히 따르고, contradiction 세 쌍의 길이가 거의 같다).
- avoidance 는 "보이지만 막힌 통로"가 아니라 검은 허공 + 통과됨(체크리스트 9 미반영). 도착 문이 1.7 m 에서는 다른 패턴과 비슷한 밝기.
- contradiction 되돌림이 방 A 부피를 관통하고(28), 되돌림 두 다리가 0.4 m 겹친다. fixation 은 수정 후 방 밖에 놓였지만 "안이 밖보다 큰 옷장"식 불가능 공간이 contradiction 에 남아 있다(방은 숨기고 이동은 문틀에서만 이어 새지는 않음).
- 사물 충돌 없음 — 나무·창틀을 통과한다. 좁은 자리엔 안 두는 것으로만 막았다.
- 소리는 실제 청취 검증 0(헤드리스 ctx 'none'). 음량 숫자만 확인. 저음은 모노.
- 깜빡임 주기(발산 0.9 에서 1.75 s)·walk 조향 시간상수(0.8 s)는 모션 규칙 3.5 s 보다 빠르다. 잔떨림 스캔라인 측정 안 함.
- 눈높이 0.9 에서 벽이 "높다"로 읽히는지는 캡처(22·40·41)로만. 폭은 안 줄였다.
- 이질 조각보는 재료 분할 뒤에도 조명이 어두우면 대비가 작다. sRGB 출력에서는 더 갈린다(42).
- 옆 단면 뷰는 통로 중간 z 한 곳에서만 자르므로 휘는 통로에선 대부분 잘려 나가 문서 그림용으론 위 단면만 쓸 만하다.
- 수정 후 영상 2편은 프레임을 눈으로 열지 못했다(ffmpeg 없음). 시작·끝 상태만 확인.
- 헤드리스 SwiftShader 렌더라 실제 GPU 화면과 밝기가 다를 수 있다. 판정은 가능하면 페이지를 직접 열어서.
- 코드 잔재: ~~줄무늬 위상 어긋남(t 0.5 경계)~~(저녁 수정, §11.1), teleport(t≤0) 자막 플래그, 항상 참인 삼항, 미사용 import.

### 10.2 통로 규칙 (추가분)

- **닫힘 e(t) = lerp(e_A, e_B, t)** (fixation 은 e_B = e_A). 링마다 벽 높이 h = e(t)·min(H_수준, lerp(H_A, H_B, t)) — 닫힌 방은 그 천장이 상한(거짓말 1.9 가 관으로 이어짐). **e < 0.08 인 링 사이는 벽·천장 없이 바닥만.** 천장 = 양쪽 벽 꼭대기 선반이 안쪽으로 (w/2−r)·c, c = smoothstep(0.75, 1, e) — c < 1 이면 가운데 하늘 틈. 폭 규칙(수준·수렴·목)은 종전.
- **환경도 t 로 A→B lerp**(관객 위치, 2.5 s 지수 접근): 하늘색 = scene.background = 안개색, 안개 밀도 = lerp(fogBase)×(1+2(1−a)) (closed 0.05 / open 0.06 / void 0.14, avoidance ×4.8), ambient(closed 0x2a2838×1.2 / open 0xb9c2cf×1.0 / void 0x0a0a10×0.8), 태양광(open 0.45, 나머지 0), 관객 국소광 배율(closed 1 / open 0.15 / void 0.5).
- **눈**: 열린 땅 상자 36×7×36 에 2600×밀도 개(닫힌 공간·지붕 덮인 통로 부피 제외), 통로 링당 round(10·lerp(p_A,p_B,t)·(1−e(t))) 개 — 벽이 낮아진 곳으로 눈발이 들어온다. 낙하 0.45~0.8 m/s, 관객 0.8 m 안 숨김, 전부 해시(난수 0). 입자 밀도 lerp 는 세울 때 링마다 구워진 값(실시간 아님 — 하늘·안개·빛은 실시간).
- **이동**: 열린 땅·무의 땅 = 원판(r−0.3) − 벽 선 통로 부피(e≥0.08) − 문의 입(문 밖 0~2.5 m·좌우 1.3 m) − 숨은 닫힌 공간 − 더 가까운 다른 공간(보로노이). 벽 없는 링이고 문 2.5 m 밖이면 문 없이 땅↔통로 옆으로 드나듦. 닫힌 방 문턱 규칙은 종전. 열린 땅·무와 그 눈은 늘 그려진다(그게 바깥 세계).
- 작은 문은 smallDoors 프리셋(거짓말) 쪽 절반·e≥0.6 에만(2.4 m 부터 2.2 m 마다).
- 훅 `start()` 추가. `state()` 에 space:{A,B}, eA/eB, enclosure(t), ceilingCover, skyOpen, skyBright, sky, ambient, sun, localK, snow, points[].h/e. 상태줄에 공간 A/B 종류·e·하늘(열림·밝음 / 열림·어둠 / 닫힘)·눈 수.

### 11.3 감각의 시간차 (검토 ②)

시각(벽색·빛 세기·빛색·하늘·안개·ambient·태양·국소광·눈발) · 배경 소리(비·바람·웅웅·삐·벨) · 발소리(바닥재) · 도착 소리(드론·허밍)가 진행도 t 를 **각자 다른 구간**에서 읽는다. 구간 [a, b]: t ≤ a 출발 재료, t ≥ b 도착 재료, 사이 직선. **통로 구조(닫힘 e(t)·폭·중심선·사물)는 곡선을 타지 않는다** — 길과 걷는 속도는 어느 설정에서도 같다(검토 "비교할 때는 길과 이동 속도를 동일하게").

|---|---|---|---|---|---|
| 동시 (종전) | 0→1 | 0→1 | 0→1 | 0→1 | 오전·오후판과 같다 |
| **눈이 먼저** (기본) | 0.10→0.70 | 0.30→0.90 | 0.75→1.00 | 0.50→1.00 | 검토의 예: "눈은 이미 보이지 않는다. 발밑에서는 여전히 눈 밟는 소리. 형광등 아래 도착한 뒤에야 발소리가 바뀐다" |

### 11.4 여정 · 흔적 (검토 ①, 첫 시제품 = 눈 한 줌)

- **여정** `S.journey` = 봉인된 앞 구간들 [{from, to, pattern, alignment}]. 현재 구간의 출발 = 마지막 도착. "다음 기억으로 잇기"(도착한 뒤에만 — 공간 B 에 들어서야 버튼이 켜진다)가 현재 구간을 봉인하고 도착 공간을 출발로 다음 구간을 그 공간의 시작 자리에서 세운다. 쌍을 손으로 바꾸면 새 여정. fixation 은 도착 = 출발 공간.
- **흔적**은 지나온 공간의 입자(눈)만: hop 0 = 현재 출발 공간(마당→병실이면 병실에 눈 1), hop 1 = 그 앞 구간의 출발(마당→병실→전화면 전화에 눈 0.5), … 한 칸에 ×0.5. 도착 공간이 스스로 눈밭이면 안 둔다. **기록** = `state().trace {snow, origin, originName, hops, via[], parts[], gain}` — 검토의 "눈이 어디에서 왔고, 어떤 방문을 거쳐 남았는지" 그대로. 상태줄·조절판에 "눈 0.50 ← 첫눈의 마당 (1칸, 병실 복도 거쳐)".
- **자리**: 도착 문 안쪽 0.6 m(문으로 들어온 사람이 처음 밟는 자리, 54) + 상징 사물 아래 ×0.7(병실 = 링거대 아래, 창 = 창 아래, 전화 = 탁자 곁) + **통로 바닥**: 시각 곡선이 0.85 를 넘은 자리부터 도착 문 앞 0.8 m 까지 1.1 m 마다 작은 눈덩이(도착으로 갈수록 작게, 벽 쪽 좌우 교대) — "벽은 이미 병실인데 발밑엔 눈"(53). 동시 곡선에선 통로 눈덩이 없음. 빌더 `buildSnowTrace(amount)` = 납작 무더기 1 + 작은 덩이 round(2·amount) + 녹은 자국(어두운 원판).
- 세션 안에서만(저장 0, 정본화 없음 — trajectory bridge 원칙). 이본지층 "발길" 계수의 통로 판이며, 강화·망각·재응고 중 **망각(한 칸 ×0.5)** 만 옮겼다. 강화(같은 길을 여러 번)·재응고는 미착수.
- 검증: 마당→병실 눈 1·hop 0·메시 7(문턱 1 + 링거대 1 + 통로 5) → 잇기(병실→전화) 0.5·hop 1·via[병실] → 잇기(전화→창) 0.25·hop 2·via[전화·병실]. 도착이 눈밭(병실→마당) 0. 눈 없는 여정(창→병실) 0. 도착 전 잇기 거절 → 걸어 들어간 뒤 허용.

### 11.7 판정 질문 (§7·§10.4 에 더함)

6. **병실에서 자신이 지나온 눈밭을 알아차리는가?** — 검토가 세운 성공 기준. 54(눈 1)·55(눈 0.5). 눈 무더기 크기(반지름 0.5 m)가 "한 줌"인지 "무더기"인지, 녹은 자국이 읽히는지.
7. **눈이 먼저 / 귀가 먼저 / 동시 중 어느 시간차가 "기억이 겹친다"로 겪어지는가?** — 페이지를 직접 열어 마당→병실을 세 번 걷는다. 헤드리스 캡처는 시각(53·58)만 보인다.
8. **정렬도 쓰임을 종전(편안함)에서 신안(잔류·겹침)으로 바꿀 것인가?** — 조절판 스위치로 같은 자리(자리 유지)에서 전후 비교. 바꾸면 §3.2 안개·빛 거리·문 속도 규칙과 §5.4 캡처(정렬도 0.2)가 무효가 된다.
9. **좌우 = 감정가 이동이 맞는가?** — 57. 같은 결 안의 이동(거짓말→병실)은 반폭으로 휘어 길이 목표에 못 미친다. 대안: 같은 결 안에서는 다른 축(예: 각성)을 좌우 원료로.

### 11.8 남은 것

- **소리 청취 0** — 검토문도 "실시간 플레이와 청취까지 검증한 건 아니야". 자리(HRTF)·먹먹함(로패스)·뒤 저음 방향은 숫자만. 서버를 열어 직접 걷는 것이 첫 청취.
- 좌우 규칙이 **뜻을 바꿨다**(지배 축 늘어남/줄어듦 → 감정가 밝아짐/어두워짐). 캡처 1~52 중 12/20 쌍의 좌우가 저녁판과 다르다. §3.3 "델타가 닿는 곳"의 side 서술은 저녁판에서 이 절이 덮는다.
- 같은 결 안의 이동은 옆 폭 반(K≈0) — echo/bridge 길이가 목표(1 + 0.75(1−a))에 못 미친다(거짓말→병실 ×1.067 vs 목표 1.225). 길이 규칙을 지키려면 진폭 대신 마디 수를 늘리는 다른 형태가 필요.
- 흔적은 **눈 하나**뿐. 비(창)·형광등 빛·전화벨 잔향 같은 다른 기억의 흔적은 정의 안 됨. 강화(같은 길 반복)·재응고 미착수. 여정은 세션 안에서만(새로고침에 사라짐 — 의도).
- 자리 유지는 통로 t 와 공간 B 만 — 공간 A 안의 정확한 자리는 안 돌려놓는다(시작 자리).
- 정렬도 신안의 "반복"(사물 되풀이) 미구현. 신안 기본값은 종전 — 사용자 판정 8.
- 검토 ④ 홀로 선 문(보이는 경계 / 문 통과 시 다른 공간 연결)은 미착수 — 별도 실험(§10.5 열린 땅의 contradiction 과 같은 묶음).
- 통로 눈덩이는 avoidance 제외(바닥 띠뿐). 눈덩이·흔적에 충돌 없음(밟고 지나간다).
- `state().sound.src` 는 세계 좌표 그대로(반올림 없음) — 캡처 스크립트 비교 시 주의.
