## 1. 메모리 진입

Q: 첫 유령이 어디 박혀 있나? 진입 즉시 보임 / 공간 안 어딘가 / 다른 유령들은 안 보임 / 희미하게?

A: 메모리 진입시 플레이어는 문앞에 서있는다. 그리고 플레이어가 문쪽을 돌아봤다가 다시 정면을 바라볼때, 그때 유령이 한발치 앞에 나타나있다.

## 2. 첫 유령 (gateway) 발화 풀

Q: 첫 유령 발화 풀 어떻게 박나? 결마다 변주 몇 개?
- 첫입장 변주 ("엄마랑 ~~했을 때... 그때가 기억나네... 누군가 찾아왔네")
- 재입장 변주 ("돌아왔구나")
- 가이드 변주 ("저쪽이야")
- 메타 변주 ("기억이 흐려져...", "기억이 너무 선명해")

발자국 메모리 = gateway 누구로 박나? 기존 풀 중 1개 / 신규?

A: 원래 기존풀중 하나를 쓰는데, 기존 풀에 있는 유령의 ego를 많이 죽이고 간단한 한마디+ 대충 기억에 대해서 감을 잡을수있는 힌트 한마디. 이건 브레인스토밍 회의를 좀 해봐야알듯

> **추가 회의 자리** = gateway 발화 톤 + 변주 개수 + 발자국 gateway 누구

## 3. 첫 유령과 멀티턴 대화

Q: 첫 유령과 몇 턴 대화 박나? 끝나는 신호는?
- N턴 자동 (현재 V2.1.1 = 3턴)
- 자유 입력으로 끝낼 수 있음
- "여기까지 대화하기" 버튼 = gateway에서도 박혀 있음 / 없음
- 닮은 정도 점수가 어느 기준 넘으면 자동 종료 (= "임계 자동" 옵션 = 닮은 정도 ≥ 0.7 같은 *기준선* 도달 시 자동 끝)

A: 첫유령과의 대화는 무조건 3턴, 자유입력으로 끝낼수없음, 여기까지 대화하기 가능. *기준선 자동 종료는 안 박음* (3턴 고정)

## 4. 다음 유령 매치

Q: 첫 유령 멀티턴 끝나면 다음 유령이 매치됨. 매치 알고리즘 어떻게 박나?
- 매치 입력 = 멀티턴 누적 감정 12축 / 마지막 1턴만
- 후보풀 = 메모리 안 모든 유령 / gateway 외 / 안 만난 유령만
- 매치 임계 미달 시 = 매치 실패. gateway가 "다른 데서 찾아봐" 메타 발화 / 임계 무시하고 top1 강제

A: **장면 핀 궤적 매처 (`SceneNavigator`) 그대로 재활용**. 기존 박혀 있는 자리 ([docs/SceneNavigator_설계_v1-260329.md](SceneNavigator_설계_v1-260329.md)). 후보풀만 *씬 → 유령*으로 바꿈. 입력 시그니처 (플레이어 감정 12축) 동일.

> **추가 결정 자리** = 후보풀 정확히 어떤 자리 (안 만난 유령만? 만난 유령도 후보?) — 11번에서 박음

## 5. 유령 b 등장 + 파동 spot 활성

Q: 매치되면 유령 b가 공간 안에 나타남. 어떻게 등장?
- 위치 = 작가 박은 고정 좌표 / 근처 자리 자동 배치
- 시각 = 페이드인 / 카메라 펄스 / 사운드 swell / 셋 다 / 다른 자리
- **파동 spot 활성** — b 자리에 동그라미 파동 박힘 (b의 감정 12축 → 파동 색·속도·모양)

A: 미니맵에 핑 찍히면서 유령이 "다른곳으로 가봐"라고 해줌. 나머지 연출 (카메라 유도 / 사운드 swell / vignette 등) 고민해봐야할듯. **파동 spot은 박음** — b 자리 동그라미 파동 활성.

> **추가 회의 자리** = 미니맵 핑 외 부가 연출 (카메라 / 사운드 / vignette / 다른 자리)

## 6. 유령 b로 다가감 + 파동 강도 단계

Q: 플레이어가 b 쪽으로 걸어감. 다가감 단계별 가시화?
- 멀리 = 윤곽만 / 안 보임 / **파동 spot 안 보임**
- 중간 = 자세 보임 / 사운드 들림 / **파동 spot 희미**
- 가까이 = 사운드 + 메아리 단어 + 자세 다 보임 / **파동 spot 또렷**
- 반경 임계 (= 거리 기준선) 몇 단계, 각 단계 거리?

A: 그건 알아서 해. *파동 spot 강도도 거리 단계 따라 자동* (멀=숨김, 중=희미, 가=또렷)

## 9. drift 즉시 가시화 (4채널)

Q: 대화 중 분기가 일어남. 발동 조건 + 가시화?
- 발동 = *닮은 정도 점수* 결마다 / 명사 흡수 발생 / 둘 다
  - 닮은 정도 점수 = 플레이어 입력 감정이 그 유령 원본 감정과 얼마나 비슷한지 (0~1).
  - 점수 결 셋: **공명** (≥0.7, 매우 닮음) / **모호** (0.4~0.7, 어중간) / **충돌** (<0.4, 매우 다름)
- **4채널 가시화** (각 결마다):
  - 카메라 펄스 (V2-5 박힘)
  - 사운드 변화 (작가 풀에서 다른 사운드로 swap)
  - 메아리 단어 변화 (작가 풀 swap / 플레이어 입력에서 추출)
  - **파동 변형** — 공명 = 잠깐 밝아짐 / 모호 = 떨림 증가 / 충돌 = 파동 위아래로 요동 + 색 살짝 다름

A:

> **답 박을 자리**:
> - 발동 조건 (점수 결 / 명사 흡수 / 둘 다)
> - 4채널 다 박나? 또는 일부?
> - 메아리 단어 변화 = 작가 풀 swap / 플레이어 입력 추출 / 둘 다?
> - 파동 변형 어휘 OK?

## 14. b 세번째 만남 — 완전 대체

Q: 또 말 걸면 b 발화가 바뀌어 있음 ("아빠 → 엄마 사줬던 아이스크림"). 완전 대체 시점?
- 세번째 = 같은 회차 안 / 다음 회차 (재진입)
- 풀 픽 가중치 = 만남 횟수 3회 시점 흡수 row 100% 픽 / 모티프 사전 채움 결과 대체 / 둘 다 박힘
- 발동 기준 = **만남 횟수만** (3회) / **점수 누적** (한 회차 안 닮은 정도 점수 합계가 어느 선 넘음) / 둘 다

> **풀이**: "점수 누적" = 한 회차 안 매 턴 점수가 *쌓임*. 점수 합계 또는 평균이 어느 *기준선* 넘으면 발동. 단순한 자리 = **만남 횟수만 박음** (3회). 점수 누적은 V2-12 튜닝 자리에 미루는 자리.

A:

## 16. 회차 끝 처리 — 모티프 사전 갱신

Q: 플레이어가 만든 흡수가 메모리에 박힘. 갱신 룰?

> **풀이**:
> - **모티프 사전** = 한 메모리에 박힌 *명사 변환표*. 예: 발자국 메모리 사전 = `{"주체 인물": "아빠"}`. 플레이어가 "엄마" 박으면 → 갱신 = `{"주체 인물": "엄마"}`. 다음 플레이어가 들어올 때 모든 유령 발화에 사전 적용 → "엄마 사줬던 아이스크림".
> - **갱신 시점**:
>   - (가) 흡수 *즉시* — 플레이어가 "엄마" 박은 그 자리에서 사전 갱신
>   - (나) 회차 *끝* — 한 회차 모든 흡수 모아 회차 끝에 한 번 갱신
> - **사전 칸 이름 (key)**: 작가가 박은 *모티프 태그* (`주체 인물`) / 명사구 자체 (`아빠`)
> - **사전 채움 (value)**: 플레이어 입력 그대로 (`엄마`) / 작가 박은 *대안 풀*에서 매칭
> - **모든 흡수 박음** / **임계 통과한 것만** (= 닮은 정도 점수 ≥ 0.5 등 기준선)

> **추천 자리**: 갱신 시점 = **회차 끝**. key = **모티프 태그**. value = **플레이어 입력 그대로**. 임계 = **안 박음** (모든 흡수 박음, 단순 폼).

A:

## 19. 다음 플레이어 (메모리 전체 변화)

Q: 다른 플레이어가 같은 메모리 들어옴. 모티프 사전 적용 룰?

> **풀이**: 모티프 사전 = 16번 풀이 참조. 메모리 단위 명사 변환표.
> - **적용 시점**:
>   - (가) 회차 *시작* — 진입 시점에 모든 유령 발화에 사전 적용해서 *고정*

> - **다른 메모리에도 영향** / **이 메모리만**

> **추천 자리**: 적용 시점 = **회차 시작**. 모든 유령 발화 적용. 이 메모리만 (다른 메모리 영향 X).

## 21. 시연 (영상 + 파일럿)

> **풀이**:
