# 응결점 v2 — 사물 중심 지형 + 조건 응결 침묵 인물 (계획, 260804)

> 상태: **승인됨 → Phase 1·2 구현 + Phase 3 최소 시드 완료 (260804, 같은 날).**
> 채택된 결정: 안전망 없음 / 모티프 매칭+폴백 / 되새김 단독 방아쇠 / 명칭 잠정("아직 유령이
> 되지 못한 사람", 작가 감수 대기). 구현 요지: call_words 는 씬 meta 가 아니라 **응결점 항목에**
> 싣는다 ({x,z,scene_id,trigger:'recall',call_words:[…]}) — 씬 데이터 무수정, admin 점 편집으로 관리.
> 시드: 대표 기억 씬 10(엄마) 1점, 부름말 팬티·레이스 (작가 감수 대기 초안). 알려진 한계:
> 응결은 FP(1인칭) 전용 — 모바일 2D 지도 경로에는 침묵 인물 은닉이 적용되지 않음(후속). 알파 파일럿 2인 반응("사물만 나오다가 사람이 나오고,
> 내가 먼저 말 걸면 대답해주는 게 재밌다")에서 출발한 재편.
> 배경 조사: 침묵 인물의 정체 = 지문 없는 씬의 자유 대화 폴백. 대표 기억에서는 **씬 10(본문 "…",
> ghost_name=엄마)** 단 하나 — 즉 작가가 이미 저작한 침묵이 폴백을 타고 의도대로 동작했다.
> 응결점 시스템(ghost_condensation_points + lumen_scene_ghosts)은 현재 단어 잔상 전용·대표 기억 0개.

## 핵심 문장

**화석(사물을 본다) → 부름(그 단어를 내 말에 담는다) → 응결(그 기억의 사람이 생긴다) → 이름(공명하면 드러난다)**

유령(지문 인물) = 이미 굳은 절단면, 대답하지 않는다 (7-30 형식 불변).
침묵 인물 = 아직 유령이 되지 못한 사람 — 덜 굳어서, 부르면 응답한다. (어휘 확정은 작가 몫)

## Phase 1 — 사물에 앞사람의 말이 배어든다 (반나절, 독립 배포 가능)

**배선**: 회차 시작에 이미 뽑히는 드리프트 픽(ghost_variants)을 사물 열람 창에 연결.
- 매칭: 사물 단어 ↔ ghost_variants.motif_tags 일치 우선, 없으면 회차 픽 1줄 폴백.
- 표시: 열람 발췌 아래 희미한 이탤릭 한 줄 — "…누군가 여기 두고 간 말 — '(앞사람 이어쓰기)'".
- 파일: js/ui/lumen_scene_objects.js (_showClickUI) + play-test 풀 전달.

**플레이 변화**: 사물 발췌는 지금 백 명이 봐도 같은 글 → 앞사람의 문장이 회차마다 다르게 발굴됨.
재방문자는 자기 문장이 화석이 된 걸 본다. 릴레이가 지형만 아니라 말에서도 돈다.

**롤백**: 표시 블록 제거 (독립 커밋).

## Phase 2 — 응결점 v2 코어: 조건이 차면 사람이 응결 (1~2일)

**배선**: 응결점 시스템 승격 재사용.
- 데이터: `ghost_condensation_points` 점에 필드 추가 — `{x, z, scene_id, trigger, threshold?}`.
  scene_id 있는 점 = "사람 응결점" (지문 없는 씬과 묶임). 없는 점 = 기존 단어 잔상 그대로 (하위호환).
- 방아쇠(trigger): `recall` = 되새김 앵커 감지(관객이 그 씬의 모티프/사물 단어를 이어쓰기에 담는 순간).
  기존 오염 임계(pollution) 판정도 뼈대 재사용으로 공존 가능.
- 게이트: **궤적 엔진 AND** — 조건이 차도 accessiblePinIds 에 그 씬이 있어야 응결. 엔진 우회 금지
  (override 예산 원칙). 엔진이 아직이면 "대기" 상태로 두고 매 턴 재검사.
- 응결 연출: 안개 개화(openAt) + 마네킹 서서히 등장 + 미니맵 점 생성 + 되새김 연출과 접속.
- 응결된 핀 = 지문 없는 씬 → 기존 자유 대화 폴백 경로 그대로 (입력창만, 말 걸면 LLM 응답).
- 공명 시 이름: 기존 장치 그대로 (scenes.meta.ghost_name).
- 파일: play-test.html (배선·게이트), lumen_scene_ghosts.js 확장 (스폰 대상 분기).

**플레이 변화**: 지형 초반 = 사물 위주. 관객이 사물을 읽고 그 단어를 자기 문장에 담는 순간,
안개 저쪽에 사람이 생긴다. "내 말이 사람을 불렀다"는 인과를 관객이 스스로 발견.

**롤백**: scene_id 없는 데이터로 되돌리면 기존 단어 잔상 동작 그대로 (데이터 롤백 = 기능 롤백).

## Phase 3 — 작가 저작 (admin + 대표 기억 데이터)

- admin 응결점 편집기 확장: 점 ↔ scene_id 연결 + trigger 선택. ("잔상 유령" UI 재사용,
  admin 사용설명서의 "채우지 말 것" 딱지 갱신)
- 대표 기억 저작 (작가 작업):
  - 침묵 씬 추가 지정 — 현재 씬 10("…") 하나. 씬 10 패턴(본문 침묵 + 지문 없음)이 저작 문법.
  - ghost_name 채우기 — 현재 5/13 (엄마 5씬). 침묵 씬으로 쓸 씬은 이름 필수.
  - 응결점 좌표 찍기 (admin 3D 드래그).

## Phase 4 — 검증 + 알파 지표

- e2e: 열람 → 되새김 발화 → 응결 → 자유 대화 → 공명 이름 → 봉인 (실서버 흔적 주의, 봉인 전까지만).
- 알파 지표 추가: 응결 도달률(회차 중 응결 본 비율), 침묵 인물 대화 진입률, 이름 드러남률.
  다음 설문에 "사람이 나타난 이유를 알 것 같았나" 문항.

## 승인 시 같이 결정해 주세요 (4개)

1. **안전망**: 끝까지 사물 단어를 입에 안 담는 관객은 침묵 인물을 못 만남. 그대로 둘까(추천 —
   "부르지 않은 것"), 최소 보장(사물 N개 열람 시 1 응결)을 깔까?
2. **Phase 1 매칭**: 사물별 모티프 매칭(추천) vs 회차 픽 1줄만.
3. **방아쇠**: 되새김 단독(추천) vs 되새김+오염 임계 병행.
4. **어휘**: "아직 유령이 되지 못한 사람"의 작품 내 명칭 (문서·연출 문구에 쓸 이름).

## 리스크

- LLM 응답 채널이 보상 계층으로 승격됨 — 챗봇화 경계. 침묵 인물의 응답 턴 수는 기존
  maxFreeDialogTurns 상한 그대로 두고, 알파에서 대화 로그로 톤 감수.
- 씬 10 하나로는 응결이 회차당 최대 1회 — 저작(Phase 3)이 실질 볼륨을 정함. 코드가 먼저 가도
  데이터 없으면 체감 없음 → Phase 2·3 은 같은 주에 붙여서.
