## 0. 한 줄

응답 풀 = `ghost_variants` 변주 풀 *그대로*. 작가가 박는 자리는 **변주 자체**지 "응답 풀"이 아니다. `pickResponse` 의 `resonance/vague/dissonance` 3결은 변주 `emotion_vec` 와 본 발화 `emotion_vec` 의 cosine sim 으로 *자동* 분류된다. 작가는 변주만 잘 박으면 된다.

## 1. 차원 정합 — 세 차원이 따로 굴러간다

핸드오프의 "4 유령 × HIGH/MID/LOW = 12 슬롯" 은 코드 시그니처와 안 맞아 정정.

[lumen_ghost_response.js](../js/ui/lumen_ghost_response.js) `pickResponse` 시그니처:
- 결 = `resonance` (alignment ≥ 0.55) / `vague` (≥ 0.35) / `dissonance` (< 0.35) **3결 고정**
- 풀 = 글로벌 (씬·메모리 무관 디폴트) + 메모리 진입 시 오버라이드 가능
- "4종 (Core/Contaminated/Echo/Bridge-deferred)" 차원 = 코드에 *없음*

따라서 작가가 박는 자리는 **세 차원**:

| 차원 | 자리 | 작성 위치 | 분량 (메모리당) |
|---|---|---|---|
| **씬당** | `ghost_intro` / `choice_select` 버튼 / `choice_reply` / `free_dialog_open` | `scenes.meta.dialog_choices` | 씬당 ~10 변주 |
| **메모리당 (유령당)** | `pickResponse` 풀 / `pickUrge` 풀 | `ghost_variants` 변주 + 자동 분류 | 유령당 12~15 변주 |
| **글로벌** | `sceneLinkPrompt` | `lumen_ghost_response.js` `DEFAULTS` | 3결 × 1 = 3 어휘 (디폴트 그대로) |

본 가이드는 **메모리당 차원** (응답 풀 = ghost_variants 변주) 을 메인으로 박는다. 씬당 차원은 §6 부록.

## 2. 응답 풀 = 변주 풀 통합 — 자동 분류 룰

### 2.1 anchor 자리

각 유령은 본 발화 1개 (kind=`drift`, `is_seed=true`, `parent_variant_id=null`) 를 anchor 로 가진다. 이 anchor 의 `emotion_vec` = *유령 정체성의 중심점*.

발자국 메모리:
- 유령 1마리 (slipper child) → 본 발화 = "발자국이 잘 남는 땅이었어. 슬리퍼 자국이 도장처럼 찍힐 때마다 나는 그들의 일원이 됐어..."
- speciation 시드 1마리 (사진 속 여인) → 별도 유령, 별도 anchor

### 2.2 자동 분류 로직

```
변주 emotion_vec 와 본 발화 emotion_vec 의 cosine sim:
  ≥ 0.85    → resonance 결  (본 결과 같이 흐르는 변주)
  0.5~0.85  → vague 결      (흔들림 시작)
  < 0.5     → dissonance 결 (다른 결, near-speciation)
```

- 작가는 변주 박을 때 **결 라벨 의식 X**. emotion_vec 자동 추출 → 자동 분류 → 자동 풀 매핑.
- 자동 분류 결과는 admin UI 에서 *확인* 자리만 (V2-2 admin 도구). 결당 분포 점검용.
- 분류가 작가 의도와 다르면 admin 에서 **수동 override** 가능 (선택 컬럼 — V2-2). default = 자동.

### 2.3 풀 주입 자리

메모리 진입 시:
1. `ghost_variants` 에서 해당 메모리의 본 유령 변주 14개 + speciation 시드 N개 로드
2. 본 발화 emotion_vec 와 cosine sim 으로 결 자동 분류
3. `LumenGhostResponse.setOptions({resonancePool, vaguePool, dissonancePool})` 로 풀 오버라이드
4. `pickResponse` 가 메모리당 풀에서 픽 (글로벌 디폴트 X)

→ **코드 자리 1군데** (`lumen_dialog_phase1.js` start 시점에 setOptions 호출). V2-10 코드 세션 작업 자리.

## 3. 유령 정체성 vs 4종 프리셋 — 차원 분리

핸드오프 표현 "4 유령 (Core/Contaminated/Echo/Bridge-deferred) 별 응답 톤" 은 두 자리를 섞은 말이라 분리한다.

### 3.1 4종 프리셋 = 씬 핀 표시 차원

[유령시스템_확정_v1-260418.md](유령시스템_확정_v1-260418.md) §3 의 4종 (`core` / `bridge` / `echo` / `voidPin`) 은:
- 씬 핀의 **silhouette** (opacity / stroke / tone) 표시 자리
- 화법 결 *hint* (Core = 감각, Contaminated = 확언, Echo = 단편, Bridge = 침묵)

응답 풀 차원 X. ghost_variants 테이블에 "유령 타입" 컬럼 없음.

### 3.2 유령 정체성 = 응답 풀 차원

응답 풀의 진짜 차원:
- **메모리당 N 유령** (`ghost_variants` drift root + speciation roots)
- **유령당 3결** (resonance / vague / dissonance — emotion_vec 자동 분류)
- **결당 4~5 변주**

발자국 = 1 본 유령 + 1 speciation 시드 = **2 유령**. 4 X.

### 3.3 4종 화법 결은 *변주 작성 시 톤 가이드*

작가가 변주 utterance 박을 때 4종 화법 결을 *톤 hint* 로 활용:

| 결 hint | 발화 톤 | 발자국 변주 예시 |
|---|---|---|
| Core (감각) | 짧은 문장. 본 대로. "...그게 무슨 냄새였더라" | drift 1 슬리퍼/곰팡이, drift 13 아스팔트 |
| Contaminated (확언) | 자기 확신. 비뚤어진 단정. "맞아, 그랬지" | drift 12 엄마 유대감 끊김, drift 14 속하지 못함 |
| Echo (단편) | trail-off. "...였나" | drift 7 사진의 주인 |
| Bridge (침묵) | 반언어. "...말 안 하기로 했어" | drift 8 따라가지 못함 (한계 침묵) |

→ 작가가 변주 박을 때 *유령 정체성*이 어떤 결로 흔들리는지 따라 4종 hint 를 결당 1~2 변주씩 섞을 수 있음. 강제 X.

## 4. 톤 손실 최소화 룰 — 단일턴 압축 톤 유지

5-2 단일턴 결정의 *압축 톤*은 멀티턴 가도 유지. 즉 멀티턴 = 단일턴 × 3 이지 *대화체 풀어쓰기 × 3* X.

### 4.1 한 줄 분량

- **50~100자** (한국어 글자 기준)
- 너무 짧으면 (< 30자) = 단편으로 격하 (Echo 결 한정)
- 너무 길면 (> 120자) = 작가 ghostwriter 톤 회귀 자리. 자제.

### 4.2 어조 — 발자국 정합 톤

발자국 작가 결정 = "~했어" 체. *자기 자신에게 또는 옆 사람에게 조용히 말함*. 메모리마다 어조 다를 수 있으나 다음 룰 공통:

- ✅ 1인칭 자기 회상. "...그랬어 / ...였어 / ...했지"
- ✅ 반사적 의문. "...었나? / ...아닌가?"
- ❌ 전달자 화법. "~였대 / ~라고 했어"
- ❌ 시스템 어휘. "기억이 정렬되지 않습니다 / 오염도 75%"

### 4.3 회상 실패자 화법 ([유령시스템_확정_v1:64](유령시스템_확정_v1-260418.md#L64))

핵심 룰. 유령은 *자기 경험을 흐릿하게 기억하려는 자*이지 *남의 이야기를 전달하는 나레이터*가 아님.

- ✅ "...그게 무슨 색이었더라"
- ✅ "...아닌가?"
- ❌ "그건 검은 우산이었습니다"
- ❌ "사용자께서 본 우산은..."

### 4.4 호명 자제

호명 = 유령이 플레이어를 "너" 로 부르는 자리.

- 매 턴 X. 결당 0~1 변주.
- **resonance 결** = 1개 호명 변주 (친밀 자리). "너도 그 자리에 있었어?"
- **vague 결** = 호명 자제 (흔들림 자리는 호명이 어색).
- **dissonance 결** = 1개 호명 변주 (떠남 자리). "너는 다른 비를 봤구나."

호명 변주가 결당 1개 넘으면 작가 ghostwriter 톤 회귀.

### 4.5 시적 압축

- 이미지 1~2개 (감각: 색·소리·냄새·온도·촉감)
- 인용 1개까지 (작은따옴표 또는 직접 인용)
- 추상 어휘 자제 ("자아의 자리가 사라졌어" → "슬리퍼 자국 들어가던 자리가 사라졌어")

발자국 변주 14개가 본 룰 거의 100% 정합 — 작가 톤 시안 자리.

### 4.6 임상 프레이밍 거부

[feedback_avoid_authorial_control_framing] + [docs/유령대화_egostate_차용-260504.md](유령대화_egostate_차용-260504.md) §6.2 정합:

- ❌ "통합되어야 해 / 회복할 수 있어 / 치유의 시작이야"
- ❌ "당신은 분열되어 있습니다"
- ❌ "고착(fixation)을 풀어야 해"
- ✅ "...그랬을 거야 / ...아닌가?"

유령은 *치료자 X*, *임상가 X*. 자기 회상 실패자.

## 5. 결당 변주 분량 + 호명 빈도

### 5.1 분량 룰

- 유령당 = 3결 × 4~5 변주 = **12~15 변주** (본 발화 1 + drift 변주 11~14)
- MVP = 결당 1~2 변주부터 시작 → play-test 풀 사이클 1회 후 보강
- 결당 < 2 변주 시 = 같은 변주 반복 픽 (sampling 보임). 결당 ≥ 3 권장.

발자국 = 본 발화 1 + drift 14 = 15 변주. 분량 정합 ✓.

### 5.2 결당 분포 권장

| 결 | 변주 비중 | 발자국 자리 |
|---|---|---|
| resonance | 4~5 (본 결 따라가는 자리) | drift 1·2·3·5·6 = 5개 (예측) |
| vague | 3~4 (흔들림 시작 자리) | drift 4·7·8 = 3개 (예측) |
| dissonance | 4~5 (단절·소실 자리) | drift 9·10·11·12·13·14 = 6개 (예측) |

분포가 한 결로 쏠리면 (예: resonance 10 / vague 1 / dissonance 1) → 다른 결 보강 필요. 작가 손 시도 후 admin UI 확인 자리.

### 5.3 호명 변주 비중

- 결당 0~1 호명 변주. resonance + dissonance 마지막 자리만.
- 14 변주 중 호명 = 0~2 권장. 발자국 변주 보면 호명 0개 (전부 자기 회상) — *추가 호명 변주 없이* 갈지, 보강할지 결정 자리.

→ **권장**: 발자국 = 호명 0개 유지. 화법 결이 *자기 자신에게 또는 옆 사람에게 조용히* 톤이라 호명 자제가 정합. 다른 메모리에서 화법 결이 *상대를 향한* 톤일 때 호명 변주 보강.

## 8. 결정 기록

### (a) band 라벨 = 자동 분류 default + 수동 override optional

자동: 변주 emotion_vec vs 본 발화 emotion_vec cosine sim → resonance/vague/dissonance.
수동 override: admin UI 라벨 입력 자리 (V2-2 추가 컬럼). default null = 자동.

근거:
- `extractEmotionVec` ([js/admin/emotion_extract_helper.js](../js/admin/emotion_extract_helper.js)) 인프라 이미 박힘
- 메모리 [feedback_avoid_authorial_control_framing] — 작가 통제 자제
- 자동 분류는 일관성 보장, 수동 override 는 의도 명시 필요한 자리만

### (b) 4 유령 차원 = 씬 핀 표시 + 변주 작성 톤 hint 분리

응답 풀 차원 X. 응답 풀 차원 = **유령 정체성 (메모리당 N마리)**.

4종 (Core/Contaminated/Echo/Bridge-deferred) = §3.1 씬 핀 silhouette + §3.3 변주 작성 톤 hint. 두 자리에 *분리* 활용.

### (c) 호명 룰 = 결당 0~1 변주, resonance + dissonance 한정

매 턴 X. 결당 0~1. vague 자제.

근거: 호명이 매 턴이면 작가 ghostwriter 톤 회귀. 결의 *마찰점*에서만 호명. 발자국 = 호명 0개 유지 (자기 회상 톤이라).

### (d) 마무리 어휘 = 글로벌 디폴트 (3결 × 3 변주) + 메모리당 오버라이드 옵션

`pickUrge` 글로벌 풀 ([lumen_ghost_response.js:55-69](../js/ui/lumen_ghost_response.js#L55-L69)) 그대로. 메모리당 강한 톤 오버라이드 = V2-2 admin 옵션 (필수 X).

## 9. 부록 — 발자국 변주 자동 분류 시안 (예측)

발자국 14 drift 변주의 결 분류 *예측*. 실제 분류는 emotion_vec 박힌 후 자동 — 본 표는 *작가 의도 vs 자동 분류 결과 비교 자료*.

| # | 변주 | 결 (예측) | 근거 |
|---|---|---|---|
| 0 | 본 발화 (slipper anchor) | **anchor** | 분류 안 함 (anchor 자리) |
| 1 | drift 1 슬리퍼/곰팡이 | resonance | 본 결 일치 (소속 + 감각) |
| 2 | drift 2 떡집 아줌마 | resonance | 관찰자 + 평온 |
| 3 | drift 3 어둑한 곳 발자국 | resonance | 관찰자 + 약한 호기심 |
| 4 | drift 4 샤넬 구두 | vague | 외지인 진입 = 결 흔들림 시작 |
| 5 | drift 5 똑같은 부츠/받아들여짐 | resonance | 소속감 회복 |
| 6 | drift 6 200원 핫초코 | resonance | 친밀 자리 |
| 7 | drift 7 사진의 주인 | vague | 의문 시작 |
| 8 | drift 8 따라가지 못함 | vague | 한계 자각 |
| 9 | drift 9 노란 장화 발견 | dissonance | 배신 발견 |
| 10 | drift 10 칼로 표식 | dissonance | 자기 손상 |
| 11 | drift 11 사진 뒷면 | dissonance | 배신 확정 |
| 12 | drift 12 엄마 유대감 끊김 | dissonance | 소속 단절 |
| 13 | drift 13 아스팔트 | dissonance | 방법 소실 |
| 14 | drift 14 속하지 못함 | dissonance | 결 정점 |
| 15 | speciation 1 사진 속 여인 | **별도 유령 풀** | 분류 안 함 (다른 anchor) |

**예측 분포**: resonance 5 / vague 3 / dissonance 6 = 14 변주

**점검 자리**:
- vague 3 = 권장 하한 (3~4) 정합 ✓
- dissonance 6 = 권장 상한 근접. 결 후반이 dissonance 정점 자리라 자연 (서사 = 소속→단절 흐름)
- resonance 5 = 정합 ✓

자동 분류 결과가 본 표와 *2건 이상* 어긋나면 = 작가 의도와 emotion_vec 추출 결과 불일치. 보강 또는 수동 override 자리. 1건 이하 어긋남 = 수용.
