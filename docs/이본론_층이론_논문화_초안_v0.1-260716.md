## 0. 한 줄 주장

**기억 변이 연구의 표준 모델(나무)은 원본의 존재를 가정하지만, 층(sheaf) 모델은
원본의 존재를 계산 가능한 성질로 바꾼다. TEM은 이를 실측할 수 있는 유일한 관측
장비이며, TEM의 "오염"은 이 계산의 이름 없는 판본이었다.**

## 1. 비유 사전 (수식 없는 판본 — 세션 7-16 "할머니 이야기")

| 이야기 | 형식 대응 |
|---|---|
| 형제들이 각자 기억하는 할머니 | 국소 절편 (한 play의 감정 궤적) |
| 둘 다 기억하는 순간 (부엌) | 겹침 (공유 씬) |
| "용서 다음" vs "싸움 전" — 이음이 반대 | 전이 제약 충돌 |
| 조각 맞추면 진짜 할머니가 나오나? | 전역 절편 존재 문제 |
| 안 나옴 (이본론) | 관측 데이터와 정합하는 전역 절편 부재 |
| 안 맞는 정도의 총점 | 불일치 에너지 (층 라플라시안) |
| 한 바퀴 돌아오면 뒤틀려 있음 | 모노드로미 (경로 의존성) |

## 2. 형식 정의 (확정분 + 미정 1)

- **바탕 공간 X**: 기억 M의 씬들을 꼭짓점, SceneNavigator가 허용하는 전이를 변으로
  하는 그래프. (Alexandrov/격자 층 세팅 — 계산 가능성 확보.)
- **층 F (cellular sheaf)**: 꼭짓점마다 감정 벡터 공간, 변마다 전이 제약(별이엔진
  shape 정합)을 선형 사상으로 얹은 것.
- **절편 = play**: 한 회차가 실제로 지나간 부분 그래프 위의 감정 배정.
  DB의 plays 데이터가 곧 국소 절편. **절편은 씬 값이 아니라 이음(델타)까지 포함**
  — 값만 얹으면 항상 꿰매져서 이본론이 무의미해지는 함정(7-16 세션 확인).
- **감정 벡터 = 17축** (판단축. VAD는 결과 시각화 전용 — project_vad_17axis_roles
  준수). ⚠️ 미정: 실기여 9축으로 줄일지는 감정축 통일 결정(R4 제안서)과 연동.

## 3. 측정 도구 2개 (라벨 정정 반영 — H¹ 단일 라벨 금지)

1. **불일치 에너지** (sheaf Laplacian quadratic form, Hansen & Ghrist 2019):
   관측된 국소 절편들이 하나의 전역 절편에서 얼마나 떨어져 있는가.
   - = 0 → 원본(정합 전역 서술) 존재. > 0 → 부재 + 그 거리.
   - ⚠️ 문구 주의: "전역 절편이 없다"가 아니라 **"관측 데이터와 정합하는 전역
     절편이 없다"** (0-절편은 항상 존재).
2. **모노드로미** (경로 의존성): 겹침 사슬을 따라 한 바퀴 돌았을 때의 뒤틀림.
   "같은 씬에 다른 역사로 도착하면 물듦이 다르다" = TEM 오염 정의와 직결.
   쌍별 비교로는 원리적으로 검출 불가 → 층 기계의 존재 이유.

## 4. 반증 가능한 주장 3개

- **C1 (존재)**: TEM plays 데이터의 불일치 에너지 > 0이고, 무작위 궤적 대비
  구조적이다 (셔플 대조군으로 검정).
- **C2 (비환원성)**: 이웃 쌍이 전부 정합인데 고리에서 뒤틀리는 사례가 실재한다
  — 쌍별 거리 행렬로는 재구성 불가한 신호. **← 논문 생사 조건.**
- **C3 (대응)**: 모노드로미 크기가 ContaminationTracker의 축별 오염
  (divergence/heterogeneity)과 상관한다. ⚠️ 순환성 주의: 오염도 같은 궤적에서
  계산되므로, 주장은 "예측"이 아니라 "동일 현상의 두 형식화"로 서술.

## 7. 갭 서술 (서론의 척추)

사본학(stemmatics)의 나무 모델은 원본(archetype)을 **전제**하고 복원한다 —
"원본이 있는가"는 물을 수 없는 질문이다. 층 모델은 이 존재를 **계산 결과**로
바꾼다(에너지 = 0 ⇔ 존재). 이본론("변이는 열화가 아니라 존재 방식")의 수학적
의미론 = "불일치 에너지 > 0이 기본 상태인 대상". 한국 문헌학의 이본 연구
전통과 접속하면 수학↔문헌학 다리가 독창성 축이 됨.

### 11.3 겹침 그래프 (nerve) N

- 노드 = 회차 39개.
- 변 (p,q): |dom(p) ∩ dom(q)| ≥ m. **m=2 기본**, m=3 민감도 분석.
- 변 가중치 w_pq = |겹침 씬 수|.

### 11.4 불일치 코체인과 쌍별 정합 게이트

각 변 (p,q), 겹침 씬 s 에 대해:
- 차이 d_pq(s) = σ_p(s) − σ_q(s) ∈ R^17
- **오프셋** g_pq = mean_s d_pq(s)  (방향 규약: g_qp = −g_pq)
- **쌍별 잔차** r_pq = sqrt( mean_s ‖d_pq(s) − g_pq‖² )
  — "두 회차는 상수 이동 하나로 서로 번역된다"는 가설의 잔차.
- **정합 쌍 게이트**: r_pq ≤ τ 인 변만 "정합". τ = 전체 r 의 중앙값(기본),
  P25/P75 로 민감도 곡선 보고.

### 11.5 홀로노미 분해 (고리 열거 없이 전 고리 일괄 처리)

- 최소제곱: h* = argmin_h Σ_(p,q)∈E w_pq ‖g_pq − (h_p − h_q)‖²
  → 그래프 라플라시안 선형계 L h = δᵀ(w·g). 축별로 독립 분해되므로 17개의
  스칼라 문제(가우스 소거나 켤레기울기, 39×39 — 자명한 규모).
- **핵심 통계량 (순환 성분 비율)**:
  ρ = Σ w ‖g − δh*‖² / Σ w ‖g‖²  ∈ [0,1]
  해석: 회차별 재보정(h)으로 설명 안 되는 — 쌍별 방법으로 환원 불가능한 —
  불일치의 비율. **ρ 가 C2 의 숫자다.**

### 11.6 전시용 고리 (Exhibit A) — v1.1 기준 교체

- 스패닝 트리 → 기본 고리(fundamental cycles) 열거.
- 고리 C 의 뒤틀림 W(C) = Σ (방향 맞춘) g.
- **영모형 유도 임계 (v1.1)**: N2 재표집(§11.7) 각 회차에서 동일 파이프라인으로
  기본 고리들의 ‖W‖ 를 수집, **고리 길이(변 수)별** 분포를 만든다.
  임계 T(ℓ) = 길이 ℓ 고리의 N2 ‖W‖ 분포 P99.
- **Exhibit A 조건**: C 의 모든 변이 정합(≤τ) AND ‖W(C)‖ > T(|C|).
  → "원본이 존재하는 세계에서는 100번 중 99번 안 나오는 크기의 뒤틀림."
  임의 상수 아님 — 대조군에서 유도. 논문 그림 1 감.
- (v1 의 "≥ 3×Σr" 규칙은 폐기 — 1차 실행에서 데이터 규모상 원리적 도달 불가 판명.)

### 11.7 영모형 (각 1,000회 재표집, p-값 = null ρ ≥ 관측 ρ 비율) — v1.1 확장

- **N1 씬 셔플**: 각 회차 안에서 씬 라벨만 무작위 치환(값 집합 보존, 정렬 파괴).
- **N2 전역절편+보정 합성**: σ̃_p(s) = f(s) + h_p + ε. f = 씬별 평균,
  h_p = 회차별 평균 오프셋, ε = **축별** 관측 잔차 분산에 맞춘 iid 잡음
  (v1 실행의 구현 결정을 명세로 승격). 구성상 뒤틀림 0 인 세계 — **주 대조군.**
- **N3 잔차 부트스트랩 (v1.1 신설, 선택)**: N2 와 같되 ε 를 합성하지 않고
  **관측 잔차 벡터(씬별 σ_p(s) − f(s) − h_p)에서 통째로 재표집** — 감정 분포의
  합=1 제약이 만드는 축 간 상관을 보존하는 대조군. N2 와 p-값이 크게 갈리면
  N3 를 우선 신뢰하고 그 사실을 보고.

### 11.8 판정 기준 + 한계 고지
