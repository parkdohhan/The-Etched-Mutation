## 1. 입력 형식 — 스펙 JSON (`author-spec-v1`)

`Tem - gwonyeok/설계/권역_기억_스펙-260915.json`. 자동화 도구 4종의 공통 입력.

```
memory  : code · title · lang · status · is_public · description · completed_sentence · memory_words
          sensory_anchor{modality,content,weight} · original_vector · cont{…} · terrain_shape
          meta{motif_tags · rep_anchors · door_pos · persona_context}
scenes[]: order · code(A~Q) · role(anchor|residual) · text · text_stage_1 · echo_words · anchor_emotions
          original_emotion · motif_tags · object_tags · object_lines? · symbol_object? · ghost_name?
          ghost_intro?[] · void_info? · exclusions? · sound{prompt|url, volume, radius} · stage_position{x,z}
objects : { 단어: { file, prompt } | { alias_of } }     ← Tripo 프롬프트 (작가 원칙: 만질 수 있는 단어만)
drift_pool[]: { utterance, motif_tags }                 ← 유령 재료 (화자 목소리)
```

## 3. 저작 결정 (권역)

- **구조**: 척추 = 세제가 떨어진 날의 걷기 7씬(반지하 문 → 둥근 자국 → 골목 → 갈림길 → 노란 띠 → 슈퍼 → 호랭이). 갈비뼈 = 정류장·교문(그 애) / 공사장 / 툇마루·신발을 벗다·뒤꿈치·청라·도망(도원) / 거짓말과 칼 / **[침묵] 내 발자국**.
- **침묵 씬**(scene 13): 화자가 한 번도 본 적 없는 자기 발자국 = 본문 "…", `void_info{sceneVoid,reasonVoid,voidLevel:high}` → 지형 함몰. 대표 기억의 "검사" 씬과 같은 자리.
- **잠긴 씬**(scene 16, 칼): `exclusions=[{emotion_threshold guilt ≥ 0.4}]` — 관객 감정이 죄책감에 닿기 전엔 열리지 않음.
- **유령 몸(symbol_object)**: 화자 = 둥근 자국, 도원 = 안전화, 마지막 = 호랭이, 프롤로그(scene 1) = 자연퐁 1.5배(유령 없음, §10.1 규칙).
- **유령 이름**: 도원 장면만 "도원"(접촉 시 드러남). 그 애 장면은 이름 없음(소설에서 이름이 확인되지 않는 인물).
- **감각 앵커**: sound · "탁. 탁. 탁." · 0.85 (결말 + 발전소 박자 + 도원의 손 신호).
- **완성 문장**: "너 혹시," (후보: "뒤꿈치가 없더라." / "탁. 탁. 탁.").
- **오염 초기**: cont_depth 0 (A안 — 관객이 썩게 한다). text_stage_1 은 17씬 전부 작가판(편향=구체화·형용사 증가, 20~40%).
- **좌표**(x,z; 반경 6.1~53): 척추가 (-24,20)→(38,-36) 사선. 갈비뼈는 관련 척추 근처(집=왼쪽, 공사장=오른쪽 위, 청라=반대편 (10,44)). 침묵 구덩이 (-34,38)·칼 (-20,40)은 척추 뒤편. 출구문 (-32,30) = 반지하 문 옆.
- **소리 반경**: 선형 감쇠(반경/4 안 최대, 반경에서 0). 호랭이 씬만 r20·v0.9. 침묵 씬은 `sounds/amb_wind.mp3`.
