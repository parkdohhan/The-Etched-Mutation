# 아이디어: 탐지기 UI (Memory Detector)

> 2026-04-16 기록. 실행 보류 — Phase 4 이후 또는 플레이테스트 피드백 시 재검토.

## 컨셉

- 플레이어 = 기억을 찾으러 온 탐험자 → 손에 **탐지기 디바이스**를 쥐어줌
- 지도 위의 장면 핀을 없애고, 탐지기 안에 **미니맵**을 넣어 핀을 표시
- 플레이어가 직접 돌아다니며 탐지기로 장면을 찾아감
- 장면에 가까워질수록 소리가 커지는 기존 spatial sound 시스템과 자연스럽게 결합
- 정확한 위치에서 탐지기를 **발동**하면 장면이 열림

## 궤적 연동

- 궤적이 바뀌면 탐지기에 새로운 핀이 나타나고/사라짐
- 또다른나가 알림: "다른 게 탐지됐어", "저쪽에 다른 기억이 있어"
- accessiblePinIds 변화를 탐지기 반응으로 표현

## 왜 지금은 안 하는가

1. **구현 비용**: 탐지기 UI 오브젝트, 미니맵 렌더링, 발동 인터랙션, 알림 시스템, 모바일 대응 — 최소 4~5개 새 컴포넌트
2. **기존 시스템 충돌**: terrain bar, strata view, pin 접근 규칙이 전부 "핀을 직접 누른다"를 전제로 설계됨
3. **플레이테스트 미완**: 현재 핀 시스템으로 충분히 테스트를 돌린 뒤 "핀이 너무 노골적이다" 피드백이 실제로 나왔을 때 꺼내야 함
4. **우선순위**: Phase 2b (공간 음향) → Phase 3 (페르소나 시뮬) → Phase 4 (레거시 정리) 이후 검토

## 재검토 트리거

- 플레이테스트에서 "어디로 가야 할지 너무 뻔하다" 또는 "핀이 노골적이다" 피드백
- strata 3D 뷰가 안정화된 후 미니맵 파생이 가능해질 때
