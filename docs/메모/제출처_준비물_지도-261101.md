# 제출처·준비물 지도 (2026-11-01 조사, 11-05 기록)

> 질문: "내 연구와 프로젝트에 가장 잘 맞는 제출처가 어딜까, 뭘 준비해야 할까." 2027년 공모들은 11-01 기준 미공개 → 2025·2026 패턴으로 날짜 추정. 8-04 조사(메모리 project_submission_targets)·ICIDS 2026 LBW 거절 사유(10-07)·수학 친구 숙제(10-30~11-01)를 합친 것.

## 2. 준비물 다섯 — 심사자와 수학 친구가 같은 것을 요구

1. **사람 데이터 30명.** 2026 논문은 AI 페르소나 15명("같은 모델 역할극 = 비독립 표본"). 동일 작품, 온라인 수집 가능.
2. **동의서·철회·익명 처리 문서.** 심사자: "심의 없음을 인정했으면서 동의 절차를 안 썼다." 알파 설문 동의는 있었으나 논문 미기재. 사람 수집 전에 먼저.
3. **떼어내기 비교 표 한 장.** 심사자 "제목은 궤적인데 잰 건 순간" = 친구 "공통 17축 그래프 vs 기억별 자+통역 층 나란히". (가) 순간 점수 (나) 궤적 (다) 기억별 자+통역 — 세 줄 표. 11-01 끌개 지도·11-05 연결 그물이 재료.
4. **작품 내용 서술 + 그림.** 13씬이 뭔지·작가 감정·플레이어가 안에서 뭘 하는지 — 2026 논문에 0줄(3인 공통 최대 결함). 만화 1권 식으로.
5. **기록 영상.** Prix Ars 1차용. 작품 동결 후 촬영·편집.

## 4. 진로와의 관계 (11-05 대화 요지)

프로젝트 수준은 대학원 연구 제안서급으로 올라갔으나 **문은 신분(학점·학위·비자)으로 열린다.** NYU IMA 편입(2027 가을, 3-15)은 천장이 아니라 열쇠 — 재학이 MIT 방문학생 자격이 됨. 수준이 그대로 통하는 문은 논문·전시·상뿐. 지원서 프레임 = "연구하는 예술가"(ρ 같은 숫자 빼고 "사람 37명이 내 소설을 다시 엮었고 그 모양을 쟀다"). 한 문장 후보: **"관객의 발걸음이 건물을 짓는 이머시브 시어터 — 그리고 그 건물의 모양을 잴 수 있다."** "수학적으로 엄밀한"은 아직 아니고 "수학적으로 잴 수 있는"까지.
