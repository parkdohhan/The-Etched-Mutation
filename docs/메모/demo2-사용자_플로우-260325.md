# Demo2 사용자 플로우 (SSOT: `test/demo2.html`)

## 목적

`demo2.html`은 **데모 진입(오프닝/독백) → 기억 선택 → 플레이**로 이어지는 단축 루트다.  
이 문서는 Demo2 기준으로 실제 라우팅과 사용자 흐름을 코드 기준으로 고정한다.

---

## 플로우 한 장 요약

- **`test/demo2.html`**
  - 오프닝(Opening) → 독백(Monologue) 화면
  - Supabase에서 `memories`를 가져와 “떠다니는 문장”으로 표시
  - 문장 클릭 시 선택된 `memoryId`로 `play-test.html?memory=...` (로컬) 또는 `/play?memory=...` (배포)로 이동
- **`play-test.html`**
  - 지도(Map) 모드에서 핀을 클릭해 장면(Scene) 모드로 들어감
  - 사용자 입력을 제출하면 정렬도/패턴 결과에 따라 다음 접근 가능한 핀들이 갱신됨
  - 마지막에 Reveal 화면을 거쳐 Continue로 Strata(3D)까지 이동 가능

---

## 1) Demo2 진입 시 실행 (부트)

`DOMContentLoaded` 시점에 아래 순서로 시작한다.

- `getDemo2Memories()`를 **미리 호출**해 메모리 목록을 선-fetch
- `startOpening()`으로 오프닝 화면 시작

데이터 소스 우선순위:

1. Supabase REST: `memories?select=id,completed_sentence,title,code`
2. 실패 시 `data/memories.js` (`window.memoriesData`)
3. 그래도 없으면 최소 하드코딩 목록

---

## 2) Opening → Monologue

오프닝 화면에서 사용자 입력(클릭/키 등)을 받으면 Monologue로 전환된다(오프닝 연출 로직은 UI/사운드 중심).

Monologue 단계에서:

- `MONOLOGUES`를 화면에 배치하고(`demo2LayoutPositions(n)`),
- 각 문장 DOM(`.mono-word`)이 부유 애니메이션을 갖는다.

---

## 3) Monologue에서 기억 선택 → play로 이동

사용자가 떠다니는 문장을 클릭하면:

- 선택된 항목에서 `memoryId`를 얻고
- 언어를 `demo2DetectLang(m)`로 추정해 `lang=ko|en`을 붙이며
- `demo2PlayHref(memoryId, lang)`로 목적지 URL을 만든 뒤 `window.location.href`로 이동한다.

### 목적지 URL 규칙 (로컬 vs 배포)

`demo2PlayHref(memoryId, lang)`의 결과:

- **배포(= Vercel rewrite 존재)**: `/play?memory=<id>&lang=<ko|en>`
- **로컬 개발(= rewrite 없음)**: `play-test.html?memory=<id>&lang=<ko|en>`
  - `test/` 경로에서 실행 중이면 `../play-test.html?...`로 상대경로 보정

추가로 디버깅 편의용:

- 클릭 직전 `sessionStorage.setItem('demoMemoryId', m.id)`를 시도한다.

## 4) play-test에서의 사용자 플로우 (Demo2 관점)

Demo2는 play-test 진입까지만 책임지고, 그 이후는 `play-test.html`의 런타임 플로우를 따른다.

핵심 단계:

- **Map 모드**: 지도(등고선) + 핀들이 보임
- **핀 클릭**: 잠금이 아닌 pin만 `enterSceneMode(pin)`로 Scene 모드 진입
- **Scene 모드**: 사용자 감정/이유 입력 → 제출
- **결과 반영**:
  - 결과에서 전이 패턴(`transition_pattern`)을 결정(없으면 `getTransitionPattern(bucket, mismatch)`로 추론)
  - `updateAccess(pattern, emotionPosition, originSceneId)`가 `accessiblePinIds`를 갱신
  - `finalizePinAccess()` → `renderPins()`로 다음에 열리는 입구(entrance)가 지도에 표시됨
- **Reveal**: 특정 조건에서 Reveal 화면이 뜨고 Continue로 다음 단계 이동 가능

지도 핀 접근 규칙(잠금/해제) 상세는 별도 문서:

- `docs/play-test-지도_핀_접근규칙-260325.md`

---

## 5) Strata(3D)로 이어지는 경로

Reveal 이후(또는 디버그 콘솔)에서 memoryId를 유지한 채 Strata 뷰로 이동한다.

- Strata는 `index.html?strata=1&memory=<id>` 형태로 진입(프로젝트의 Strata 런타임이 처리)
- play-test에는 콘솔 점프 유틸이 존재한다.
  - `window.temGoStrata(memoryId)` (memoryId를 넘기면 바로 Strata로 이동)

## 콘솔 디버그( Demo2 )

`test/demo2.html`은 콘솔 헬퍼를 제공한다.

- `__demo2Debug.help()` : 사용법 출력
- `__demo2Debug.memories()` : 현재 기억 목록과 이동 URL 테이블 출력
- `__demo2Debug.go("e001")` 또는 `__demo2Debug.go("E-001")` : 해당 memory로 이동
