   "다음 사람의 메아리로 흘러갈 거야" 안내까지. 형식의 핵심 약속이 관객 시점에서 검증됨.

3. **사물 GLB** — 팬티·지갑·눈·가면(?)이 지형 위에서 실물로 읽힘. 어두운 침식 지대와 대비 좋음.
4. **대화 UI** — 절단점·연결사 8종 드롭다운·이어쓰기 입력·SKIP→나가기 전환 모두 정상.
