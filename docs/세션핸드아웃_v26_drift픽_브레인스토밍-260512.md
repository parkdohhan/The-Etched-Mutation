## 1. V2-6가 *무엇을* 결정하는 자리인가 (한국어 풀이)

### 1-1. 그림으로 풀어서

도한 님이 한 메모리 안에 들어가서 유령이랑 멀티턴(3턴) 대화를 함. 한 턴마다 도한 님 답변에서 12축 감정 점수(슬픔 0.7, 분노 0.2, 그리움 0.4 …)가 자동 추출됨. 세 턴 끝나면 도한 님 회차의 *감정 결*이 12축 벡터 한 줄로 박힘.

이제 그 메모리에 작가가 박아둔 발화 변주가 풀에 N개(예: 12개) 박혀있어요. 변주마다 자기 자신의 12축 감정 벡터를 갖고 있음 (작가가 박을 때 자동 추출됨, W2S3 자리). V2-6이 결정하는 자리 = **도한 님 회차의 감정 결과 가장 잘 어울리는 변주를 골라 유령 입에 박는 자리**.

근데 "가장 잘 어울리는 1개"를 결정성(=argmax)으로 박으면 → 같은 사람이 두 번째 들어가도 같은 변주 박힘 → V2-13 영상 컷이 비어 보임. 그래서 **확률 가중 sampling**을 쓰는 자리. 가까운 변주가 *확률 더 높게* 박히지만, 가끔 두 번째로 가까운 변주도 박힘.

### 1-2. 두 단계인 이유

```
변주 풀 전체 (12개)
   │
   │ Step 1: 글로벌 좁힘 — 메모리에 누적된 감정 방향(=다른 사람들이 평소 박은 결)에
   │         가까운 변주 N=8개로 좁힘
   ▼
활성 풀 (8개)
   │
   │ Step 2: 회차 변위 픽 — 도한 님 *이번 회차*의 변위 벡터에
   │         softmax(temperature=0.5) 가중 확률로 sampling
   ▼
박힌 변주 1개
```

**Step 1만 있으면** → 누적 평균에 가까운 변주만 박힘 = 다 비슷한 결만 박힘 (drift 못 박음).
**Step 2만 있으면** → 회차 변위가 작을 때(=평이한 회차) 풀 전체에서 너무 random.
→ 두 단계 합치면 "**평소 결을 유지하면서도 본 회차 결을 반영**"한 픽이 박힘.

### 1-3. 도장(=DB 기록)

회차 끝 시점에 `plays` 테이블 한 행에 **두 자리** 박음:
- `ghost_variant_id` = 박힌 변주의 ID
- `final_drift_vector` = 본 회차 12축 변위 벡터

박은 후엔 **재현 시 sampling 다시 안 돌림** — 도장 그대로 읽음. (디버깅·작가 손 검증 시 결과 안정성)
