**수리한 것**: 첫 플레이 오염 기준선(`_autoCreateFirstPlay` → `updateMemoryContamination`)이 anon 의 memories UPDATE RLS(42501)에 막혀 cont_depth 0 으로 남음 — 옛 흐름부터 있던 소음. record-seal 이 `contamination` 기준선을 service_role 로 함께 쓰고, 클라이언트는 `skipContamination` 으로 그 갱신을 건너뛴다 (테스트 기억 4TPWE 는 수리 전이라 cont_depth 0).
**무관한 소음**: 무대에서 `record-contact` 409 (30분 중복 판정) — 플레이 경로의 기존 동작.
