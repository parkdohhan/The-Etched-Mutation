## A. 입장 계약 카드 (신규 — play-test.html `_showEntryContract`)

눈뜨기 인트로 전, 검은 화면 위 4줄이 순차 등장 + **클릭해야 입장**:

> 이곳은 한 사람의 기억입니다. /
> 당신이 지나갈 때마다, 기억은 당신 쪽으로 조금씩 물듭니다. /
> 흐릿한 사람들에게 다가가세요. 끊긴 문장을 건네면, 당신의 말로 이어 주세요. /
> 충분히 만난 뒤에야, 나가는 문이 열립니다.

- 한 카드로 프레임(기억) + 할 일(만나서 이어쓰기) + 종료 조건(문 관문 예고) 셋을 계약.
- 재진입자(tem_lumen_visited_memories)는 생략. 클릭이 브라우저 오디오 잠금도 푼다.
- **문구는 작가 감수 대기 초안.**

## B. 조작 힌트 2단 (기존 1개 확장)

1. `[화면을 클릭한 뒤 — 마우스로 둘러보고, W·A·S·D 또는 방향키로 걷습니다]` (5초)
2. `[흐릿한 사람 곁에 가서, 겨눈 채 길게 누르면 이야기가 시작됩니다]` (6초)

이후는 기존 근접 힌트("길게 눌러 이 장면에 들어가세요")가 받는다.

## C. 연결사 "직접 입력…" (lumen_dialog_phase1.js `_renderContInput`)

- 8종 뒤 9번째 선택지 `직접 입력…` — 고르면 작은 이음말 칸이 열리고 자기 연결사를 쓴다.
- 형식 판단: era이론 §3 의 핵심은 "결핍을 어느 방향으로 채울지의 **선언**"이지 8종 목록이 아님 — 선언 행위는 보존, 목록 감옥만 해제. 분류기는 어차피 `연결사+이어쓴 문장` 전문을 받으므로 하위 배선 불변.
- 빈 채 제출 시 안내: "이음말을 먼저 적어 주세요."
- 롤백: git revert (독립 커밋).

## C-2. 재진입 자동 스킵 — 사용자 의도 확인 후 완전 철거 (⚠️ 교훈)

- 경위: 구 5-08 재진입 스킵 코드는 `game` ReferenceError 로 무동작 상태였고, Claude 가
  이를 "결함"으로 판단해 한때 수리·배포했다 → **사용자 정정: 재방문 스킵은 의도적으로 없앤
  기능** → 같은 날 완전 철거 (자동 스킵 + 방문 기록 저장 삭제, any-key 수동 스킵만 유지).
- 현행: **재방문자도 의례(인트로)와 계약 카드를 다시 밟는다.** 카드는 클릭 즉시 통과 가능이라
  재방문 비용은 한 클릭.
- 교훈: 죽은 것처럼 보이는 코드 = 고장이라고 단정하지 말 것. 되살리기 전에 의도 확인.

## D. 조치 없음 / 보류 (근거 부족 or 작가 결정 대기)

- **사물 재열람**: 이미 가능 — 같은 사물을 다시 길게 누르면 재열람되고, 미니맵 금점(260802 배포)이 위치 재발견을 담당. 테스터 불만의 본질이 "재열람 불가"가 아니라 "재열람 가능함을 모름"이면 B 계열 힌트로 흡수 — 다음 파일럿에서 재발하면 ESC 메뉴에 "지나온 기록" 목록 검토.
- **등장 전조** (할머니·유령 급등장): 안개 회랑·자막이 이미 전조 역할 — 그런데도 급작스럽다는 게 2인 공통. 씬 연출 층이라 작가 감수와 같이 다룰 것.
- **이미지 명확도**: "이미지"가 사물 GLB 인지 전반 렌더인지 특정 불가 — 다음 테스터에게 물을 것.
- **연결사 전면 개편**(개수 확대·씬별 맞춤): C 로 숨통 트고 데이터 본 뒤.
