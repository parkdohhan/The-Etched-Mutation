## 1. 파동(Wave) 계열 — 4종

### 1.1 라이브 감정 파동 (Live Emotion Wave)
- 정의: 사용자 실시간 감정 분석 결과 시각화
- 계산: `computeWaveFromEmotion()` — amplitude = intensity, frequency = 0.01 + complexity*0.005
- 위치: `js/index.js`, `js/app/live.js`, `js/app/recordChat.js`
- 용도: 라이브 세션, 고백 모드, 비교 뷰

### 1.2 아카이브 파동 (Archive Wave)
- 정의: 회상 중 감정 궤적을 사후 저장하는 파형
- 계산: `computeArchiveWaveData()` — wave point 배열 생성, width는 텍스트 길이 의존
- 저장: `plays.wave_data`
- 비교 뷰에서 **사용자 파동만** 표시 (원본 숨김)

### 1.3 Admin 파동 (Admin Preview Wave)
- 정의: 관리자 대시보드 기억 감정 미리보기
- 계산: `computeWaveData()` (admin.js) — 감정별 파동 **합산** (아카이브/라이브와 다름)
- 플레이에 영향 없음, 시각화 전용

### 1.4 Strata 파동 (Strata 3D Wave)
- 정의: 3D 지형 표면의 물결/색상 맥동
- 파형 아님 (지형 움직임)
- 파일: `js/ui/strataView.js`, `js/shared/tem_af_strata_terrain.js`
- cont_stage와 연동

## 2. 잔상(Afterimage) 계열

### 2.1 관객 발화 잔상 (Utterances Afterimage)
- 이전 관객 짧은 발화(≤280자)를 다음 관객이 "자신 말처럼" 목격
- 테이블: `utterances`, `afterimage_events`
- 매칭: 키워드×3 + 감정태그×2 + 축거리×1, 상위5 중 랜덤1
- 본인 30% / 타인 70%
- 씬 종료 후 50% 확률, 플레이당 최대 2회
- 파일: `js/lib/afterimage.js`, Edge Function `match-afterimage` (예정)
- 문서: `docs/잔상_시스템_설계-260409.md`

### 2.2 부유 앵커 (Floating Anchor)
- 장면의 `anchor_images` + `echo_words` 실시간 UI
- 타입: text / ascii / photo, vividness 0~1
- 파일: `js/ui/floatingAnchor.js`

### 2.3 Echo Words
- 작가가 장면에 사전 설정한 키워드 배열
- 저장: `scenes.echo_words`
- 부유 앵커로 떠오르는 재료

## 3. 핀/마커 계열

### 3.1 Core Pin
- 일반 기억 장면, `pin.type='core'`
- 상태: active / locked / visited / entrance

### 3.2 Bridge Pin
- `scene.scene_role='residual'` + `pin.type='bridge'`
- ⚠️ "trajectory bridge" (데이터 구조) 와 다름

### 3.3 Void Pin
- void 장면 표시, 고정 좌표
- 접근 조건: avoidance / contradiction 패턴

### 3.4 Echo Pin
- 최근 plays 흔적 시각 데코, **항상 locked** (클릭 불가)
- ⚠️ "echo words", "afterimage" 와 다름

## 4. 브릿지 계열 — 4가지

### 4.1 Author Bridge (작가 브릿지)
- 작가 수동 작성 해석 단서
- `scenes.author_bridges: [{id, text, reveal_hint}]`
- 시각: 회색 `[🔗 motif]`

### 4.2 Trajectory Bridge (궤적 브릿지)
- 공명 도달자 궤적 자동 변환 → 다음 플레이어 노출
- 별도 테이블 `trajectory_bridges`
- 자동 승인 (별도 절차 없음)
- 시각: 푸른빛 `[🌊 entry_emotion]`

### 4.3 Bridge Pin
- [3.2 참조] — 씬 역할 분류

### 4.4 모티프 점선 Edge
- `motif_tags` 기반 선택적 경로 연결
- 전역 흐름 뷰에서 감정 필터 시 표시

## 5. 감정 표현 계열

### 5.1 Original Emotion
- 기록자 입력 17차원 벡터
- `scenes.original_emotion`
- 불변

### 5.2 User Emotion
- 현 플레이어 실시간 감정 벡터
- `plays.user_emotion` (마지막값) / `emotion_evolution` (수열)

### 5.3 Emotion Distribution vs Emotion Vector
- **Distribution**: 응답자별 집계 (상대값) — admin 용도
- **Vector**: 개인 절대값
- 형식 같지만 응답 대상 다름

### 5.4 Entry Emotion
- 작품 단위 감정→시작씬 매핑
- `works.emotion_entries: {longing: "s-letter-A", ...}`

### 5.5 Anchor Emotions
- 장면별 정렬도 계산용 감정 차원 **필터**
- `scenes.anchor_emotions: ["fear","sadness",...]`
- 없으면 DEFAULT_EMOTION_ANCHORS (17개)
- ⚠️ Anchor Images와 완전 다름

## 6. 좌표계 — 2종

### 6.1 VAD (3차원 감정)
- Valence: 부정↔긍정
- Arousal: 저진정↔고진정
- Dominance: 무력↔우월
- 용도: 수학/시각화 기본 (지도 핀, 지형 투영)

### 6.2 AF 좌표 (2차원 해석)
- Attribution: 자기탓↔남의탓/운명
- Core Fear: 핵심 두려움 축
- V3에서 폐기, V4는 궤적으로 대체
- 현재: Strata 3D 투영, 오염 방향

## 7. 오염 계열 — 3가지 차원

### 7.1 2축 MVP — Drift & Fixation
- **cont_drift**: 원본에서 틀어진 정도 (0~1), EMA α=0.10
- **cont_fixation**: 특정 해석으로 굳어진 정도 (0~1)
- Stage 판정:
  - drift > fixation → Stage 1 "biased_inclination"
  - fixation > drift → Stage 3 "hypercompletion"
  - 평형 → Stage 0 "stable"
- 파일: `js/core/ContaminationTracker.js`
- 문서: `docs/Contamination_MVP_Spec_v3-260327.md`

### 7.2 3축 V2 — Divergence / Convergence / Heterogeneity
- **cont_divergence**: 원본 누적 거리 (분자시계 포화)
- **cont_convergence**: 반복 고정렬 과잉 수렴 (depth≥3부터)
- **cont_heterogeneity**: 해석 간 정렬도 분산 (Welford)
- Stage 혼합:
  - stage_1 = divergence × (1-convergence)
  - stage_2 = heterogeneity × min(depth/5, 1)
  - stage_3 = convergence × (1-heterogeneity)
- 문서: `docs/오염벡터_계산_구현_명세_v2-260327.md`

### 7.3 Stage 라벨 (연출용)
- Stage 0: stable
- Stage 1: biased_inclination (편향적 기울어짐, 수정 가능)
- Stage 3: hypercompletion (과잉 완결, 병리적)

## 8. 정렬도 계열

### 8.1 Alignment (V4 공식)
```
alignment = level × shape × void_mod
```

- **level**: scene_score(감정 코사인) 평균
- **shape**: 감정 변화 방향 유사도 (TIES 이론), 장면≥3일 때만
- **void_mod**: VOID 페널티 (플레이어 VOID & 기록자 입력 → ×0.7)

### 8.2 Bucket
- ≥0.55 HIGH / 0.35~0.55 MID / <0.35 LOW
- 마지막 3회 감정 동일 → FIXATED (우선)

### 8.3 변천
- V3: 감정(0.4) + 이유(0.4) + 태도(0.2)
- V4: 이유는 궤적으로 암시 → level × shape × void_mod

## 9. 궤적/전이 계열

### 9.1 Trajectory (궤적)
- 장면 방문 시간적 감정 수열
- 작가 의도 순서와 다를 수 있음 (비선형)

### 9.2 Transition Pattern — 6종 (별이엔진 V4)
| 패턴 | 설명 | radius |
|---|---|---|
| echo_follow | 기록자 따라감 (0.7+0.3) | 0.42 |
| bridge | 균형 탐색 (0.5+0.5) | 0.62 |
| contradiction | 반대 방향 (0.3-0.5+0.2) | 0.36 |
| displacement | 감정 유지, 귀인 이동 (0.4+0.6) | 0.48 |
| avoidance | 공백 영역 회피 (0.2+0.2+0.6) | 0.24 |
| fixation | 현 장면 고착 (0.1+0+0.9) | 0.09 |

파일: `js/core/SceneNavigator.js` `PATTERN_CENTER`

### 9.3 Mismatch Type

## 12. 특수 개념

### VOID
- level: high(진폭 0.15) / low(0.25)
- 감정 입력 회피 = 의미 있는 해석
- void_mod: 플레이어 VOID & 기록자 입력 → ×0.7

### Fixation Level
- 세션 내 마지막 3회 감정 동일 → FIXATED 버킷
- ⚠️ 오염 축 fixation(기억 단위)과 다름 (세션 단위)

### Resonance (공명)
- 평균 alignment ≥ 0.65
- True Ending = 공명 엔딩 (동의어)
- Trajectory Bridge 생성 트리거

### Completed Sentence
- 공명 시 저장되는 최종 해석 문장
- `plays.completed_sentence`
- Trajectory Bridge source
