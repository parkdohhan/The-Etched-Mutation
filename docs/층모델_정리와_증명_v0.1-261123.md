## 1. 원시 개념과 기호

**원시**(정의 없이 쓰는 말)는 정의 v1과 같다: 작가 텍스트, 관객 발화 원문. 그 위에 이미 정의된 것을 받아 쓴다.

- **씬**의 집합 V (유한). 작가가 자른 것, 주어진 것.
- **감정 공간** ℝᵏ (그 기억의 자, k개 축). 내적은 보통의 것(축끼리 직각, 눈금 같음).
- **회차** p = 서로 다른 씬의 열 (s₁, …, sₙ) + 그 씬들에 적힌 **장부** σ_p(sᵢ) ∈ ℝᵏ. dom(p) = 지난 씬의 집합. "서로 다른" = 되돌아감 없음(현 엔진, 실측 0/37).
- **걸음** = 한 회차 안의 이웃한 씬 쌍 (sᵢ, sᵢ₊₁). **걸음의 통역** = σ_p(sᵢ) − σ_p(sᵢ₊₁).

**씬 그물** G = (V, E): 누군가 한 번이라도 걸은 씬 쌍 {a, b} 를 **실**이라 하고 E 에 넣는다. 실마다 방향 규약 a→b 를 하나 정해 둔다(아무 쪽이나. 정리 4에서 무관함을 보인다).

- **무게** w_e = 그 실 위의 걸음 수 (≥ 1).
- **실의 통역** g_e = 그 실 위 걸음 통역들의 평균 (규약 방향으로 맞춘 뒤).
- **실 안 흩어짐** r_e² = 그 실 위 걸음 통역들이 g_e 에서 떨어진 제곱 거리의 평균.

**장부** h : V → ℝᵏ 에 대해 (δh)_e = h(a) − h(b). 이것이 "장부 h 가 실 e 의 통역이라고 말하는 값"이다.

**에너지** E(h) = Σ_e w_e ‖g_e − (δh)_e‖². **분모** D = Σ_e w_e ‖g_e‖².

**ρ** = (E 의 최솟값) / D. 단위 없음. D = 0(모든 통역이 0)일 때는 ρ = 0 으로 둔다(엔진도 그렇게 한다. 이때 장부를 전부 0 으로 두면 딱 맞으므로 뜻이 통한다).

**닫힌 길의 뒤틀림** W(C) = 길 C 를 따라 통역을 방향 맞춰 더한 것. ∈ ℝᵏ.

이 정의는 엔진과 같다: 무게·평균 = `tools/topo-piece/analyze_undw.mjs` 의 `edges` 계산, 풀이 = `sheaf.mjs` `solveHolonomy`, ρ = `computeRho`, W = `cycleTwist`. (회차 그물 C2 는 점이 회차이고 무게가 "같이 지난 씬 수"다. §2 의 정리 1–4 는 무게가 양수이기만 하면 그대로 성립하고, 정리 5 만 씬 그물 전용이다.)

## 2. 장부 층 — ρ 에 관한 정리

### 정리 1 (ρ 는 잘 정해진 수다) [글+숫자 / 양 끝은 기계]

**진술.** (가) E 는 최솟값을 가진다. (나) 최솟값을 주는 장부는 "덩어리(연결 성분)마다 상수 하나를 더하는 것"을 빼면 하나뿐이다. (다) 0 ≤ ρ ≤ 1. (라) ρ = 1 ⟺ 씬마다 "나가는 실의 w·g 합 = 들어오는 실의 w·g 합".

**증명.** 실마다 ℝᵏ 값을 주는 것 전체를 C¹ 이라 하고, 내적 ⟨x, y⟩_w = Σ_e w_e x_e·y_e 를 준다(w_e > 0 이라 내적이다). δ 는 선형이고 C¹ 은 유한 차원이므로 δ 의 상(im δ)은 닫힌 부분공간이다. E(h) = ‖g − δh‖²_w 이므로 최소화는 g 를 im δ 에 수직으로 내리는 것이고, 수선의 발 Πg 는 존재하며 하나뿐이다 → (가). δh = δh′ ⟺ δ(h − h′) = 0 ⟺ h − h′ 이 실로 이어진 씬끼리 같은 값 ⟺ 덩어리마다 상수 → (나). 피타고라스: ‖g‖² = ‖Πg‖² + ‖g − Πg‖² 이므로 0 ≤ E_min ≤ D → (다). ρ = 1 ⟺ Πg = 0 ⟺ g 가 im δ 에 수직 ⟺ 모든 h 에 대해 Σ_e w_e g_e·(h(a) − h(b)) = 0 ⟺ 씬마다 계수가 0 → (라). ∎

기계가 확인한 부분: E(h) ≥ 0 (`energy_nonneg`), E(0) = D (`energy_zero_ledger`). 최솟값의 존재(수선의 발)는 글 증명.

**예.** 세모꼴 a–b–c 에 같은 무게로 같은 통역 u 가 한 방향으로 돌면(a→b: u, b→c: u, c→a: u) 씬마다 들고 남이 상쇄되어 ρ = 1. 장부로는 한 톨도 설명 안 된다.

### 정리 2 (ρ = 0 의 뜻) [기계 — (ㄱ)⟺(ㄴ)의 "최솟값이 실제로 나온다"만 정리 1]

**진술.** 다음은 서로 같은 말이다.
- (ㄱ) ρ = 0 (D > 0 일 때).
- (ㄴ) 장부 h 하나가 있어서 **모든 실에서** g_e = h(a) − h(b).
- (ㄷ) 그물 위의 **모든 닫힌 길**에서 뒤틀림 W = 0.

**증명.** (ㄱ)⟺(ㄴ): 최솟값이 실제로 어떤 h 에서 나오므로(정리 1) ρ = 0 ⟺ E(h) = 0 인 h 가 있다. E 는 음 아닌 항의 합이고 w_e > 0 이므로 E(h) = 0 ⟺ 모든 항이 0 [`energy_eq_zero_iff`].
(ㄴ)⇒(ㄷ): 길 v₀→v₁→…→vₙ 을 따라 더하면 (h(v₀) − h(v₁)) + (h(v₁) − h(v₂)) + … = h(v₀) − h(vₙ). 닫힌 길이면 v₀ = vₙ 이라 0 [`walkSum_grad`, `IsGradient.zeroHolonomy`].
(ㄷ)⇒(ㄴ): 덩어리마다 기준 씬을 하나 잡고, h(v) = −(기준에서 v 까지 가는 아무 길의 통역 합) 으로 둔다. 길을 어떻게 고르든 값이 같다는 것이 (ㄷ)이다(두 길을 이으면 닫힌 길). 실 a–b 에 대해 "기준→a→b→기준" 닫힌 길의 뒤틀림 0 을 풀면 g_ab = h(a) − h(b) [`ZeroHolonomy.isGradient`]. ∎

**0 의 뜻(규율 7).** ρ = 0 은 "모든 통역이 장부 하나의 차이로 정확히 적힌다"이고, 그것은 "어디로 돌아와도 장부가 맞는다"와 같다. 통합원고 §2.3의 문구 "0 = 모든 통역이 장부 하나로 설명됨"이 이제 정리다.

### 따름 2.1 (틈이 가능하다 ⟺ 고리가 있다) [기계]

**진술.** 그물 G 에 대해 다음은 같은 말이다.
- G 에 고리가 없다(나무들의 모임).
- 실마다 **어떤** 통역을 붙여도 장부 하나로 전부 설명된다(ρ = 0).

**증명.** (⇒) 고리 없는 그물에서 닫힌 길은 간 길을 되짚어 오는 수밖에 없다. 통역은 방향을 뒤집으면 부호가 바뀌므로 되짚은 몫은 상쇄된다. 엄밀히는: 길에서 "같은 씬으로 돌아오는 구간"을 쳐내도 합이 안 변함을 길이에 대한 귀납으로 보인다. 쳐낸 구간은 x 에서 u 로 가는 외길이고, 고리가 없으면 외길은 실 x–u 하나뿐이라 그 합이 정확히 −g(u→x) 이기 때문이다 [`walkSum_bypass`]. 닫힌 길을 다 쳐내면 빈 길이 남고 합은 0. 정리 2 로 장부가 있다 [`isGradient_of_isAcyclic`].
(⇐) 고리가 있으면 "끊어도 그물이 안 갈라지는 실" x–y 가 있다. 그 실에만 통역 1 을 주고 나머지는 0 을 준다. 실 x–y 를 안 지나고 x 에서 y 로 가는 길이 있으므로, 그 길 + 실 y→x 는 뒤틀림 −1 인 닫힌 길이다. 정리 2 로 장부가 없다 [`exists_not_isGradient_of_not_isAcyclic`]. 합쳐서 [`isAcyclic_iff_forall_isGradient`]. ∎

**뜻.** 정의 v1 §2-4 "층은 고리가 있어야 설 자리가 생긴다. 첫 실(한 줄)만 있으면 어긋남을 정의조차 못 한다"의 정확한 판: 한 줄에서는 어긋남이 정의는 되지만 **항상 0** 이다. 그래서 "층 없이 시계열로 충분"이 맞는 것은 정확히 고리가 없을 때다.

### 따름 2.2 (회차 하나에는 틈이 없다) [기계]

**진술.** 한 회차가 씬마다 장부를 하나씩 적었다면, 그 회차의 걸음만으로 만든 그물은 (모양이 어떻든) ρ = 0 이다.

**증명.** 걸음의 통역이 σ_p(a) − σ_p(b) 이므로 장부 h = σ_p 가 그대로 답이다 [`single_run_isGradient`, `single_run_zeroHolonomy`]. ∎

**뜻.** 통합원고 §2.3 "이본은 회차 안이 아니라 회차 사이에 산다. 실 하나는 모순이 없다"가 정리가 된다. 단서는 §5.4.

### 정리 3 (남는 몫은 고리 뒤틀림만의 함수다) [글+숫자]

**진술.** 그물의 뼈대 나무를 하나 잡으면 뼈대에 없는 실마다 기본 고리가 하나씩 생긴다(β = |E| − |V| + 덩어리 수 개). 기본 고리 i 가 실 e 를 지나는 방향을 C_ie ∈ {+1, −1, 0} 로 적은 표를 C, 무게를 대각에 놓은 표를 D_w 라 하면, 감정 축 하나에 대해

  E_min = Wᵀ (C D_w⁻¹ Cᵀ)⁻¹ W,  W = C g (기본 고리들의 뒤틀림).

전체 E_min 은 축마다 더한 것이다.

**증명.** 정리 2 로 im δ = {x : Cx = 0} (기본 고리에서 0 이면 모든 닫힌 길에서 0 이다 — 뼈대로 만든 장부가 뼈대 밖 실까지 맞추므로). ⟨·,·⟩_w 에서 이 공간에 수직인 것은 D_w⁻¹Cᵀλ 꼴이다(⟨D_w⁻¹Cᵀλ, x⟩_w = λᵀCx). 남는 벡터 r = g − Πg 는 그 꼴이고 Cr = Cg = W 이므로 λ = (C D_w⁻¹ Cᵀ)⁻¹ W. C 의 행들은 독립(고리마다 자기만 지나는 실이 있음)이라 역행렬이 있다. E_min = ‖r‖²_w = λᵀ C D_w⁻¹ Cᵀ λ = Wᵀ(C D_w⁻¹ Cᵀ)⁻¹W. ∎

**뜻.** ρ 의 분자에는 통역 g 가 **고리 뒤틀림 W 를 통해서만** 들어간다. "갈라진 틈 = 고리를 한 바퀴 돌 때 장부가 안 맞는 자리"(정의 v1 §1)가 정의이자 계산식이다. 뒤틀림이 같은 두 자료는 ρ 의 분자가 같다.
숫자 확인: 무작위 그물 200개에서 엔진이 낸 E_min 과 이 식의 값이 상대 오차 10⁻¹⁵ 안에서 일치.

### 정리 4 (무엇을 바꿔도 안 변하고, 무엇을 바꾸면 변하나) [글+숫자]

**진술.** ρ 는 다음에 대해 변하지 않는다.
1. 씬에 번호를 다시 매기기.
2. 실의 방향 규약 뒤집기.
3. 계산에 쓰는 뼈대 나무·기준 씬 바꾸기.
4. 그림에서 씬을 놓는 자리 바꾸기.
5. 감정 축 전체를 직각을 지키며 돌리기, 모든 축을 같은 배율로 늘리기.
6. 회차마다 그 회차의 장부 전체에 상수 벡터 하나를 더하기.

다음에 대해서는 **변한다**.
7. 축 하나만 늘리기, 축 빼기(값이 0 뿐인 축을 빼거나 더하는 것은 무관).

정확히는 ρ = Σ_k (D_k / D) · ρ_k — **축별 ρ 를 그 축의 분모 몫으로 가중 평균한 것**이다.

**증명.** 1: 번호 바꾸기 π 에 대해 장부 h 와 h∘π 가 일대일로 대응하고 E 가 항마다 같다. 2: g_e 와 (δh)_e 가 함께 부호가 바뀌어 ‖g_e − (δh)_e‖ 가 같다. 3·4: ρ 의 정의(최솟값)에 뼈대·기준·자리가 나오지 않는다. 5: 직각 돌리기 Q 에 대해 ‖Qg_e − δ(Qh)_e‖ = ‖Q(g_e − (δh)_e)‖ = ‖g_e − (δh)_e‖ 이고 h ↦ Qh 는 일대일. 배율 λ 는 분자·분모에 λ² 가 같이 곱해진다. 6: 걸음의 통역 (σ(a) + c) − (σ(b) + c) = σ(a) − σ(b) [`step_of_shifted_ledger`] 이라 g 가 그대로. 7: 내적이 축끼리 직각이라 E 와 D 가 축마다의 합으로 갈라지고, 최소화도 축마다 따로 된다. 따라서 ρ = Σ E_k,min / Σ D_k = Σ (D_k/D) ρ_k. 축 k 를 λ 배 하면 D_k 만 λ² 배가 되어 가중이 바뀐다. ∎

**예 (7).** 세모꼴, 무게 1. 축 1: 통역이 1, 1, 1 로 한 방향 → ρ₁ = 1, D₁ = 3. 축 2: 장부 (0, 1, 2) 의 차이 → ρ₂ = 0, D₂ = 6. ρ = 3/9 = 0.33. 축 1 을 5배 늘리면 ρ = 75/81 = 0.93.

**뜻.** 규율 5(불변량으로 정의)에 대한 답: ρ 는 **그림·번호·배치에 대해서는 불변량**이고, **자(축의 눈금)에 대해서는 상대량**이다. 정의 v1 §4.1 의 "축별 ρ"·"축별 에너지 몫" 두 줄이 전체 ρ 를 정확히 재구성한다는 것도 이 식이다.

### 정리 5 (무게 = 걸음 수는 강제된다) [기계 — (나)의 부등식만 글]

걸음마다 가닥 하나를 두는 **다중 그물**(D4 후보)에서, 걸음 t 의 통역을 d_t 라 하고 무게 없이 Σ_t ‖d_t − (δh)_{e(t)}‖² 를 최소화하는 문제를 생각한다.

**진술.** 어떤 장부 h 에 대해서도

  Σ_걸음 ‖d_t − (δh)_{e(t)}‖² = Σ_실 w_e r_e² + Σ_실 w_e ‖g_e − (δh)_e‖².
  (다중 그물 에너지)   (실 안 흩어짐, h 와 무관)  (씬 그물 에너지)

따라서
- (가) 다중 그물에서 가장 잘 맞는 장부 = 씬 그물에서 **걸음 수를 무게로** 가장 잘 맞는 장부.
- (나) 걸음 단위 ρ_multi = (Σ w r² + E_min) / (Σ w r² + D) ≥ ρ.
- (다) ρ_multi = 0 ⟺ 장부 h 하나가 있어서 **모든 회차** p 가 σ_p = h + (그 회차의 상수) 로 읽었다.

**증명.** 실 하나 위에서 Σ_t ‖d_t − c‖² = Σ_t ‖d_t − 평균‖² + (걸음 수)·‖평균 − c‖² (가운데 항 Σ(d_t − 평균) = 0 이 사라짐) [`sum_sq_decomp`]. 실마다 더하면 항등식 [`multi_energy_decomp`]. (가)는 첫 항이 h 와 무관해서 [`multi_energy_le_iff`]. (나)는 분자·분모에 같은 양이 더해진 것이고 E_min ≤ D 라 커지는 쪽. (다) ⇐ 는 정리 6. ⇒: ρ_multi = 0 이면 모든 걸음에서 d_t = (δh)_{e(t)}, 즉 σ_p(sᵢ) − h(sᵢ) = σ_p(sᵢ₊₁) − h(sᵢ₊₁). 회차는 한 줄로 이어져 있으므로 σ_p − h 가 그 회차 내내 같은 값이다 [`const_shift_of_steps`]. ∎

**뜻.** 규율 6(자유 상수 금지)에 대한 답: 씬 그물의 무게 w = 걸음 수는 조정할 수 있는 값이 아니다. "걸음 하나하나를 똑같이 대접한다"고 정하는 순간 따라 나온다.
**고리 수.** 다중 그물의 독립 고리 수 = 걸음 − 씬 + 덩어리 = (실 − 씬 + 덩어리) + (걸음 − 실). UNDW-001: 179 − 13 + 1 = 167 = 42 + 125. 굵기 검토 문서의 "167 = 42 + 125"와 일치(숫자 확인 통과). 125개의 "겹친 가닥 고리"가 실 안 흩어짐을, 42개가 실 사이 어긋남을 나른다.

### 정리 6 (원본이 있는 세계에서 ρ = 0) [기계]

**진술.** 장부 f 하나가 있고 모든 회차가 σ_p = f + c_p (c_p 는 회차마다의 상수) 이면 ρ = ρ_multi = 0.

**증명.** 모든 걸음의 통역이 f(a) − f(b) [`step_of_shifted_ledger`]. 평균도 그렇다. 정리 2 (ㄴ). ∎

**뜻.** 영모형 N2("전역 장부 하나 + 회차 오프셋 + 잡음")에서 잡음을 빼면 ρ 가 정확히 0 이다. N2 에서 나오는 ρ 는 전부 잡음 몫이라는 것, 그래서 N2 가 "뒤틀림 0 인 세계"의 대조군이라는 명세 §11.7 의 말이 증명된다.

## 3. 순서 층 — 실의 같음, 꿰맴, 켄달

회차 p 에서 "a 가 b 보다 먼저"를 a <_p b 로 적는다(a, b ∈ dom(p)).

**정의.**
- **양립**: p 와 q 가 **둘 다 지난** 씬 쌍 전부에서 선후가 같다. (정의 v1 D2 ② 의 지금 문구가 이것이다.)
- **실 같음(수리안)**: dom(p) = dom(q) 이고 양립.

### 정리 9 (양립은 같음이 아니다) [기계]

**진술.** (가) 양립은 자기 자신과 성립하고, 뒤집어도 성립한다. (나) **건너뛰기는 안 된다**: A 와 B 가 양립, B 와 C 가 양립인데 A 와 C 는 양립이 아닌 경우가 있다. (다) 실 같음(수리안)은 동치 관계다. (라) 지난 씬 집합이 같은 회차끼리는 양립 = 실 같음.

**증명.** (가) 정의가 대칭 [`Compat.refl`, `Compat.symm`]. (나) A = 1→2→3, B = 1→4, C = 3→2→1. A·B 와 B·C 는 같이 지난 씬이 1 하나라 견줄 쌍이 없어 저절로 양립. A·C 는 정반대 [`compat_not_transitive`, `compat_not_equivalence`]. (다) dom 이 전부 같으므로 견줄 쌍이 세 회차에서 같고, "선후가 같다"는 건너뛴다 [`same_equivalence`]. (라) 정의 그대로 [`compat_iff_same_of_dom_eq`]. ∎

**실데이터(탐색, 판정 아님).** UNDW-001 37회차: 회차 쌍 666 중 같이 지난 씬이 2개 이상인 쌍 341, 그중 순서가 부딪히는 쌍 220. 건너뛰기 실패 삼중 2,873건. 예: 회차 5 `3→2→6→5→9→13→10`, 회차 8 `1→6→5→10`, 회차 7 `1→6→5→10→9→13→7→11→3→2→4→8→12`.

### 정리 10 (순서의 꿰맴) [기계]

**정의.** 회차들이 **꿰매진다** = 모든 회차의 선후를 한꺼번에 지키는 한 줄 순서가 씬 전체 위에 있다.

**진술.** (가) 꿰매진다 ⟺ "어느 회차에선가 a 가 b 보다 먼저"라는 화살표를 따라가서 제자리로 돌아오는 길이 없다. (나) 꿰매지면 둘씩은 반드시 양립이다. (다) **역은 거짓**: 둘씩은 전부 양립인데 꿰매지지 않는 회차들이 있다.

**증명.** (가) ⇒: 한 줄 순서가 있으면 화살표를 따라갈 때마다 그 순서에서 뒤로 가므로 제자리로 못 온다. ⇐: 돌아오는 길이 없으면 "화살표로 닿을 수 있다"가 부분 순서가 되고, 부분 순서는 한 줄 순서로 늘릴 수 있다(슈필라인 정리) [`glues_iff_no_cycle`]. (나) 두 회차가 한 쌍에서 부딪히면 그 쌍이 길이 2 의 돌아오는 길이다 [`Glues.compat`]. (다) P = 1→2→3→4, Q = 3→4→5→6, R = 5→6→1→2. 둘씩은 같이 지난 쌍에서 선후가 같다. 그런데 2→3 (P), 3→5 (Q), 5→2 (R) 로 돌아온다 [`exPQR_pairwise_compat`, `exPQR_not_glues`]. ∎

**뜻.** 정리 8 의 순서 판이다. 장부 층에서 "쌍은 다 맞는데 고리는 안 맞는다"가 가능하듯, 순서 층에서도 "둘씩은 다 맞는데 전체는 한 줄로 안 선다"가 가능하다. 양립이 건너뛰지 못한다는 것(정리 9)이 흠이기만 한 것이 아니라, **꿰맴 문제가 살아 있는 자리**라는 뜻이다.
**실데이터(탐색).** 37가닥 전체는 꿰매지지 않는다(돌아오는 길 있음). 둘씩 전부 양립인데 셋이 안 꿰매지는 삼중이 3건. 예: 회차 8 `1→6→5→10`, 회차 22 `2→3→10→9`, 회차 37 `2→9→13→7→6→4→11` — 6→10 (8), 10→9 (22), 9→6 (37). 단서: 사전 등록 없음, 37회차 중 12회차는 관리자 계정, 걸음은 관객과 엔진의 공동 산물(정의 v1 §3 단서).

### 정리 11 (켄달이 거리인 때와 아닌 때) [기계]

**정의.** disc(p, q) = 둘 다 지난 씬 쌍 가운데 선후가 뒤집힌 쌍의 수. 켄달 K(p, q) = disc / (둘 다 지난 쌍의 수). 범위 0–1. 둘 다 지난 씬이 2개 미만이면 **정의되지 않는다**.

**진술.** (가) disc(p, q) = 0 ⟺ 양립. (나) 지난 씬 집합이 같은 세 회차에서는 disc(p, r) ≤ disc(p, q) + disc(q, r). (다) 지난 씬이 다르면 깨진다.

**증명.** (가) 정의 [`disc_eq_zero_iff`]. (나) p 와 r 이 뒤집힌 쌍 (a, b) 를 보자. q 는 a, b 를 다 지났으므로 둘 중 한 순서다. q 가 p 와 같은 순서면 q·r 에서 뒤집힌 쌍이고, r 과 같은 순서면 p·q 에서 뒤집힌 쌍이다. 뒤집힌 쌍의 집합이 두 집합의 합에 들어가므로 개수도 그렇다 [`disc_triangle`]. (다) A = 1→2→3→4, B = 3→4, C = 2→1→3→4: disc(A, B) = 0, disc(B, C) = 0, disc(A, C) = 1 [`disc_triangle_fails`]. ∎

**무사한 것.** 문서의 켄달 0.302 는 각 회차를 작가의 첫 실(13씬 전부)과 댄 값이라 언제나 정의되고 뜻이 분명하다. 재현 확인: 씬 3개 이상 25회차, 평균 0.302, 최소 0, 최대 0.667.

## 4. 회차 그물 — 꿰맴 정리와 "쌍별로는 못 본다"

Track B(C2)의 바닥. 점 = 회차, 두 회차가 씬을 같이 지났으면 잇는다. 쌍 (p, q) 에 대해 같이 지난 씬 s 마다 차이 d_pq(s) = σ_p(s) − σ_q(s).

**정의.**
- **쌍별 정합**(잔차 0): d_pq(s) 가 같이 지난 씬 전부에서 같은 값 g_pq 다. "두 회차는 상수 이동 하나로 서로 번역된다."
- **전역 장부**(원본 자격): 씬마다 f(s), 회차마다 h_p 가 있어서 σ_p(s) = f(s) + h_p (p 가 s 를 지났을 때).

### 정리 7 (꿰맴) [기계]

**진술.** 회차 그물을 "씬을 **하나라도** 같이 지나면 잇는다"(m = 1)로 만들었을 때,

  전역 장부가 있다 ⟺ (A) 모든 쌍이 정합 **그리고** (B) 회차 그물의 모든 닫힌 길에서 g 의 뒤틀림이 0.

**증명.** (⇒) σ_p(s) − σ_q(s) = h_p − h_q 이므로 (A) [`HasLedger.pairOffsets`], g 가 h 의 차이이므로 정리 2 로 (B). (⇐) (B)와 정리 2 로 g_pq = h_p − h_q 인 h 가 있다. f(s) = σ_p(s) − h_p (s 를 지난 아무 p) 로 둔다. p 를 달리 골라도 값이 같다: p, q 가 둘 다 s 를 지났으면 이어져 있고 (A)로 σ_p(s) − σ_q(s) = g_pq = h_p − h_q 이기 때문 [`hasLedger_iff_zeroHolonomy`]. ∎

**뜻.** 통합원고 §3.2 "불일치 에너지 = 0 ⟺ 관측과 정합하는 전역 절편이 존재"의 이 모델에서의 정확한 모양. "원본이 있는가"가 **쌍 조건 하나와 고리 조건 하나**로 완전히 갈린다. (A)만으로 부족함이 정리 8, (B)만으로 부족함은 쉬운 예(회차 둘이 씬 둘을 같이 지났고 차이가 씬마다 다르면, 그물은 실 하나라 (B)는 저절로 참이지만 장부는 없다).

### 정리 8 (쌍별 비교로는 원리적으로 못 본다) [기계]

**진술.** 회차 셋, 씬 여섯, 감정 축 셋인 두 세계 X, Y 가 있어서
- 두 세계 모두 모든 쌍이 정합(잔차 0),
- 쌍마다의 거리 ‖g_pq‖ 가 두 세계에서 완전히 같은데,
- X 에는 전역 장부가 있고, Y 에는 없다. (ρ 로는 X 가 0, Y 가 1 — 이 두 수치는 엔진 확인.)

따라서 "꿰매지는가"와 ρ 는 **쌍별 거리표·잔차표의 함수가 아니다.**

**구성.** 회차 p, q, r. 겹침: p∩q = {a, b}, q∩r = {c, d}, r∩p = {e, f}. 셋이 다 지난 씬은 없다(있으면 그 씬에서 세 차이의 합이 저절로 0 이 되어 뒤틀림이 못 생긴다).
- X: 회차 상수를 (1,0,0), (0,1,0), (0,0,1) 로 둔 장부 하나. 쌍의 차이는 (1,−1,0), (0,1,−1), (−1,0,1). 한 바퀴 더하면 0.
- Y: 세 쌍의 차이가 전부 (1,−1,0). 한 바퀴 더하면 (3,−3,0) ≠ 0.
두 세계 모두 쌍마다 ‖g‖² = 2 [`Blind.pairwise_blind`]. ∎

감정 분포로도 유효한 판(음수 없음, 합 1: 바탕 (⅓,⅓,⅓) 에 위 벡터의 0.1배를 더함)을 **실제 C2 파이프라인**(`loadRuns` → `runPipeline`, m = 2)에 넣어 확인: 쌍별 표가 두 세계에서 글자까지 같고(거리 0.141421 / 잔차 0), ρ(X) = 0.000, ρ(Y) = 1.000.

**뜻.** 층이론 초안 §4 C2("쌍별 거리 행렬로는 재구성 불가한 신호 ← 논문 생사 조건")의 **수학 쪽 절반**. "그런 배치가 존재한다"는 이제 정리다. 나머지 절반("실관객 자료에 그런 배치가 실재한다")은 측정 몫이고 이 문서는 건드리지 않는다.

## 5. 찾은 흠과 수리안 (결정은 사용자)

### 5.1 F1 — "실 같음 (동치)" 는 동치가 아니다

정의 v1 §7 D2 행: "② 실 같음 = 공통 씬 쌍의 선후가 같음(동치)". 정리 9(나)로 건너뛰기가 안 된다. 통합원고 §2.3 ② 도 같은 문구다. 규율 1 위반.
**수리안**: 이름을 가른다(규율 9). **양립** = 지금 문구. **실 같음** = 지난 씬 집합이 같고 양립. "이본 = ①은 같은데 실 같음이 아닌 것 또는 통역이 다른 것". 이본의 **종류**는 실 같음의 묶음으로 세고, 양립은 "꿰매지는가"(정리 10)를 묻는 재료로 쓴다.
**대안**: 같음을 포기하고 "② 는 같음이 아니라 양립(유사)이다"라고 명시(통역 ③ 의 측정판에 이미 한 것과 같은 처리).
③ 통역 같음도 "공통 걸음"에서 재면 같은 문제가 생긴다. 실 같음인 회차끼리만 재면 동치이고, 그때 "통역 같음 ⟺ 두 장부가 상수 하나만큼만 다르다"(정리 5(다)의 꼴).

### 5.2 F2 — 켄달은 회차–회차 거리가 아니다

정리 11. 통합원고 §2.3 "②의 수량 = 켄달 거리". 첫 실과 댄 값(0.302)은 무사하다. 회차끼리는 666쌍 중 325쌍이 잴 수 없고, 잴 수 있는 쌍끼리도 삼각부등식이 없다.
**수리안**: 이름을 "뒤집힌 쌍 비율"로. "거리"는 지난 씬 집합이 같은 회차끼리만.
선행 이름(인용 전 원문 확인): 지난 항목이 다른 순위끼리의 켄달이 거리가 못 되는 것은 순위 집계 문헌에 알려진 일이다(Fagin–Kumar–Sivakumar, "Comparing top k lists", 2003).

### 5.3 F3 — "겹침 2 이상"(m = 2)은 놓치는 어긋남이 있다

정리 7 은 m = 1 일 때 성립한다. 명세 §11.3 의 기본 m = 2 에서는 씬을 하나만 같이 지난 쌍을 안 본다. 예: p∩q = {a,b} 정합, q∩r = {c,d} 정합, p∩r = {e} 에서 어긋남 → m = 2 로는 ρ = 0·전 쌍 정합, m = 1 로는 ρ = 0.5 (숫자 확인 통과).
**방향은 한쪽만 뚫려 있다**: 전역 장부가 정말 있으면 어떤 m 에서도 ρ = 0 이다(정리 7 ⇒ 방향은 m 과 무관). 그러므로 "ρ > 0 ⇒ 원본 부재"라는 기존 판정은 그대로 서고, 오히려 보수적이다. 위험한 것은 "ρ = 0 ⇒ 원본 존재"로 읽는 것뿐.
**수리안**: 논문 한계에 한 줄. 민감도 분석에 m = 1 추가(지금은 m = 3 만). m = 2 를 고른 이유(씬 하나로는 잔차가 저절로 0)는 타당하므로 기본값 유지.

### 5.4 F4 — "최소 두 사람"은 되돌아감이 없을 때의 말

따름 2.2 는 "회차가 씬마다 장부를 **하나씩만** 적는다"를 쓴다. 현 엔진은 되돌아감이 없어(0/37) 성립한다. 되접힘(D5)을 열어 같은 씬을 두 번 지나며 장부를 두 번 적으면, 한 회차 안에 닫힌 길이 생기고 그 뒤틀림은 정확히 (첫 방문 장부 − 재방문 장부)다(망원경 합). 정의 v1 §2-3 "기억은 최소 두 사람의 실이 겹칠 때 처음 모양을 가진다"는 **"되돌아감이 없는 한"**을 달아야 한다. THEORY §6.1 D5 의 "개인 고리 = 파괴적 복제 측정"은 이 등식으로 정확해진다.

### 5.5 F5 — ρ 는 자에 달린 수다

정리 4-7. ρ = Σ (D_k/D) ρ_k. 축 세트·눈금이 다르면 다른 수다. C2 의 A12/A17/A9 판정 갈림, 씬 그물 15축과 19축의 차이가 이 식의 귀결이다. 기억별 좌표계(기억마다 자가 다름) 아래에서 **기억끼리 ρ 를 직접 비교할 수 없다**는 것도 따라 나온다. 값이 0 뿐인 축을 채우거나 빼는 것(A17 의 0-패딩)은 무관.

### 5.6 F6 — 씬 그물 ρ 는 "같은 실 위의 사람 차이"를 세지 않는다

정리 5. 씬 그물 ρ 는 실마다 평균을 낸 뒤 잰다. 같은 실을 밟은 사람들 사이의 흩어짐(Σ w r²)은 분자에도 분모에도 없다. 걸음 단위로 재면 들어간다.
**예시 계산(탐색, 판정 아님)**: `undw_piece-261105.json` 에 저장된 소수 3자리 값으로 Σ w r² = 96.86, D = 54.69, ρ = 0.5018 → **ρ_multi ≈ 0.82**. 뜻: 걸음 하나하나를 장부 하나로 설명하려 하면 82%가 남는다. 이 수는 사람 차이(잡음처럼 무게가 늘면 줄어드는 몫)를 통째로 포함하므로 "구조"의 크기가 아니다. THEORY §4 "칼만 역이용" 행의 결론(틈의 대부분은 사람 차이)과 같은 방향.
**D4 와의 관계**: "굵기 = 가닥 수가 정의의 일부인가"(D4)가 "나"로 풀리면 ρ_multi 가 정의에 맞는 수가 되고, 아니면 지금 ρ 가 맞는 수다. 이 문서는 고르지 않는다. 다만 정리 5(가)로 **장부는 어느 쪽이든 같다**.

### 5.7 F7 — 지금 쓰는 수학의 정확한 이름

통역 규칙 D1 이 "다(걸음의 감정 변화 숫자가 정본)"로 정해진 결과, 지금 측정에서 실마다 붙는 것은 "이쪽 장부를 저쪽 장부로 바꾸는 규칙(제한 사상)"이 아니라 **차이 벡터 하나**다. 수학의 말로는 "상수 층 위의 1-사슬"이고, ρ 는 그것을 **기울기 성분(장부로 설명됨)과 나머지(순환 성분)**로 가른 비율이다. 일반 셀 층(Hansen–Ghrist)의 장치 가운데 제한 사상이 항등이 아닌 부분은 **아직 쓰이지 않는다.**
선행 이름(인용 전 원문 확인): 이 분해와 "순환 성분의 비율을 비일관성의 자로 쓰기"는 순위 통계에 있다 — Jiang·Lim·Yao·Ye, "Statistical ranking and combinatorial Hodge theory" (HodgeRank, 2011). 회차 그물의 "쌍마다 상수 이동을 맞추고 고리에서 닫히는지 보기"는 **이동 동기화**(translation synchronization) 문제의 꼴이다.
**논문에의 뜻**: 심사자·수학 친구가 "이건 층이 아니라 그래프 호지 분해 아닌가"라고 물으면 답은 "지금 측정은 그렇다"이다. 먼저 밝히고, 층이 필요해지는 자리(통역이 차이가 아니라 **규칙**이 되는 때 — 전이 패턴 6종을 실에 얹는 D1 의 다른 후보, 기억별 자가 다른 기억 사이의 통역)를 "다음 단계"로 적는 편이 안전하다. 반대로 얻는 것: 호지 분해 쪽에는 이미 증명된 도구(기울기·회전·조화 3분해, 통계 검정)가 있다.
