> 방법: 지휘 세션이 playwright 로 실제 저작 흐름 완주 — 새 기억 생성 → 씬 2개 추가 →
> 필드 입력 → 저장 → 재진입 → Canvas → 잔상 탭 → 삭제. 콘솔·DB 대조 병행.
> 스크린샷: `docs/admin_UX검수_스크린샷-260717/`. 시험 데이터 전량 삭제 확인.
> 전제: R1 수리로 **안전성은 확보된 상태** — 본 검수는 안전이 아니라 **편의(상용성)** 감사.

## 1. 실측 버그 (기능 결함 — 편의 이전 문제)

| # | 증상 | 실측 | 심각도 |
|---|---|---|---|
| B1 | **저장 직후 새 기억이 목록에 없음** | 저장 성공(콘솔 id 확인) → 대시보드 복귀 → 카드 부재 → **새로고침 후에야 등장** | 🔴 "저장 안 됐나?" 패닉 유발. B2와 결합 시 최악 |
| B2 | **저장 무피드백 + 편집기 강제 퇴출** | 저장(1.2초) 동안·후에 알림 0 (토스트·알림창·문구 전무), 완료되면 대시보드로 튕김 | 🔴 반복 편집 루프 파괴 — 저장마다 재진입+재스크롤 |
| B3 | 삭제 알림 조사 오류 | "아카이브**이** 삭제되었습니다" | 🟢 사소하나 눈에 띔 |
| B4 | 운영 탭 = 빈 방 | "향후 이곳으로 이관 예정" 안내문뿐 | 🟡 탭이 3개인데 1개가 허당 — 신뢰 인상 감점 |

## 2. 상용 대비 마찰 (구조적 불편 — 우선순위순)

| # | 마찰 | 실측 근거 | 상용 기대치 |
|---|---|---|---|
| F1 | **씬 폼이 괴물** — 씬 1개당 입력 요소 41개, 접기 없음 | 씬 2개 = 페이지 7,422px (화면 6장). 6씬 기억이면 ~2만px | 씬 카드 접기/펼치기 + 씬 목차 사이드바 |
| F2 | **저장 루프 마찰** (B1+B2+F1 복합) | 쓰기→저장→퇴출→카드 찾기→재진입→재스크롤 | 저장 후 제자리 유지 + 성공 토스트 |
| F3 | **Canvas 에 기억 선택기 없음** | 전환하려면 목록 탭→카드 열기→Canvas 복귀 (암묵 동선, 발견 불가) | 상단에 기억 드롭다운 |
| F4 | 목록에 검색·정렬·페이지 없음 | 현재 7개라 견딤 — 20개부터 고통 | 제목/코드 검색 1칸 |
| F5 | 알림 전부 브라우저 기본창 (confirm/alert) | 삭제 흐름 실측 | 인라인 토스트/모달 |
| F6 | 휴지통·되돌리기 없음 — 삭제 즉시 영구 | 삭제 confirm 1번 → 영구 | soft-delete 30일 (어제 평가 D 항목과 동일 뿌리) |
| F7 | 자동저장·임시저장 없음 | 폼 상태는 메모리에만 — 탭 크래시 = 작성분 증발 (이탈 경고 confirm 은 있음 ✓) | 로컬 임시저장(localStorage) |
| F8 | 잔상 모더레이션이 편집화면 하단에 숨음 | 운영 탭 이관 미완 (Phase 0.5 잔재) | 운영 탭으로 이동 |
| F9 | i18n 혼재 | Anchor Images 섹션만 영어, 나머지 한글 | 통일 |

## 3. 저작 커버리지 구멍 (오전 검수분 — 참조용 요약)

**dialog_choices**(씬별 유령 대사 4종) / **choices**(감정 결 선택지) /
**plays 작가 원본 궤적 시딩**(§11). 상세 = 채팅 검수 기록(7-17 오전) +
`docs/데모기억_풀기능_체크리스트-260707.md`.
