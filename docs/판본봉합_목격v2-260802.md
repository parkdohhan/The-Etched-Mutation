# 판본 봉합 + 목격의 순간 v2 — 260802

> 배경: "내가 가지고 나갈 나의 판본"으로 문 나가기 연출 개념 전환 (사용자 결정 260802).
> 사전 조사에서 확인된 구멍 — 방문 순서·감정·발화는 plays/run_journals 로 복원 가능하지만,
> **그 회차에 플레이어가 실제로 읽은 판본 텍스트는 어디에도 저장되지 않았다**
> (scenes.text_stage_* 는 다음 사람용으로 덮어써지고, cont_depth 는 최신값만 남아 역산 불가).

## 1. 판본 봉합 (데이터)

### DB (Supabase migration `run_journals_personal_variant_record`)
- `run_journals.run_traces` (jsonb) — 봉인 시점 여정 스냅샷
  `{ visit_order: [scene_id…], scenes: [{ order, scene_id, pin_type, seen_stage, seen_depth, seen_text, user_emotion, scene_link_input, alignment, bucket, pattern, mismatch }] }`
- `run_journals.reveal_narrative` (text) — generate-reveal 이 써준 봉인 서사 (여태 localStorage 에만 있었음)
- RLS 기존 정책 그대로 (row 24h 내 update 허용) — 봉인은 같은 세션이라 통과.

### 코드 (play-test.html)
- `_noteSeenText(scene, stage, text, depth)` — `game._seenTexts[sceneId]` 장부.
  `applyStageText` 의 **모든 return 지점**에서 기록: `original` / `stage_1/2/3` / `fallback_<stage>`.
- `game.traces` 항목에 `seenStage`·`seenText` 필드 추가 (고전·대화 두 push 자리 모두).
- 대화 경로도 `game.visitOrder` 를 채움 (여태 고전 경로만 채워서 e2e 실측 시 빈 배열로 봉인됐다).
- 봉인 시 `_jSnap.run_traces` 로 여정 전체 patch, reveal 도착 시 `reveal_narrative` patch.

### 판본 재구성 쿼리 (한 회차 = 한 판본)
```sql
SELECT run_traces, reveal_narrative, silent_visits
FROM run_journals WHERE run_id = '<run>';
-- 발화 원문·유령 답은 plays.dialog_turns (run_id 로 조인)
```

## 2. 목격의 순간 v2 (연출)

봉인 직후, 퇴장(reveal) 전. **v2 실패/조건 미비 시 기존 v1(즉시 재빌드+자막 2.6초)로 자동 폴백.**

시퀀스 (`_witnessCinematicV2`, play-test.html):
1. 플레이어 자리에 ybot 몸(유령과 같은 반투명 잿빛) — `spawnCinematicBody` (lumen_scene_mannequins.js 신규 API, 1회용·응시/클릭 대상 아님)
2. 카메라가 몸을 빠져나가 등 뒤 3.4m·위 1.1m — **render wrap 카메라 탈취 재사용** (`_temDialogCam` + `_runCamTween`, 대화 줌인과 동일 검증 패턴)
3. `morphHeights` 로 땅이 옛 모습 → 이번 몫 반영 모습으로 수 초에 걸쳐 보간
4. 변형 최대 지점(침식 물길 argmin / 융기 argmax, 6유닛 내 중복이면 1곳) 클로즈업 순회
5. 자막("네가 지나간 자리가 굳는다") → 원래 시점 복귀 → 몸 제거
- 연출 중 입력은 capture 단계에서 삼킴 (lumen_rewind_playback 패턴).

### morphHeights (tem_af_strata_terrain.js 신규 runtime API)
- 재빌드(지오메트리·머티리얼·셰이더 재컴파일 = 히치) 없이 **현재 메시 정점 Y만** easeInOut 보간.
- **마지막 빌드의 정규화(mn/rg)를 저장(`_lastMn/_lastRg`)해 같은 기준으로 매핑** — 재정규화 팝 방지, 변하지 않은 셀은 안 움직임.
- 노멀 재계산은 4프레임에 1번. `buildTerrain` 이 돌면 진행 중 보간 자동 중단(재빌드가 이긴다).
- gH 는 pos 배열을 읽으므로 보간 중에도 발밑 높이 연속.

## 3. e2e 실측 (260802, 대표 기억 `1835926d…`, ?variant_strata=1)

### 자동화 함정 (다음 검증자용)
