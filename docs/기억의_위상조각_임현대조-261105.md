## 0. 결론 세 줄

1. **반전의 구조는 같은 말로 쓸 수 있다.** 되돌이 실(뒤의 점에서 앞의 점으로 되돌아가는 실) + 고리 + 틈. 좋은 반전 = 되돌이 실이 만든 고리에 틈 ≠ 0(재해석). 분위기만 바꾸는 반전 = 틈 0. 누락 = 되돌이 실이 내려앉을 점 없음. 두 비밀 다 뒤에 = 틈 둘이 한 자리에 겹침. 인과적 수습 = 모든 점이 의도 점에 묶인 별.
2. **지속행동도 쓸 수 있다. 다만 낱말 하나가 더 든다 — 막대.** 모든 점을 한 가닥에 꿰는 공통 축(전역 절편 = 허브). 막대가 끝나면 이야기가 끝남(살이 안 간 마지막 점). 점마다 새 알(새 상황)이 붙어야 반복이 아님(없으면 고착). 주제 점은 막대에서 떨어져야 빈틈. 정적(골방) = 막대만 있고 점끼리 실이 없는 별.
3. **독자의 고리와 작가의 고리는 다르다.** ①(37명)에서 초록 고리는 사람들 사이에서 저절로 생긴 것(측정, ρ 0.50). 소설에서는 작가가 되돌이 실로 고리를 손수 만든다. 작가 혼자의 장부는 어떤 고리를 돌아도 틈 0이므로, 소설의 "재해석"은 독자 실이 와야만 재어진다(정의 v1 §2-4의 작법 판).

## 3. 다른 앵커에서 본 것 (보조 작업자 03·04)

- 「평면도」: 평면도는 액자이지 엔진이 아님(연필 든 장면 = 도입·결말뿐). 행동 패턴 후보는 오히려 모래시계·잠자 씨(고양이). 결말에서 선이 **추가**됨 = 소파 원리의 역방향. 화자 앵커("일단 물러났다 → 이번에는 그럴 수 없다")는 있으나 선생님이 짚지 않음.
- 「사나」: 비밀(임신)은 1/4 지점에서 자진 공개 = 전제. 고양이 간식 반전은 2단(37·40)이나 둘 다 분위기만(틈 0). 앵커 없음("다 거짓말일 수도").
- 「토끼 접시」: 환상 요소 전부 현장 배치, 사라짐 4회 연쇄. 합평본 ≠ PDF본 가능성(누나 이름 신우/민영).

## 4. 정직 칸

- ①만 측정값. ②③④는 작가 실과 합평 시연을 같은 문법으로 옮긴 **그림값**. 틈은 있고 없음만 적었고 크기는 없다.

- 처음 만든 판은 모래밭 평면 위에 눌러 그려 위상이 아니라 지도였음 → 사용자 교정("왜 위상인데 높이가 다 같고 평면 위인데") → 기존 「기억의 위상 조각」의 공간 문법으로 재작성. 폐기 판은 별도 아티팩트 https://claude.ai/artifact/9BioZ9bhm1wUEweCMrdhHZ 에 남아 있음(삭제는 사용자 결정).
