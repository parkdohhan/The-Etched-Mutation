## 1. 진단 — V2.1.1 차용 후 남은 약점

V2.1.1 ego-state turn-taking 차용 후 매 턴 풀 픽 작동. 단 `pickResponse` 가 `alignment` 점수만 보고 *playerInput 내용*은 안 봄 — `_extractQuote/_applyQuote` 가 dissonance 결 한정 *첫 N단어 인용*만 처리.

### 1.1 남은 약점 3가지

**(가) 휘발성** — quoting 인용은 *그 자리* 응답에만 박힘. 다음 플레이어 풀에 안 들어감. §2 명제 "관객 파편이 다음 관객 유령으로 흘러간다" 는 시나리오 C (speciation 시드 분기) 에서만 작동.

**(나) dissonance 한정** — quoting 은 결 하나에서만 작동. resonance / vague 결의 *부드러운 흡수* 자리 없음.

**(다) 첫 N단어 추출** — 명사구 단위 X. 입력 "엄마를 기다렸잖아" → 첫 5단어 그대로 인용 "'엄마를 기다렸잖아'라고?". 명사 ("엄마") 단위로 *유령 입에 옮겨 담기* 안 됨.

## 2. 보완 — 슬롯 흡수

### 2.1 차용·확장 분리

**확장**: 기존 quoting 인프라 (`_extractQuote`, `_applyQuote`, `'____'` 마커) 한 발 더. 명사구 NER + 슬롯 매처 + DB 영속.

**거부**: LLM 응답 (V3 자리), 자유 콘텐츠 변이 (V3), 인명 NER 일반화 (V2-12 위임).

### 2.2 변경 항목

| 자리 | V2.1.1 | V2.1.2 |
|---|---|---|
| 입력 추출 | 첫 2~5단어 그대로 | 한국어 명사구 NER (어미 패턴 + 색 형용사) |
| 슬롯 표기 | `'____'` 1개 | `{대상}` `{대상:을/를}` `{대상:이/가}` `{대상:은/는}` `{대상:와/과}` `{색}` (자동 조사) |
| 작동 결 | dissonance 만 | resonance + vague (dissonance 는 기존 quoting 그대로) |
| 영속 | 휘발 | `ghost_variants` 새 drift row 자생 (`is_seed=false`, `parent_variant_id=본_유령`) |
| 다음 플레이어 | 못 만남 | 풀 픽에 자동 들어가 만남 |
| 안전 | 빈 토큰 fallback | + BLOCK_NOUNS (욕설·금기) + TOO_GENERIC_NOUNS + alignment 임계 + 메모리당 흡수 상한 30 |

### 2.3 인프라 — 이미 박혀 있는 자산 + 확장

**재활용** (코드 변경 X 또는 한 줄):

- `lumen_ghost_response.js` PRNG (FNV-1a + mulberry32) — SlotAbsorber 시드 픽
- `pickResponse({memoryId, sceneId, turn, alignment, playerInput})` 시그니처 — 이미 playerInput 받음
- `insert-ghost-variant` edge function — kind enum 한 줄 확장 (`'speciation'` → `'speciation' | 'drift'`)
- `claude-scene emotion_extract` — 흡수 변주 emotion_vec 추출 자리

**신규**:
- `js/core/SlotAbsorber.js` — NER + 슬롯 매처 + 받침 처리
- `lumen_dialog_phase1.js _backgroundInsertAbsorbed` — 비동기 fire-and-forget insert
- `memories.meta.absorption_slots` JSONB 자리 — 메모리당 슬롯 풀
- `lumen_ghost_response.js resonanceSlotPool` / `vagueSlotPool` 옵션 — 메모리 진입 시 주입
- `play-test.html loadMemoryData` 슬롯 풀 wiring — `setOptions` 호출

→ **코드 인프라 거의 그대로.** 콘텐츠 *구조*만 바뀜.

### 3.0 씬 가정

- **메모리**: 발자국 (작가 = 슬리퍼 신은 아이, 본 유령 = slipper child)
- **씬 5**: 2년 후 — 엄마와 노란 장화 인력의 혼인신고
- **원본**: 엄마 ≠ 등장인물의 직접 부름 대상 (3인칭 "엄마" 사용)

### 3.1 시나리오 V2.1.1 차용 후 (현재)

```
[유령]   ...아스팔트 깔리던 날의 냄새. 뜨겁고 시커먼.
[유령]   ...너도 그런 날 있었어? 두 가지가 같이 끝나던 날.

[플레이어 턴 1] "엄마를 기다렸잖아."
[시스템] alignment 0.62 → resonance
[유령]   ...같은 자리에 너도 있었구나.       ← resonance 풀 픽 (입력 내용 X)

→ 엄마라는 단어가 유령 입에 안 옮겨감.
→ 다음 플레이어가 같은 메모리 진입 시 풀 동일 (변화 X).
```

### 3.2 시나리오 V2.1.2 (슬롯 흡수)

```
[유령]   ...아스팔트 깔리던 날의 냄새. 뜨겁고 시커먼.
[유령]   ...너도 그런 날 있었어? 두 가지가 같이 끝나던 날.

[플레이어 턴 1] "엄마를 기다렸잖아."
[시스템] alignment 0.62 → resonance
[NER]    명사구 추출 → "엄마" (조사 "를", type=object)
[슬롯]   resonance 풀 pick → "...그래. {대상:이/가} 거기 있었구나. 발자국 옆에."
[채움]   "엄마" + 받침(받침X) → "엄마가"
[유령]   ...그래. 엄마가 거기 있었구나. 발자국 옆에.   ← 흡수 응답

[background insert]
  ghost_variants new row {
    memory_id: <발자국>,
    kind: 'drift',
    is_seed: false,
    parent_variant_id: <본 발화 id>,
    utterance: "...그래. 엄마가 거기 있었구나. 발자국 옆에.",
    motif_tags: ["발자국", "함께", "엄마"],
    emotion_vec: <claude-scene 추출>,
  }

→ 다음 플레이어 진입 시 pickGhostVariant 풀에 이 변주 들어감.
→ 다음 플레이어가 *엄마*가 등장하는 변주를 만남.
→ §2 명제 "관객 파편이 다음 관객 유령으로 흘러간다" 시연.
```

## 4. 정당화 — "기억을 다시 쓰는다" 컨셉과의 정합

### 4.1 §6.5 #6 "Record = first Play"

기억을 서술하는 행위 자체가 그 기억의 첫 경험. 슬롯 흡수 = *유령과 대화하면서 기억을 다시 쓴다*. 작품 명제 §2 의 *진짜 메커니즘*. V2.1.1 차용이 *마찰점*을 만들었다면, V2.1.2 는 *그 마찰의 흔적이 메모리에 남는* 자리.

### 4.2 §6.2 기억유전학 v0.3 동형성

| TEM 자산 | 기억유전학 작용 |
|---|---|
| V2.1.1 quoting (휘발) | (작용 없음) |
| **V2.1.2 슬롯 흡수 (drift row 자생)** | §1 destructive replication + §2 biased mutation 둘 다 |
| V2.1 speciation 시드 | §6 mnemonic recombination |

→ **V2.1.2 가 기억유전학의 §1·§2 메커니즘을 *체험 자리* 에서 작동시키는 자리.** 박사 framing 자료 강력.

### 4.3 §15-1 두 층 구조 정합

- **층1 (drift)** = 같은 유령 발화 변주. V2.1 까지 *작가 박은 변주 풀에서 픽*만. V2.1.2 = *플레이어 흡수로 풀이 자라는* 자리 추가. 점돌연변이 → *유령이 진짜로 변형된다*.
- **층2 (speciation)** = 새 유령 시드. V2.1 차용 그대로.

→ V2.1.2 = §15-1 층1 의 *체험 자리 작동*.

## 6. 결정 기록

### 6.1 V2.1.2 발동 — 2026-05-05

V2.1.1 ego-state turn-taking 차용 후 남은 약점 3종 (§1.1 (가)~(다)) 으로 발동. 본인 페이스 1.67× × 14일 안에 들어가는 자리 (1.2일 추가).

근거:
- 작품 명제 §2 시연 강화 — drift 흡수 자리 = *플레이어가 메모리를 다시 쓰는* 자리
- §10 성공 판정 8번째 (같은 메모리 두 명 다른 유령 풀) 강화
- 시나리오 D (자생 새 유령 0건) 위험 자동 감소
- 박사 framing 자료 — 기억유전학 §1·§2 체험 자리 작동

### 6.2 LLM 응답 거부 — V3 자리

LLM 호출로 자유 응답 생성하면 *진짜* 흡수 가능 (V3 박사 단계). 5-19 데모는 슬롯 매처 80% 체감으로 충분.

근거:
- 비용 + 응답 지연
- 안전 필터 인프라 부담
- [메모리 feedback_no_llm_judgment] — LLM 판정 추가 호출 거부 룰 정합 (단, 응답 생성은 별도 — 본 룰 적용 X. V3 재검토 자리.)

### 6.3 인명 NER 일반화 V2-12 위임

한국 인명 NER 은 false positive 큼 (일반 명사도 매치). 5-19 데모 친구 표본 7명에서 인명 박힘 확률 매우 낮아 MVP 에서 제외. V2-12 튜닝 자리.

### 6.4 흡수 결 = resonance + vague

dissonance 결은 기존 quoting (`'____'` 마커) 그대로. 흡수가 *부드럽게 받아들여지는* 자리는 본 결 따라가는 resonance / 흔들리는 vague 한정.

근거:
- dissonance 결의 *거부 톤* 과 흡수의 *받아들임 톤* 충돌
- §15-1 층1 drift = 본 결 변주 자리 (vague 까지 포함)

### 6.5 메모리당 흡수 상한 30

`insert-ghost-variant` edge function 에서 검증. 5-19 데모 한 회 = 최대 18 흡수 (3턴 × 6씬). 1 메모리에 30 도달은 *15회 풀 사이클* — 데모 안에서 도달 불가. 본격 서비스 시 V2-12 또는 V3 lifecycle 정책.

### 6.6 anchorVariantId = 옵션 (없으면 null)

본 유령 id 자리. opening.js V2-3 / V2-4 에서 sessionStorage 박을 자리 있을 수도. 없으면 null = parent_variant_id null = 계보 추적 X. 데모 작동에는 영향 없음. V2-12 정확한 wiring.
