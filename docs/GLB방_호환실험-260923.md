# 조각 B — 방 규모 GLB 무대 호환 실험 (2026-09-23)

> 발단: 기억마다 "방"을 생성기(Higgsfield 3D Jutsu / World Labs Marble)로 만들어 무대에 심는 안. 무대는 Three.js r128 전역 빌드(지형 셰이더·안개 벽·마네킹·FBX 로더가 한 묶음)라 스플랫 렌더러는 못 들어오고, **GLB 경로만** 검증했다. 저장소에는 사물 GLB(상징 사물 1.725 m 규격)만 있고 방 규모 표본은 없어서 공개 표본 3종 + 페이지 안에서 만든 합성 방 1종으로 대신했다.
> 선례 형식: `docs/생애전승_T2_유령표현비교-260922.md`. **본 코드 0줄 수정 · 서버 0 · 저장 0.** 신규 파일은 `test/` 와 `docs/` 아래에만.
> 판정은 사용자 몫이다. 이 문서는 관찰과 수치만 적고 "읽힌다/안 읽힌다"를 단정하지 않는다.

## 0. 결과 한 줄

실험 페이지 `test/glb-room-test.html` 하나로 GLB 표본 4종(디오라마·램프·도시·합성 방)을 r128 무대 잠금값(배경·안개·조명 3종·유령 재질) 안에 넣어 시점 3종(밖·입구·안)으로 캡처했다 — 4종 모두 로드됨, 콘솔 오류 0, 표본별 새 경고 0. 자동으로 걸리는 손질은 셋: 단위 맞춤(cm 파일은 8 m 로), 내장 조명 감쇠(최대 세기를 2 로), 내부 유무 판정(5방향 광선). 무대 안개 0.045 는 방 규모에서 사실상 0 이라는 것이 수식과 캡처 양쪽에서 확인됐고, 방 안의 가림 수단(안개 vs 어둠+국소 조명)은 §6 의 사용자 판정으로 넘긴다.

## 6. 사용자 판정 — 세 질문

캡처(또는 페이지를 직접 열어)를 보고 답한다. 헤드리스 밝기는 실제 화면과 다를 수 있으니 가능하면 페이지에서.

1. **방 GLB 가 무대 톤(어둡고 안개 낀 지형·회색 반투명 유령) 안에 "같은 세계"로 앉는가, "이물"로 앉는가?** — b1-09/10/11(합성 방, 목표 2) 과 T2 캡처를 나란히. 특히 램프 옆 유령의 분홍빛(b1-03/12)이 허용 범위인가.
2. **방 안에서 가림 수단은 무엇인가?** — (가) 안개 0.15~0.25 로 잠그기(b1-16/21: 방 톤이 안개색으로 균일해짐, 가까운 사물엔 약함) / (나) 어둠 + 국소 조명(b1-14/15: 무대 조명만 또는 내장 배율 0.1~0.2, 사물은 다 보이되 낮게 가라앉음) / (다) 벽·문 자체가 가림(방 구조로 해결, 안개·조명은 보조).
3. **생성기 방을 실제로 하나 받아 볼 것인가?** — Higgsfield GLB(조명·압축·텍스처 형식 미확인) 또는 Marble 충돌용 GLB(10~20만 삼각형, 좌표계 Y·Z 반전). 받아 보기 전엔 §7 의 "미확인" 세 항목이 안 풀린다.

| 답 | 다음 |

| 1 이물 | 무대 이식 보류. 재질 후처리(GLB 재질을 무대 팔레트로 되씌우기) 실험을 이 페이지에 한 슬라이더로 추가해 재캡처. 유령 재질 보정도 여기서 |

## 7. 알려진 한계 · 본 코드 수정이 필요한 항목

**한계 (이 실험 안에서)**
- **진짜 실내 방 공개 표본 미확보** — Khronos Sponza 는 분리형 60 MB 초과, ABeautifulGame 은 jsdelivr 403. 디오라마·램프·도시 + 합성 방 왕복으로 대체. "실내가 모델링된 GLB 가 무대 안 시점에서 어떻게 보이는가"는 합성 방 하나가 유일한 근거.
- **KTX2(KHR_texture_basisu) 실측 불가** — r128 전역 빌드에 KTX2Loader 없음(404). 모듈판은 별도 three 인스턴스를 끌고 와 섞이지 않음. 생성기가 KTX2 를 내보내면 PNG/JPG 재변환 전제.
- **Higgsfield/Marble 의 압축(Draco/meshopt)·텍스처 형식·조명 포함 여부 미확인** — 공개 문서에 없음. 실제 파일을 받아야 풀림.
- 램프처럼 깊이가 얕은 표본은 "안" 카메라가 표본 뒤로 나감(공식 그대로). 하한을 `min.z` 로 묶는 한 줄로 고칠 수 있으나 "열림" 배지가 붙으므로 그대로 둠.
- 안개 0.15~0.25 는 입구 시점에만 효과, 안 시점(사물 1~3 m)에선 미세. 안 시점의 가림은 안개로는 안 됨(수식·캡처 일치).
- 헤드리스 SwiftShader 라 밝기·AA 가 실제 GPU 와 다를 수 있고, Tokyo(14만 삼각형) 카메라 전환이 13~15 s 걸림(GPU 화면에선 2.5 s 규칙).
- `_report.json` 에 b1-21/22 의 수치 항목이 없음(안개 0.25 외에는 b1-10/11 과 동일).
- 미수정 잔여(§5 #3·#4·#6·#13·#14·#18)는 실험 페이지 조작감·메모리·훅 반환형 문제로, 결과 수치에는 영향 없음.
- 표본 GLB 3개는 `.git/info/exclude` 로 로컬 제외 — 클론엔 안 따라오니 커밋 전 `git status` 확인.

**본 코드 수정이 필요한 항목 (이번엔 0줄, 이식하려면)**
- **GLTFLoader 에 DRACOLoader·MeshoptDecoder 연결** — 현재 `lumen_scene_mannequins.js` 의 `_loadGlb` 는 사물 GLB(비압축) 전제. 생성기 GLB 가 Draco/meshopt 면 로더 설정 추가 + jsdelivr 디코더 경로(또는 로컬 복사) + 캐시버스터.
- **단위 자동 판별·바닥/중심 정렬을 방 규모로 확장** — 사물 몸 보정(`symbolMaxDim` 1.725 m)은 "가장 긴 변을 규격에 맞춤"이라 방(6~8 m)에는 별도 규격값 필요.
- **내장 조명 감쇠 규칙(목표 2)** — 무대엔 KHR_lights_punctual 을 받는 자리가 없음. 방 GLB 조명을 켤지(감쇠 적용) 끌지(무대 조명만) 규칙 하나.
- **방 진입 시 안개 밀도·ambient 별도 값** — 2번 판정 결과에 따라. 지형 안개 벽(`tem_af_strata_terrain.js`)과의 충돌 조사 선행.
- **밖 프리셋은 이식 금지** — 관객 카메라는 입구·안 두 시점만. 전체 조감은 admin 전용.
- **내부 판정(5방향 광선)** — 방 GLB 등록 시 검사기로 쓰면 "실내 없는 파일"을 저작 단계에서 걸러냄. 저작 도구(`tools/`) 쪽 후보.
- 유령이 GLB 조명 가까이 설 때 재질(Additive) 포화 — 유령 재질에 조명 무시(emissive/unlit) 옵션이 필요할 수 있음. 1번 판정 후.
