# 세션 핸드아웃 — 파동 부활 (V2-5 보강, 2026-05-06)

## 목표

박혀 있는 파동 자산을 메모리 1인칭 공간에 부활. 유령에 다가갈 때 *그 유령 감정에 맞춰* 파동 변하는 연출 + 닮은 정도 점수 (alignment) 따라 파동 변형 + 모티프 사전 갱신 시 메모리 baseline 파동 갱신. **메모리마다 다른 분위기 + 유령마다 다른 파동 + 점수가 눈에 보임**.

V2-5 본 자리 (카메라 + 사운드/메아리 단어 런타임 갱신) 옆에 *별개 모듈*로 박힘. V2-5 본 자리는 다른 세션이 박음. 본 세션은 *파동 자리만*.

박는 자리 = `~2일`.

## 작업 — 3 단계 + 보너스

### 단계 1 — 메모리 ambient baseline 파동 (화면 전체 깔림)

메모리 진입 시 화면 전체에 옅게 파동 깔림. 메모리 평균 감정 → 파동 모양. 메모리마다 색·속도 다름.

**박을 자리**:
- 새 캔버스 박는 자리 = `play-test.html` 또는 1인칭 공간 wrapper에 `<canvas id="lumenAmbientWaveCanvas">` 추가. z-index = three.js 캔버스 위, UI 아래 (예: 5).
- `Visualizer.js`의 `transparentBackground` + `lineWidthMultiplier` 박힌 자리 재활용.
- 메모리 진입 시 `memories.meta.baseline_emotion_vec` 또는 *모티프 사전 적용 결과 평균* 읽어서 → `emotionVectorToWaveStyle` → Visualizer에 넘김.
- 알파 ~0.15 (옅게).

**메모리 평균 감정 어디서 박나** — 결정 자리:
- (가) `memories.meta.baseline_emotion_vec` 새 컬럼 박음
- (나) 메모리 안 모든 ghost_variants `emotion_vec` 평균 (런타임 계산)
- (다) 작가가 admin에서 박는 자리

**추천**: (나) 런타임 평균. 새 컬럼 X, admin 변경 X.

### 단계 2 — 유령 spot wave (다가갈 때 동그라미 파동)

유령 b 자리에 *spot 파동* 박힘. b의 `emotion_vec` → waveStyle. 거리 단계별 강도 (멀=숨김 0%, 중=희미 30%, 가까이=또렷 100%).

**박을 자리**:
- `Visualizer.js`에 신규 메서드 `renderSpotWave(canvas, x, y, radius, waveStyle, alpha)` 박음. waveStyle 보간 자리 (`_lerpWaveStyle`) 재활용.
- 또는 신규 모듈 `js/ui/lumen_spot_wave.js` 박음 (Visualizer 패턴 따라). 깨끗한 자리.
- 1인칭 공간 wrapper의 ambient 파동 캔버스 *위에* spot wave 그림. 또는 별도 캔버스 (단계 1 캔버스 위).
- 매 프레임 plays 1인칭 위치 → 각 유령 `pose` 좌표 거리 계산 → 단계별 alpha 결정 → spot wave 그림.

**거리 단계 임계**:
- 멀리 ~10m+ = alpha 0
- 중간 ~5~10m = alpha 0.3 페이드 인
- 가까이 ~5m 이하 = alpha 1.0 또렷

(임계 거리는 V2-12 튜닝 자리. 시드값으로 박음)

**유령 위치 어디서 박나** — 결정 자리:
- (가) `ghost_variants.pose` 텍스트 컬럼 = 자세 메타 ("쪼그려 앉음, 등 돌림 ...") — 좌표 X
- (나) 새 컬럼 `ghost_variants.position` (JSONB `{x, y, z}`)
- (다) 매치 시 *근처 자리* 자동 배치

**추천**: (다) 자동 배치 — 매치 발동 시 SceneNavigator가 결정 (V2-6 자리). spot wave는 결정된 좌표 받아서 박음. 새 컬럼 X.

### 단계 3 — 닮은 정도 점수 따라 파동 변형 (대화 중)

플레이어 멀티턴 응답마다 점수 결 (resonance / vague / dissonance) 결정. 그 결마다 파동 변형:

- **공명** (resonance, ≥0.7) — 파동이 잠깐 *밝아짐* (saturate +20%, brightness +15%, 300ms)
- **모호** (vague, 0.4~0.7) — 파동 *혼돈 증가* (chaos +30%, 700ms)
- **충돌** (dissonance, <0.4) — 파동 *위아래 요동* (`_ghostTremor` 발동) + 색 살짝 다른 결로 (hue-rotate 15deg, 1200ms)

**박을 자리**:
- spot wave 모듈에 `pulse({resonance, durationMs})` API 박음
- `lumen_dialog_phase1.js`의 `driftVis.pulse` 호출 자리 옆에 `spotWave.pulse` 박음 (V2-5 본 세션이 박음 또는 본 세션이 박음 — *합의 필요*)
- 흡수 발생 시 `setWaveOverride` (이미 박힌 진폭 감쇠 + 탈채도) 활용

### 보너스 — 모티프 사전 갱신 시 baseline 갱신

모티프 사전 (`memories.meta.motif_dictionary`)이 갱신되면 → 단계 1 ambient baseline 파동 색깔/속도 같이 갱신. 다음 플레이어 들어올 때 *첫 1초에* 메모리 변화 보임.

**박을 자리**:
- 다른 세션 (백엔드 세션 A)이 emit 박는 이벤트 `lumen:dictionary-changed` 받음
- 받으면 ambient baseline 파동 *waveStyle 다시 계산* (재진입 안 해도 즉시 갱신)
- 또는 회차 시작 시점에만 갱신 (재진입 시 보임)

**추천**: 회차 시작 시점만. 즉시 갱신은 *너무 시각 자극*일 수 있음. V2-12 튜닝.

## 다른 세션과의 인터페이스 합의

본 세션이 받아야 할 신호 (다른 세션이 emit):
- `lumen:memory-entered` `{memoryId, baselineEmotionVec, motifDictionary}` — 메모리 진입 시. 단계 1 활성.
- `lumen:ghost-revealed` `{ghostVariantId, position, emotionVec}` — 유령 등장 시. 단계 2 활성.
- `lumen:player-position-changed` `{x, y, z}` — 매 프레임 (또는 throttle 100ms). 단계 2 거리 계산.
- `lumen:drift-pulse` `{resonance, durationMs?}` — 결 결정 시. 단계 3 변형.
- `lumen:dictionary-changed` `{key, oldValue, newValue}` — 모티프 사전 갱신 시. 보너스.

이벤트 시그니처는 본 세션이 결정 → 다른 세션 (A 백엔드 / V2-5 본 세션)에 알림. window CustomEvent 또는 runtime hook.

## 의존 자리

- 다른 세션 A (백엔드)이 이벤트 emit 박은 후 *연결*. 단 *코드는 먼저 박을 수 있음* — 이벤트 안 박혀도 모듈 자체는 박힘.
- 모티프 사전 컬럼 (`memories.meta.motif_dictionary`)은 다른 세션 C (DB)가 마이그레이션 박은 후 작동. 단 단계 1/2/3는 *모티프 사전 없이도* 작동.

## 검증 절차

1. **단계 1 단위 검증** — 메모리 진입 시 ambient 파동 보임 + 메모리마다 색 다름
2. **단계 2 단위 검증** — 발자국 메모리 진입 → 유령에 다가가면 spot wave 보임 + 거리 단계별 alpha 변화 확인
3. **단계 3 단위 검증** — 멀티턴 입력 → 응답 결마다 spot wave 변형 (밝아짐/떨림/요동) 확인
4. **통합 검증** — 다른 세션 박힌 후 풀 사이클 (gateway → b 매치 → b 다가감 → 멀티턴 → 회차 끝) 한 번 박고 4채널 (카메라 + 사운드 + 메아리 단어 + 파동) 정합 확인. V2-12 자리.

## 결정할 자리

본 세션 시작 전 사용자에게 받을 답:

1. **단계 1/2/3 다 박나? 단계 빼나?** (예: 1만 박고 2/3은 V2-12)
2. **메모리 평균 감정 어디서 받나?** (위 추천: (나) 런타임 평균)
3. **유령 위치 어디서 받나?** (위 추천: (다) 자동 배치)
4. **거리 단계 임계 시드값 OK?** (멀 10m+ / 중 5~10m / 가까이 5m 이하)
5. **닮은 정도 점수 결마다 변형 어휘 OK?** (공명 = 밝아짐 300ms / 모호 = 혼돈 700ms / 충돌 = 요동 1200ms)
6. **보너스 박나?** (모티프 사전 갱신 시 baseline 갱신)
7. **새 모듈 박나? `Visualizer.js`에 메서드 추가?**
