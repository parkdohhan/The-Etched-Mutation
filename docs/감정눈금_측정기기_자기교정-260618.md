# 감정 눈금 — 측정 기기로서의 자기교정 (TODO)

## 0. 맥락
지형 매트릭을 손보려다 "감정을 어떻게 표현하나(1번 입력)"를 깊이 팠고, TEM이 단순 작품이 아니라 **감정·기억을 재는 측정 기기**이기도 하다는 사용자 스탠스가 확정됨. 그 결과 감정 라벨 = 측정 기기의 눈금이라는 정의가 나왔다.

## 1. 스탠스 (중요 — 구성주의 아님)
- 감정 라벨이 "객관적 진실일 필요 없다"는 **구성주의적 프레임은 거부**한다(2026-06-18 사용자 명시 교정).
- **측정 실재론**: 객관적 감정 구조에 *완전 도달*은 불가능하지만, 그것을 **규제적 이상(regulative ideal)**으로 삼아 끊임없이 향해 정밀화한다.
- 비유 = 온도계. 참값 도달은 못 해도 표준에 교정하고 보정한다. "참값 없으니 눈금 맘대로"가 아니다.

## 2. 골격 — 베이지안 재교정(Bayesian recalibration)
1. **prior** = 외부 검증 분류체계(NRC-VAD 좌표 등)를 초기 눈금으로 부트스트랩.
2. **데이터** = 사용자가 입력한 감정 + 그 궤적(별이엔진이 모음).
3. **posterior** = 데이터로 보정된 눈금. 데이터 적으면 외부 체계 지배(안전), 많을수록 우리 모집단의 실제 구조로 수렴.
- "도달 못 해도 향해 간다"의 수학적 형태.

## 3. 반드시 지킬 안전장치 3
1. **순환성 탈출** — 사용자 *자유 입력* 필수. 우리 라벨 안에서만 받으면 자기 편향만 강화됨. 라벨 밖을 가리킬 통로가 있어야 신규 라벨을 발견. (`normalizeAnchor` 자유입력 허용이 이미 존재 — 출발점.)
2. **관성(inertia)** — 강한 prior + 느린 보정. 눈금이 휙휙 바뀌면 측정 일관성 붕괴. 데이터 신뢰도 가중. **generic 평균/EMA로 때우지 말 것.**
3. **층 구분** — 좌표 미세보정(쉬움/안전) vs 라벨 추가·병합(어려움/신중, 강한 증거 필요).
