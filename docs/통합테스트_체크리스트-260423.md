# TEM Lumen 통합 테스트 체크리스트

**날짜**: 2026-04-23
**목적**: 지금까지 만든 거 한 바퀴 돌면서 버그 찾기. 오늘 코드 수정 금지.
**소요 예상**: 3~5시간 (천천히 꼼꼼히)

---

## 이 문서 사용법

1. 위에서부터 아래로 순서대로 진행.
2. 각 체크박스 `- [ ]` 를 실제로 해본 뒤 `- [x]` 로 바꿈.
3. 이상한 거 발견하면 **맨 아래 "버그 기록" 섹션에 즉시 적기**. 고치지 말고 계속 진행.
4. 심각도 표시:
   - 🔴 **심각** — 진행 불가능 / 튕김 / 저장 실패 / 개념 자체가 안 돌아감
   - 🟡 **보통** — 작동은 하는데 이상함 / 원복 안 됨 / 연출 어색
   - 🟢 **사소** — 오타, 색 살짝 이상, 한 프레임 깜빡임

**"original_reason_vector" 섹션.** 3+4 = 7 슬라이더.

- [ ] 합계 표시가 실시간으로 바뀌는가? (보통 합계 라벨이 있음)
- [ ] 합계가 1이 안 나오면 **"정규화" 버튼** 눌러서 1 만들기
- [ ] 정규화 후 합계 표시가 1.000 인가?

### A-5. 오염 초기 상태 (12-1)

- [ ] **cont_depth** range 슬라이더를 `2` 쯤으로
- [ ] **cont_divergence** / **convergence** / **heterogeneity** 3 슬라이더 아무렇게나

### A-8. 씬별 AF picker (12-2)
