## Wave 3 — 상용 심화 (feat(ADM3) + 마이그레이션 커밋 분리)

- **I. 마이그레이션 1건** `202607170001_admin_trash_and_versions.sql`:
  ```sql
  ALTER TABLE memories ADD COLUMN IF NOT EXISTS deleted_at timestamptz;
  CREATE TABLE IF NOT EXISTS admin_versions (
    id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    memory_id uuid NOT NULL REFERENCES memories(id) ON DELETE CASCADE,
    snapshot jsonb NOT NULL,          -- {memory, scenes[], choices[]}
    note text,
    created_at timestamptz DEFAULT now()
  );
  ALTER TABLE admin_versions ENABLE ROW LEVEL SECURITY;
  CREATE POLICY admin_versions_auth_all ON admin_versions
    FOR ALL TO authenticated USING (true) WITH CHECK (true);
  ```
  원격 apply + 저장소 파일 동시(드리프트 금지, W2 판례).
- **J. 휴지통 (F6)**: 삭제 버튼 = **soft-delete**: `deleted_at=now()` + `is_public=false`
  (행 보존 — play-test 는 공개 해제로 자연 숨김, play-test 무수정). 목록 기본 필터
  `deleted_at IS NULL`. "휴지통" 보기 토글 → 복원(deleted_at=null, is_public 은 **수동** —
  자동 재공개 금지)·영구 삭제(confirm 2단, 기존 hard delete 경로). Canvas 선택기·검색도
  휴지통 제외.
- **K. 판본 이력**: `saveMemory` 성공 직후 스냅샷 {memory row, scenes[], choices[]} 를
  admin_versions INSERT, 기억당 최근 **20개** 유지(초과분 삭제). 편집화면에 "판본" 패널
  (시각·note) + [이 판본으로 복원]. **복원 = 스냅샷을 편집기 상태로 로드 → saveMemoryGraph
  경유 저장** (직접 DB 쓰기 금지 — plays·씬 id 보존이 생명). 복원 직전 현재 상태도 스냅샷
  (note='복원 전 자동'). 복원 후 검증: 씬 id·plays 수 불변 SELECT (보고서에 실측).
- **L. 자동저장 (F7)**: 편집 변경 시 디바운스 30초 localStorage 임시본(기억 id 키).

## 실기 검증 의무 (보고서의 심장)

시험 기억 1개로: ① 저장 → 잔류+토스트+목록 즉시 반영 ② 접기/목차 점프 ③ ghost_name
저장·재로드 왕복 ④ 휴지통: 삭제→목록 소실→휴지통 복원→재등장 (is_public false 유지 확인)
⑤ 판본: 수정 2회→이전 판본 복원→**씬 id·plays 수 불변 SELECT** ⑥ 자동저장: 입력→새로고침
→배너→복원 ⑦ choices 2개 입력→저장→emotion_dist 재계산 확인 ⑧ 시딩→관객 인구 쿼리 불변.
각 항목 스크린샷 또는 SELECT 결과. 종료 후 시험 기억+시딩+판본+임시본 전량 삭제, 잔재 0.
