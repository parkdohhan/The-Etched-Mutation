## 0. 한 줄

지형은 **미리 차려놓고 가서 보는 콘텐츠가 아니라, 장면을 체험하고 난 그 자리에서 솟아오르는 흔적**이다. 한 사람의 체험이 다음 사람에게 지형째로 전해지며 계속 변형된다(소문·전언처럼). 작가의 첫 지형은 동작에서 사라지되, 박물관 표본으로 따로 보존된다.

## 2. 절차적 변인 — 두 종류 (지질학 비유)

지형을 빚는 변인을 둘로 나눈다. 6-18 메모(terrain_algorithm_direction)의 "(다)감정·시간·오염 → 지질과정"의 구현.

### 2.1 재료 변인 — 이 땅이 *무엇으로* 만들어졌나 (17축 감정 분포)
광물 성분에 해당. 장면의 17축 감정 분포 자체의 통계량에서 **연속 함수로** 뽑는다(룩업 표 없음):

- **쏠림 vs 흩어짐(엔트로피)** — 한 감정에 몰렸나 여러 감정에 퍼졌나 → 봉우리 하나 vs 복합 능선
- **VAD 투영** — Valence(솟음/패임), Arousal(거칠기/주파수), Dominance(안정 고원/불안정 첨탑)
- **양가성** — 상반 감정 공존(fear+joy 등) → 갈라진 단층/균열
- **강도** — 분포 전체 크기 → 지형 전체 높이 스케일

핵심: 17축을 VAD 3개로 **뭉개기 전에** 분포 원본의 구조(엔트로피·양가성)를 본다. "안 뭉갠 분포(색 비유)" 지시(6-18) 준수.

### 2.2 과정 변인 — 이 땅이 *어떻게* 빚어졌나 (별이엔진 궤적)
지질 작용(퇴적·침식·단층)에 해당. 별이엔진 출력이 그대로 작용으로 번역:

| 별이엔진 출력 | 지질 작용 | 땅 모양 |
|---|---|---|
| level 높음(가까이 감) | 퇴적 | 물려받은 땅 위에 곱게 쌓임 |
| level 낮음 | 침식 | 깎여나감 |
| shape 일치 | 나란한 층리 | 결이 가지런한 지층 |
| echo_follow | 퇴적층 | 결 따라 순하게 |
| contradiction | 단층·협곡 | 쩍 갈라짐 |
| displacement | 주향이동단층 | 옆으로 어긋나 미끄러짐 |
| avoidance | 카르스트 공동 | 비고 꺼짐(void) |
| fixation | 관입암맥·주상절리 | 한 자리만 수직 솟구침 |

같은 재료(17축)라도 과정(궤적)이 다르면 다른 땅 → 이본이 태어나는 메커니즘.

**수제 EMO_NOISE 표(감정 이름마다 손으로 박은 노이즈 설정)는 폐기.** 단 새 방식이 만든 지형과 나란히 대조하는 **검증용으로만 병행 보관**(사용자 결정 6-19).

## 3. 완전 릴레이 + 아카이브 분리

### 3.1 동작 루프 (완전 릴레이)
- 다음 체험자는 **직전 체험자가 끝낸 지형**을 물려받아 그 위에서 시작.
- 별이엔진도 **직전 체험자 궤적**과 비교해 alignment/transition_pattern을 냄.
- 따라서 지형과 비교 자가 **같은 좌표계** → 침식·퇴적이 물려받은 땅 위에 자연스럽게 적용됨.
- "거스름(contradiction)"은 작가가 아니라 **나에게 기억을 넘겨준 직전 사람에 대한 반응**이 됨. 소문·전언의 본질.

### 3.2 왜 비교 자를 작가 원본에 고정하지 않는가 (기각된 안)
지형은 릴레이로 표류하는데 비교 자만 작가 원본(0번)에 고정하면, 표류한 지형 좌표와 원본 좌표가 **달라서 침식·퇴적을 어디에 쌓을지 안 맞는다.** 그래서 비대칭 고정안은 기각(6-19). 동작은 한 좌표계(릴레이)로 일관시킨다.

### 3.3 작가 원본 = 보존 아카이브
작가의 첫 서술 지형은 동작에 끼지 않는다. **박물관 0번 표본**으로 따로 보존(언제든 꺼내 볼 수는 있음). 이로써 철학 기둥 둘의 충돌을 봉합:
- "회상은 원본을 덮어쓴다(Destructive Replication)" → 동작에선 원본이 사라진다
- "작가 원형 보존" → 아카이브엔 남는다

### 3.4 화석 (입자의 운명, 6-19 결정)
체험은 입자(파티클)로 발생해 물려받은 땅 위에 쌓이거나 깎인다(과정 연출). 안착하면 **높이값에 흡수되어 굳고 입자는 소멸**(화석). 개별 화석층 데이터는 남기지 않음 — 합쳐진 결과 지형 하나로 충분. base 메시는 건드릴 수단이 없고 이본은 파티클 레이어에만 사는 구조라, "원본 안 망가짐"이 코드 구조로 강제됨.

### 3.5 DB에 남는 것
- **작가 원본 아카이브** (영구 1개, 동작엔 안 씀)
- **최신 지형** (덮어씀, 1개)
- **최신 체험자 궤적** (다음 사람의 비교 자, 덮어씀, 1개)

중간 모든 체험자의 개별 지형·궤적은 버린다. 무한 누적 부담 0.

## 4. 철학 정합

| 기둥 | 정합 |
|---|---|
| Destructive Replication | 동작에서 원본이 덮어써져 사라짐 — 1번 작용 순수형 |
| 이본론 | 각 체험자가 직전 변형본을 받아 또 변형 → 판본이 끝없이 갈라짐 |
| 변이=부산물, 원형 보존 | 변이는 릴레이로 굴러가고, 원형은 아카이브에 박제 |
| Player sees fog | 미리 안 보여주고 체험 후 솟음 = "겪고 나서야 모양을 안다" |
| Record = first Play | 작가 첫 서술이 곧 첫 지형 생성. 생성 경로 단일화 |

## 5. 참인 동작 vs 아직 안 정한 연출 (경계 명시)

브레인스토밍 중 "세상이 원본과 견준다" 식의 과장이 있었음 — 걷어냄. 시스템에서 **참인 것**만:
- 체험자는 직전까지 변형된 지형을 물려받는다.
- 화면 표시가 없으면, 체험자는 그게 작가 원본인지 N번째 변형인지 **모른다**.
- 별이엔진은 내부적으로 직전 체험자 궤적과 비교해 alignment를 낸다.

**아직 안 정한 연출**: "물려받은 게 원본이 아니다"라는 걸 플레이어가 *느끼게* 할지 말지. 그런 감각을 주려면 별도 연출 장치가 필요하며 지금은 없다. 비었음을 명시.

## 8. v2 검토 노트 (2026-06-19, 평가 세션)

> 비전·철학 정합(§4·§5)과 재료/과정 분리 골격은 단단함. 단 **§7 "동결" 목록에 동결하면 안 되는 항목 두 개가 섞여 있음.** 아래 ①②는 동결 → **미정(재검토)** 으로 내려야 함. ③④⑤는 정합성 구멍.

### ① 🔴 §2.1이 자기 목표("안 뭉개기")를 위반 — distinctness FAIL 경로 잔존
- §2.1 재료 변인에 **VAD 투영이 그대로 포함**돼 있음. 직전 결정은 "모양 생성에서 17축→VAD 투영 단계 자체를 제거"였음(그 투영이 distinctness FAIL의 원인).
- 엔트로피·양가성 2개를 *추가*했을 뿐 VAD 투영을 *제거*하지 않음 → VAD 기여분에서 슬픔/죄책감 장면이 여전히 같은 점으로 뭉침. 완화일 뿐 해소 아님.
- 증거: §6 첫 항목 "projectToVAD 재활용" = FAIL 났던 투영 함수를 그대로 끌고 감. **선언("안 뭉갠 분포 준수")과 구현이 어긋남.**
- **고침:** VAD는 모양 변인에서 빼고 **위치(평면 배치)에만** 남김. 모양 = 엔트로피 + 양가성 + 17축 각 축→지질 동사(침강/융기/침식…)로만 구성.

### ② 🔴 "완전 릴레이"가 붕괴 방지·공명 재정의 없이 동결됨
- **(a) model collapse 위험:** 릴레이로 침식·퇴적 무한 누적 → N세대 뒤 작가 원본과 무관한 노이즈로 수렴. 이는 deep-research에서 확인한 "telephone game / 모델 붕괴"와 동일 현상. §4는 이를 "이본 갈라짐"으로 *긍정*만 함 — 통제 없으면 이본(재창조)이 아니라 **열화**(이본론이 부정하는 것)로 무너짐. **원형 복원력 또는 세대 제한 등 붕괴 방지 장치 부재.**
- **(b) 공명 정의 흔들림:** 비교 자를 "직전 사람"으로 바꾸면(§3.1) alignment가 "원작자와의 공명"이 아니라 "직전 낯선 사람과의 공명"이 됨. **트루엔딩(=작품 핵심 정서 도달=공명)의 정의·trajectory_bridge와 충돌 가능.** "누구와 공명해야 트루엔딩인가"가 미해결.
- §3.2의 비대칭 기각 논리(표류 지형 vs 고정 비교자 좌표 불일치)는 옳으나, 그 결론이 (b)를 *생성*함 — 부작용 미인지.

### ③ §3.4 화석 vs base 모순
- "base 메시 못 건드림(원본 안 망가짐)"인데 §3.1은 "물려받은 땅 위에 변형". **물려받는 게 base냐 파티클 레이어냐 미정.** base면 화석이 원본을 바꾼 것(§3.4 위반), 파티클 레이어면 무한 누적 부담. 정의 필요.

### ④ 동시 플레이어 미처리
- §3.5 "최신 지형 1개 덮어쓰기" → 두 사람이 동시에 같은 기억 시작 시 서로 덮어써 **한 명 체험 증발.** 릴레이를 단일 사슬로 가정하나 실제 플레이는 병렬. 동시성 정책 없음.

### ⑤ "언제 굳히나"는 입자 단위만 답함
- §3.4 화석으로 입자 굳힘 타이밍은 정의됨(good). 단 **플레이 도중 같은 장면 재방문(귀환 시퀀스) 시 그 장면 땅이 그새 변하는지** 미명시. §6의 "transition_pattern→거리 EMA를 릴레이에서 어떻게"와 연결되나 미해결.

### 작업 순서 (검토 결론)
1. **§2에서 VAD를 모양 변인에서 제거** (구멍①, 최하위 토대).
2. **지배 감정 5~6개 → 지질 동사 매핑, 실제 distinctness 갈라지는지 숫자로 측정** (이게 통과해야 §2가 "선언만"이 아니라 "진짜" 안 뭉갬).
3. 통과 후 릴레이(구멍②) 붕괴 방지 장치 + 공명 재정의 설계.
4. ③④⑤ 정합 메움.

## 9. 재생 굽기 모델 — 궤적의 지형화 수정 (2026-07-02)

> 배경: §2.2의 "별이엔진 출력→지질 작용" 표는 궤적을 **요약 통계**(level 스칼라 하나 + 패턴 라벨 하나)로
> 뭉갠다. 순서 정보가 형성에 안 들어가므로 `슬픔→분노→체념`과 `체념→분노→슬픔`이 같은 땅이 됨.
> 17축 분포를 입구에서 뭉개지 말자던 원칙을 궤적에 똑같이 위반한 것 (사용자 지적 7-02).
> **리트머스: 장면 순서를 섞어 구웠을 때 땅이 달라져야 궤적이 지형화된 것.**

### 9.1 전환 — 일괄 계산 → 재생(replay)
체험 종료 후 측정값을 한꺼번에 넣지 않고, **여정을 박자(장면) 단위로 순서대로 다시 틀며** 굽는다.
- **박자마다**: 그 장면의 입력 분포(안 뭉갠 17축)가 로브들을 융기시킴
- **박자 사이**: 직전→현재 **이동 벡터(delta)** 가 물길 침식을 굴림 — 방향=물의 방향, 크기=물의 세기
- **순서 비가환**: 이른 융기는 이후 모든 물에 깎임(옛 지층), 마지막 융기는 생생 → 순서가 지층으로 기록됨
- **void(침묵)**: 물도 융기도 없음 → 경로 단절·공백 (§2.2 avoidance→카르스트 자리의 대체 구현. 복류)
- **릴레이 합류**: 물은 이미 파인 골로 모이므로(양의 되먹임) 여정이 겹치면 골이 깊어짐. 별도 구현 불요

### 9.2 §2.2 표의 지위 격하
패턴 6종 라벨은 **별이엔진의 보고 언어**로만 남는다. 형성은 라벨 대신 **날것 delta**를 직접 소비.
협곡(contradiction)·수직 골(fixation)·공백(avoidance) 등의 모양은 재생에서 **창발**함 — §2.2 표는
"창발 결과가 이 결에 맞나"를 대조하는 검증용으로 유지.

### 9.3 로브 공간 (§8-① 준수 경계)
- 17감정은 조각 **내부 국소 공간**에 각자 고정 자리(로브)를 가짐. 배치는 친척표(감정 간 VAD 거리)에서 유도
- 융기(모양)는 분포 **전체**가 로브별로 각자 기여 — 안 뭉갬
- 분포의 무게중심 투영점은 **물길 경유점(waypoint)에만** 사용. 판단 금지·전역 VAD 평면 배치 아님
- 조각 사이 배치는 여전히 거리(퀼트)만 — "좌표 두 집 살림 청산" 유지

### 9.4 물 구현 — 물방울(droplet) 침식
표준 물방울 기법(운반 한도 · 침식/퇴적 · 증발 · 관성 · 반경 커널, **질량 보존 내장**) + 특수화 3:
1. **태어나는 자리** = 전이 경로 선분 위 (개수·에너지 ∝ |delta|)
2. **초기 방향** = 이동 벡터 (여정 방향이 첫 걸음을 새기고, 이후는 지형이 이어받음 — 관성 항)
3. **태어나는 순서** = 재생 순서
보조: 비탈 무너짐 패스(열 침식, 질량 보존). 난수는 씨앗 방식(플레이 id) → **같은 입력 = 같은 땅**
(결정론. DB에 높이맵 대신 입력만 저장해도 복원 가능).

### 9.5 물리 상수의 지위
운반한도·증발률·관성·침식/퇴적 속도·커널 반경 등 6개 내외. 폐기한 EMO_NOISE(감정별 수제 표)와 지위가
다름 — **전 감정·전 체험 공통의 물리 상수**(세상의 무르기). 의미는 전부 입력(분포·궤적)에서 옴.
1회 시각 보정 후 근거와 함께 고정.

### 9.6 검증
- **질량 로그**: 굽기마다 흙 총량 기록, 침식·무너짐 단계에서 보존되는지 확인 (어긋나면 버그)
- **셔플 리트머스**: 같은 장면들 순서만 섞어 굽기 → 높이맵 RMS 차이가 유의해야 통과 (§9 도입부)
- §8 작업순서 2(distinctness 관문)에 셔플 시험을 추가

### 9.7 시뮬레이터
`terrain-replay-sim.html` + `js/terrain-replay-sim-page.js` — **독립 페이지** (play-test/admin 불변, 롤백=파일 삭제).
재생 박자 스테핑 · 셔플 리트머스 · 릴레이 세대 · 질량 로그 내장. 여정 프리셋 5종(완만/널뛰기/고착/회피/격정→침잠).

### 9.9 젖은 땅 원칙 + 소급 변경 (2026-07-02 사용자 확정)

사용자 제안("3번째 조각이 생길 때 2번째도 바뀌게") 채택 — 단 **스케줄이 아니라 물리로**:

- **젖은 땅 원칙**: 체험 중에는 그 기억의 땅 전체가 **한 장의 젖은 점토**다. 조각(장면 영역)은
  개별로 굳지 않는다. **화석화(§3.4)는 체험 종료 시점에 한 번.**
  → v1의 "장면 = 각자 완결된 고유 지형"은 *화석화 이후*의 상태로 재정의. 체험 중에는 미고정.
- **소급 변경은 규칙이 아니라 물리**: "N번째가 생기면 N-1을 바꿔라" 같은 스케줄 금지(배선표의 재림).
  N번째 박자의 전이 물이 흐르다 앞 조각 영역에 닿으면 깎이고, 안 닿으면 안 바뀐다.
  바뀌는 순간이 우연적이어서 사건이 된다(변화 맹시 방지).
- **오프닝 정합**: 검은 공허 + 유령 → 첫 대화 종료 → 안개 해제는 **이번에 생성된 조각까지만**
  (Player sees fog 원칙 유지).
- **측정 정합**: 소급 변경은 저장물 수정이 아니라 **불변 박자 로그로부터의 순수 재계산**(재생 굽기).
  같은 로그 = 같은 땅. 드리프트 없음.
- 남은 연출 설계(§5의 빈칸): 변화 순간의 입자 연출 + 안개 해제 반경.
- **안개 v0 구현됨 (7-02)**: `js/ui/lumen_replay_fog.js` — 체험 시작 = 짙은 안개(플레이어+가까운 유령만),
  박자마다 전역 밀도가 한 겹씩 감쇠(clear + (start−clear)·decay^박자). 유령 = 기존 마네킹 시스템
  (접근 가능 핀마다 1구, 턴 전환 시 rebuild) 재사용 — 신규 배치 코드 없음.
  **정직 주석**: v0은 전역 밀도 단계 해제다. 진짜 "생성된 조각까지만" 공간 안개는 지형 셰이더
  마스크가 필요 — 미정 항목으로 유지.

### 9.10 실플레이 적용 기록 (2026-07-02, flag 기본 OFF)

§9 엔진을 실제 플레이에 연결. **켜기 전에는 어떤 경로도 변하지 않는다.**

- **provider**: `js/shared/tem_replay_terrain.js` (신규) — `computeAfTerrainFields`와 동일 계약의
  드롭인 높이 계산기. 재료=장면 17축 분포(로브 융기), 과정=플레이어 박자(전이 물길), 재생 순서 비가환.
  최초 굽기 = 작가 첫 서술 여정(sceneAF 순서) → 그 위에 이번 체험의 박자가 실시간으로 얹힘(젖은 땅).
- **hook 1**: `tem_af_strata_terrain.js` — `computeAfTerrainFields` 입구의 guarded block 하나
  (flag OFF → 원본 그대로, provider 실패 → 원본 폴백).
- **hook 2**: `play-test.html` — `insertPlay()` 상단에서 박자 기록(+ strata 떠 있으면 즉시 재굽기).
  두 제출 경로(processEmotionResult/finishScene)가 모두 insertPlay를 지나므로 한 곳으로 충분
  (진입점 전수 확인: index.html·demoFlow.js는 지형 미사용).
- **flag**: `localStorage.tem_replay_terrain='1'` 또는 URL `?replay_terrain=1`
  또는 콘솔 `TemReplayTerrain.setEnabled(true)`.
- **롤백**: ① flag 끄기(즉시) ② 코드 제거 = guarded block 1개 + insertPlay 블록 1개 + script 태그 1줄
  + 모듈 파일 삭제. 원본 지형 코드는 한 줄도 수정 안 됨(입구 분기만 추가).
- 등고선(2D)도 같은 computeAfTerrainFields를 쓰므로 flag ON 시 자동으로 일관됨.
- admin도 같은 함수 경유 — flag ON 상태의 admin 미리보기는 재생 지형을 보여줌(작가 확인용, 의도됨).

**퀼트 갱신 (7-02, provider v0.3)** — 사용자 지적("퀼트처럼은 못하냐")으로 단일 대륙 → 조각보 전환:
- 장면마다 자기 **조각(섬)** 이 공허 바닥(FLOOR −5) 위에 뜬다. 배치 = 여정 순서 사슬 + 기억별 씨앗 방향
  (감정 평면 아님 — **감정 좌표는 조각 안 로브에만**, 좌표 두 집 살림 청산 준수).
- 배치는 **세계 좌표 단위**로 계산 (해상도 독립 — 저해상도 굽기와 strata 굽기가 같은 조각 위치를 공유.
  격자 칸 단위로 했다가 굽기마다 조각이 움직이는 버그를 잡은 결과).
- 전이 물이 조각 사이 공허를 건너며 **이음새(퇴적 다리)** 를 꿰맨다 — 질량 보존이라 다리 재료는
  조각에서 깎인 흙 그 자체.
- `getPiecePos(memoryId, sceneId)` 노출 → play-test 핀 빌더가 이 좌표를 최우선 사용
  (**flag ON일 때 scene.meta.stage_position보다 조각이 우선** — 유령·핀·소리가 자기 조각 위에 섬. 의도된 우선순위).
- 검증: 핀 10개 전부 조각 중심과 거리 0, 높이맵에 이산 조각 10개 확인, 에러 0.
- 미반영: terrain-replay-sim.html 은 아직 조각 1개 내부 모델(§9 검증용) — 퀼트 미적용.

**플레이 플로우 확정 (7-02, 사용자 제공, provider v0.5)** — 조각보 = 정사각 판이 모서리를 맞대는
격자 패치워크(자기회피 걷기 배치), 판은 체험이 낳는다:
1. 공허 + 유령 — beginRun 시점엔 판 0장 (검은 안개, 유령 실루엣만)
2. 대화 종료(beat) → 그 장면의 판이 그 자리에서 태어남 (감정 로브가 새겨진 판)
3. 이번에 **열린(접근 가능) 장면의 판은 맨땅**으로 미리 솟음 — 유령이 설 터. 그 밖은 안개+공허
   (setAccessibleScenes, 턴 전환 시 갱신)
4. 열린 판에 들어가면 유령(기존 마네킹) — 대화 후 그 판에도 감정이 새겨짐
5. 궤적이 쌓일수록 물이 앞 판들을 되건드림 (젖은 땅, 비가환 재생)
6. **막다른 장면(접근 가능 0) 도달 → 안개 전체 해제(liftAll)** — 지나온 판들과 발자국
   (기존 lumen_footprints 자국)이 드러남
- 기술 노트: buildTerrain이 높이를 세로 20으로 정규화하므로 provider가 기준 범위(FLOOR~FLOOR+18)를
  선언해 공허가 산맥으로 뻥튀기되는 것을 방지. 스크립트 태그에 ?v= 캐시버스터 도입.
- 미정: "갈 수 없다"의 물리적 차단은 없음(안개·공허 연출 + 기존 접근 규칙의 chat 차단뿐),
  판 탄생 순간의 입자/융기 애니메이션.
