# 아카이브 = 사람 칸 결정 (2026-11-24)

> **2026-11-28 바뀜**: 칸의 단위가 사람에서 **기억**으로 바뀌었고(제목 큰 글씨 · 쓴 사람 작은 글씨), 이어 걷기는 꺼졌다. "걸어 본 기억의 주인만 보인다"도 내려서 올라온 기억 전부가 보인다. 순서·가명 규칙은 그대로다. 정본 = [[아카이브_기억칸_질문_결정-261128]].

## 무엇이 바뀌었나

ARCHIVE 메뉴는 이제 기억을 하나씩 늘어놓지 않고 **사람 칸**을 보여 준다. 칸 하나에는 `가명 · 기억 N`이 적힌다.
작가 의도는 "한 플레이어의 인생을 들여다보는 느낌"이다.

## 정한 것 (작가 결정)

| 자리 | 결정 |
|---|---|
| 이름 | **가명**으로 받는다. 기억 만들기(record-space)의 "올리기 전에" 장에 칸이 있고, 비어 있으면 올릴 수 없다. 로그인 아이디와 같으면 서버가 거절한다(`pen name is login id`). |
| 누가 보이나 | **이 브라우저가 한 번이라도 걸어 본 기억의 주인만** 보인다. 숫자 N은 그 사람이 올린 공개 기억 전체 개수다. |
| 누르면 | **그 사람의 첫 기억부터 올린 순서대로 이어서 걷는다.** 한 기억이 끝나면 메뉴로 가지 않고 다음 기억 입구로 간다. 마지막 기억이 끝나면 메뉴로 돌아간다. ESC → 나가기를 누르면 이어 걷기도 끝난다. |
| 작가 칸 | 대표 기억(UNDW-001, 영어 설정이면 UNDW-001-EN)이 작가 칸 하나가 된다. 표시 이름은 `js/shared/person_shelf.js`의 `AUTHOR_NAME`이다(지금은 "작가" / "the author"이고, 작가가 정하면 바꾼다). |
| 순서 | 최근에 기억을 올린 사람이 위에 온다. **기억 개수 순서로는 줄 세우지 않는다.** 개수 순서는 순위표로 읽힌다. |

## 정의

- **칸** = `memories.curator_id`가 같은 공개 우주 무대 기억(`meta.space_record`)의 묶음이다. 주인 칸이 비어 있는 기억(로그인 관문 전에 올라온 것)은 그 기억 하나가 칸 하나가 되고, 이름은 "이름 없는 사람"으로 보인다.
- **칸 이름** = 그 사람의 가장 최근 기억에 적힌 `meta.space_record.pen_name`.
- **걸어 봤다** = 이 브라우저의 `localStorage`에 `tem_walked:<기억 id>`(우주 무대 입장 시 기록, 데모·연습 걸음은 제외)나 `tem_first_play:<기억 id>`(그 기억을 직접 만든 사람)가 있는 상태.
- **이어 걷기** = `sessionStorage`의 `tem_shelf_chain` = `{ ids, at }`. 끝난 기억이 `ids[at]`일 때만 다음으로 넘어가고, 그 밖의 경우에는 지운다. 아카이브에 들어올 때도 지운다.

## 걸리는 자리

- `supabase/functions/record-space-seal` — `pen_name`을 받아서 검사하고 `meta.space_record.pen_name`에 적는다(서버 3번째 판으로 배포).
- `record-space.html`, `js/recordspace/main.js`, `css/record-space.css` — 가명 칸, 동의 문장 한 줄, 지난 가명 미리 채우기.
- `js/shared/person_shelf.js` (새 파일) — 칸 묶기, 걸어 봤다는 표시, 이어 걷기.
- `js/app/archive.js` (`renderShelves`, `openShelf`), `js/index.js` (ARCHIVE 메뉴 → `enterArchive({ shelves: true })`), `js/lib/i18n.js`·`index.html` (메뉴 설명).
- `js/spaceblank/main.js` — 입장할 때 걸어 봤다는 표시를 남기고, 끝나면 다음 기억으로, 나가기를 누르면 이어 걷기를 끊는다.

새 표 0개, 새 열 0개. `profiles`는 계속 본인만 읽을 수 있다. 아이디는 로그인에 쓰는 값의 절반이라 남에게 보이면 안 된다.

## 되돌리기

`js/index.js`의 두 곳을 `window.__archivePlayedOnly = true; enterArchive();`로 되돌리면 예전 "내가 들어간 기억" 목록으로 돌아간다. 가명은 기억 데이터 안에 남아 있어도 해가 없다.

## 아직 아닌 것

- 걸어 본 표시가 브라우저에 남기 때문에, 다른 기기에서는 칸이 비어 보인다.
- 옛 지형 무대(play-test) 기억은 칸에 들어가지 않는다. 우주 무대 기억만 들어간다.
- 가명을 나중에 바꾸는 화면은 없다. 다음 기억을 올릴 때 다른 가명을 쓰면 칸 이름이 그 가명으로 바뀐다.
