## 0. 한 줄

관객이 **제목 · 한 줄 · 장면(앞 토막·뒷 토막·떠 있는 말·묻힌 말)** 을 쓰고, 장면마다 **감정(또다른 나와 짧은 대화 → 17축 막대, 손으로 고침) · 조형물(글에서 그림 조리법을 받아 돌려 봄) · 소리(초안 → 소리)** 를 붙이고, 순서를 정하고, **동의 한 장**을 읽고 올리면, 기억·장면·**작가 순서 = 장부의 첫 실**이 한 번에 들어가고 곧 그 기억의 우주로 들어간다.

## 2. 흐름

1. `record-space.html` 을 연다. 검은 화면에 "한 기억을 놓아 두는 자리 / 기억 만들기"가 타자로 찍힌다. 장면 카드 하나가 이미 있다.
2. 제목, 한 줄 설명. 장면 카드: 앞 토막(글자 수 자), 뒷 토막, 떠 있는 말(쉼표), 묻힌 말(쉼표).
3. **감정 뽑기**: 앞 토막을 또다른 나에게 건네면(측정 1회) 감각 하나를 묻는다. 답할 때마다 측정(claude-scene, 맥락 없음 — 작가가 제 장면을 말하는 것이므로 "관객이 유령에게 건넨 말" 틀을 쓰지 않는다). 답 둘부터 "됐어"가 보이고, 다섯이면 저절로 닫힌다. 평균이 17축 막대로 서고, 끌어서 고칠 수 있다. "직접 정하기"는 대화 없이 막대만.
4. **조형물 만들기**: 앞 토막·뒷 토막·떠 있는 말·묻힌 말을 보내면 조리법(§4)이 온다. 카드 안의 작은 검은 틀에서 천천히 돈다(무대와 같은 해석기). "다시"는 방금 것의 한 줄 설명을 피하라고 보낸다. "빼기"면 무대에서 기둥 하나.
5. **소리**: 관리 화면의 두 단계 그대로 — 초안 문장(글에서) → 고쳐서 → 소리 만들기(ElevenLabs → scene_sounds 저장소). 그 장면에서만 난다(U12).
6. **순서**: 카드의 ↑ ↓. 첫 카드가 첫 장면. 끝 장면은 마지막 카드.
7. **올리기** → 동의 한 장(§5) → 체크 → "올린다" → 검은 화면에 "묻는 중……" → `record-space-seal` → "묻었어. 이제, 들어가 봐." → 우주 무대.
8. 무대: 걸음이 끝나면 `bake-room-layers`가 돌아 겹을 굽는다. 다음 관객이 돌아간 장면에서 둘째 겹을 읽는다.

연습: `?test=1` — 서버에 저장하지 않는다(대화·조형물·소리는 실제로 서버에 묻는다). 내용은 콘솔에.

## 3. 정의 (데이터 계약)

**memories** (새 컬럼 0)
- `title`, `description`, `status = 'nascent'`, `is_public = true`, `lang`, `curator_id`(로그인 시), `original_vector` = 장면 감정 평균, `cont_depth = 0`(굽기가 올린다)

- `meta.space = { b: [뒷 토막 줄들], words: [떠 있는 말], deep: [묻힌 말], thing: 조리법|null }` — 무대가 이미 읽던 자리(`partB`·`pieceLines`)

- `meta.record_space = { version, dialog: [{role, content}], measured: [vec…] }` — 증거 보존(어느 대화에서 그 벡터가 나왔나)
- `meta.motif_tags`, `meta.object_tags`

**plays — 작가의 첫 실** (새 컬럼 0)
- 한 `run_id`, 장면마다 한 줄, `created_at` 1초 간격(작가 순서가 그대로 시간 순서), `persona_id = 'room-author'`, `alignment = 1`, `user_emotion` = 그 장면의 작가 벡터, `dialog_turns = [{ stage: 'room_v1', place: 'space_v1', form: 'author_thread_v1', input_form: 'record_space_v1', visit: 1, order }]`
- 축적 모형(`topo.accumulate`)은 이 줄들을 다른 걸음과 똑같이 읽는다. `room-test` 만 뺀다. 굽기의 `runs`(= 깊이)에도 1로 센다. 글 겹의 재료(`raw_text`)는 없다.

**scenes.meta.room_text / stage_bake** — 굽기가 쓴다(§6).

## 4. 조형물 조리법 v1 (정의)

조리법 = `{ v: 1, h, note, parts: […], motion: […] }`. 한 걸음 화면의 문법 그대로: 어두운 면·밝은 모서리, 선은 가늘게, 호박색은 "관객이 가져온 것" 한둘뿐, dim 은 물러나는 것, blue/rust 는 드물게. 바닥 y=0 위에 서고, 1.2~3.5 높이, 4.5 상자 안.

부품: `box(size[w,h,d])` · `cyl(r[top,bottom], h, n)` · `ico(r, detail, scale)` · `cone(r, h, n)` · `stroke(pts…, closed)` · `oval(r[rx,rz], n)` · `glow(c, size, o)` · `profile(s, mirror)` · `garment(y)`. 각 부품 `at`(자리) `rot`(라디안) `m`(line|dim|amber|blue|rust).
움직임: `spin · bob · sway · ring · pulse · drift` (부품 번호 `i`, 세기 `v`, 폭 `amp`, 축 `axis`).

**같은 자(sanitize)가 세 군데에 있다** — `generate-scene-thing`(서버) · `record-space-seal`(서버) · `js/spaceplay/things.js sanitizeRecipe`(무대·미리보기). 모든 수가 범위로 잘리고(부품 28개, 점 64개, 움직임 12개 상한), 그릴 것이 없으면 null → 무대는 기둥 하나. **깨진 조리법은 깨진 무대가 아니라 심심한 조형물을 만든다.**

생성: Claude(sonnet)에 문법과 본보기 둘(UNDW 1번 욕조·3번 전화기)을 주고 JSON만 받는다. `temperature` 는 넣지 않는다(이 모델이 거절, 261123 첫 배포 502의 원인).

대표 기억(UNDW-001)의 열 개 조형물은 그대로 손으로 그린 것이다. `SETS[code][scene_order]` 가 있으면 그것, 없고 조리법이 있으면 조리법, 둘 다 없으면 기둥.

## 5. 연출 (어떻게 보이나)

- 화면 = 검은 한 열(글 방 토큰 `--rp-*`, Noto Serif KR 300), 머리글 타자, 카드는 위 선 하나로 나뉜다. 느리고 넓고 무겁게(260809): 전환 900~1800ms, 튐 없음.
- 감정 막대 17개: 값이 있는 축이 위로, 0인 축은 흐리게. 숫자는 Cormorant.
- 조형물 미리보기: 카드 안 4:3 검은 틀, 천천히 회전(0.22 rad/s), 화면 밖이면 그리지 않는다(WebGL 문맥 여럿).
- 동의 한 장(검정 0.985 + 흐림): 네 줄 그대로 —
  "이 기억은 공개돼. 누구나 걸을 수 있어." / "남의 걸음이 쌓이면 장면의 글이 바뀌어. 그 사람들 말이 들어와." / "니 순서대로 플레이 안 됨 ㅋ 첫 번째 실일 뿐임. 문은 엔진이 열어." / "네가 정한 순서는 첫 걸음으로 장부에 남아." — 작가가 준 말투를 그대로 둔다.
- 봉인: 검은 막 → "묻는 중……" → "묻었어. 이제, 들어가 봐." → 우주 무대 입구("지금부터 너는 한 기억을 떠올리게될거야" → 떠올린다). `from=record` 는 표식일 뿐, 입구는 그대로 선다(소리 자동 재생에 손 한 번이 필요).
- 떠나려 하면(글이 있는데 저장 전) 브라우저가 한 번 묻는다.

## 6. 무대 쪽 변경 (space-play · space-blank 둘 다)

1. **조리법 조형물** — `things.js`: `sanitizeRecipe` · `fromRecipe` 추가, `makeThing` 이 `scene.meta.space.thing` 을 읽는다.
2. **다시 갔을 때 겹 올라가기** — `stageText`: 첫 겹이 없으면 둘째·셋째 중 있는 겹으로 **올라간다**(전에는 원문으로 떨어졌다). 기억 만들기 기억은 첫 겹(`text_stage_1`)이 없어서, 이 한 줄이 없으면 다섯 명이 걷기 전엔 돌아가도 글이 그대로였다. 고정 길(rig)이 있는 기억은 `riggedStage` 가 덮어쓰므로 영향 없음.
3. **걸음 끝 굽기** — `finish()`에서 `bakeLayers()`: `meta.space_record` 기억만, 연습 걸음(`as=test`) 제외, 기다리지 않는다. 장부를 다시 읽어 오염 상태를 재생(`ContaminationTracker.replayFromPlays`)해 함께 보낸다.
4. 캐시 번호 `261123c`(두 html의 main.js, main.js 안의 things.js).

**bake-room-layers** = `tools/room-sim/bake_stage.mjs` 의 규칙을 서버로 옮긴 것: 둘째 겹 = 그 장면 줄 가운데 정렬 가장 높은 줄 + 가장 낮은 줄(다른 걸음)을 마지막 문장 앞에 끼움(60자 이하, 위기 낱말·반쪽 자모 제외). 셋째 겹 = 둘째 겹을 `contaminate-text` 과완결로 한 번. 깊이 = 방 장부의 걸음 수 → `memories.cont_depth`(내려가지 않음). `meta.space_record` 없는 기억은 403 — 손으로 지은 기억들의 겹과 도구는 그대로다.

## 7. PROFILE 재단장

- 마크업(`index.html #mypageScreen`)을 검은 한 열로 바꿨다. 채우는 코드가 보는 id 는 전부 그대로(`displayUsername` … `mypageNotesList`).
- 글: `js/lib/i18n.js` `profile.*` 열여덟 키(ko/en). 이 자리에 남은 것 / 처음 온 날 / 걸은 기억 / 남긴 걸음 / 내가 만든 기억 / 받은 말 / 나가기.
- 목록 줄(`js/app/auth.js`): 제목 · 날짜 · 걸음 N → 기억 만들기 기억은 "우주로 →"(space-play), 나머지는 "지형으로 →". 받은 말은 어느 기억에서 · 말 · 날짜, 안 읽은 것은 밝게.
- 스타일은 `css/profile.css` 한 파일, `#mypageScreen` 안에서만. 메뉴의 PROFILE 단추 숨김은 건드리지 않았다.

- 화면이 콘솔 오류 0으로 뜬다. 감정 뽑기: 또다른 나가 "그 우산들 색깔이 뭐였어?" 식으로 묻고, 답 둘에 측정 3회(본문 1 + 답 2), "됐어" 뒤 15축이 막대로 섰다. 직접 정하기 + 막대 끌기 동작. ↑로 순서 바꾸면 번호·첫 장면 표시·상태 줄이 따라온다.
- 조형물: "비 오는 날 현관의 우산 셋" → 13부품(우산 셋, 하나 호박색, 바닥 판, 물방울 빛) — 카드 미리보기와 무대(peek) 둘 다 같은 모양. 둘째 장면 9부품(빈 우산걸이, 바닥 자국 셋).
- 소리: 초안 문장(영어) → 소리 파일 → `scene_sounds/record-space-<id>/…mp3`.
- 연습 올리기(`?test=1`): 저장 없이 콘솔에 내용. 실제 올리기: `memories` 1(nascent·public·`space_record`·motif 6) · `scenes` 2(`space.b` 3줄·`thing`·`object_tags`) · `plays` 2(`room-author`, 같은 run, 1초 간격, order 1→2) → 우주 무대로 이동 → 입구 → 둘러보기(peek)에서 조형물 둘이 서 있고 지도에도 둘.
- 굽기 장치: 걸음 0인 새 기억에 돌리면 `runs 1 · depth 1 · written 0`(재료 없음이 정상), `cont_depth` 0→1.
- 시험 기억은 확인 뒤 지웠다(공개 목록을 어지럽히지 않게). 만드는 데 3분이면 된다.

**확인 못 한 것**
- 실제 관객 걸음이 쌓인 뒤의 굽기(둘째 겹에 남의 말이 들어가는 것) — 재료가 없어 규칙만 옮겨 적었다. 도구(`bake_stage.mjs`)와 같은 식이지만 안전 필터는 낱말표만 옮겼다(`safetyForAbsorb` 는 안 옮김).
- 소리가 무대에서 그 장면에서만 나는지(저장 자리는 같은 `meta.sound_url`).
- 영어 화면(`?lang=en`) 전체, 휴대폰 너비, 로그인한 채 올릴 때 `curator_id` 가 붙는지(같은 저장소 세션이면 붙게 되어 있다).
- PROFILE 은 로그인 없이는 열리지 않아 채워진 화면은 가짜 줄로만 봤다.
- 빈칸 가지(space-blank.html)에서 이 기억을 걷는 것 — 같은 데이터를 읽으므로 되게 되어 있다.

## 10. 남은 결정 (작가)

1. 메뉴에 언제 올리나(지금은 주소로만). 올릴 때 RECORD 단추를 이 화면으로 돌릴지, 옛 대화 RECORD(v4)와 나란히 둘지.
2. 또다른 나의 말투(반말 "~였어?")가 작가 자신에게 묻는 자리에도 맞는지.
3. 조리법에 **사람**을 어떻게 그리게 할지(지금은 기둥 몸 + 다면체 머리 하나뿐). 얼굴은 옆모습 한 줄만.
4. 사진 자리(보류) — 넣는다면 우주가 아니라 글 방의 길 양옆.
5. 굽기의 때 — 걸음마다(지금) 대로 둘지, 몇 걸음마다로 늦출지(글 겹이 너무 자주 바뀌면 "돌아갔더니 또 달라져 있었다"가 매번이 된다).
