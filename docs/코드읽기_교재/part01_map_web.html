더블클릭하면 검은 창이 뜨고 브라우저가 열립니다. 그 사이에 일어나는 일은 딱 두 줄입니다.

읽는 법
  • node는 자바스크립트를 브라우저 밖에서 돌려주는 프로그램입니다. 4번째 줄은 "node야, tools/serve.cjs 파일을 돌려라, 첫 페이지는 index.html 로" 라는 뜻.
  • 서버란 거창한 게 아닙니다. 브라우저가 "index.html 줘" 하면 폴더에서 찾아 건네주는 심부름꾼입니다. PORT = 8777은 그 심부름꾼이 서 있는 문 번호. 그래서 주소창이 localhost:8777로 시작합니다.
  • 주석 1번째 줄의 "의존성 0"은 "남의 부품을 안 빌렸다"는 뜻. 이 파일은 node 만 있으면 돕니다.
파일 이름을 들으면 폴더부터 봐라. js/core/면 판단, js/ui/면 연출, supabase/면 서버, docs/면 문서. 이 네 글자만 봐도 "무엇이 바뀌었을 수 있는가"의 범위가 정해진다.

html: 상자 속 상자

메뉴 화면의 뼈대입니다. 실제 파일에서 그대로 잘라 왔습니다.

index.html : 144~152, 168~169 
<div class="intro-screen main-menu-intro" id="introScreen">
    <div class="main-menu-wrap">
        <div class="bg-image"></div>
        <div class="left-gradient"></div>
        <div class="main-content">
            <div class="main-sidebar">
                <div class="main-header">
                    <h1>THE ETCHED<br><span>MUTATION</span></h1>
                <div class="menu-list" id="mainMenuList">
                    <div class="menu-item active" data-menu-id="play" data-action="enterPlayInterview">
읽는 법
  • 꺾쇠 한 쌍이 상자 하나. <div>로 열고 </div>로 닫습니다. 사선(/)이 있으면 닫는 쪽. 안에 다른 상자가 들어가고, 들어갈수록 오른쪽으로 밀려 적힙니다(6장의 들여쓰기와 같은 원리).
  • id = 이름표, 한 화면에 하나뿐. id="introScreen"은 "이 상자 이름은 introScreen". 자바스크립트가 이 이름으로 찾아옵니다.
  • class = 종류표, 여러 상자가 같이 가질 수 있음. class="menu-item active"는 종류표 두 장("메뉴 항목"이면서 "켜진 상태"). css가 이 종류표를 보고 옷을 입힙니다.
  • data-… = 자바스크립트에게 남긴 쪽지. data-action="enterPlayInterview"는 "이걸 누르면 enterPlayInterview 를 하라"고 코드가 읽을 쪽지. 이 프로젝트 메뉴는 전부 이 방식입니다.
  • <h1>은 큰 제목 상자, <br>은 줄바꿈(닫는 짝 없음), <span>은 글자 일부만 감싸는 작은 상자.

css: "누구에게" + "무엇을"

css/index.css : 1~8, 4269~4271 
:root {
  --bg-deep: #0a0a0c;
  --bg-surface: #12121a;
  --text-primary: #e8e4df;
  --text-muted: #6b6b7b;
  --accent-memory: #c4a882;
  --accent-interpretation: #7b8fa8;
}

.hidden {
  display: none !important
}
읽는 법
  • css 한 덩어리는 항상 "누구에게 { 무엇을: 어떻게; }" 모양입니다. 10번째 줄: .hidden(종류표가 hidden 인 상자들에게) display: none(보이지 마라).
  • 앞의 점(.)은 class, 앞의 우물 정(#)은 id를 가리킵니다. .hidden은 종류표, #selectScreen은 이름표.
  • !important는 "다른 규칙과 부딪혀도 이게 이긴다". 이 프로젝트에서 화면을 확실히 숨길 때 씁니다.
  • 1번째 줄 :root 안의 --이름: 값은 색 이름표입니다. --accent-memory가 기억의 금색. 다른 곳에서 var(--accent-memory)라고 쓰면 이 색을 꺼내 씁니다. 색을 한 군데서 바꾸면 전체가 바뀌게 한 장치.
  • #0a0a0c 같은 것은 색을 숫자로 적은 것. 앞 두 자리 빨강, 가운데 초록, 뒤 파랑. #0a0a0c는 거의 검정.

세 겹이 서로를 찾는 방법

이 프로젝트의 화면 전환은 거의 전부 한 가지 동작입니다. 자바스크립트가 id로 상자를 찾아 → class(종류표)를 붙이거나 떼면 → css 가 보이거나 숨긴다. 실제 코드에서 그 세 줄을 보겠습니다.

js/index.js : 377 (restart 함수 안, 일부) 
const introScreen = document.getElementById('introScreen');
if (introScreen) { introScreen.classList.remove('hidden');
                   introScreen.classList.add('visible'); }
읽는 법
  1. document.getElementById('introScreen') = "문서에서 이름표가 introScreen 인 상자를 찾아와". 2장 첫 코드의 1번째 줄, 바로 그 상자입니다.
  2. if (introScreen) = "찾았으면"(못 찾으면 아무것도 안 함). 이 프로젝트 코드에 이 문지기가 수백 번 나옵니다. 없으면 오류로 멈춥니다(14장).
  3. classList.remove('hidden') = 종류표 hidden 을 뗀다 → css 의 .hidden 규칙이 더 이상 안 붙음 → 보인다. classList.add('visible') = 종류표 visible 을 붙인다.

즉 html 이 이름을 달고, js 가 이름으로 찾아 종류표를 바꾸고, css 가 종류표를 보고 옷을 갈아입힙니다. 이 삼각형만 알면 "메뉴가 안 사라져요" 같은 문제를 어느 겹에서 찾을지 정할 수 있습니다.

겹을 불러오는 줄: link 와 script

index.html : 15, 17, 599, 612 
<link rel="stylesheet" href="css/index.css?v=260714">
<link rel="stylesheet" href="css/tem_cursor.css?v=260809">
<script src="js/ui/strataSection.js?v=260714"></script>
<script type="module" src="js/index.js?v=260909c"></script>
읽는 법
  • <link rel="stylesheet" href="…"> = "저 css 파일을 옷으로 입혀라". <script src="…"> = "저 js 파일을 신경으로 붙여라". html 파일이 다른 두 겹을 여기서 끌어옵니다.
  • ?v=260809 는 캐시버스터. 날짜를 적어 두고, 파일을 고치면 이 숫자도 올립니다. 안 올리면 브라우저가 "전에 받아둔 옛 파일"을 계속 씁니다. 이 저장소에서 여러 번 사고가 났고, 12장에서 따로 다룹니다.
  • type="module" 이 붙은 script 와 안 붙은 script 는 서로 이름을 못 봅니다. 이것도 12장.
play-test.html 은 세 겹이 한 파일에 다 들어 있습니다(안에 <style> 수백 줄, <script> 수천 줄). 그래서 30만 바이트, 8천 줄이 넘습니다. 파일 하나가 크다고 겁먹을 것 없습니다. 안에서도 세 겹은 그대로고, 18장의 "큰 파일 지도" 기술로 다룹니다.
