## 1. 최종 목표 (Terminal Goal)

### 1.1 정식 진술

**인류 집단 기억의 염기서열화 및 새로운 서열 생성.** 기억의 변형 연산(기억유전학 v0.3 §2의 6연산)을 데이터에서 자동 판정할 수 있는 규칙으로 환원하고, 이 규칙으로 인간 집단의 기억 체험 궤적을 이산·연속 결합 서열로 표기(sequencing)하며, 이 서열 공간 위에서 새로운 서열을 합성(generation)하는 수학적·계산적 파이프라인을 구축한다.

### 1.2 기초과학 연구 단위로 규정하는 근거

예술 작품 단위가 아닌 이유: 최종 산출물의 검증 조건이 "관객 반응" 또는 "비평적 수용"이 아니다. 생성된 서열이 (a) 기존 서열 분포와 같은 함수 패밀리에 속하는가(§1.3 기준 1), (b) 적응도 함수에 대해 예측적인가(§1.3 기준 2)로 판정된다. 이는 quasispecies 이론이 바이러스 진화를 판정하는 방식과 동일한 구조의 반증 가능성을 갖는다.

플랫폼 단위가 아닌 이유: 목표가 "서비스 채택률"이 아니라 "서열 공간의 식별"이다. TEM은 이 목표를 위한 데이터 생성 인프라이지, 목표 자체가 아니다.

### 1.3 검증 조건

최종 목표가 "달성됐다"는 판정은 다음 둘 중 하나 이상이 충족될 때 성립한다.

1. **함수 패밀리 일치**: 수집된 인간 기억 체험 서열의 주요 분포 속성(heterogeneity 누적 곡선, divergence 포화 곡선, convergence 스케일링) 중 3개 이상이 quasispecies 이론이 예측하는 함수 패밀리와 일치한다(95% CI 내 기각되지 않음). 비교 기준: [docs/기억유전학_v0.3.md](../기억유전학_v0.3.md) §12.2, §13.4의 기질-비의존적 속성 4종.
2. **생성물의 외부 판정**: 파이프라인이 합성한 서열이 제3자 평가(패널 또는 기계 판정)에서 인간 생성 서열과 구분되지 않는 비율이 우연 수준을 넘는다. 비율과 패널 구성은 §6 Q12 참조.

이 문서는 "증명"이라는 표현을 사용하지 않는다. 위 두 조건은 반증 실패 조건이다.

## 2. 역산된 5단계 (Backward Chaining)

### 2.0 단계 순서의 논증

순서는 임의가 아니다. 각 단계의 선행 조건이 직전 단계의 산출물이다.

- **1 → 2**: 6연산이 데이터 레벨에서 구별되는 결정 규칙으로 환원되지 않으면, 측정 도구는 정의 안 된 양을 측정한다. 조작적 정의 없이 만든 메트릭은 사후 해석 변경에 취약하다.
- **2 → 3**: 종단 프로토콜의 스키마는 측정 도구가 무엇을 요구하는지에 의해 결정된다. 데이터가 축적된 뒤 스키마를 바꾸면 소급 적용 불가한 손실이 발생한다.
- **3 → 4**: 레퍼런스 코퍼스(BLOSUM-유사 전이 행렬, HIV 계통역학 메트릭 등)와의 비교는 비교 대상이 충분한 규모일 때만 통계적으로 성립한다. 합성 사용자 파이프라인도 실제 데이터가 있어야 보정 기준이 생긴다.
- **4 → 5**: 생성 모델의 아키텍처 선택은 입력 공간의 함수 패밀리에 의존한다. 함수 패밀리가 식별되지 않은 상태에서 모델을 고르면 귀납 편향(inductive bias)이 임의로 주입된다.

### 2.1 단계 1 — 6연산의 조작적 정의

- **목표**: 6연산 각각을 TEM `plays` 테이블의 결정 규칙(decision rule)으로 환원한 규칙집과, 이 규칙의 자동 판정 출력이 수동 레이블과 일치함을 보인 검증 세트
- **측정 가능한 산출물**:
  - 규칙 문서: 각 연산당 (a) 입력 필드, (b) 임계, (c) 예외 처리, (d) 근거 인용([docs/기억유전학_v0.3.md](../기억유전학_v0.3.md) §2, [docs/TEM_시스템_매뉴얼-260410.md](../TEM_시스템_매뉴얼-260410.md) 해당 절)
  - 자동 판정 스크립트: 기존 `ContaminationTracker`·`ByeoriEngine`의 출력에서 6연산 레이블을 생성
  - 검증 세트: 최소 30개 plays에 대한 수동 레이블, 자동 판정과의 Cohen's κ ≥ 0.7(목표치)
  - 한계 문서: 현재 데이터로 구별 불가능한 연산 쌍을 명시(예: Op 1과 Op 5의 초기 시그널은 동일 가능, v0.3 §2 논의)
- **선행 조건**:
  - TEM `plays` 스키마가 현재 수준으로 안정화되어 있음 ([docs/데이터계약_브릿지_v1-260412.md](../데이터계약_브릿지_v1-260412.md) 기준)
  - 페르소나 시뮬 293 plays ([docs/paper/TEM_paper_draft_v0.1-260419.md](../paper/TEM_paper_draft_v0.1-260419.md) §6.1) 또는 파일럿 데이터
- **예상 소요**: 6–12개월. 학부 잔여 기간 내 수행 가능.

### 2.2 단계 2 — 측정 도구

- **목표**: 6연산과 오염 4축(depth·divergence·convergence·heterogeneity)을 독립적으로 계산하는 분석 스크립트, 각 스크립트의 단위 테스트, v0.3 §13.4의 4가지 기질-비의존적 검증 항목 중 최소 2개의 실행 결과
- **측정 가능한 산출물**:
  - 분석 라이브러리: 입력 `plays`→출력 `(ops[], axes{})`의 재현 가능 파이프라인
  - 단위 테스트: 합성 데이터(페르소나 파이프라인) 기준으로 각 축의 기대 분포 재현
  - 검증 리포트: v0.3 §13.4 항목 중 (1) 분자시계 포화 곡선 형태 비교, (2) BLOSUM 유사 금지 구역 비교 — 중 2개 이상의 실행 결과를 단일 아티클 초안으로
- **선행 조건**: 단계 1 완료. 특히 Cohen's κ ≥ 0.7 충족 없으면 측정 도구가 정의되지 않은 양을 측정하므로 진입 금지.
- **예상 소요**: 6–12개월. 단계 1과 일부 병행 가능(규칙 설계와 스크립트 스텁을 같은 iteration에 두는 경우).

### 2.3 단계 3 — 종단 데이터 수집 프로토콜

- **목표**: 동일 체험자의 장기 반복 방문 데이터 수집 설계, IRB 승인, 최소 N과 관찰 기간 확정, 데이터 계약 문서
- **측정 가능한 산출물**:
  - IRB 승인서 (소속 기관 결정 후 — §6 Q3 참조)
  - 프로토콜 문서: 최소 N, 재방문 간격, 중도 이탈 처리, PII 필터링 규칙
  - 수집 시스템: 기존 TEM 인프라 위의 종단 인덱스(session_id 체인, 재방문 식별), [docs/안전_설계-260324.md](../안전_설계-260324.md)의 block_high/mid 규칙 유지
  - 최종 데이터셋: N≥30, 최소 6개월 관찰 (§6 Q4의 N 결정 기준 참조)
- **선행 조건**: 단계 2의 측정 도구가 안정화되어 있어야 스키마를 고정할 수 있다. IRB 심사에는 측정할 양의 정의가 요구되므로 단계 2의 검증 리포트가 사실상 심사 자료.
- **예상 소요**: 18–36개월. 박사 과정 내 수행. IRB 심사·모집·관찰 기간이 소요의 대부분.

### 2.4 단계 4 — 레퍼런스 코퍼스 구축

- **목표**: 기억 서열과 비교 가능한 분자적 레퍼런스 데이터의 확보, 합성 사용자 파이프라인의 외적 타당성 보강 결과, 두 경로의 교차 검증 문서
- **측정 가능한 산출물**:
  - 분자 레퍼런스: BLOSUM 치환 행렬, HIV 계통역학 공개 데이터(LANL 가용성은 §6 Q5) 또는 대체 레퍼런스(§6 Q6), 분자시계 공개 데이터셋 — 각각 TEM 데이터와의 매핑 테이블
  - 합성 사용자 보강: 페르소나 파이프라인(IPIP-NEO-300 기반, 현 293 plays)을 단계 3의 실제 인간 데이터와 교차 비교한 보정 리포트, LLM 편향 감사 프로토콜([docs/paper/TEM_paper_draft_v0.1-260419.md](../paper/TEM_paper_draft_v0.1-260419.md) §7.2 후속)
  - 교차 검증: 분자 레퍼런스와 TEM 실제 데이터, 합성 데이터 세 축의 함수 패밀리 일치도 리포트
- **선행 조건**: 단계 3의 실제 인간 데이터. 이 데이터 없이 합성 파이프라인만으로 레퍼런스 비교를 하면 LLM 편향이 비교 대상에 이미 주입된다.
- **예상 소요**: 24–48개월. 박사 중후반. 분자 데이터 전처리·재현이 주요 병목.

### 2.5 단계 5 — 생성 모델

- **목표**: 수집·식별된 서열 공간 위에서 새로운 서열을 합성하는 모델의 아키텍처 후보 비교, 최소 1개 구현 프로토타입, 생성물 평가 프로토콜
- **측정 가능한 산출물**:
  - 아키텍처 비교 문서: 후보군과 선택 근거. 후보 예시(이 순서는 확정 아님): (a) 이산 토큰+연속 감정 벡터를 위한 VAE, (b) 상태공간 모델(SSM), (c) quasispecies ODE 위의 학습된 적합도 함수 — 각 후보에 대해 입력 서열의 함수 패밀리(단계 4 산출물)와의 정합성을 기준으로 평가
  - 프로토타입: 재현 가능한 학습·평가 파이프라인. 논문 드래프트 수준의 산출물
  - 평가 프로토콜: §1.3의 두 검증 조건을 생성물에 적용하는 구체 절차. 제3자 판정 구성 및 prior(§6 Q12)
- **선행 조건**: 단계 4의 교차 검증 리포트. 함수 패밀리 미식별 상태에서의 모델 선택은 귀납 편향이 임의로 주입되므로 진입 금지.
- **예상 소요**: 24–60개월. 박사 후반–포닥. AlphaFold 유형의 분자 구조 모델은 본 단계의 직접 후보가 아니다(§6 Q13).

## 4. 위험 레지스터

### 4.1 R1 — 작품 성공 드리프트

- **설명**: TEM이 작품으로 성공하면서 전시·후속 제작·파일럿이 연구 시간을 빨아먹고, 연구 프로그램의 단계 1–2가 정체되는 위험.
- **탐지 지표**: 분기 감사 시 (a) 단계 1의 Cohen's κ 목표 대비 진척, (b) 지난 분기에 연구 artifact 대 작품 artifact의 커밋 비율. 작품 쪽이 80%를 넘는 분기가 2연속이면 경보.
- **완화 행동**: 2026-07-22(첫 분기 감사) 박소정이 직전 분기의 커밋 비율과 §2.1 산출물 진척을 본 문서 부록 C에 기록. 경보 발생 시 다음 분기의 작품 작업량을 절반 이하로 조정.

### 4.2 R2 — LLM 에코 챔버

- **설명**: 이론 작성·규칙 초안·페르소나 시뮬이 모두 단일 LLM 세션군으로 이뤄지면, 이론이 외부 반증 없이 자기 일관되게 정교화된다. 현존 문서에서도 LLM 편향이 페르소나 시뮬의 한계로 명시됨([docs/paper/TEM_paper_draft_v0.1-260419.md](../paper/TEM_paper_draft_v0.1-260419.md) §7.2, [docs/paper/TrackA_TEM_system_paper_outline-260419.md](../paper/TrackA_TEM_system_paper_outline-260419.md) §199).
- **탐지 지표**: (a) 단계 1·2 산출물 중 외부 검토(외부 연구자, 저널 리뷰, 다른 LLM 가족) 거친 항목의 수, (b) 규칙 초안의 주장 중 비-LLM 원본(논문·교과서·실험 로그) 인용 비율.
- **완화 행동**: 박소정이 2026-10-21(제2회 분기 감사) 이전에 최소 1개의 외부 검토 경로를 확보(Leonardo 투고 또는 지도교수 후보 접촉). 확보 실패 시 본 문서 §6 Q7로 이관.

### 4.3 R3 — 조작적 정의 미완 상태의 데이터 축적

- **설명**: 단계 1이 완료되기 전 Lumen·V2 등에서 `plays` 데이터가 대량 축적되면, 데이터는 쌓이나 각 레코드가 어떤 연산에 해당하는지 사후에 레이블링할 비용이 폭증한다. 스키마 재설계 시 소급 적용 불가한 데이터가 생긴다.
- **탐지 지표**: (a) 단계 1 산출물 완료 전 생성된 plays 수와 이 중 수동 레이블링 후보가 될 비율, (b) 스키마 변경 PR의 "migration downgrade path" 존재 여부.
- **완화 행동**: 박소정이 Lumen 제출(2026-05-23) 직후 2026-06 첫째 주에 현재 스키마를 단계 1 관점으로 한 번 점검하고, 추가 필드 없이 사후 레이블링 가능한지 결정. 필요 시 단계 1 산출물 이전에는 추가 스키마 변경을 동결.

### 4.4 R4 — 가용 장비가 연구 질문을 왜곡

- **설명**: AlphaFold·가족 연구소 장비 등 접근 가능한 도구가 생기면, "이 도구로 무엇을 할 수 있는가"가 "연구 질문이 무엇을 요구하는가"를 앞설 위험. 분자 구조 예측이 6연산의 필수 증명 경로가 아닌데도 경로가 되는 상황. 메모리 기록: AF2 분자적 증명은 박사 과정으로 연기됨.
- **탐지 지표**: 본 문서 §2의 단계 산출물 외의 장비 활용 계획이 연구 로드맵에 추가되는 커밋의 빈도.
- **완화 행동**: 박소정이 분기 감사마다 §2의 단계 산출물과 실제 활동의 정합성 확인. 장비 기인 활동이 단계 산출물에 기여하지 않으면 부록 C에 "장비 드리프트"로 기록하고 다음 분기 계획에서 제거.

### 4.5 R5 — 단독 연구자 리스크

- **설명**: 번아웃, 건강(약물 중단 포함), 멘토 관계 변동, 가족 자원 변동 중 하나라도 중단되면 10년 프로그램이 단절된다. 공동연구자 부재(§3 매트릭스)로 단일 장애점.
- **탐지 지표**: (a) 분기당 연구 artifact 생성량의 표준편차, (b) 멘토 관계 현황 자기 보고, (c) 건강 상태 자기 보고.
- **완화 행동**: 박소정이 분기 감사 시 1문단 자기 보고를 부록 C에 기록. 변동 시 즉시 단계별 최소 작업량을 재설정. 박사 진학 시점(§6 Q8)에 최소 1명의 공동연구자 확보를 진학 조건으로.
