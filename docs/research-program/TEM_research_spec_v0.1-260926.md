## 1. 핵심 정의 — 대화에서 확인한 방향

TEM은 기억의 전승 규칙과 사람이 경험을 지각·기억·재구성하는 규칙을 실행 가능한 모델로 구성하고, 두 모델의 상호작용을 실제 참여자의 전승 자료와 비교하여 검증·수정하는 연구 시스템을 지향한다.

사용자가 제안한 '기억 유전학'은 기억이 사람 사이에서 전승될 때 함께 보존되는 정보 단위, 그 변형과 소실, 그리고 그 조건을 탐구하는 연구 구상이다. 생물학적 유전자나 물리적 양자 현상의 존재를 전제하지 않는다. 독립된 새 학문으로 성립했음을 선언하는 문서는 아니다.

핵심 질문:

- 기억이 전승될 때 무엇이 함께 남는가?
- 표현이 달라져도 어떤 관계·행동·감각 구조가 유지되는가?
- 개인의 인지 과정, TEM의 표현과 변형, 전달 조건은 각각 어떤 영향을 미치는가?
- 발견한 규칙이 새로운 기억과 독립적인 전승 사슬을 예측하는가?

## 3. 두 모델의 역할과 접점

다음 구분은 합의된 방향을 구체화한 설계 초안이다. 구체적인 이론·수식·모듈 API는 미정이다.

| 구성 | 담당 범위 | 입력 | 출력·검증 대상 |
|---|---|---|---|
| 인지 모델 | 지각·주의·부호화·유지·회상·재구성에 관한 특정 가설 | 실제 제시 조건, 경험 이력, 필요한 참가자 정보 | 회상·재구성·행동에 대한 예측 |
| 전승 모델 | 표현이 다음 사람에게 전달될 때 보존·변형·소실되는 과정의 가설 | 이전 판본, 실제 재구성 결과, 전달 조건 | 다음 판본과 전승 단위 후보의 변화 예측 |
| TEM 경험 환경 | 공간·소리·조작·변형 규칙을 실행 | 판본, 조건, 엔진 매개변수 | 다음 참가자에게 실제로 제시되는 경험 |
| 관찰·비교 계층 | 예측과 실제 자료의 비교 | 모델 예측, 원본 기록, 조건 | 오차, 반복되는 패턴, 가설 수정 근거 |

앞사람의 재구성이 다음 사람의 경험 조건이 된다. 인지 모델은 한 사람 안에서의 처리 과정을, 전승 모델은 사람과 판본 사이의 변화를 중심으로 기술한다. 경계는 설계상의 구분이며 완전히 독립된 현상이라는 주장은 아니다.

인지심리학은 시청각 연출에만 한정되지 않는다. 사용자가 무엇을 선택해 기억하고 다시 표현하는지까지 포함한다. 화면을 보았다는 로그만으로 주의·이해·기억을 직접 관찰했다고 간주하지 않는다.

## 4. 실험과 시뮬레이션의 구분

- 사람 참여 실험: 실제 참가자가 경험하고 재구성한 결과를 관찰한다. 인지 모델의 예측을 참가자의 실제 기억으로 대체하지 않는다.
- 시뮬레이션: 인지·전승 모델을 연결해 가설이 어떤 결과를 만드는지 계산한다. 여기서 나온 규칙성은 모델의 결과이며 사람에 관한 독립적 증거가 아니다.
- 검증: 사전에 정한 측정 기준으로 시뮬레이션의 예측과 실제 참여자 자료를 비교한다.
- 엔진을 연구 가설에 맞춰 변형한 경우 그 개입을 기록한다. 자동으로 남긴 흔적을 사람이 자발적으로 보존한 흔적으로 해석하지 않는다.

## 5. 엔진 요소 정의 틀

각 요소에는 이름뿐 아니라 작동 정의·예측·측정·반박 조건이 필요하다.

| 항목 | 정의할 내용 |
|---|---|
| 개념 | 무엇을 설명하려는가? |
| 상태 | 무엇을 저장·변경하는가? |
| 규칙 | 어떤 입력에서 어떤 변화가 발생하는가? |
| 근거 | 특정 이론인가, 작품의 표현 규칙인가, 새 가설인가? |
| 관측 | 참가자의 어떤 반응·표현으로 측정하는가? |
| 비교 | 어떤 조건과 비교하는가? |
| 실패 조건 | 어떤 결과에서 가설이 지지되지 않는가? |

예: '강화'는 다음 세 가지를 별도로 명명해야 한다.

1. 엔진상의 지속: 시스템이 흔적의 수명·강도·출현 빈도를 높인다.
2. 개인 기억의 강화: 참가자의 회상 또는 재구성 수행이 특정 조건에서 개선된다.
3. 전승상의 지속: 여러 판본에 걸쳐 특정 특징이 유지된다.

셋은 연결할 가설의 대상이지 동일한 값이 아니다. '망각' 역시 엔진의 삭제·흐림, 개인의 회상 실패, 다음 판본의 누락을 구분한다. 침식·퇴적·재응고는 현재 대화에서 사용한 엔진 개념이며 심리학적 과정과의 대응은 아직 확정하지 않았다.

## 6. 최소 기록 명세 — 제안

| 기록 단위 | 최소 필드 |
|---|---|
| 실험 | experiment_id, protocol_version, condition_id |
| 전승 계보 | chain_id, generation_index, artifact_id, parent_artifact_ids |
| 참가 세션 | participant_pseudonym, session_id, 시작·종료 시각 |
| 실제 입력 | 제시 판본과 공간·음향 상태, 노출·이동·상호작용 이벤트 |
| 사람의 출력 | 원본 서술·녹음 또는 허용된 표현, 배치·삭제·수정·선택 기록 |
| 엔진 개입 | 전후 상태, engine_version, 매개변수, random_seed, 변경 주체 |
| 모델 예측 | model_version, 예측 생성 시점, 입력 버전, 예측값 |
| 분석 | analysis_version, 후보 특징, 추출 방법, 평가자 판단, 불확실성 |

원본 표현은 파생된 감정 점수와 함께 보존한다. 분석 결과가 바뀌어도 원본을 덮어쓰지 않는다. 참가자 동의 범위에 맞춰 기록하며, 직접 식별 정보와 연구 식별자는 분리한다. 이 표는 구현 완료를 의미하지 않는다.

## 7. 첫 실험의 후보 설계 — 미확정

- 같은 출발 기억에서 여러 독립적인 전달 사슬을 만든다.
- 다음 참가자는 해당 조건에서 지정한 이전 판본을 경험하고 재구성한다.
- 자동 변형을 끈 조건과 켠 조건을 비교한다. 다른 조건은 가능한 한 맞춘다.
- 사물의 문자 그대로의 반복뿐 아니라 관계·행동·감각의 공동 보존도 살핀다.
- 일부 사슬에서 전승 단위 후보를 찾고, 분리된 새 사슬에서 예측을 검증한다.
- 단순한 기준 모델과 비교한다. AI가 추출한 의미 관계는 원본과 독립적인 평가로 확인한다.

5회 전달은 대화 중 제시한 예비 실험의 예시이며 확정된 표본 수가 아니다. 실험 규모, 참가자 배정, 지연 시간, 재구성 방식, 평가 척도는 별도 결정이 필요하다.

## 8. 양자·유전학·관련 분야의 위치

- 양자 수학: 자료를 설명하는 경쟁 모델로 검토 가능하나 채택은 미정이다. 실제 양자 하드웨어 사용은 별도 결정이다.
- 생물학적 유전: 현재는 전승·변형·계보를 생각하는 참고 틀이다. 생물학적 유전이나 기억의 양자성을 입증했다는 주장은 하지 않는다.
- 문화 전승·문화진화 연구: 반복 전달과 정보의 보존·변화 연구 방법을 참고한다.
- 인지심리학·계산 인지과학: 특정 이론을 실행 가능한 모델로 만들고 실제 수행과 비교한다.
- HCI: 환경과 인터페이스가 행동과 경험에 미치는 영향을 설계·검증한다.
- 통계·인과추론: 엔진 개입과 사람의 반응을 비교하고 대안 설명을 검토한다.
- 서사학·기호학·정보이론: 의미 구조와 정량 지표를 함께 다룬다. 수치적 유사성을 의미 보존과 동일시하지 않는다.

### Q4. 17축·다섯 작용의 실제 코드 입출력

| 요소 | 위치 | 입력 | 출력 | 손잡이(현행값) |
|---|---|---|---|---|
| 17축 | [math.js](../../js/shared/math.js) `DEFAULT_EMOTION_ANCHORS` (부정·고통 10 + 긍정·회복 7) | — | 판단 좌표계. 단 2026-07-27부터 **기억별 좌표계** 우선: 씬 anchor > 기억 저작 어휘 > 17축 기본 | — |
| 융기 (퇴적) | `applyVisitorErosion` ⓪ (W1-6) | 회차의 beat 목록 `{sceneId, sceneEmo, userEmo, isVoid}` | 느낀 씬 로브에 봉우리 + 둘레 해자 (질량 net≈0) | `k_uplift` 0.5 |
| 침식 (강화 내장) | 같은 함수 ① | 현재 땅 + 발길 지도(이전 관객 누적) | 물방울이 깎은 흙 이동, 발길 많은 칸 ×min(2, 1+k·발길) | `k_reinforce` 0.6, `erosion_scale` 0.3 |

반환 묶음: `{delta, footMap, generation, invariants, massLog}` → `serializeLayer` → `terrain_layers`.

**원문 §5의 '강화 3분리'와 대조**: 코드의 "강화"는 셋 중 오직 **①엔진상의 지속**이다 — "발길 많은 칸을 더 깊게 판다"는 지형 규칙이지 사람 기억 강화의 측정이 아니다. 원문의 구분이 저장소 실물과 정확히 맞는다. "망각"도 같다 — 코드의 망각은 높이맵 잔주름 소멸(엔진의 흐림)이지 회상 실패가 아니다. 재현성: 지형 난수는 `memoryId:generation`으로 결정론이라 원문 §6의 random_seed를 따로 저장할 필요가 없다 (같은 로그 = 같은 땅).

**빠진 것 (원문 §6 기준)**

- `experiment_id / protocol_version / condition_id` — 없음. 알파 3회차도 조건 없이 단일 흐름.
- `chain_id` — 없음. 병렬 사슬을 구분할 열이 없다 (Q1 참조).
- `engine_version`을 **행마다** 남기는 자리 — 없음. 상수는 있으나 `plays`·`terrain_layers`에 기록되지 않아, 손잡이 값을 바꾸면 과거 행이 어느 값으로 구워졌는지 사후 복원 불가. (손잡이 6개는 2026-10 튜닝 예정 — 튜닝 전에 정하지 않으면 원문 §4 "개입 기록" 원칙 위반)
- `model_version / 예측값` 테이블 — 없음. 예측을 저장하는 자리 자체가 없다 (인지·전승 모델 부재와 같은 이유).
- `analysis_version / 평가자 판단` — 없음. 분석은 `docs/실험/` 문서와 `tools/` 스크립트 결과 파일로만 남음.

기존 자산: v0.5 §6.3 영향력 4신호(기능어 스타일 / 임베딩 유사도 초과분 / 고유 어휘 출현 / 감정 벡터 이동), [접촉희소성_측정-260716.md](../이본지층/접촉희소성_측정-260716.md) (최근접 코사인), 이어받기 리트머스. 원문 §7 "관계·행동·감각의 공동 보존" 판정은 **없다** — 감정 벡터·어휘 수준까지만 있고 "우산→지붕" 같은 의미 관계 보존 판정기는 미구현. v0.5 §6.3의 정직한 경계("영향 증거가 아니라 영향과 정합한 신호", 동종선호 교락 상주)는 원문 §4에도 그대로 적용된다.

### Q7. 두 모델의 접점·중복 계산

현재 코드에는 **전승 쪽 사슬만** 있다: 별이엔진(판단) → 오염(누적) → 지형(변형) → 접근 기하(다음 씬). 인지 모델이 없으므로 중복 계산 문제는 아직 생기지 않는다. 다만 접점 후보는 이미 코드에 있다 — RECORD v4의 `rhythm(open|surge|lull|closing)` 힌트가 "엔진 리듬이 질문 결을 바꾼다"(CLAUDE.md §6.5 #6)는 자리이고, 원문 §3 "인지 모델 = 한 사람 안의 처리"를 붙인다면 이 자리가 첫 접점이 된다. 결정은 사용자 몫.
