# 기억별 좌표계 — 측정론 정본 결정 (260727)

> 사용자 결정 2026-07-27: **"기억 하나가 하나의 감정 우주다."**
> 판단(별이엔진)·분류(발화→감정)의 좌표계 = 그 기억의 씬들이 실제 쓰는 감정 어휘의 합집합.
> 발단: docs/씬은_사건이다_결정-260727.md §3.5 진단의 후속 백테스트.

## 1. 병명 — 판단 축과 저작 어휘의 어긋남

판단 정본 17축(`DEFAULT_EMOTION_ANCHORS`)에 **longing / confusion / emptiness 가 없다.**
전 아카이브 실측(scenes.original_emotion, 44씬): longing 은 43씬이 쓰는 **2위 축**,
confusion 11씬, emptiness 는 2씬이지만 평균 0.75 로 박히는 주축. 엔진은 코사인 계산에서
이 축들을 통째로 버려 왔다 — 작가의 주축에 눈먼 판정.

관객 플레이 26건 백테스트 (LLM 재호출 없이 저장 지문으로 결정적 계산):

| 사례 | 17축(구) | 기억 축 |
|---|---|---|
| 적대 발화 "역겨워" ×3 | 0.65 HIGH | ~0.50 경계 |
| 냉소 "신경 안 써" | 0.56 HIGH | 0.41 MID |
| 그리움 애도 | 0.65 | **0.74 HIGH** |
| 혼란 발화 (원본 confusion 0.6 씬) | **0.12 (거의 LOW)** | 0.69 HIGH |

구 17축에서는 적대(0.65)가 깊은 애도(0.65)와 **동률** — 순위 자체가 뒤집혀 있었다.
극단 최소 재현: user {longing .7, sadness .4} vs orig {longing .7, sadness .4, confusion .3}
→ 17축 **1.000 (완벽 일치라는 거짓)** / 기억 축 0.937.

유래: R4-1(260714)이 유령 키(grief/tenderness)를 정리하며 실사용 축 3개를 유령으로
오인해 함께 제거 — 절반의 수리였다.

## 2. 결정 — 기억별 좌표계 + 이중 구조

검토한 다섯 안(20축 고정 확장 / 측정별 합집합 / **기억별 좌표계** / 번역 사전 / 측정불가
보고) 중 **기억별 좌표계** 채택. 근거:

- **기억유전학 정합**: 유전학은 공용 유전자 목록을 요구한 적 없다 — 종마다 유전체가
  달라도 법칙(변이·선택·표류)은 구조의 변화 방식에 대해 보편이다. 감정 축 = 그 기억의
  유전체, 전이 패턴·오염 델타·고착률 = 좌표계 무관(frame-invariant)한 보편 법칙의 관측량.
- **번역 불가능성**: longing 을 17축 어디로도 접을 수 없다는 사실 자체가 번역 사전안의 반증.
- **시스템 통일**: 분류기는 이미 씬 어휘로 동작 중이었다 — 반쪽 분열의 해소.
- 20축 고정 확장은 다음 새 축에서 같은 병이 재발하는 임시 처방 → 기각(③이 ①을 삼킴).

### 이중 구조 (측정장비로서의 TEM 보존 — 사용자 우려에 대한 화해)

- **플레이 구동 판단** = 기억별 자. 체험의 좌표계.
- **연구 아카이브** = plays 에 감정 벡터 **원시값 그대로 보존**. 좌표계는 저장되는 것이
  아니라 계산 시점에 적용된다 — 어떤 고정 틀이든 전체 데이터에 소급 재측정 가능
  (본 백테스트가 그 실증: LLM 없이 26건 × 3개 자 재측정).
- **기억 간 원시 정렬값 비교는 공식적으로 무의미** (자가 다름). 비교가 필요하면
  기억 내 표준화 또는 소급 고정틀 재측정으로만.
- era 사전등록·논문(TrackA) 측정 파트에 이 구조를 명시할 것 (후속).
