## 1. 개요

> **"이건 도구가 아니라, 도구를 빙자한 선언문이다."**
> — 박도한, artist statement 초안 (미작성, 2026년 5월 중순 예정)

**TEM Admin** 은 작가가 "기억" 을 저작하는 도구다. 일반적으로 기억은 저작되지 않고 떠오른다는 점에서 이 도구의 존재 자체가 이미 전제를 위반한다. 도구의 목적이 "만들어진 기억" 을 관객에게 "떠오른 기억처럼" 체험시키는 것이기 때문에, 이 역설 자체가 작품의 뼈대다.

기술적으로는 **분기형 내러티브 저작기 + 감정 좌표 주입기 + 3D 공간 지형 편집기 + 실시간 분기 시뮬레이터** 를 한 화면에서 돌리는 통합 환경이다. 이 네 가지를 동시에 하는 상용 도구는 현재 존재하지 않는다. 비교군 부재가 이 도구의 난이도를 불필요하게 올리는 원인 중 하나이지만, 동시에 TEM 작품의 핵심 개념 **이본(異本)** 과 구조적으로 일치한다.

비교군 없음이 문제가 아니라 선언인 도구. ~~문제이긴 한데 선언이기도 한 도구.~~

## 3. 특징 및 디자인 철학

### 3.1. 복합적 저작 영역 (4-in-1)

상용 내러티브 저작 도구들이 **하나씩** 다루는 걸 TEM Admin 은 **동시에** 다룬다.

| 상용 도구 | 담당 영역 | TEM Admin |
|---|---|---|
| [Twine](https://twinery.org/) | 텍스트 분기 | ✓ (씬 + choice) |
| [Ink / Inky](https://www.inklestudios.com/ink/) | 분기 + 변수 | ✓ (motif_tags) |
| [Articy:Draft](https://www.articy.com/) ($49/월) | 분기 + 메타데이터 | ✓ (AF / 오염 / 앵커) |
| Unity Scene Editor | 3D 좌표 | ✓ (응결점 SVG + Strata 3D) |
| [TouchDesigner](https://derivative.ca/) | 실시간 파라미터 | ✓ (분기 시뮬) |
| Articy + Unity + Touch | **네 개 전부** | **✓** |

이게 가능한 이유 3 가지:
1. **엔지니어가 하나뿐** — 컨벤션 충돌 없음
2. **도메인이 작가의 뇌 안에만 있음** — 요구사항 명세 과정 없음
3. **도구가 작품의 부수물이 아니라 본체의 일부** — 툴 자체가 작품 철학 구현

### 3.2. 이본론(異本論) 기반

작가 박도한의 핵심 개념 **이본론** 이 도구에 직접 박혀 있다.

> 같은 기억을 각자 다르게 기억한다. 변이는 부산물이 아니라 조건이다.

이게 현실의 도구가 되면:

- **감정 6 차원** — 같은 텍스트가 관객마다 다른 감정 강도로 읽힘
- **AF 좌표 (attribution × core_fear)** — 같은 사건을 "누구 탓 / 무엇이 두려운가" 로 분해
- **오염 상태 (cont_depth / 3 축 / 3 stage)** — 해석이 얼마나 누적·변이됐는가의 지표
- **유령 응결점** — 다른 관객의 파편이 유령으로 돌아오는 3D 좌표
- **잔상 모더레이션** — "작가/관객의 목소리는 동일하게 처리됩니다" (작가 발화도 승인 필요)

TEM 은 "관객이 자기 기억 확신을 잃고 나오는 것" 이 목적이다. 이를 저작 단계에서 **구조적으로 보장** 하기 위해 감정·귀인·오염이 전부 "변이 가능한 축" 으로 설계됐다.

### 3.3. 수정 금지 함수 원칙

**어댑터 패턴 + 수정 금지 함수** 가 전체 구조를 관통한다. 원본 Strata 3D 엔진 [js/shared/tem_af_strata_terrain.js](../js/shared/tem_af_strata_terrain.js) 의 5 개 함수[^1] 는 **한 글자도 수정하지 않는다**. 새 기능은 전부 **wrap 모듈** 로 확장한다.

[^1]: `enterFirstPerson` (L1159), `_fpTick` (L1159 내부), `gH` (L645), `buildMemoryItems`, `computeAfTerrainFields`. 실수로 손댔다가 regression 터지면 작업 중단 + 10 분 쉰 뒤 재개 ([LUMEN_DEMO_SCOPE §6](LUMEN_DEMO_SCOPE-260424.md)).

이 원칙 덕에 어댑터 (walk_effects / visual_effects / audio_space / scene_ghosts / rewind_playback) 가 서로 간섭 없이 쌓인다. **디자인 결정이 아니라 규율**.

### 3.4. 로컬-first 백업 전략

1. Supabase INSERT/UPDATE
2. 로컬 `localStorage` 캐시 갱신
3. **JSON 파일 브라우저 다운로드** (자동, 파일 선택 다이얼로그 없이)

마지막 (JSON 자동 다운로드) 이 의외로 중요. DB 장애 · RLS 정책 변경 · 실수 삭제 시 복구 경로. ~~단, 다운로드 폴더가 쓰레기로 가득 차는 부작용이 있다.~~

## 4. 핵심 개념 용어 해설

**처음 쓰는 사람은 이 섹션을 먼저 읽자.** 용어가 밀도 있게 등장하므로 화면에 앞서 개념을 잡아두는 편이 낫다.

### 4.1. 기억 (Memory)

TEM 의 가장 큰 단위. `memories` 테이블 1 row. 씬 7~10 개 + 메타 (제목·코드·앵커·AF·오염·지형·응결점·사운드) 로 구성. 관객 1 명이 1 세션에 체험하는 범위.

### 4.2. 씬 (Scene)

기억의 구성 단위. `scenes` 테이블 1 row. 본문 text + scene_type + 감정 + VOID 토글 + 잔향 단어 + 씬 AF. 플레이어가 한 번에 보는 한 덩어리.

### 4.3. 감정 6 차원

`fear / sadness / anger / joy / longing / guilt`.

각 0~1 float. **관객 입력 / 씬 Original Emotion / 페르소나 평균 / 시뮬 입력** 에 공통으로 쓰이는 좌표계.

**6 개가 된 이유**: 초기엔 17-dim 고려했으나 파일럿 인지부하 과다. 17-dim 은 V2 이월.

### 4.4. AF (Affective Framework) 좌표

**Attribution (귀인, 3차원)**: `self / other / fate` — 사건을 누구 탓으로 보는가
**Core Fear (핵심 공포, 4차원)**: `abandonment / rejection / powerlessness / loss` — 무엇이 두려운가

각 그룹 합 ≈ 1 (정규화 권장). **Strata 3D 지형의 좌표** 로 쓰인다: attribution X축 / core_fear Z축.

메모리 레벨 + 씬 레벨 둘 다 존재. 씬 AF 가 있으면 메모리 AF 를 오버라이드.

### 4.5. 오염 (Contamination)

관객 첫 진입 시 기억이 이미 "해석 누적" 된 상태를 표현.

- `cont_depth` (0~30) — 누적 깊이
- `cont_divergence` / `cont_convergence` / `cont_heterogeneity` (0~1) — 3 축 상태
- `cont_stage_1/2/3` (합=1) — biased / juxtaposed / hypercompletion 단계 비율

**사용처**: Lumen noise floor gain 계산 (`min(0.25, 0.02 + 0.06 × cont_depth)`), Strata 시각화.

**SCOPE §1 규약**: 오염은 **이동을 제어하지 않는다**. 환경 연출 (fog / vignette / bob / drone) 에만 쓴다.

### 4.6. 응결점 (Ghost Condensation Point)

Lumen 1 인칭 공간에서 유령이 출현할 3D 좌표. `memories.ghost_condensation_points` (JSONB 배열). 각 점은 `{x, z, threshold}`.

**threshold 의미**: 관객 감정 벡터와 점 좌표 거리 ≤ threshold 일 때 점 활성. 0.8 이상 = 거의 안 깨어남, 0.2 이하 = 쉽게 깨어남.

### 4.7. 이본 (異本)

같은 기억의 서로 다른 판본. TEM 의 핵심 개념. "관객마다 기억이 같지 않다" 를 구조로 보장.

기술적 구현: 감정·AF·오염·응결점이 관객 입력과 상호작용해 매 세션 다르게 렌더. `plays.spatial_trajectory` 에 각 관객의 궤적이 저장됨.

### 4.8. ByeoriEngine (별이 엔진)

관객 입력 감정 → 씬 정렬도 계산 엔진. 공식:
```
alignment = level × shape × void_mod
```
- `level` — 감정 강도 일치 (유저 vs 씬)
- `shape` — 감정 분포 일치 (cosine similarity)
- `void_mod` — void 씬 보정

반환: `{alignment_score, alignment_bucket, transition_pattern, mismatch_type, current_scene_score, debug}`

**bucket** 4 단계: `HIGH` / `MID` / `LOW` / `FIXATED`
**transition_pattern** 6 종: `echo_follow / bridge / contradiction / displacement / avoidance / fixation`

### 4.9. SceneNavigator (씬 내비게이터)

ByeoriEngine 의 pattern 을 받아 다음 씬 후보를 결정. **BASE_RADIUS = 0.35** (cosine similarity). 반경 내 후보 없으면 fallback.

패턴별 geometry 조정:
- `echo_follow` — 기본 반경
- `bridge` — 반경 ±15%
- `contradiction` — 반대 방향
- `displacement` — 90° 회전
- `avoidance` — 반경 외
- `fixation` — 현재 고정

### 4.10. VAD Projection

감정 6 차원 → 2D (Valence × Arousal). Canvas "감정 지형 모드" 토글 시 사용. 각 감정의 V/A 값:
```
fear:     {v:-0.9, a:+0.9}
sadness:  {v:-0.8, a:-0.4}
anger:    {v:-0.7, a:+0.8}
joy:      {v:+0.9, a:+0.6}
longing:  {v:-0.3, a:+0.2}
guilt:    {v:-0.8, a:+0.2}
```
씬 감정 벡터의 가중 평균으로 2D 배치.

### 4.11. Fallback

SceneNavigator 가 반경 내 후보 씬을 못 찾은 상태. **버그 아님**. 씬들이 감정 공간에 뭉쳐 있거나 관객 감정이 극단적일 때 발생. 해당 기억의 **"감정 다양성 지표"** 로 해석 가능.

### 4.12. 잔상 (Utterance / Afterimage)

Record/Play 중 관객이 남긴 발화 후보. 모더레이션 승인 시 다른 관객의 씬 종료 후 "유령처럼" 출현. `ghost_utterances` 테이블.

### 4.13. 페르소나 (Persona)

여러 관객 플레이 세션을 클러스터링한 대표 궤적. `plays` 테이블에서 자동 추출. Canvas 탭에서 재생 / 분기 시뮬 입력으로 활용.

#### 5.3.1. 기본 정보 섹션 (8 필드)

진엔딩 보상. 관객이 좀 깊이 들어가면 보여줄 메시지.

**좆같**: **100자 넘으면 UI 레이아웃 깨짐**. 검증 없어서 알아서 조심. ~~깨져도 저장은 됨. 관객에게 깨진 채로 나감.~~

#### 5.3.2. 감각 앵커 섹션 (12-1)

##### modality 라디오 (없음/냄새/소리/촉감) 선택하면
`sensory_anchor.modality` 저장. 관객 첫 30초 톤에 쓰임.

**재밌**: 한 기억의 단일 감각을 지정하는 게 **매체 특수성 살림**. 소설에서 잘 안 쓰는 저작 개념.
**좆같**: 내용 단어 입력 필드가 **모달리티와 무관하게 항상 같은 스타일**. 냄새 고르면 냄새 관련 힌트가 떠도 좋을 텐데 없음.

##### weight 슬라이더 (0~1) 조정하면
앵커 세기. 높을수록 몰입 강화.

**재밌**: 0.7 이 기본값으로 설정됨 — 너무 튀지 않으면서 인지 가능한 정도.
**좆같**: **0 으로 내려도 저장 됨**. "그럼 왜 앵커 설정했지" 라는 의도 불분명 상태 가능.

#### 5.3.3. AF 좌표 섹션

##### attribution 슬라이더 3 개 조정하면
self / other / fate 합이 실시간 표시.

**재밌**: 슬라이더 움직일 때마다 상단 `합 = 0.75` 식으로 숫자 바뀜. 피드백 좋음.
**좆같**: **합 1 안 맞아도 저장됨**. 정규화 버튼 안 누르고 [저장] 하면 DB 는 이상한 값 받고, Strata 3D 가 기울어짐. 왜 기울어졌는지 한참 찾다가 AF 확인하는 패턴.

##### [합=1 정규화] 누르면
현재 값 비율 유지하면서 합 1 로 스케일. 3 축 동시.

**재밌**: 0.3 / 0.4 / 0.3 처럼 이미 맞아있으면 누르나 마나. idempotent.
**좆같**: 전부 0 이면 정규화 안 됨 (나누기 0 방지). 버튼 눌러도 반응 없음. ~~"왜 안 되지" 1 분 고민.~~

##### core_fear 도 같음
abandonment / rejection / powerlessness / loss.
**재밌**: 4 차원이라 attribution 보다 더 정교한 배치 가능.
**좆같**: 4 개 심리학 어휘 동시 노출. 각 단어 의미 정확히 모르면 대충 찍게 됨.

#### 5.3.4. 오염 초기 상태 섹션

##### cont_depth 슬라이더 (0~30) 움직이면
값에 따라 오른쪽 span 에 숫자 갱신 + Lumen 엔진 noise floor gain 영향.

**재밌**: 0~30 범위라 의외로 넓음. depth=30 은 "극단적 누적" 상태 테스트용.
**좆같**: **depth 가 씬별이 아니라 기억 전체 단일값**. 기억 안에서 변화 못 줌. V2 이월.

##### 3축 (divergence / convergence / heterogeneity) 입력하면
각 0~1 저장. 상관 관계 검증 없음.

**재밌**: 셋이 서로 독립. 원하는 조합 자유.
**좆같**: **이 셋이 실제로 어디에 쓰이는지 UI 에서 설명 없음**. `README` 안 찾으면 의미 모름. ~~이 문서가 그 README.~~

##### stage 3개 입력하면
합=1 정규화 버튼 있음.

**재밌**: 기본값 `stage_1: 0.33, stage_2: 0.33, stage_3: 0.34` 로 살짝 비대칭. 합 1 맞추려 마지막만 0.34.
**좆같**: 세 단계 이름 `biased / juxtaposed / hypercompletion` 이 어딘가에 설명 있는데 UI 에는 없음. 알아서 찾아야 함.

#### 5.3.5. 공간 설정 + 응결점 편집기 (12-3)

##### SVG 빈 공간 클릭하면
거기에 새 응결점 추가. 좌표 `{x, z, threshold: 0.5}` 로 기본.

**재밌**: 클릭 = 추가 라는 직관적 인터랙션. **이 섹션이 Admin 전체에서 제일 재밌는 부분**.
**좆같**: **중앙 void (R=5.6) 안쪽 클릭하면 자동으로 경계 밖으로 밀려남**. 기능이긴 한데, 처음 보는 사람은 "내가 누른 데랑 왜 다르지" 어리둥절.

##### 점 드래그하면
좌표 업데이트 + 리스트 동기화.

**재밌**: 즉각 반응. 30 fps 정도 스무스.
**좆같**: **드래그 중 실수로 threshold 슬라이더 잡으면 점이 안 움직이고 threshold 만 바뀜**. SVG 영역과 리스트 영역이 너무 가까움.

##### threshold 조절하면
해당 점만 값 업데이트.

**재밌**: 값 바꿀 때 리스트 옆 숫자 실시간.
**좆같**: **threshold 0.5 가 "중간" 인지 "기본" 인지 직관 없음**. 실제로는 BASE_RADIUS=0.35 보다 크면 거의 안 깨어나서, 0.5 = 이미 꽤 잠든 상태. UI 에 설명 0.

##### 리스트 ✕ 버튼 누르면
점 삭제. 즉시 반영. 확인 다이얼로그 **없음**.

**재밌**: 실수 삭제도 편집기 [저장] 안 하면 DB 반영 안 됨 → 취소 시 복구 가능.
**좆같**: 저장 후 삭제한 점은 영영 복구 불가. 다시 찍어야 함.

#### 5.3.6. 사운드 매핑 섹션

##### 5 채널 중 하나에 경로 입력하면
DB `sound_map` JSONB 에 저장 (작업 12-1 이후 조건부).

**재밌**: 경로가 `sounds/` 로 시작하면 로컬, `https://` 면 외부. 둘 다 됨.
**좆같**: **경로 오타 나도 저장 시 에러 안 남**. 재생 시점에야 404 콘솔 로그. UI 에 "잘못된 경로" 표시 없음.

##### [▶ 재생] 누르면
해당 필드의 경로를 즉시 재생.

**재밌**: 미리듣기 됨. 경로 확인용으로 유용.
**좆같**: **여러 필드 [▶] 연타하면 소리 겹침**. 정지 안 하고 동시 재생. [■ 정지] 는 마지막만 정지.

#### 5.3.7. 씬 편집기 섹션 (가장 무거움)

##### [+ 씬 추가] 누르면
빈 씬 하나 생성. scene_order = 기존 최대값 + 1.

**재밌**: 자동 코드 생성 (`{memcode}-{scene_order:02d}`).
**좆같**: **씬 10 개 만들고 나면 스크롤이 지옥**. 펼침/접음 토글 있긴 한데 한 번에 여러 개 접기/펼치기 없음.

##### 씬 안의 text 쓰면
textarea 에 입력. 자동 저장 X. 편집기 [저장] 때 같이 DB 반영.

**재밌**: 긴 텍스트 가능. 줄바꿈 유지.
**좆같**: textarea 가 자동 resize 안 됨. 스크롤 봐야 전체 읽힘.

##### VOID 토글 체크하면
voidStart / voidEnd 불리언 저장. voidLevel 숫자로 깊이.

**재밌**: voidEnd ON + voidLevel 높음 = 씬 끝에 강한 void 연출. 관객이 "이 다음은 어디지" 상태 유도.
**좆같**: **voidStart/voidEnd 두 개 동시에 ON 할 수 있음**. 의미상 이상한데 막지 않음. 결과는 "씬 전체가 void" 상태.

##### 씬 AF Picker
메모리 레벨 AF 오버라이드.

**재밌**: 필요한 씬만 개별 AF 설정 가능. 기억 내 감정 굴곡 표현.
**좆같**: **슬라이더 전부 0 으로 내려도 null 이 아님**. 완전 비우려면 input 필드를 빈 문자열로. UI 에서 "비우기" 버튼 없음.

##### [분기 추가] 누르면
타겟 씬 선택 다이얼로그. 선택 시 choice 엣지 생성.

**재밌**: 다이얼로그에 현재 기억의 모든 씬 드롭다운. 선형 말고 복잡한 분기 가능.
**좆같**: **타겟 씬 삭제 후에도 choice 가 남음** → orphan. Canvas 에서 끊긴 엣지로 보임. 수동 청소 필요.

#### 5.3.8. 편집기 하단 [저장] / [취소]

##### [저장] 누르면
- (1) Supabase INSERT/UPDATE
- (2) 로컬 `localStorage` 캐시 갱신
- (3) **브라우저에 JSON 파일 자동 다운로드**
- (4) 대시보드 복귀

**재밌**: JSON 자동 다운로드가 의외의 백업. DB 날려도 로컬에 남아있음.
**좆같**: **매 저장마다 다운로드 폴더에 `memories-YYYYMMDD-HHMMSS.json` 쌓임**. 1 주일 후 다운로드 폴더 보면 50 개. 다 같은 데이터, 버전만 다름.

##### [취소] 누르면
- dirty-flag ON 이면 `confirm()` 다이얼로그
- OK → 저장 없이 대시보드
- Cancel → 편집 유지

**재밌**: 이 다이얼로그가 12-5 마감의 핵심. 없을 때와 비교하면 **편집 실수 유실이 체감상 90% 줄었음**.
**좆같**: **저장 성공 직후에 "아 제목 잘못 썼네" 하면 복구 없음**. [취소] 는 "저장 안 하고 나가기" 이지 "방금 저장한 거 되돌리기" 가 아님.

#### 5.3.9. JSON 내보내기 / 가져오기

##### [JSON 다운로드] 누르면
현재 모든 memories 배열 JSON 파일 생성 + 다운로드.

**재밌**: 저장 안 해도 현재 편집기 상태도 포함됨 (로컬 캐시 기준).
**좆같**: **파일명이 고정** (`memories-YYYYMMDD.json`). 같은 날 여러 번 다운로드 = 덮어씌움 또는 `(1)` 붙음. 브라우저 별 다름.

##### [JSON 가져오기] 누르면
파일 다이얼로그 → 선택 → `importMemoriesJSON(event)` 실행.

**재밌**: 백업 복구 경로. DB 망했을 때 구세주.
**좆같**: **스키마 검증 거의 없음**. 옛 버전 JSON (예: sound_map 있던 시절) 을 현 스키마에 import 하면 일부 필드 null. 또는 알 수 없는 필드로 warning.

#### 5.3.10. [잔상] 탭

##### Status 필터 바꾸면
pending/approved/rejected/all 중 하나. 리스트 재조회.

**재밌**: `pending` 기본. 모더레이션 워크플로 맞춤.
**좆같**: **필터 바꾼 뒤 리스트 갱신까지 1~2초**. 로딩 스피너 없어서 멈췄는지 로딩 중인지 헷갈림.

##### [승인] 누르면
`ghost_utterances.status = 'approved'` 업데이트. 리스트에서 사라짐 (필터 pending 이면).

**재밌**: 다음 관객의 씬 종료 후 이 발화가 유령처럼 떠오를 수 있음.
**좆같**: **취소 버튼 없음**. 승인 실수하면 Status 필터 `approved` 로 바꿔서 찾은 뒤 [거절] 로 변경. 2 스텝 필요.

##### [거절] 누르면
`status = 'rejected'`. 풀에서 제외.

**재밌**: 같음.
**좆같**: 같은 이유로 번복 어려움. 그리고 **"왜 거절했는지" 메모 필드 없음**. 나중에 보면 이유 기억 안 남.

### 5.4. Canvas 탭 (궤적 뷰어) — 실사용 관점

3 컬럼 레이아웃 중 중앙이 SVG 그래프. **씬 관계 한눈에 보이는 유일한 곳**.

#### 5.4.1. 좌측 사이드바 주요 상호작용

##### [+ 새 기억] 누르면
편집기 열지 않고 **빈 기억을 바로 Canvas 에서 생성**. 이후 [+ 원본 씬] 반복으로 씬 추가.

**재밌**: 편집기 전체 오픈 안 하고도 저작 가능. 빠른 프로토타이핑.
**좆같**: **메모리 레벨 필드 (앵커 / AF / 응결점) 는 Canvas 에서 못 건드림**. 결국 편집기 한 번은 열어야 함. "빠른 프로토타이핑" 이 반쪽짜리.

##### [+ 원본 씬] vs [+ 잔상 씬]
원본 = 작가 씬 (anchor). 잔상 = 다른 관객 파편 파생 (초록 테두리).

**재밌**: 색 구분이 명확. 녹색 = 잔상. amber = 원본.
**좆같**: **두 번째 버튼 [+ 잔상 씬] 이 사실상 "지금은 쓸 일 없음"**. 실제 파일럿 데이터 쌓이기 전엔 manual 잔상 생성이 맞는지 의문. UI 존재감만 크고 쓸 상황 드묾.

##### 감정 진입점 리스트 클릭하면
해당 emotion 의 entry 씬이 캔버스에서 하이라이트 + 중앙 스크롤.

**재밌**: 여러 감정 클릭하며 "이 기억의 진입 경로" 파악 가능.
**좆같**: **emotion_entries 가 설정 안 된 기억은 리스트가 비어있음**. 빈 상태에서 뭘 해야 하는지 안내 없음.

##### [전체 표시] 토글
모든 씬 + 엣지 노출. 필터링 해제.

**재밌**: 빈 기억에서 토글 켜면 "아 아직 아무것도 없구나" 확실히 확인.
**좆같**: **한번 ON 하면 OFF 해도 이전 필터 기억 안 함**. 감정 진입점 하나 누른 뒤 [전체 표시] 토글하고 다시 OFF 하면 초기 상태로 돌아감.

##### [모든 브릿지] 토글
숨은 `trajectory_bridges` 까지 노출.

**재밌**: 궤적 브릿지 (🌊) 가 많이 쌓인 기억은 **비선형 경로** 가 보임. 작품 완성도 확인용.
**좆같**: 브릿지 100 개 넘으면 그래프가 거미줄 됨. 줌 많이 해야 구분 가능.

##### [감정 지형 모드] 토글
기본 Dagre 레이아웃 → VAD 2D 좌표 기반 배치.

**재밌**: 씬들이 감정 공간에서 어디에 분포하는지 시각화. **분기 시뮬 FALLBACK 원인 파악에 유용**.
**좆같**: **씬 감정이 거의 같으면 노드들이 한 점에 겹침**. "왜 그래프가 이상하지" 순간이 옴.

##### [레이아웃 초기화] 누르면
`tv_positions_{memoryId}` localStorage 삭제 + Dagre 재계산.

**재밌**: 드래그해서 난장판 만든 뒤 초기화 한 번이면 깔끔.
**좆같**: **확인 다이얼로그 없음**. 실수로 누르면 정성스레 배치한 게 다 날아감.

##### [🌐 Strata 미리보기] 누르면
3D 지형 팝업 (`#strataView`). WebGL canvas.

**재밌**: **이 도구 전체에서 제일 "와" 하는 순간**. 숫자로만 설정한 AF 좌표가 3D 공간으로 구현된 모습. 작가 자부심 포인트.
**좆같**:
- 모바일 / 일부 브라우저는 WebGL 지원 X → **검은 화면**. 안내 없음.
- 팝업 닫고 다시 열면 **매번 재렌더**. 무거움.
- 1인칭 중 `F` 안 먹힐 때가 있음. 포커스가 canvas 밖으로 빠져서. 한 번 canvas 클릭 후 `F`.

##### 페르소나 드롭다운 + [▶ 재생]
선택 페르소나의 궤적 따라 씬 하이라이트 이동 + 엣지 깜박임.

**재밌**: **가장 영화 같은 피처**. 누군가의 기억 여행을 재생하는 감각.
**좆같**:
- `plays` 테이블에 데이터 없으면 드롭다운 `"— 페르소나 로드 중 —"` 에서 무한 대기. "로드 중" 이라는 거짓말.
- 재생 중 다른 탭 누르면 재생은 계속되는데 시각화는 멈춤. 돌아오면 끝나 있음.

##### 분기 시뮬 프리셋 선택 + A 슬라이더 + [▶ 시작]
runner A 생성 + `#simOverlay` SVG 그림.

**재밌**:
- **꽉 찬 원 = 현재** / **점선 링 + 화살 = 후보** / **점선 라인 = 방문**. 시각 언어가 깔끔.
- 한 스텝 돌릴 때마다 readout 에 `pattern` 바뀜. "이 관객이 이 기억을 어떻게 읽는지" 실시간.

**좆같**:
- **readout 글씨 작음**. 0.7rem. 시뮬 한번 돌리고 readout 보려면 얼굴 가까이 가야.
- FALLBACK 처음 보면 "버그인가" 싶음. 설명 UI 없음.
- [다음 →] 눌러도 runner 가 done 이면 아무 반응 없음. 버튼은 `disabled` 되는데 그 이유 안 알려줌.

##### [비교 모드] 체크하면
B runner 슬라이더 패널 등장. teal 색.

**재밌**: A (grief) vs B (numb) 동시 돌리면 **두 관객 궤적이 어떻게 갈라지는지** 실시간. 이본론 시연.
**좆같**:
- A 와 B overlay 가 가까우면 원이 겹쳐서 구분 안 됨. A 위 / B 아래 8px offset 이 있지만 부족할 때 있음.

#### 5.4.2. 중앙 SVG 그래프

##### 씬 노드 클릭하면
우측 디테일 패널 `#tvDetail` 에 씬 편집 폼 로드.

**재밌**: 편집기 전체 열지 않고 text 만 빠르게 고칠 수 있음.
**좆같**: 노드 텍스트가 작아서 **우클릭으로 컨텍스트 메뉴** 같은 거 기대하지만 없음. 좌클릭만.

##### 씬 노드 드래그하면
위치 이동 + `tv_positions_{memoryId}` localStorage 저장.

**재밌**: 저장 위치가 기억별로 분리돼 다른 기억에 영향 없음.
**좆같**: **브라우저 바꾸면 위치 다 초기화**. Chrome 에서 배치한 게 Firefox 에서 보면 Dagre 기본 상태.

##### 스크롤 휠로 줌
d3-zoom 통한 스무스 줌.

**재밌**: 줌 레벨 0.1x ~ 10x. 넓은 범위.
**좆같**: **트랙패드 핀치 제스처가 간헐적으로 안 먹힘**. 마우스 스크롤은 괜찮은데.

##### 엣지 (choice / bridge) 는 비인터랙티브
클릭 안 됨. 호버 시 특별한 동작 없음.

## 6. 핵심 엔진 원리 (Under the Hood)

### 6.1. ByeoriEngine.calculateStep 의 흐름

```
Input:
  userVector:      { base: {fear, sadness, ...} }
  originalVector:  { base: scene.original_emotion,
                     reason_analysis: scene.original_reason_vector }
  userTrajectory:  [...previous user emotions]
  originalTrajectory: [...previous scene emotions]
  sceneScores:     [...previous alignment scores]

Internal:
  level = |userVec| · |origVec| normalized
  shape = cosine(userVec, origVec)
  void_mod = voidLevel 반영
  alignment = level × shape × void_mod

  bucket =
    alignment > 0.75 → HIGH
    alignment > 0.5  → MID
    alignment > 0.25 → LOW
    alignment ≤ 0.25 → FIXATED

  transition_pattern =
    shape 기울기 + reason_analysis 방향
    → echo_follow / bridge / contradiction /
      displacement / avoidance / fixation

Output:
  { alignment_score, alignment_bucket,
    transition_pattern, mismatch_type,
    current_scene_score, debug }
```

### 6.2. SceneNavigator.navigate 의 로직

```
1. 현재 씬의 original_emotion 으로부터
   pattern-specific 방향 벡터 생성.

2. 후보 씬들 (visited 제외) 과 cosine similarity.

3. BASE_RADIUS=0.35 이내 씬 선택.
   가장 가까운 것 반환.

4. 후보 없음 → fallback narrative 생성 반환.
   ("재배치 후보 없음. 감정 공간 클러스터 검토 권장.")
```

### 6.3. 응결점 → Lumen 배치

Admin 에서 `{x, z, threshold}` 저장. Lumen FP 진입 시:

```
for point in ghost_condensation_points:
  distance = |userEmotion - point_emotion_estimate|
  if distance <= point.threshold:
    activate(point)

activated points →
  lumen_scene_ghosts.js 가
  world coord (x, baseY, z) 에 sprite 배치
  baseY = runtime.gH(x,z) + 2.8 + bob(sin)
```

`point_emotion_estimate` 는 해당 좌표의 AF 역투영.

### 6.4. 분기 시뮬의 시작 씬 선택 로직

```js
// admin-trajectory.js:695
function _pickStartIdx(emotion) {
  const entries = memory.meta?.emotion_entries || {};
  if (Object.keys(entries).length) {
    const top = Object.entries(emotion)
      .sort((a,b) => b[1] - a[1])[0];
    if (top[1] > 0 && entries[top[0]]) {
      const idx = scenes.findIndex(
        s => s.meta?.scene_code === entries[top[0]]
      );
      if (idx >= 0) return idx;
    }
  }
  return 0; // fallback: scene_order=0
}
```

즉:
1. `memory.meta.emotion_entries` 있으면 dominant 감정의 entry 씬 사용
2. 없으면 `scene_order=0` 첫 씬

## 8. 자주 나오는 오류 (Hall of Shame)

각 오류마다 **뭐해서 터졌는지 → 뭐 뜨는지 → 왜 혈압 오르는지 → 뭐 해야 살아나는지** 로 정리.

### 8.1. 코드상 예상되는 오류

#### 8.1.1. 저장 실패 — 코드 중복 (★★☆ 짜증도)

**뭐해서**: 새 기억 만들고 코드 `A-001` 입력 → 이미 있는데 모르고 [저장].
**뭐 뜸**: 큰 alert `"저장 중 오류가 발생했습니다: duplicate key value violates unique constraint 'memories_code_key'..."` + 콘솔 빨간 에러.
**왜 좆같**:
- 중복 체크를 **저장 시점에만** 함. 편집 중엔 안 알려줌.
- 씬 7 개 다 쓰고 [저장] 눌렀을 때 에러 뜨면 "진작 말해줬어야지" 가 입에서 자동 출력.
- alert 닫아도 편집 상태는 유지됨 (다행).

**뭐 해야**: 코드 바꿔서 재저장. 또는 대시보드 가서 기존 `A-001` [수정] 경로로 가기.
**예방**: 네이밍 규칙. Bath 시리즈 `B-`, 편지 `E-`, 아카이브 `A-` 등 접두사.

#### 8.1.2. 저장 실패 — RLS 거부 (★★★ 짜증도)

**뭐해서**: 세션 만료된 상태로 오래 편집하다 [저장].
**뭐 뜸**: alert `"new row violates row-level security policy"` + 콘솔.
**왜 좆같**:
- 세션 만료를 UI 가 **선제적으로 안 알려줌**. 저장 시점까지 뻐김.
- 편집 내용은 유지되지만 로그아웃 → 재로그인 해야 함. 로그인 후 돌아왔을 때 편집 상태는 localStorage 캐시로 복구 가능하지만 **Dirty flag 상태는 초기화** → 변경점 파악 어려움.

**뭐 해야**: 새로고침 → 재로그인 → 캐시에서 복구 또는 JSON 덤프에서 수동 복구.

#### 8.1.3. 저장 실패 — `sound_map` 잔존 참조 (해결됨)

**뭐해서**: 2026-04-21 직후 어느 시점에 저장 시도.
**뭐 뜸**: `"column 'sound_map' does not exist"`.
**왜 좆같**: **스키마 마이그레이션과 코드 패치 사이 시간차**. DB 는 이미 컬럼 없는데 JS 는 아직 참조.
**현재 상태**: **해결됨** (조건부 spread + [smoke_task_12_1.js](../test/smoke_task_12_1.js) 가드). 단 과거 JSON 가져오기 시 재현 가능.

#### 8.1.4. `cont_stage` 합 != 1 저장 (★☆☆ 짜증도)

**뭐해서**: stage_1=0.5, stage_2=0.5, stage_3=0.5 로 합 1.5 만들고 [합=1 정규화] 건너뛴 채 [저장].
**뭐 뜸**: 아무 에러 없이 저장 성공. 평화.
**왜 좆같**:
- **성공처럼 보이지만 실제로 잘못된 값이 DB 에 들어감**. 가장 은밀한 실수.
- Strata 3D 미리보기에서 지형이 이상하게 기울어져 있음. "왜 이상하지" 수십분 고민.

**뭐 해야**: 편집기 재진입 → [합=1 정규화] → [저장].

#### 8.1.5. 응결점 좌표가 경계 밖 (★☆☆ 짜증도 / ★★★ 구경 재미)

**뭐해서**: JS 콘솔에서 `window._ghostPoints.push({x: 9999, y: 0, threshold: 0.5})` 식으로 우회.
**뭐 뜸**: 겉보기엔 정상. 저장도 됨.
**왜 좆같**:
- 클램프가 SVG 이벤트 핸들러에만 있고 **데이터 자체에는 검증 없음**. 콘솔로 우회 가능.
- Lumen FP 진입 시 **유령이 하늘 너머 저 멀리 어딘가에서 출현**. 관객은 이유 모름.

**뭐 해야**: 응결점 리스트에서 ✕ 삭제 → SVG 재배치.
**예방**: 콘솔로 직접 조작 금지. ~~콘솔 열지 말자.~~

#### 8.1.6. 씬 choice orphan edge (★★☆ 짜증도)

**뭐해서**: 씬 B 를 삭제했는데 씬 A 의 choice 목록에 B 가 남아있음.
**뭐 뜸**: Canvas 에서 **A 에서 허공으로 뻗은 엣지** 가 보임.
**왜 좆같**:
- 씬 삭제 시 참조 청소를 자동으로 안 해줌.
- Play 중 관객이 해당 choice 선택하면 `"scene not found"` → 씬 렌더 실패 → 블랙스크린.
- **자동 클리너 없음**. 작가가 수동 확인.

**뭐 해야**: Canvas 에서 씬 A 클릭 → 우측 패널 choice 리스트 → 끊긴 타겟 ✕.

#### 8.1.7. 씬 AF 전부 0 → null 아님 (★★★ 짜증도)

**뭐해서**: 씬 AF Picker 슬라이더 7 개 전부 0 으로 내림. "다 0 이면 비우는 거겠지" 라는 합리적 기대.
**뭐 뜸**: 저장 성공. 표면 평화.
**왜 좆같**:
- 실제 DB 에는 `{self:0, other:0, fate:0, abandonment:0, ...}` **0 벡터** 로 저장됨. null 아님.
- 엔진이 이걸 "AF 값 존재" 로 해석 → 시뮬에서 이상한 pattern 결정.
- UI 에서 **"비우기" 전용 버튼이 없음**. 슬라이더 0 이 빈 걸로 안 잡힘.

**뭐 해야**: 각 input 필드의 **value 를 빈 문자열로** 직접 입력 (슬라이더 말고 숫자 box). 또는 콘솔에서 `scene.original_reason_vector = null` 강제 (위험).
**재설계 영역**: V2 에서 "초기화" 버튼 필요.

#### 8.1.8. 사운드 경로 오타 (★★☆ 짜증도)

**뭐해서**: `sounds/Rain_indoor.mp3` 를 치다 실수로 `sounds/Rain_indor.mp3` 로 입력 후 저장.

**뭐 해야**: [▶ 재생] 으로 **매 필드 한 번씩 들어보기**. 안 나오면 콘솔 열고 404 확인.

**예방**: 편집기 진입 전 `confirm("다른 탭에서 편집 중이면 충돌합니다. 계속?")` 같은 UI 없음. 작가 규율에 의존.

### 8.2. UX 어려움 Top 5

#### 8.2.1. **FALLBACK 이 무슨 뜻이지?**

- **정의**: SceneNavigator 가 BASE_RADIUS=0.35 내 후보 못 찾음.
- **원인**: (a) 감정 극단 / (b) 씬 뭉침 / (c) pattern-방향 없음.
- **대응**:
  - 프리셋 여러 개 돌려보기
  - 씬 AF 재배치
  - "감정 다양성 지표" 로 해석
- **기원**: 작가 본인도 처음 "이게 뭔소리" 라고 함.

#### 8.2.2. **용어 과밀**

한 화면 동시 등장:
```
AF · VAD · cosine · bucket · pattern · mismatch
cont_depth · cont_3축 · cont_3stage
originalReasonVector · motif_tags
ghost_condensation_points · echo_words
emotion_entries · scene_code · scene_order
```
**신규 사용자 1 세션 내 전부 이해 불가**. 이 문서 옆에 두기.

#### 8.2.3. **피드백 시간차**

값 1 개 바꿔도 체감까지 5 탭 왕복:
```
편집기 수정 → 저장 → Canvas 그래프 →
분기 시뮬 → Strata 미리보기 → play-test
```
분기 시뮬이 많이 줄였지만 기억 전체 체감은 여전히 멀다.

#### 8.2.4. **시각 힌트 부족**

AF 슬라이더 옆에 "지금 이 기억이 감정 공간 어디에 있는지" 미니맵 없음. 응결점 편집기만 SVG 있고 나머지는 숫자 지옥.

#### 8.2.5. **예제 기억 복제 불가**

빈 화면 → 전부 채워야 함. 진입 장벽 계단이 아니라 절벽.
