# 자료 스키마 명세 v1.1 — 어떤 데이터가 어떤 이론의 어떤 주장에 먹이는가 (2026-07-17)

> 관객 한 명이 지나가면 무엇이 남고, 그것이 어느 논문·이론의 어느 주장을 먹이는지의
> **단일 지도**. 알파 가동 전 동결본. 스키마·기록 코드를 바꾸면 이 문서 갱신 의무(§7).
> 근거: 7-17 이론 자료 감사(run_id·dialog_turns 봉합, 커밋 57220d0) + 코드 실측.
>
> **v1.1 (2026-07-17, admin 상용화 W3)**: admin 휴지통(`memories.deleted_at`) + 판본 이력
> (`admin_versions`) 마이그레이션 + 작가 궤적 시딩(`persona_id='author-seed'`) 추가. §3·§4·§5 갱신.

## 0. 회차의 생애 — 수집 시점 지도

```
진입(initFpPlay)      → run_id 발급, 회차 시작 시각 (play-test.html)
씬 박자(beat)         → 지형 엔진 로그(메모리 내 — 봉인 때 일괄 반영)
대화 턴               → dialogTurns 누적(메모리 내), 접촉 시 record-contact 즉시 시도
씬 종료(insertPlay)   → plays 1행: 감정·정렬·어긋남·대화 원문·run_id
봉인(sealBtn)         → plays 도장(UPDATE, run_id 필터) + record-contamination(26컬럼)
                       + record-drift-cumulative + record-erosion(지형+스냅샷)
                       + 접촉 봉인-재시도(W4-4b) + generate-reveal(이본 명명)
이탈(봉인 없이)        → plays 행만 남음. 도장·오염·지형 반영 없음 = 자연 데이터(§6-4)
```

## 1. plays — 관객 행동의 원장(元帳). 행 = 씬 방문 1회

| 컬럼 | 채우는 주체·시점 | 이론 소비자 |
|---|---|---|
| `run_id` (7-17 신설) | 진입 시 발급 uuid, 씬마다 기록 | **층 논문 절편 단위**, 궤적 복원, 도장 범위 |
| `memory_id`, `scene_id` | 씬 종료 | 겹침 계산(C1·C2), 지형 인구 |
| `user_emotion` | 씬 종료 (대화 추출 or 고전 제출. 관측축 ~12) | Track A 정렬 검증, C2 값-겹침, 지형 융기 재료 |
| `alignment`, `mismatch_type` | 씬 종료 (별이엔진) | Track A 핵심 주장, 이본 명명 재료 |
| `user_reason` | 씬 종료 ('void' = 회피 표식) | VOID 페널티 검증, 질적 분석 |
| `dialog_turns` (7-17 영속화) | 씬 종료. 턴별 `{turn, raw_text, fingerprint, alignment, resonance, ghost_reply, via, ts}` | **기억유전학 언어 변이**(관객 원문↔유령 답), 접촉 임계 결정(턴별 resonance 분포), 턴 단위 궤적(C2 향후) |
| `created_at` | 씬 종료 (실시간) | run_id 와 함께 **회차 내 순서 = C2 Level-E** |
| `ghost_variant_id` | 씬 종료 (회차 시작 drift 픽) | 변주 계보(재조합) |
| `final_drift_vector` | 봉인 도장 | 전이/귀환 이론(회차 감정 변위) |
| `sky_stains` | 봉인 도장 | 개인 읽기 기록(릴레이 제외 원칙) |
| `unreturned_flag` | 봉인 도장 | 전이 이론(미귀환) |
| `user_id` | 로그인 시만 | 재방문 종단 분석(알파는 로그인 권장) |
| `persona_id`, `persona_name`, `strata_label`, `visit` | 시뮬 도구 + **작가 시딩**(W3-P: `persona_id='author-seed'`) | **인구 분리**(§5) — 실관객은 전부 null. 非null = 시뮬/시딩 인구 |
| `wave_data`, `layer_id` | 레거시(admin 저장이 wave 행 삽입 — §6-7) | 없음 |
| `vad`, `terrain_pos`, `spatial_trajectory`, `reason_vector` | **미기록**(레거시 — 7-17 grep 실측: 쓰는 코드 0) | 없음 — 분석에서 무시 |

## 2. memories 오염 26컬럼 — 기억의 누적 상태 (봉인마다 R6 창구 경유)

- `cont_depth`(max 보존)·`cont_divergence/convergence/heterogeneity`·`cont_stage_1..3`·
  `cont_drift/fixation`·`drift_dir_v/a/d`·Welford 내부 상태·`cumulative_emotion_vec`(EMA).
- 소비자: **오염 이론**(연출 제어 모델 — 진실 모델 아님 주의), **층 논문 C3**(순환
  성분↔오염 상관 — 순환성 주의: "동일 현상의 두 형식화"로 서술), Stage 렌더 블렌드.
- ⚠️ 저장값 = 캐시. 정본은 plays 재생(7-09 결정). 검증 시 재계산과 대조 가능.

## 4. scenes/memories 원본 — 비교 기준 (불변 아카이브)

- `scenes`: `text`(원문)·`text_stage_1..3`(오염 판본)·`original_emotion/emotion_dist`
  (17축 정본)·`echo_words`·`anchor_emotions`·`scene_role`·`meta.stage_position`.
- 역할: **telling_trajectory 비교 기준**(Track A shape), 지형 제0판 재료(결정론),
  depth 0 = 원문 보장(Phase D ③ 실증). 이본론의 "작가 바닥 = 보존 아카이브".
- `memories.deleted_at`(W3-J 휴지통, 7-17): admin soft-delete 표식. `deleted_at IS NOT NULL`
  = 휴지통(공개 해제 동반). play-test 는 `is_public=false` 로 자연 숨김 — 별도 처리 없음.
  분석 인구 쿼리는 필요 시 `deleted_at IS NULL` 추가(단 plays 는 행 보존이라 소급 영향 없음).

## 5. 인구 규칙 (분석 진입로 — 전 이론 공통)

- **실관객 판별** = `persona_id IS NULL AND created_at >= '2026-07-09'`
  (DEMO_EPOCH, play-test.html:4641 `isVisitorPlay` 와 동일 규칙).
- **유효 씬 방문 행** = 위 + `scene_id IS NOT NULL` (admin wave 행 제외).
- **회차 복원** = `run_id` 그룹, 회차 내 순서 = `created_at`.
  run_id null(과거 행·구형 브라우저) = (user_id, 30분 군집) 근사 — 근사임을 명시.
- 시뮬 인구(persona_id 有)는 별도 트랙: 논문에 "합성"으로만 표기(paper_scope 결정).
- **작가 시딩 인구**(W3-P, 7-17) = `persona_id='author-seed'` (+`user_reason='author-seed'`,
  `alignment=1.0`, 회차당 공유 `run_id` 1개). persona_id 非null 이므로 **실관객 쿼리에서 자동 배제**.
  ⚠️ 이 표식이 빠지면 관객 인구·지형 융기·오염·논문 데이터가 오염됨 — 시딩은 반드시 author-seed 표식 동반.

## 6. 알려진 공백·한계 (정직 — 알파 전 상태)

1. **transition_pattern 미기록** — 엔진이 bridge 단일 산출이라 담을 값 자체가 무의미
   (7-14 A급 열쇠·결정 회의 안건). 복원 시 plays 컬럼 신설 + 이 문서 v2.
2. **제시-선택 집합 미기록** — SceneNavigator 가 그 턴에 연 후보 핀(accessiblePinIds)이
   영속 안 됨. "무엇을 안 골랐나"가 필요한 주장(항법 검증)은 현재 불가. 중요도 중.
3. **감정축 미통일** — 기록 관측축 ~12 / 정본 17 / 판단 실기여 9. 분석은 관측축
   그대로(A12 방식, C2 v1.1 판례). 통일은 결정 회의 안건 1.
4. **봉인 없는 이탈** — 도장·오염·지형 무반영, plays 행만. 결측 아니라 자연 데이터
   (이탈률 자체가 관찰값).
5. **목격 연출 노출 여부 미기록** — 관객이 목격의 순간을 봤는지 데이터에 없음.
   알파에서는 관찰 체크리스트(질적)로 보완.
6. **자생 변주 429 유실** — LLM 요청 제한 시 그 세션의 흡수 변주는 재시도 없이 스킵.
7. **admin 저장 wave 행** — 저장 1회당 plays 에 scene_id null 행 1개 삽입(레거시).
   §5 규칙으로 분석에서 배제됨. 4차 위생 후보.
8. **Storage 고아 스냅샷** — 삭제된 층 참조 2건(protect_delete). 무해, 후속 정리.
9. **plays DELETE 정책 부재** (R3-N1) — 브라우저(익명·인증) 세션으로 plays 삭제 불가
   (200-0행 침묵). 기억 삭제 시 plays 행이 고아로 잔존(scene_id SET NULL). §5 유효행
   필터가 자동 배제하므로 분석 무해하나, 시험/폐기 데이터 정리는 service-role 필요.
   7-18 파이프라인 감사에서 재확인 (docs/admin_파이프라인_감사-260718.md).

## 7. 변경 규칙

- plays·terrain_layers·trajectory_bridges·오염 컬럼·기록 코드(insertPlay/sealBtn/Edge)를
  바꾸는 커밋은 **이 문서 버전 갱신을 포함해야 한다** (v1 → v1.1 …).
- 새 이론 주장(논문 초안 갱신)이 새 자료를 요구하면: §6 에 공백으로 먼저 등록 →
  기록 코드 수리 → 본문 승격. (자료 없는 주장 금지 — 7-17 감사 원칙.)

## 부록 — 분석 진입 쿼리 2개

```sql
-- 실관객 유효 회차 추출 (C2 절편)
SELECT run_id, scene_id, user_emotion, alignment, created_at
FROM plays
WHERE persona_id IS NULL AND created_at >= '2026-07-09'
  AND scene_id IS NOT NULL AND run_id IS NOT NULL
ORDER BY run_id, created_at;

-- 접촉 희소성 (회차 대비 접촉률)
SELECT (SELECT count(*) FROM trajectory_bridges WHERE status='contact') AS contacts,
       (SELECT count(DISTINCT run_id) FROM plays
         WHERE persona_id IS NULL AND run_id IS NOT NULL) AS runs;
```
