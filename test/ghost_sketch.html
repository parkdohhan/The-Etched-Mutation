3D preview — Three.js sprite

같은 SVG 실루엣을 canvas 텍스처로 구워 Three.js Sprite(billboard)로 3D 공간에 배치. 드래그 회전 · 스크롤 줌. 유령은 카메라 항상 바라봄.

파이프라인: SVG 실루엣 → data URL → Image → canvas → THREE.CanvasTexture → SpriteMaterial → Sprite. 유령 당 텍스처 1장, 초기화 시 한 번만 굽고 재사용.

TEM strata 렌더러(tem_af_strata_terrain.js, strataView.js)가 이미 쓰는 Sprite 패턴과 동일. CSS2DRenderer 같은 별도 레이어 없음.

Bob 애니메이션은 sprite.position.y += sin(t). 각 유령마다 phase offset으로 비동기 움직임.
