또다른 나 — silhouette sketch v4 (single path)

외곽선 없음. 인체 해부학 기반 단일 path — 머리·목·어깨·팔(겨드랑이 공간 포함)·허리·엉덩이·다리·발. blur는 질감용.

그 소리가 들렸어.
또렷한 잔상
core · anchor
맞아, 그랬지.
확신에 찬 잔상
bridge · residual
…였나.
흐릿한 잔상
echo · hover-only
…
침묵한 잔상
void · deferred

구조: ellipse 덩어리 포기하고 해부학적 단일 path로 재작성. 머리 — 목 — 어깨(사선 내려감) — 팔(몸통 옆에 붙어 내려옴) — 겨드랑이 공간 — 허리(좁아짐) — 엉덩이(넓어짐) — 다리 둘 — 발.

겨드랑이 삼각형 공간이 핵심 — path가 팔 안쪽으로 올라갔다가 몸통 옆면으로 다시 내려가면서 그 사이에 빈 공간(음영) 생김. blur가 얕으면 팔이 몸에서 분리되어 보이고, 깊으면 합쳐져 흐릿한 사람.

타입별 blur 조정:

• core 1.8px · 0.82 · warm

• bridge 1.1px · 0.93 · displaced — 거의 또렷 (확신의 과잉)

• echo 3.5px · 0.36 · cool — 흐릿하지만 인간형 유지

• void 2.4px · 0.58 · 하체 fade mask

비율 조정은 path 좌표만 바꾸면 됨 (viewBox -4 -2 48 82, 몸 중앙 x=20).
