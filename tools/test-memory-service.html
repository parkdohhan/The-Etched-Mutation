MemoryService 테스트

1. Payload 구성 및 검증 테스트 (DB 저장 없음)

1-2. 실제 DB 저장 테스트 (선택사항)

⚠️ 실제 DB에 저장됩니다. RLS 정책이나 권한 문제로 실패할 수 있습니다.

2. 검증 실패 테스트 (제목 없음)

3. 검증 실패 테스트 (장면 없음)

4. 콘솔에서 직접 테스트

브라우저 콘솔(F12)에서 다음 코드를 실행하세요: 

// 테스트용 메모리 객체
const testMemory = {
    title: '테스트 기억',
    scenes: [
        {
            text: '첫 번째 장면',
            originalEmotion: '기쁨',
            originalReason: '좋은 일이 있었기 때문',
            original_reason_vector: {},
            choices: ['선택지 1', '선택지 2']
        }
    ]
};

// MemoryService 호출
MemoryService.saveMemory({ memory: testMemory })
    .then(result => {
        console.log('결과:', result);
        if (result.ok) {
            console.log('✅ 저장 성공:', result.data);
        } else {
            console.error('❌ 저장 실패:', result.error);
        }
    });
